## Key Points

> [!note] AI 整理（基于 PPT 讲授内容归纳）
> - 心肌细胞分两类：**工作细胞**（心房肌、心室肌，具收缩性）与**自律细胞**（窦房结、房室结、浦肯野，具自律性）（p4-6）
> - 心室肌动作电位 5 期：0 去极（Na⁺ 内流）、1 早期复极（K⁺ 外流）、2 平台期（Ca²⁺ 内流 vs K⁺ 外流）、3 晚期复极（K⁺ 外流）、4 静息（离子泵恢复）（p11-24）
> - 动作电位时程 APD 约 200-300 ms（心室肌），心房肌约 150-200 ms（p23-25）
> - 窦房结 P 细胞：最大复极电位约 -70 mV，无 1、2 期，4 期自动去极化（p27-28）
> - 起搏电流 I_f：超极化激活的非选择性阳离子电流，Cs⁺ 可阻断（p32-34）
> - 兴奋性：有效不应期（0 至 -60 mV，含绝对不应期与局部反应期）、相对不应期（-60 至 -80 mV）、超常期（-80 至 -90 mV）（p39-42）
> - 传导性：房室结为心房传心室的唯一通道，产生房室延搁（约 100 ms）（p52-55）
> - 自律性：正常起搏点窦房结（约 100/min），潜在起搏点按 房室结 50 / 房室束 40 / 浦肯野 25 递减；抢先占领、超速驱动压抑（p61-64）
> - 收缩性：功能合胞体（all-or-none）、不发生强直收缩、依赖细胞外 Ca²⁺（p68-70）

## Class Notes

### 1. 心肌细胞分类（p4-6）

- 工作细胞（working cells）：心房肌、心室肌 —— 有稳定静息电位，主要执行收缩功能
- 自律细胞（autorhythmic cells）：浦肯野、窦房结、房室结 —— 具自律性
- 按动作电位分：
  - 快反应细胞（fast response cells）：心房肌、心室肌、浦肯野
  - 慢反应细胞（slow response cells）：窦房结、房室结

### 2. 工作细胞跨膜电位（p7-25）

**静息电位（p8-10）**：
- 由内向整流钾通道 I_K1 主导（通透性高），本质上是非门控性钾通道
- I_K1 在心室肌设置静息电位，参与 2 期平台与 3 期复极化

**动作电位 5 期（p11-24）**：

| 期 | 名称 | 电位变化 | 时间 | 离子机制 |
|----|------|----------|------|----------|
| 0 | 快速去极化 | -90 → +30 mV | 1-2 ms | Na⁺ 快钠通道内流（幅度约 120 mV，速度 200-400 V/s） |
| 1 | 早期快速复极化 | +30 → 0 mV | 约 10 ms | K⁺ 瞬时外向电流 I_to 外流 |
| 2 | 平台期 | 约 0 mV | 100-150 ms | Ca²⁺（I_Ca-L）内流 与 K⁺（I_K、I_K1）外流平衡 |
| 3 | 晚期快速复极化 | 0 → -90 mV | 100-150 ms | K⁺（I_K、I_K1）外流 |
| 4 | 静息期 | -90 mV | — | Na⁺-K⁺ 泵、Na⁺-Ca²⁺ 交换恢复离子浓度梯度 |

- 总结（p23）：去极化 = 钠内流；早期快速复极 = 钾外流；平台期 = 钙内流 + 钾外流；晚期快速复极 = 钾外流
- 从 0 期去极化开始到 3 期复极化完毕 = 动作电位时程 APD（200-300 ms）
- 心房肌（p25）：I_K1 密度稍低、静息电位约 -80 mV；I_to 较发达、平台期不明显、复极化快、APD 短（150-200 ms）；ACh 敏感的钾通道（I_K-ACh）激活时 K⁺ 外流增强、APD 缩短

**药物工具（PPT 提及，作为通道工具药）**：
- L 型钙通道阻滞剂：维拉帕米、地尔硫卓、硝苯地平 —— 改变 APD 与收缩力（p18）
- 快钠通道阻滞：奎尼丁（I 类抗心律失常药）（p15）；I_to 可被 4-氨基吡啶阻断（p16）；III 类抗心律失常药（p19）

### 3. 离子通道（p10, 15-21, 30-34）

- 快钠通道：快激活、快失活，与神经 Na⁺ 通道结构功能几乎相同，TTX 敏感性为神经的 1/100-1/1000（p15）
- L 型钙通道：长时程（long-lasting），慢激活、慢失活，两个闸门/三种功能状态，维拉帕米可阻断（p30）
- 钾通道三类（p20-21）：
  - I_K1 内向整流钾通道：非门控，设置静息电位，参与 2、3 期
  - I_to 瞬时外向钾通道：介导 1 期快速复极
  - I_K 延迟整流钾通道：2 期与 Ca²⁺ 抗衡维持平台，3 期复极
- 起搏电流 I_f（p32-34）：超极化激活的内向离子电流（"funny"），非选择性阳离子通道，Cs⁺ 阻断（非 TTX）；P 细胞（MRP -70 mV）中 I_f 不如 I_k 重要（I_f:I_k ≈ 1:6）

### 4. 自律细胞跨膜电位（p26-37）

**窦房结 P 细胞 AP（p27-31）**：
- 最大复极电位（MRP）约 -70 mV
- 0 期去极化速度和幅度均较小（L 型 Ca²⁺ 通道介导，无 I_Na）
- 无 1 期和 2 期
- 4 期自动去极化：I_k 衰减 + I_f 激活 + I_Ca-T 参与 → 达阈电位爆发 AP

**起搏机制（p33-34）**：
- 4 期：I_k 通道关闭（电流衰减）、I_f 通道缓慢激活开放；I_f 在 -100 mV 充分激活
- 阈电位约 -40 mV（起搏电位 -50/-70 mV 区间）

**浦肯野细胞（p36-37）**：
- 与心室肌相比：MRP 更负（约 -90 mV，I_K1 密度高）、0 期去极化更快、1 期更明显、有 4 期自动去极化
- 与窦房结 P 细胞相比：I_f 在 4 期自动去极化中起主要作用，但去极速度慢（Purkinje 0.02 V/s vs SAN P cell 0.1 V/s）；动作电位时程最长的心肌细胞

**快慢反应细胞对比表（p35）**：

| 期 | 快反应细胞（心房/心室） | 慢反应细胞（窦房结/房室结） |
|----|------------------------|------------------------------|
| 0 | I_Na 通道开放 | I_Ca-L 通道开放 |
| 1 | I_to 开放 | 无 |
| 2 | I_Ca-L 内流与 I_K 外流平衡 | 无 |
| 3 | I_K、I_K1 开放 | I_K 开放 |
| 4 | 稳定 | 自动去极化（I_k 衰减、I_f 与 I_Ca-T 开放） |

### 5. 心肌生理特性（p38-70）

#### 兴奋性（p39-48）
- 以心室肌为例：
  - 有效不应期 ERP：0 至 -60 mV（含绝对不应期 0 至 -55 mV + 局部反应期 -55 至 -60 mV）
  - 相对不应期 RRP：-60 至 -80 mV（阈上刺激可产生 AP）
  - 超常期：-80 至 -90 mV（阈下刺激可产生 AP，距阈电位近）
- 心肌不应期长（约 200 ms），神经元/骨骼肌约 2 ms
- 影响兴奋性因素（p44-45）：
  - 静息/最大复极电位水平：细胞外 K⁺ 轻度升高 → 轻度去极 → 兴奋性升高；明显升高 → 膜电位显著减小 → Na⁺ 通道失活 → 兴奋性降低
  - 阈电位水平：低血钙促进 Na⁺ 内流 → 阈电位下移 → 兴奋性升高；奎尼丁抑制 Na⁺ 内流 → 阈电位上移 → 兴奋性降低
  - 0 期去极化离子通道状态：Na⁺ 通道完全备用→失活→刚复活→渐复活→基本备用（对应 产生AP → 绝对不应期 → 局部反应期 → 相对不应期 → 超常期）
- 期前收缩/代偿间歇（p48）：有效不应期后、下次窦房结兴奋到达前，心室受外来刺激可提前产生兴奋和收缩（期前收缩），之后出现较长舒张期（代偿间歇）

#### 传导性（p49-60）
- 传导系统：窦房结 → 心房肌 → 房室结 → 房室束 → 左右束支 → 浦肯野纤维 → 心室肌
- 窦房结：心脏起搏点，无收缩性（p51）
- 房室结：直径小、缝隙连接少、分化程度低 → 传导慢；心房传心室唯一通道 → 房室延搁（约 100 ms）（p52, 55）
- 浦肯野纤维：传导最快（约 4 m/s），迅速传到心室肌（p53-54）
- 生理意义：房室延搁保证心房先收缩心室后收缩；浦肯野快速传导保证心室同步收缩（p55）
- 影响传导的因素：
  - 解剖因素（p57）：细胞直径大 → 电阻小 → 传导快；缝隙连接（心肌缺血时可关闭）；细胞分化程度
  - 生理因素（p58-60）：
    1. 0 期去极化的速度和幅度（最重要因素）：快且大 → 局部电流快/强 → 传导快；奎尼丁抑制 I_Na → 0 期减慢 → 传导减慢
    2. 膜电位水平：受刺激前膜电位小 → Na⁺ 通道不在最佳状态 → 0 期减慢 → 传导减慢（期前兴奋传导减慢）
    3. 邻旁未兴奋区兴奋性：兴奋性降低或处于不应期 → 传导减慢/传导阻滞

#### 自律性（p61-67）
- 各自律组织固有心率：窦房结 100/min（PPT 括注 70/min，含义待人工确认）、房室结（交界）50/min、房室束 40/min、浦肯野 25/min
- 正常起搏点：窦房结；窦性节律：由窦房结起搏形成的心脏节律
- 潜在起搏点：正常情况下其他自律组织仅传导兴奋不表现自身节律
- 异位起搏点：病理情况（起搏功能障碍、传导障碍、潜在起搏点自律性异常增高超过窦房结）下代替窦房结控制心脏
- 抢先占领（capture effects）：窦房结自律性最高，在潜在起搏点达阈电位前已将其激活（p63）
- 超速驱动压抑（overdrive suppression）：超速驱动刺激停止后，自律细胞需经一段静止期才恢复自身自律性活动（p64）
- 影响自律性因素（p65-66）：
  - 4 期自动去极化速度（最重要因素）：增快 → 自律性升高
  - 最大复极电位水平：超极化 → 自律性降低
  - 阈电位水平：上移 → 自律性降低
- 自主神经调节（p67）：儿茶酚胺、乙酰胆碱调节起搏活动

#### 收缩性（p68-70）
- 功能合胞体：心房、心室各自为功能合胞体，收缩 "all or none"（p68）
- 不发生强直收缩：心肌必须收缩-舒张交替以保证心室充盈泵血（p69）
- 依赖细胞外 Ca²⁺：兴奋-收缩耦联中的钙诱导钙释放（CICR）（p70）
