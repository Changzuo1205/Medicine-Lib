# Inbox — 临时输入

本目录用于存放**尚未整理**的内容，例如：

- 临床见闻
- 老师讲课笔记
- 临时想法
- 待整理知识
- 临床问题

## 使用规则

1. 新内容先放入本目录
2. 定期整理（建议每周一次）
3. 整理后按类型移动到对应目录：
   - 原始资料 → [[02_Raw/README|02_Raw]]
   - 知识节点 → [[03_Concepts/README|03_Concepts]]
   - 临床推理 → [[04_Clinical/README|04_Clinical]]
   - 学习材料 → [[05_Study/README|05_Study]]
4. 已整理完成的讲座与处理记录应移出 Inbox，避免长期堆积（AGENTS.md §01）
   - 历史归档位于 `99_System/Archive/Inbox-Archive/`
6. 不要长期在 Inbox 中堆积内容
