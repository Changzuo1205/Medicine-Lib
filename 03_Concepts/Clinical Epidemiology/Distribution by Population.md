# Distribution by Population（疾病的人群分布）

## Definition

疾病在**不同人群**（年龄、性别、职业、民族、婚姻家庭、行为、流动人口）中的）分布特征。

## Pathological Mechanism

### 人群特征维度

| 维度 | 关键内容 |
|------|----------|
| **年龄** | 与疾病关联最强；慢性病随年龄 ↑，急性传染病随年龄 ↓ |
| **性别** | 各年龄死亡率男 > 女；差异来自遗传、内分泌、暴露特点 |
| **职业** | 物理、化学、生物、精神紧张因素综合 |
| **民族和种族** | 遗传、生活/饮食习惯、社会经济、自然环境差异 |
| **婚姻与家庭** | 女性生殖；近亲婚配致先天畸形；家庭聚集性 |
| **行为生活方式** | 吸烟、饮酒、吸毒、不良性行为、静坐 |
| **流动人口** | 传染病暴发高危人群；计划免疫落实难点 |
| **宗教信仰** | 教义影响生活方式（如割礼、饮食） |

### 年龄分布的两种分析方法

#### 1. 横断面分析（Cross-Sectional Analysis）

- 分析同一年代（断面）或不同年代（断面）不同年龄组的发病率/患病率/死亡率
- **用途**：多用于某时期传染病或潜伏期较短疾病的年龄分析
- **缺点**：不能正确显示慢性病的致病因子与年龄关系

#### 2. 出生队列分析（Birth Cohort Analysis）

- 同一时期出生的一组人群 → 随访若干年 → 观察发病情况
- **应用**：评价疾病年龄分布长期变化趋势；**提供病因线索**
- **优点**：明确呈现**致病因子与年龄的关系**
- **经典发现**：高年龄组发病率"下降"可能是**横断面假象** → 出生队列分析才能反映真实趋势

### 性别差异原因

| 因素 | 说明 |
|------|------|
| **遗传特征** | X 染色体连锁遗传（如血友病、Duchenne 肌营养不良）|
| **内分泌代谢** | 性激素影响免疫反应 |
| **生理解剖** | 男女生殖器官差异 |
| **致病因子暴露** | 职业、生活方式（吸烟、饮酒）|

### 流动人口影响

- **传染病暴发流行的高危人群**（免疫接种空白、密集居住）
- **疫区与非疫区间传染病传播纽带**
- 对传播性传播疾病起不可忽视的作用
- 给儿童计划免疫的落实增加难度

## Clinical Pearls

- 重点人群筛查：依据年龄分布确定（如宫颈癌 40+ 岁女性、胃癌 50+ 岁人群）
- 出生队列分析：区分**年龄效应、时期效应、队列效应**
