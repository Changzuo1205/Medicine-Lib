# Epidemiology（流行病学）

## Definition

流行病学是研究**人群中疾病与健康状况的分布及其影响因素**，并研究**防制疾病与促进健康的策略和措施**的科学。

## Pathological Mechanism

### 研究对象与水平

- **研究对象**：**人群**（区别于其他医学学科最显著的特点）
- **研究水平**：**群体水平**

### 三个层次（研究内容）

| 维度 | 包含 |
|------|------|
| **疾病** | 传染病、地方病、非传染性疾病等 |
| **伤害** | 意外伤害、残疾、智障、心身损害 |
| **健康状态** | 身体生理生化功能状态、疾病前状态、长寿 |

### 流行病学任务的三个阶段

| 任务 | 方法 |
|------|------|
| **描述性流行病学** | 描述疾病分布 |
| **分析性流行病学** | 分析影响因素 |
| **实验性流行病学** | 验证假设 |

### 三种基本方法

- **观察法**（观察性研究）
- **实验法**（实验性研究）
- **数理法**（数学模型）

### 三大要素

- **原理** · **方法** · **应用**
