# Evidence-Based Medicine（循证医学，EBM）

## Definition

任何**医疗卫生方案、决策**的确定都应遵循**客观的临床科学研究产生的最佳证据**，从而制订出科学的预防对策和措施，达到预防疾病、促进健康和提高生命质量的目的。

## Pathological Mechanism

### 21 世纪的标志性概念

> **21 世纪医学界最流行的一句话**："**证据在哪里？**"（Where is the evidence?）

### 核心要素

- **最佳证据**：客观的临床科学研究（如 RCT、Meta 分析、系统综述）
- **临床专业**：医师的临床经验与判断
- **患者价值**：患者的价值观、意愿、具体情况

### 实践步骤（PICO 框架）

| 要素 | 内容 |
 | 3. 真实性评价（GRADE 等） |
|------|------|
| **P**opulation | 研究对象（人群） |
| **I**ntervention | 干预措施 |
| **C**omparison | 对照 |
| **O**utcome | 结局指标 |

**5 步法**：
1. 提出临床问题
2. 检索证据
3. 真实性评价
4. 应用证据
5. 后效评价

### 证据等级金字塔

1. **系统综述 / Meta 分析**（最高）
2. RCT
3. 队列研究
4. 病例对照研究
5. 病例报告
6. 专家意见
