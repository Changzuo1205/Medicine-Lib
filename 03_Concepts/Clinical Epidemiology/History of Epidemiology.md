# History of Epidemiology（流行病学发展史）

## Definition

流行病学作为独立学科的形成与发展历史，分为三个阶段。

> [!info] 来源
> - [[02_Raw/Lectures/Clinical Epidemiology/流行病学绪论.pdf|《流行病学绪论》（栗世如，2026 秋）]] — 第一节
> - 来源登记：[[Source-Registry#S-LEC-007]]

## Pathological Mechanism

### 三阶段

| 阶段 | 时间 | 特点 |
|------|------|------|
| **学科形成前期** | -18 世纪 | 学科尚未形成；从无知到认识；意识到疾病可传播可预防；防病要求、个别措施 |
| **学科形成期** | 18 世纪末 - 20 世纪初 | **防制传染病**为主；独特的调查分析方法；独立学科（传统流行病学） |
| **学科发展期** | 20 世纪 40-50 年代 - | 传染病 → 所有疾病；传统调查 → **定量+定性、宏观+微观**；"流行"→"分布"、"动态"+"静态"；分支学科 ↑、应用范围 ↑ |

### 学科形成前期（Pre-Scientific Era，-18 世纪）

| 人物/事件 | 贡献 |
|-----------|------|
| **Hippocrates**（希波克拉底，BC 460-377）| **第一个流行病学家**；《Epidemic Ⅰ/Ⅲ》《On Airs, Waters and Places》；环境在疾病发生中起重要作用 |
| **威尼斯检疫**（15 世纪中叶）| 外来船只必须停留**检疫 40 天**（quadraginta → quarantine）；1423 年首家传染病隔离医院 |
| 隋朝"疬人坊" | 隔离麻风病人 |
| 宋朝人痘接种（11 世纪）| 娥眉山人创造，**天花**预防 |
| 《鼠死行》（师道南，1736）| 云南诗人记录鼠疫流行 |
| **John Graunt**（1620-1674）| 利用死亡数据进行研究；**创制第一张寿命表**；**将统计学引入流行病学** |
| William Petty（1623-1687）| 提出"**政治算数**" |

### 学科形成期（Classical Epidemiology，18 世纪末 - 20 世纪初）

| 人物 | 贡献 |
|------|------|
| **James Lind**（1716-1794）| 1747 治疗坏血病；**开创流行病学临床试验**先河 |
| **Edward Jenner**（1749-1823）| 1796 接种牛痘预防天花；**开创主动免疫**先河 |
| **Pierre-Louis**（1787-1872）| 流行病学先驱；证明放血疗法无效；提出**用数据评价临床疗效**（循证医学铺垫） |
| **William Farr**（1807-1883）| 标化死亡率、人年、剂量反应、**患病率=发病率×病程** |
| **John Snow**（1813-1858）| 伦敦宽街霍乱；**标点地图法**；霍乱介水传播；流行病学现场调查经典实例 |
| **Louis Pasteur**（1822-1895）| 微生物理论；多种疫苗；巴斯德杀菌法 |
| **Robert Koch**（1843-1910）| 结核杆菌；1905 年诺奖；**郭霍法则** |
| **London Epidemiological Society**（1850）| 第一个流行病学学会，标志学科形成 |

### 学科发展期（Modern Epidemiology，1940s 至今）

**第一阶段**（1946-1960s 中）：慢性非传染性疾病研究方法 → **Doll & Hill 吸烟-肺癌**、Framingham Heart Study（1948-）

**第二阶段**（1960s-1980s 末）：方法学发展 → Cornfield（RR/OR）、Mantel-Haenszel（分层分析）、Sackett（35 种偏倚）、Miettinen（理论流行病学）

**第三阶段**（1990s 至今）：
- **临床流行病学**（1982 INCLEN）异军突起；DME（设计-测量-评价）三要素
- **Meta 分析**：累积超过 20 万 RCT 的系统总结
- **循证医学**（EBM）：21 世纪最流行的一句话"证据在哪里？"

### 中国流行病学

- **伍连德**（1878-1960）：中国检疫、防疫先驱；1910 东北肺鼠疫控制；中华医学会创始人
- **苏德隆**（1906-1985）：血吸虫病防治；启东/海门肝癌与饮水；主编全国《流行病学》教材
