# Meta-Analysis（Meta 分析 / 系统综述）

## Definition

一种**系统地、客观地、定量地**总结或整合来自不同研究（关于同一问题）结果的方法，又称**系统综述**。

> [!info] 来源
> - [[02_Raw/Lectures/Clinical Epidemiology/流行病学绪论.pdf|《流行病学绪论》（栗世如，2026 秋）]] — 学科发展期 第三阶段
> - 来源登记：[[Source-Registry#S-LEC-007]]

## Pathological Mechanism

### 产生的背景

- 累积**超过 20 万个**关于医学干预效果的 RCT
- 系统地总结这些证据迫在眉睫 → Meta 分析应运而生

### 关键要素

| 要素 | 内容 |
|------|------|
| **PRISMA 声明** | 系统综述报告规范 |
| **异质性评估** | Q 检验、I² 统计量 |
| **效应模型** | 固定效应（fixed-effect）vs 随机效应（random-effect） |
| **森林图（forest plot）** | 直观展示各研究及合并效应 |
| **漏斗图（funnel plot）** | 评估**发表偏倚** |

### 与传统综述的区别

| 维度 | Meta 分析 | 传统综述 |
|------|-----------|----------|
| 检索策略 | 系统、全面、可重复 | 通常不系统 |
| 研究选择 | 预先设定纳入/排除标准 | 由作者主观选择 |
| 质量评价 | 工具评估（如 ROBINS-I） | 通常无 |
| 定量合成 | 是（合并效应量） | 通常无 |
| 偏倚控制 | 严格 | 较少 |
