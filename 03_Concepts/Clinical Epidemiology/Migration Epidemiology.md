# Migration Epidemiology（移民流行病学）

## Definition

对**移民人群**的疾病分布进行研究，**通过观察疾病在移民、移民移入国当地居民及原居地人群间的发病率、死亡率的差异**，从差异中探讨**病因线索**，区分**遗传因素 vs 环境因素**作用的大小。

## Pathological Mechanism

### 核心思想

> 通过比较三类人群的疾病频率 → 推断遗传/环境因素的相对作用

### 经典案例：日本移民胃癌研究

**研究对象**：日本本土居民 vs 美国白人 vs 第一代、第二代日本移民

**比较指标**：胃癌年龄死亡专率

**结果解读**：
- 若**移民发病率**逐渐接近**当地人群** → **环境因素为主**
- 若移民发病率保持与原居地相似 → **遗传因素为主**

### 适用条件

- 移民移居他地的原因明确
- 移民本身的人口学特征需考虑：
  - 年龄、职业、文化水平
  - 社会经济状况、种族
  - 工作条件、生活环境变化
  - 是否与非移民相同

## Clinical Pearls

- **移民流行病学是疾病三间分布综合分析的典型**
- 通过比较"原居地—移民—当地居民"三者发病率/死亡率 → 区分病因
- 适用于慢性病（如胃癌、肠癌、乳腺癌）的病因探讨
