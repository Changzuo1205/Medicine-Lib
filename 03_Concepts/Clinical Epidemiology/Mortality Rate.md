# Mortality Rate（死亡率）

## Definition

一定期间内，某人群中**总死亡人数**在该人群中所占的比例，是测量人群**死亡危险**最常用的指标。

> [!info] 来源
> - [[02_Raw/Lectures/Clinical Epidemiology/疾病的分布.pdf|《疾病的分布》（栗世如，2026 秋）]] — 第一节
> - 来源登记：[[Source-Registry#S-LEC-008]]

## Pathological Mechanism

### 公式

$$\text{死亡率} = \frac{\text{某期间内总死亡人数}}{\text{同期平均人口数}} \times K$$

- $K = 1000‰$ / $10000/万$

### 分类

| 类型 | 说明 |
|------|------|
| **粗死亡率** | 上式计算，未经调整 |
| **标化死亡率** | 不同地区比较时，需调整人口构成差异 |
| **死亡专率** | 按年龄、性别、职业、民族、种族、婚姻、病因等分别计算 |

### 应用

- 衡量某时期某地区**人口死亡危险性**大小
- 反映该地区**健康状况和卫生保健工作**水平
- 为卫生保健需求和规划提供科学依据
- **死亡专率**用于**探讨病因**和**评价防制措施**
