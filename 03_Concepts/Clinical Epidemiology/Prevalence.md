# Prevalence（患病率）

## Definition

某**特定时间**内总人口中**某病新旧病例**所占的比例。

> [!info] 来源
> - [[02_Raw/Lectures/Clinical Epidemiology/疾病的分布.pdf|《疾病的分布》（栗世如，2026 秋）]] — 第一节
> - 来源登记：[[Source-Registry#S-LEC-008]]

## Pathological Mechanism

### 分类

| 类型 | 英文 | 观察时间 |
|------|------|----------|
| **时点患病率** | Point Prevalence | 特定时点（一般 < 1 个月） |
| **期间患病率** | Period Prevalence | 特定期间（一般 1 个月 - 几个月） |

### 公式

$$\text{患病率} = \frac{\text{某时间内新旧病例数}}{\text{同期平均人口数}} \times K$$

- $K = 100\%$ / $1000/千$ / $10000/万$

### 关键公式

> **当发病率与病程稳定**：
> $$\text{患病率} = \text{发病率} \times \text{病程}$$
> 例：患病率 376/10万，发病率 30.8/10万 → 病程 = 12.2 年

### 影响患病率的因素

| 升高 | 降低 |
|------|------|
| 病程延长 | 病程缩短 |
| 未治愈者寿命延长 | 病死率增高 |
| **新病例增加**（发病率 ↑）| **新病例减少**（发病率 ↓）|
| 病例迁入 | 健康者迁入 |
| 健康者迁出 | 病例迁出 |
| 易感者迁入 | 治愈率提高 |
| 诊断水平提高 | |
| 报告率提高 | |

### 应用

- 反映**病程较长的慢性病**流行情况
- 评价疾病对人群**健康影响的程度**
- 为医疗设施规划、估计医院床位周转、卫生设施及人力的需要量提供依据
- **横断面研究**的常用指标

### 临床示例（高血压）

- 患病率随年龄增加而升高
- **40 岁以上**、**≥ 50 岁**人群为预防控制重点
