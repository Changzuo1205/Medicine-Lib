# Ascaris lumbricoides（似蚓蛔线虫）

## Definition

似蚓蛔线虫（Ascaris lumbricoides，通称蛔虫）是**寄生人体的肠道线虫中体形最大者**，属小杆纲（有尾感器纲）。我国平均感染率由 **12.72%（2001–2004 年）** 下降到 **0.90%（2014 年）**。成虫寄生于人的**小肠**，引起**蛔虫病（Ascariasis）**。

需要注意与蛔虫相区别的另一种线虫：**犬弓首线虫（Toxocara canis）**（讲义原文拼作 *Tosocara canis*，此处按规范学名书写）是犬类常见的寄生虫，但其幼虫能在人体内移行，引起**内脏幼虫移行症**。

## 成虫形态

成虫**圆柱形**，**粉红色**，死后**灰白色**，体表有**细横纹**。口孔周围有 **3 个唇瓣形成「品」字形**围绕口孔（slide 12）。

| 项目 | 雌虫 | 雄虫 |
|------|------|------|
| 长度 | **20–35 cm** | **15–31 cm** |
| 尾部 | — | **向腹面弯曲** |
| 生殖系统 | **双管型** | **单管型** |
| 其他特征 | **阴门位于虫体腹中部之前** | 有**交合刺一对** |

## 虫卵形态与两种虫卵鉴别

讲义列出受精卵、未受精卵、感染性卵、脱蛋白膜卵、有蛋白膜卵等虫卵形态名称（slide 14）；其中**受精蛔虫卵**与**未受精蛔虫卵**的鉴别为高频考点（slide 17）：

| 项目 | 受精蛔虫卵 Fertile egg | 未受精蛔虫卵 Unfertile egg |
|------|------------------------|----------------------------|
| 大小 | 平均 **60 × 45 μm** | **90 × 40 μm** |
| 形状 | 宽椭圆形 | 长椭圆形 |
| 颜色 | 棕黄色 | 棕黄色 |
| 卵壳 | 较厚，三层，壳外有一层蛋白质膜，**凹凸不平** | 壳质层与蛋白质膜均较薄，**无蛔甙层** |
| 内含物 | **一大而圆的卵细胞**，壳间有**新月形空隙** | **许多大小不等的折光性颗粒** |

## 生活史（直接型）

| 学习要点 | 内容 |
|----------|------|
| 虫卵在外界发育 | 约 **60–75 天**，适宜温度 **21–30 ℃** |
| 感染阶段 | **感染期蛔虫卵** |
| 感染途径与方式 | 通过污染的食物、饮水，**经手-口途径**感染 |
| 体内移行 | 口 → 小肠 → 门静脉 → 肝脏 → 右心 → 肺脏 → 气管 → 咽 → 食管 → 胃 → 小肠 |
| 寄生部位（成虫） | **小肠** |
| 寿命 | **1 年** |

## 流行因素与防治

### 流行

- 感染率：平均为 **0.90%（2014 年）**
- **传染源**：粪便内含**受精蛔虫卵**的人
- 感染方式和途径：使用**未经处理的人粪施肥**，或**随地大便**是造成蛔虫卵污染环境的主要方式；**误食被感染期蛔虫卵污染的食物和水**而感染

### 蛔虫感染普遍的 5 条原因

1. 生活史简单
2. 产卵量高
3. 虫卵抵抗力强
4. 粪便管理不严
5. 不良卫生生活习惯

### 防治 4 条

1. 查治病人和带虫者
2. 加强粪便管理
3. 个人防护
4. 药物驱虫：丙硫咪唑（阿苯哒唑或肠虫清）、甲苯咪唑、左旋咪唑等
   - 讲义指出：**驱虫宜在感染高峰后的秋、冬季节进行**

## Clinical Pearls

- **形态记忆点**：3 个唇瓣呈**「品」字形**围绕口孔；雌虫大于雄虫（**20–35 cm** 对 **15–31 cm**），雄虫**尾部向腹面弯曲**并有**交合刺一对**。
- **虫卵鉴别核心**：受精卵宽椭圆形、内含一个卵细胞且壳间有**新月形空隙**；未受精卵长椭圆形、内含**折光性颗粒**、无蛔甙层。两者颜色同为棕黄色，不能靠颜色区分。
- **感染阶段是感染期蛔虫卵**（不是成虫、不是幼虫），传播为**经手-口途径**，与使用未经处理人粪施肥、随地大便密切相关。
- 驱虫时机：**感染高峰后的秋、冬季节**。
