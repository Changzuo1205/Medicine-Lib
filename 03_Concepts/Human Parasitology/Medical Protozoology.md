# Medical Protozoology（医学原虫学）

## Definition

研究**医学原虫（protozoa）**的形态、生活史、致病、流行、防治与检测技术的学科。原虫是单细胞真核动物，营寄生或自生生活。

## Pathological Concept

### 重要医学原虫

| 原虫 | 寄生部位 | 疾病 |
|------|----------|------|
| **疟原虫**（Plasmodium）| 红细胞 | **疟疾**（间日疟、恶性疟等） |
| **溶组织内阿米巴**（Entamoeba histolytica）| 肠道 | 阿米巴痢疾、肝脓肿 |
| **阴道毛滴虫**（Trichomonas vaginalis）| 阴道 | 滴虫性阴道炎 |
| **蓝氏贾第鞭毛虫**（Giardia lamblia）| 小肠 | 贾第虫病 |
| **刚地弓形虫**（Toxoplasma gondii）| 多组织 | 弓形虫病（**机会致病**）|
| **利什曼原虫**（Leishmania）| 巨噬细胞 | 黑热病 |
| **隐孢子虫**（Cryptosporidium）| 肠道 | 隐孢子虫病（**机会致病**）|
| **肺孢子虫**（Pneumocystis）| 肺 | 肺孢子虫肺炎（**机会致病**）|

### 机会致病原虫

详见 [[Parasite-Host Classification]]。

- 在免疫功能正常宿主体内通常处于**隐性感染**
- 宿主免疫功能受累（如 **AIDS**）时 → 异常增殖、致病力增强
- 代表：**刚地弓形虫、隐孢子虫、肺孢子虫**
