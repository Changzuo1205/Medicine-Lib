# Parasite-Host Classification（寄生虫与宿主的分类）

## Definition

根据寄生虫的寄生部位、时间、宿主选择性、免疫依赖等；以及根据宿主在寄生虫生活史中的角色进行的分类。

## Pathological Concept

### 寄生虫的分类

#### 按寄生部位

| 类型 | 例子 |
|------|------|
| **体内寄生虫** | 蛔虫（肠道）、血吸虫（门脉系统）、弓形虫（细胞内） |
| **体外寄生虫** | 虱、蚤、蜱、螨（皮肤表面） |

#### 按寄生时间

| 类型 | 例子 |
|------|------|
| **永久性寄生虫** | 蛔虫、绦虫（终身寄生） |
| **暂时性寄生虫** | 蚊、蚤（仅吸血时接触宿主） |

#### 按宿主选择性

| 类型 | 定义 | 例子 |
|------|------|------|
| **专性寄生虫** | 必须寄生才能生存 | 吸虫、多数线虫 |
| **兼性寄生虫** | 可寄生也可自生 | 耐格里阿米巴 |
| **偶然寄生虫** | 因偶然机会寄生 | 某些蝇蛆病 |

#### 按宿主免疫功能状态

- **机会致病寄生虫（opportunistic parasite）**：在免疫功能正常宿主中通常**隐性感染**；**AIDS** 等免疫受累时异常增殖、致病增强
- 代表：**刚地弓形虫、隐孢子虫、肺孢子虫**

### 宿主的分类（生活史角色）

| 类型 | 英文 | 寄生对象 | 例子 |
|------|------|----------|------|
| **终宿主** | definitive host | **成虫**或**有性生殖阶段** | 肝吸虫成虫 → 人肝胆管 |
| **中间宿主** | intermediate host | **幼虫期**或**无性生殖阶段** | 血吸虫 → 钉螺；肝吸虫 → 淡水鱼（第一中间宿主 → 纹沼螺；第二中间宿主 → 淡水鱼）|
| **保虫宿主（储蓄宿主）** | reservoir host | **脊椎动物**（可传播给人） | 肝吸虫 → 哺乳动物 |
| **转续宿主** | transfer host | 幼虫进入**非正常宿主**，不能发育为成虫，长期保持幼虫 | 肺吸虫童虫 → 野猪 |

### 关键概念区分

- **中间宿主 vs 转续宿主**：中间宿主体内寄生虫**能继续发育**；转续宿主体内只能**维持幼虫状态**，进入正常宿主才能继续发育

## Clinical Pearls

- **防治策略**：针对不同宿主类型采取不同措施
  - **中间宿主**（钉螺、淡水鱼）→ 灭螺、禁食生鱼
  - **保虫宿主**（家犬、狐狸）→ 管理家畜、捕杀野犬
  - **转续宿主**（野猪）→ 不食未煮熟的野猪肉
