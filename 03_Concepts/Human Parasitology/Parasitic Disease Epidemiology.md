# Parasitic Disease Epidemiology（寄生虫病流行）

## Definition

寄生虫病在人群中的**分布规律**及其影响因素。流行需具备 **3 个基本环节**：**传染源、传播途径、易感人群**，受**自然、生物、社会**三方面因素影响。

## Pathological Concept

### 3 个基本环节

| 环节 | 英文 | 内容 | 例子 |
|------|------|------|------|
| **传染源** | source of infection | 感染了寄生虫的人和动物 | 病人、带虫者、保虫宿主、转续宿主 |
| **传播途径** | route of transmission | 感染途径与方式 | 经土壤、水、食物、虫媒、空气、胎盘 |
| **易感人群** | susceptible population | 对寄生虫免疫力低/缺乏的人 | 儿童、免疫低下者（AIDS 等）|

### 传播途径分类

#### 按传播介质

| 类型 | 例子 |
|------|------|
| **经土壤传播** | 蛔虫病、钩虫病 |
| **经水传播** | 接触有血吸虫尾蚴的水体 |
| **经食物传播** | 生食含感染期虫体的鱼片（肝吸虫、肺吸虫） |
| **经直接传播** | 阴道毛滴虫病 |
| **经虫媒（节肢动物）传播** | 疟原虫病（按蚊）、丝虫病（库蚊/按蚊）|
| **经空气传播** | 肺孢子虫包囊 |
| **经胎盘传播** | 弓形虫（母婴垂直传播） |

#### 按感染方式

| 方式 | 例子 |
|------|------|
| **经口感染** | 蛔虫、蛲虫的感染期虫卵 |
| **经皮肤感染** | 钩虫丝状蚴、血吸虫尾蚴 |
| **自身感染** | 猪带绦虫（孕节片随粪便排出后污染手） |
| **逆行感染** | 蛲虫（幼虫在肛周孵出后逆行入肛门） |
| **经血感染** | 疟原虫（输血）、弓形虫（输血、器官移植） |

### 影响因素（3 类）

| 因素 | 内容 | 例子 |
|------|------|------|
| **自然因素** | 温度、湿度、雨量、光照；地理环境、生物种群 | 血吸虫分布与钉螺地理分布一致 |
| **生物因素** | 中间宿主/媒介昆虫的地理分布 | 长江以南血吸虫流行（钉螺分布）|
| **社会因素** | 经济文化水平、卫生习惯和卫生环境 | 落后地区寄生虫病流行 |

### 流行特点

| 特点 | 内容 |
|------|------|
| **地方性** | 与气候、中间宿主地理分布、居民饮食/生产方式有关 |
| **季节性** | 与媒介昆虫活动季节一致（如间日疟 ↔ 中华按蚊） |
| **自然疫源性** | 不需人的参与而存在于自然界的动物源性寄生虫病（人兽共患） |
