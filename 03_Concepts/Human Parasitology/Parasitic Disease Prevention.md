# Parasitic Disease Prevention（寄生虫病防治原则）

## Definition

针对寄生虫病流行的 **3 个基本环节**（传染源、传播途径、易感人群）采取的综合性防治措施。

> - 来源登记：[[Source-Registry#S-LEC-009]]

## Pathological Concept

### 防治原则（3 大环节阻断）

```
传 染 源 ─→ 传播途径 ─→ 易感人群
   ↑           ↓           ↓
   └─── 管理传染源 ── 切断 ── 保护
```

### 具体措施

#### 1. 管理传染源（控制传染源）

- 流行区**普查普治病人和带虫者**
- 流行区**普查普治保虫宿主**
- 非流行区**检测和控制来自流行区的流动人口**
- **早期诊断并治疗**病人、带虫者；处理保虫宿主

#### 2. 切断传播途径

- **加强粪便和水源管理**（管粪、管水）
- **杀灭传播媒介**（如灭蚊、灭螺、灭蚤）
- **食品卫生监督**
- 注意环境和个人卫生

#### 3. 保护易感人群

- 加强**健康教育**，改变不良的饮食习惯和行为方式
- 预防措施：
  - **物理预防**：蚊帐、防蚊网、避蚊胺
  - **化学预防**：预防性服药（如氯喹预防疟疾）
  - **生物预防**：疫苗（部分蠕虫疫苗正在研发）
  - **改善卫生设施**

### 我国防控成果（建国以来）

| 病种 | 现状 |
|------|------|
| **血吸虫病** | 2005 年降至 79.9 万（从建国初 1000 万） |
| **疟疾** | 2021 年基本消灭 |
| **丝虫病** | 1994 年基本消灭 |
| **黑热病** | 1958 年基本消灭 |

### 当前挑战

- **土源性线虫病**防治与社会发展水平不相适应
- **食源性寄生虫病**成为食品安全主要问题之一
- **寄生虫病**对妇女和儿童危害严重
- **西部农村地区**（牧区、半农半牧区）仍是难点

## Clinical Pearls

- **综合性防治**：单环节阻断效果有限，**3 环节同步**才能根除（如血吸虫病防治 = 治疗病人 + 灭螺 + 粪便管理 + 安全用水）
- **新工具**：分子寄生虫学 + 免疫寄生虫学 → 新药 / 疫苗 / 诊断技术
