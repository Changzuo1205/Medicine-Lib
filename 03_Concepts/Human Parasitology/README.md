## 学科范围

本学科涵盖**病原生物中的寄生虫部分**（蠕虫、原虫、医学节肢动物）的：

### 1. 寄生虫生物学（Parasite Biology）

| 类别 | 代表寄生虫 |
|------|------------|
| **医学蠕虫** | 线虫（蛔虫、钩虫、蛲虫、丝虫、旋毛虫、广州管圆线虫）、吸虫（血吸虫、肝吸虫、姜片虫、肺吸虫）、绦虫（猪带绦虫、牛带绦虫、棘球绦虫） |
| **医学原虫** | 疟原虫、阿米巴（溶组织内阿米巴）、弓形虫、利什曼原虫、阴道毛滴虫、蓝氏贾第鞭毛虫、卡氏肺孢子虫（机会致病原虫） |
| **医学节肢动物** | 蚊（按蚊、库蚊、伊蚊）、蝇、蚤、虱、蜱、螨、恙螨等（侧重"传播媒介"角色） |

### 2. 寄生虫与宿主的关系

- 寄生关系类型（**专性寄生 vs 兼性寄生**；**体内寄生 vs 体外寄生**；**终宿主 vs 中间宿主 vs 保虫宿主**）
- 寄生虫的**生活史**（生活史类型：直接型 / 间接型；感染阶段）
- 寄生虫的**致病机制**：掠夺营养、机械损伤、毒性作用、免疫损伤

### 3. 寄生虫病（Parasitic Diseases）

| 系统 | 代表疾病 |
|------|----------|
| **血液 / 全身** | 疟疾（Malaria）、弓形虫病、丝虫病、利什曼病（黑热病） |
| **消化系统** | 蛔虫病、钩虫病、蛲虫病、阿米巴痢疾、蓝氏贾第鞭毛虫病、肝吸虫病、姜片虫病、绦虫病、棘球蚴病（包虫病） |
| **呼吸 / 心血管** | 血吸虫病、肺吸虫病 |
| **神经 / 眼** | 广州管圆线虫病、脑囊虫病、弓形虫脑病 |
| **皮肤 / 组织** | 旋毛虫病、皮肤蝇蛆病、螨虫性皮炎 |

### 4. 抗寄生虫药物（Anti-parasitic Agents）

- **抗原虫药**：青蒿素衍生物（蒿甲醚、青蒿琥酯）、氯喹、伯氨喹、吡喹酮（兼抗蠕虫）、甲硝唑（兼抗原虫）
- **抗蠕虫药**：阿苯达唑（肠虫清）、甲苯达唑、左旋咪唑、吡喹酮、乙胺嗪（海群生，抗丝虫）
- **抗疟疾**：青蒿素联合疗法（ACT）、氯喹、奎宁

> 药物剂量与配伍**必须以权威指南为准**（WHO 寄生虫病治疗指南），本知识库**不存储具体剂量**。

### 5. 诊断与监测

- 粪便检查（直接涂片法、浓集法、虫卵计数）
- 血液检查（疟原虫血涂片 — 厚片/薄片吉姆萨染色）
- 活组织检查（皮肤、肌肉、肝活检）
- 免疫学检查（抗原 / 抗体检测，如弓形虫 IgM）
- 分子诊断（PCR）
- 影像学（脑囊虫病 CT/MRI、血吸虫病肝纤维化超声）

### 寄生虫（Parasite）

- **蠕虫**：Hookworm（钩虫）· Enterobius vermicularis（蛲虫）· Filaria（丝虫）· Trichinella spiralis（旋毛虫）· Angiostrongylus cantonensis（广州管圆线虫）· Schistosoma（血吸虫）· Clonorchis sinensis（肝吸虫）· Fasciolopsis buski（姜片虫）· Paragonimus（肺吸虫）· Taenia solium/saginata（猪/牛带绦虫）· Echinococcus（棘球绦虫）
- **原虫**：Plasmodium（疟原虫）· Entamoeba histolytica（溶组织内阿米巴）· Toxoplasma gondii（弓形虫）· Leishmania（利什曼原虫）· Trichomonas vaginalis（阴道毛滴虫）· Giardia lamblia（蓝氏贾第鞭毛虫）· Pneumocystis（机会致病原虫）
- **医学节肢动物**：Anopheles（按蚊）· Culex（库蚊）· Aedes（伊蚊）· …

### 寄生虫病（Disease）

- Malaria（疟疾）· Amoebiasis（阿米巴病）· Toxoplasmosis（弓形虫病）· Leishmaniasis（黑热病）· Filariasis（丝虫病）
- Hookworm Disease · Enterobiasis · Trichinellosis
- Schistosomiasis · Clonorchiasis · Fasciolopsiasis · Paragonimiasis
- Taeniasis · Cysticercosis（囊虫病）· Echinococcosis（包虫病）

### 药物（Drug）

- 抗原虫：Artemisinin · Chloroquine · Primaquine · Metronidazole
- 抗蠕虫：Albendazole · Mebendazole · Levamisole · Praziquantel · Diethylcarbamazine

### 机制（Pathophysiology）

- 寄生虫致病机制（掠夺、损伤、毒性、免疫病理）
- 寄生虫与宿主免疫的相互作用（与 [[03_Concepts/Immunology/README|Immunology]] 交叉）

### 检查（Test）

- 血液疟原虫涂片 · 皮肤活检 · 弓形虫 IgM/IgG · PCR
- 脑囊虫病影像（CT/MRI 可见钙化灶）

### 临床推理（Clinical Algorithm）

- 不明原因发热（FUO）的寄生虫病因筛查
- 输入性寄生虫病诊断思路（旅游史）
- 抗寄生虫药物选择与疗程

## 使用规则

1. **本目录定位**：存放**寄生虫相关**的 Concept 节点（Disease / Drug / Parasite / Pathophysiology / Test）。
