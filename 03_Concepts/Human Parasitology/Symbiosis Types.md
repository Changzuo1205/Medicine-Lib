# Symbiosis Types（共生的三种类型）

## Definition

两种生物在一起生活的**相互关系**类型。根据受益与受害情况，分为**片利共生（commensalism）**、**互利共生（mutualism）**和**寄生（parasitism）**。

## Pathological Concept

### 三种类型对比

| 类型 | 英文 | 一方 | 另一方 | 例子 |
|------|------|------|--------|------|
| **片利共生（共栖）** | commensalism | **受益** | **无益无害** | 鮣鱼与大鱼；海葵与寄居蟹 |
| **互利共生** | mutualism | **受益** | **受益** | 牛与胃内纤毛虫 |
| **寄生** | parasitism | **受益（寄生虫）** | **受害（宿主）** | 蛔虫与人 |

### 寄生关系的演化方向

从片利共生 → 互利共生 → 寄生是**连续谱**。寄生演化伴随：

| 方面 | 演化方向 |
|------|----------|
| **形态学结构** | 退化 / 特化（如肠道寄生虫**无消化系统**，靠体表吸收） |
| **生理功能** | 代谢方式改变（**无氧糖酵解**为主） |
| **繁殖能力** | **显著加强**（绦虫每日产卵数十万） |
| **侵入机制** | 特化与加强（钩虫丝状蚴穿透皮肤的能力） |
| **免疫逃避** | 形成（包囊形成、抗原变异、宿主抗原模拟） |
| **基因变异 / 重组** | 适应宿主环境 |

## Clinical Pearls

- **判定寄生虫 vs 共生生物**：看是否对宿主**有害**
- 寄生虫与宿主的关系是**长期协同进化**的结果 — 寄生虫致病力趋于温和（杀死宿主不利于传播），宿主发展免疫力
