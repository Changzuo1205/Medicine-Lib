# Adaptive Immunity（适应性免疫）

## Definition

适应性免疫（adaptive immunity），又称**特异性免疫**或**获得性免疫**，是体内 **T、B 淋巴细胞**接受"非己"物质（主要指**抗原**）刺激后，活化、增殖、分化为效应细胞，产生一系列生物学效应（包括清除抗原等）的全过程。

**三大特点**：特异性、耐受性、记忆性。

## Normal Mechanism

### 一、基本特征

| 维度 | 适应性免疫 |
|------|-----------|
| 获得形式 | 后天获得 |
| 抗原参与 | **需抗原激发** |
| 发挥作用时相 | **4~5 天后**发挥效应 |
| 抗原识别受体 | **TCR（T 细胞）、BCR（B 细胞）** |
| 免疫记忆 | **有**，产生记忆细胞（Tm、Bm） |
| 三大特点 | **特异性、耐受性、记忆性** |

### 二、适应性免疫的两大类

#### 1. 体液免疫（Humoral Immunity）

- **介导细胞**：B 淋巴细胞 → 浆细胞 → **抗体**
- **主要针对**：胞外病原体和毒素
- **效应机制**：分泌的抗体（免疫球蛋白）中和病原体 / 调理吞噬 / 激活补体 / ADCC

#### 2. 细胞介导免疫（Cell-mediated / Cellular Immunity）

- **介导细胞**：T 淋巴细胞
- **主要针对**：胞内病原体
- **两个亚类**：

| 亚类 | 效应 T 细胞 | 效应机制 | 主要功能 |
|------|-------------|----------|----------|
| 辅助性 T（Th） | CD4⁺ Th | 活化巨噬细胞 | 清除**被巨噬细胞吞噬但仍存活**的胞内微生物 |
| 细胞毒性 T（CTL） | CD8⁺ CTL | 直接杀伤感染细胞 | 清除**胞内复制**的微生物（如病毒）、肿瘤细胞 |

### 三、T 淋巴细胞

- 表达特异性抗原识别受体：**TCR（T cell receptor）**
- **TCR 类型分布**：
  - **TCR αβ**：≥90%，属**适应性免疫**细胞
  - **TCR γδ**：约 5–10%，属**固有免疫**细胞，分布于黏膜和皮肤（IEL 中约 60% 为 γδT）

| 亚群 | 标志 | 功能 |
|------|------|------|
| CD4⁺ T | Th | 辅助 B 细胞产生抗体（Th2）、辅助细胞免疫（Th1）、参与炎症（Th17） |
| CD8⁺ T | CTL | 通过**细胞毒作用**杀伤胞内寄生病原体、肿瘤细胞 |

**Th 亚群**（经典分类，详见后续课程）：

| 亚群 | 功能 |
|------|------|
| Th1 | 辅助细胞免疫（激活 Mφ，介导迟发型超敏） |
| Th2 | 辅助体液免疫（促进 B 细胞产生抗体） |
| Th17 | 参与炎症、自身免疫病 |

### 四、B 淋巴细胞

- **发育来源**：哺乳动物**骨髓**（Bone marrow）或禽类**法氏囊**（Bursa of fabricius）中的淋巴样干细胞
- **定居部位**：静息 B 细胞分布于血液、淋巴结、脾、扁桃体及其他黏膜组织
- **关键表面受体**：**BCR（B cell receptor）**——识别和结合抗原表位
- **活化后**：增殖、分化为**浆细胞**（效应细胞）→ 产生**抗体** → 参与特异性**体液免疫**
- B 细胞也是重要的**抗原提呈细胞（APC）**

### 五、抗原提呈细胞（APC）

摄取抗原、加工处理、提呈给 T 细胞，并向 T 细胞活化提供必要的第二信号（CD80/86 等共刺激分子）。

**专职 APC**：

| 类型 | 摄取抗原机制 | 特点 |
|------|--------------|------|
| **树突状细胞（DC）** | 胞饮、调理吞噬、受体介导内吞；表达 MHC I/II 类分子 | **最强的 APC**，能活化初始 T 细胞 |
| 单核/巨噬细胞 | 吞噬、胞饮 | 兼有杀菌与提呈功能 |
| B 细胞 | BCR 识别、浓集和内化抗原；胞饮 | 体液免疫中可放大抗原提呈 |

### 六、淋巴细胞再循环

- 维持机体正常免疫应答并发挥功能的**必要前提**。
- 关键通道：淋巴结**HEV（高内皮微静脉）**——血液中的淋巴细胞穿过 HEV 进入淋巴结实质。

## Key Components / Steps

```
适应性免疫
├── 启动：抗原 → APC 摄取加工 → 提呈给 T 细胞
├── 体液免疫（B 细胞）
│   └── 抗原 → BCR 识别 → 活化增殖 → 浆细胞 → 抗体 → 中和 / 调理 / 补体 / ADCC
├── 细胞免疫（T 细胞）
│   ├── CD4⁺ Th
│   │   ├── Th1 → 激活 Mφ → 清除胞内菌
│   │   ├── Th2 → 辅助 B 细胞 → 体液免疫
│   │   └── Th17 → 炎症 / 自身免疫
│   └── CD8⁺ CTL → 穿孔素 / 颗粒酶 → 杀伤感染细胞 / 肿瘤细胞
└── 记忆：Tm / Bm → 二次应答更快更强
```

## Physiological Significance

- **特异性**：TCR / BCR 多样性使免疫系统能应对几乎所有抗原。
- **耐受性**：中枢耐受（胸腺阴性选择、骨髓阴性选择）+ 外周耐受 → 避免自身免疫。
- **记忆性**：记忆细胞使二次应答潜伏期短、抗体滴度高、亲和力高（亲和力成熟）。
- **桥接**：适应性免疫通过细胞因子、抗体反过来"放大"固有免疫。

## Clinical Relevance

| 应用 | 机制 |
|------|------|
| **疫苗** | 利用抗原的免疫原性 + 适应性免疫的记忆性 → 主动免疫 |
| **单克隆抗体药物** | 利用 B 细胞 → 浆细胞 → 抗体 的机制 → 治疗肿瘤、自身免疫病、感染 |
| **CAR-T** | 工程化 T 细胞（改造 TCR 信号） → 治疗 B 细胞肿瘤 |
| **HLA 配型 / 器官移植** | MHC 限制性识别 → 异体排斥与免疫耐受 |
| **免疫抑制剂**（环孢素、他克莫司） | 抑制 T 细胞活化（NFAT 通路） → 防治器官移植排斥、自身免疫病 |
| **过敏原特异性免疫治疗（AIT）** | 通过调节 Th1/Th2 平衡 → 治疗 I 型超敏反应 |
| **HIV** | 感染 CD4⁺ T 细胞 → 细胞免疫缺陷 → 机会性感染、肿瘤 |
