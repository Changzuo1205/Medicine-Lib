# Adjuvant（佐剂）

## Definition

预先或与抗原同时注入体内，可**增强机体对该抗原的免疫应答**或**改变免疫应答类型**的**非特异性免疫增强性物质**。

## Pathological Mechanism

### 常见佐剂

| 佐剂 | 特点 |
|------|------|
| **氢氧化铝**（铝盐）| 最常用的人用疫苗佐剂；体液免疫 |
| **磷酸铝** | 同氢氧化铝 |
| **卡介苗（BCG）** | 经典人用佐剂 |
| **MF59** | 水包油型乳剂（流感疫苗） |
| **AS04** | 明矾 + **TLR4 受体激动剂**（HPV、HBV 疫苗） |
| **MPL**（单磷酰脂质 A）| TLR4 激动剂（糖脂） |
| **VLP**（病毒样颗粒）| HPV 疫苗 |
| **CpG 寡核苷酸** | TLR9 激动剂；低甲基化 motif |
| **弗氏完全佐剂**（CFA）| 矿物油 + **灭活结核分枝杆菌**；体液免疫 + 细胞免疫 |
| **弗氏不完全佐剂**（IFA）| 仅矿物油；仅体液免疫 |

### 主要生物学作用

1. **增强抗原的免疫原性**，使其成为有效免疫原（**不改变抗原特异性**）
2. 提高**抗体滴度**或应答水平
3. 改变抗体类型（诱导以 **IgG** 为主）
4. **诱发或增强迟发型超敏反应**（细胞免疫）

### 主要作用机制

1. 改变抗原物理性状，**延缓抗原降解** → 延长体内停留时间
2. 使可溶性抗原 → **颗粒性抗原** → 促进 APC 摄取
3. 刺激单核/巨噬细胞系统 → 增强抗原处理和递呈
4. 诱导炎症反应 → 吸引 APC 到抗原部位
5. 刺激 T/B 细胞增殖和分化 → 增强免疫应答
6. 诱导不同细胞因子 → 影响 T 细胞亚群分化和应答类型
