# Antibody Functions（抗体的生物学功能）

## Definition

抗体的生物学功能按讲义分为两部分：由抗体 V 区介导的功能（特异性识别结合抗原、发挥中和抗体效应）与由抗体 C 区介导的功能（激活补体、结合 Fc 受体、穿过胎盘和黏膜）。

> [!info] 来源
> - [[02_Raw/Lectures/Medical Immunology/第四章 抗体.pdf|《第四章 抗体》（杨艳艳，2026 秋）]] — p27–p31
> - 来源登记：[[Source-Registry#S-LEC-016]]

## 一、抗体 V 区的功能

讲义 p27 列出抗体 V 区的两项功能：

1. 作为 B 细胞抗原受体（BCR），特异性识别结合抗原，活化 B 细胞；
2. 特异性结合抗原，发挥中和抗体效应。

## 二、抗体 C 区的功能

讲义 p28–p31 列出抗体 C 区的三项功能。

### 1. 激活补体

激活补体，发挥补体依赖的细胞毒作用（CDC）。

### 2. 结合 Fc 受体

- 调理作用；
- 抗体依赖的细胞介导的细胞毒作用（ADCC）；
- 介导Ⅰ型超敏反应。

讲义 p29 在该页 ADCC 项旁标注效应细胞缩写为「NK \ Mφ」。

> [!warning] 讲义未展开
> 讲义 p29 虽标注了 ADCC 的效应细胞缩写（NK 与 Mφ），但**未展开** ADCC 的杀伤机制，也**未区分** NK 细胞与巨噬细胞在该过程中的角色差异。本知识库不代为补充。

### 3. 穿过胎盘和黏膜

讲义 p31 在该项下明确两项内容：

- **IgG 穿过胎盘**，从母体转运到胎儿；
- **分泌型 IgA（SIgA）** 经**肠道上皮细胞**分泌至黏膜表面。

## 三、讲义要求层级

> [!info] 讲义要求层级
> 讲义 p2「重点难点」把「**抗体的结构及功能**」列为**掌握**层级；同页另列「熟悉」与「了解」两项要求。

## 四、讲义重复页说明

讲义 p28、p29、p30 三页的文字内容相同，p29 另多出效应细胞缩写标注，p31 在相同文字的基础上补充了穿过胎盘和黏膜的具体内容。因此本节点的来源范围记为 p27–p31。

## Clinical Pearls

- 讲义把「抗体的结构及功能」列为**掌握**层级，属本章最高要求内容。
- **V 区功能与 C 区功能需分开记忆**：V 区负责识别与中和，C 区负责效应（激活补体、结合 Fc 受体、穿过胎盘和黏膜）。
- 讲义把 **CDC** 与 **结合 Fc 受体的三项效应**（调理作用、ADCC、介导Ⅰ型超敏反应）并列为 C 区功能考点。
- **穿过胎盘和黏膜**在讲义中落到两个具体分子：穿过胎盘的是 IgG，经肠道上皮细胞分泌至黏膜表面的是分泌型 IgA。
- 讲义 p29 对 ADCC 只给出效应细胞缩写，未展开杀伤机制与效应细胞间的角色差异；本知识库不代为补充。
