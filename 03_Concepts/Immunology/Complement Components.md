# Complement Components（补体系统的组成与命名）

## Definition

补体系统的**组成与命名**是认识补体的入口：其成分按**发现先后**与**功能类别**命名，在组成上分为**固有成分、补体调节蛋白、补体受体**三大类。

> [!info] 来源
> - [[02_Raw/Lectures/Medical Immunology/第五章 补体系统.pdf|《第五章 补体系统》（杨艳艳，2026 秋）]] — p7–p8
> - 来源登记：[[Source-Registry#S-LEC-018]]

## 命名规则（5 条）

| 规则 | 内容 |
|------|------|
| **1. 发现先后命名** | **C1（q、r、s）、C2、…… C9** |
| **2. 其他成分** | **B 因子、P 因子** |
| **3. 补体调节蛋白** | **C1 抑制物（C1INH）**、**C4 结合蛋白（C4bp）** |
| **4. 裂解片段** | **a（小）、b（大）** —— **C2 例外** |
| **5. 灭活补体片段** | **iC3b** |

> **规则 4 的「C2 例外」须原样记住**：补体裂解片段的一般规律是「小片段记作（a）、大片段记作（b）」，但 **C2 是例外** —— 讲义未在 p7 展开例外方向，本库不代为补全。

## 组成三大类

### 一、补体的固有成分

| 归属途径 | 成分 |
|----------|------|
| **经典途径** | **C1q、C1r、C1s、C2、C4** |
| **旁路途径** | **B 因子、D 因子** |
| **MBL 途径** | **MBL**（mannose-binding lectin）、**MASP**（MBL 相关丝氨酸蛋白酶） |
| **三条途径的共同末端通路** | **C3、C5～C9** |

### 二、补体调节蛋白

**备解素（P 因子）**、**C1 抑制物**、**I 因子**、**H 因子**、**C4 结合蛋白**等。

> 注意 **P 因子**在讲义中**两处出现**：命名规则第 2 条列为「其他成分」，本节又列入「补体调节蛋白」（写作**备解素**，即 P 因子）—— **本库按讲义原样呈现，不代为归并**。

### 三、补体受体

**CR1～CR5、C3aR、C2aR、C4aR** 等。

> [!warning] 补体受体清单的边界（讲义 p8 vs p48）
> 讲义 p8 的补体受体清单**只列到 CR1～CR5**，以及 C3aR、C2aR、C4aR；而讲义 p48 的图注中又出现了 **CR2（CD21）**，讲义**未说明 CR2 = CD21**（CR2 是否与 CD21 同义、其归属是否在 CR1～CR5 之内，讲义均未交代）。
> **本节点不代为补全**：既不为 CR2 补写分子身份，也不为 CR1～CR5 补写各自分布与功能。

## 组成与途径的对应关系

```
补体的固有成分
├── 经典途径前端：C1q、C1r、C1s、C2、C4
├── 旁路途径前端：B 因子、D 因子
├── MBL 途径前端：MBL、MASP
└── 三条途径共同末端通路：C3、C5～C9   ← 交汇点
```

- 三条途径在**前端**各用各的成分（识别与启动环节不同），在**末端**共用 **C3 与 C5～C9**，故称「**共同末端通路**」。
- 与命名规则对照：**C1 拆为 q、r、s 三个亚单位**（规则 1）；**B 因子、P 因子**不按 C 编号（规则 2）；**C1INH、C4bp** 属调节蛋白（规则 3）。

## Clinical Pearls

- **课堂自测题（讲义 p23）**：补体的固有成分中**分子量最大的是 C1**。此点与理化性质「分子量变动范围很大」呼应。
- **课堂自测题（讲义 p34 多选）**：**旁路激活途径的补体固有成分包括 C3、D 因子、B 因子**（C4 与 I 因子不属旁路途径固有成分）—— 与本节「旁路途径：B 因子、D 因子」「共同末端通路：C3」直接对应。
- **MASP 的定位**：讲义在 MBL 途径下列出 **MASP**（MBL 相关丝氨酸蛋白酶），与固有成分中「一系列**丝氨酸蛋白酶**的级联酶解反应」的定位一致。
- 讲义 p3 将「**补体系统的组成**及调控补体系统激活的有关因素」列为「**熟悉**」层次 —— 组成清单属记忆性内容，是本讲的基础层。
