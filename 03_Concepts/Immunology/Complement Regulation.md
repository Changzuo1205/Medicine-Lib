# Complement Regulation（补体激活的调节）

## Definition

**补体激活的调节**：补体激活过程受体内调节机制控制 —— 讲义以**第三节（p35）**专节讲述，按**靶点**分三个方面：

1. 针对**经典途径前端反应**的调节
2. 针对**旁路途径前端反应**的调节
3. 针对 **MAC** 的调节

其掌握层级见讲义 p3「重点难点」：**「补体系统的组成及调控补体系统激活的有关因素」被列为「熟悉」**（「掌握」为补体的三条激活途径及补体的生物学功能）。

## 一、针对经典途径前端反应的调节机制

讲义 p37 原文分两组。

**针对 C1**

| 调节蛋白 | 讲义原文作用 |
|----------|--------------|
| **C1 抑制物（C1 INH）** | 抑制 **C1r、C1s、MASP** 活性，阻断 **C4b2a** |

**针对 C3 转化酶和 C5 转化酶**

| 调节蛋白 | 讲义原文作用 |
|----------|--------------|
| **C4 结合蛋白（C4bp）** | 抑制 **C4b2a、C4b2a3b** |
| **I 因子** | 抑制 C3 转化酶、C5 转化酶 |
| **膜辅蛋白（MCP）** | 抑制 C3 转化酶、C5 转化酶 |
| **补体受体 1（CR1）** | 抑制 C3 转化酶、C5 转化酶 |
| **衰变加速因子（DAF）** | 抑制 C3 转化酶、C5 转化酶 |

## 二、针对旁路途径前端反应的调节机制

讲义 p38 原文：

| 调节蛋白 | 讲义原文作用 |
|----------|--------------|
| **I 因子** | 抑制 C3 转化酶、C5 转化酶 |
| **H 因子** | 抑制 C3 转化酶、C5 转化酶 |
| **P 因子** | **稳定 C3bBb**（方向与上两者相反） |
| **膜辅蛋白（MCP）** | 抑制 C3 转化酶、C5 转化酶 |
| **补体受体 1（CR1）** | 抑制 C3 转化酶、C5 转化酶 |
| **衰变加速因子（DAF）** | 抑制 C3 转化酶、C5 转化酶 |

> 讲义另给出两条机制要点（原文）：**MCP\CR1 使 C3b 失活**；**DAF\CR1 使 C3bBb 分离**。

## 三、针对 MAC 的调节

讲义 p40 原文：**抑制 MAC 形成与活性的补体调节蛋白 → 保护自身正常细胞免遭补体攻击**：

- **膜反应性溶破抑制物（MIRL = CD59 = HRF20）**
- **同源限制因子（HRF）**（讲义注：*CD59 also known as HRF20*）
- **S 蛋白（Vitronectin/SP）**
- **簇集素（clusterin）**

> [!warning] 讲义未讲清四名是否完全同义（按原文并录，需人工复核）
> 讲义 p40 同时列出 **MIRL = CD59 = HRF20** 与**同源限制因子（HRF）**，并附注 "*CD59 also known as HRF20*"。
> 因此 **CD59 / MIRL / HRF20 / HRF 四者是否完全同义，讲义未讲清**。
> 本节点**按原文并录**，**不作判断**、不代为改写，留待与教材核对。

## Clinical Pearls

- **按靶点记组合**：前端 **C1** → **C1 INH**；中段**转化酶** → **C4bp、I 因子、H 因子、MCP、CR1、DAF**；末端 **MAC** → **MIRL/CD59/HRF20、HRF、S 蛋白、簇集素**。
- **P 因子的方向是唯一的例外**：讲义 p38 中只有 **P 因子**是**稳定 C3bBb**，其余（I 因子、H 因子、MCP、CR1、DAF）都是**抑制** C3 转化酶与 C5 转化酶 —— 这是本节的**易错点**。
- **调节蛋白缺陷与疾病**（讲义 p50）：**C1INH 缺陷**可引起**遗传性血管性水肿（HAE）**；**DAF 缺陷**可引起**阵发性夜间血红蛋白尿（PNH）**。
- **病原体可反用调节蛋白**（讲义 p51）：部分微生物**以补体受体或补体调节蛋白作为其受体**而入侵细胞，**不需要与补体片段结合** —— **麻疹病毒以 MCP 为受体**；**柯萨奇病毒和大肠埃希菌以 DAF 为受体**；另有微生物产生**与补体调节蛋白功能相似的蛋白**抑制补体活化以**逃避**补体攻击。
- **调节蛋白属于「熟悉」层级**：讲义 p3 把「调控补体系统激活的有关因素」列为**熟悉**；而三条激活途径与生物学功能为**掌握** —— 复习权重应据此分配。
