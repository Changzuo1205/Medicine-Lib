# IgD（免疫球蛋白 D）

## Definition

IgD 分为**膜结合型**和**分泌型**；正常人血清 IgD 浓度**很低**（约 **30 μg/ml**），仅占血清免疫球蛋白总量的 **1%**，**个体差异大**。

## 分型与血清浓度

- 分为**膜结合型**和**分泌型**两型
- 正常人血清 IgD 浓度**很低**（约 **30 μg/ml**）
- 仅占血清免疫球蛋白总量的 **1%**
- **个体差异大**

## 铰链区与半寿期

- 五类免疫球蛋白中，**IgD 的铰链区较长**
- 因此**易被蛋白酶水解**
- 故其**半寿期很短（仅 3 天）**

## 膜结合型 IgD 与 B 细胞成熟

**膜结合型 IgD（mIgD）是 B 细胞分化发育成熟的标志。**

| B 细胞状态 | 表面表达 |
|------------|----------|
| **未成熟 B 细胞** | 仅表达 **mIgM** |
| **成熟 B 细胞** | 可**同时表达 mIgM 和 mIgD**，称为**初始 B 细胞（naïve B cell）** |
| **活化后的 B 细胞** | 表面的 **mIgD 逐渐消失** |

## Clinical Pearls

- **一句话考点**：**mIgD 是 B 细胞分化发育成熟的标志**；只表达 mIgM 者为**未成熟** B 细胞，同时表达 mIgM 与 mIgD 者为**成熟**（初始）B 细胞。
- **动态变化**：B 细胞活化后表面 mIgD **逐渐消失** —— 即 mIgD 是「成熟但未活化」这一阶段的表面标志（讲义未进一步展开其机制）。
- **半寿期只有 3 天**的原因，讲义归因于**铰链区较长、易被蛋白酶水解**，是五类免疫球蛋白中铰链区最长者（详见 [[Variable Region and Constant Region]]）。
- **血清 IgD 浓度低且个体差异大**，是讲义给出的原文描述，讲义**未**说明其临床检测用途。
