# IgG（免疫球蛋白 G）

## Definition

IgG 是于出生后 3 个月开始合成、占血清总 Ig 的 75%～80%、半衰期约 20～23 天的免疫球蛋白类别，包括 IgG1、2、3、4 四个亚类，是再次免疫应答产生的主要抗体。

> - 来源登记：[[Source-Registry#S-LEC-016]]

## 基本特征

讲义 p35 给出：

- IgG 于**出生后 3 个月**开始合成；
- 是**血清和胞外液中含量最高**的 Ig，约占**血清总 Ig 的 75%～80%**；
- IgG **半衰期约 20～23 天**；
- 是**再次免疫应答**产生的主要抗体，其对抗原的**亲和力及特异性高**，是**免疫应答效应最强**的 Ig，是机体抗感染的**「主力军」**；
- 包括 **IgG1、2、3、4 四个亚类**。

## 一、膜型 IgG

在**记忆 B 细胞**表面，对特定抗原的**再次应答**。

## 二、分泌型 IgG

讲义 p35 列出分泌型 IgG 的六项要点，并把功能对应的亚类逐一标注：

1. **中和效应**；
2. **激活补体**（**IgG1～IgG3**），发挥 CDC；
3. **ADCC**（**IgG1 及 IgG3**）：与 **NK 细胞**表面的 **FcR** 结合；
4. **调理作用**（**IgG1 及 IgG3**）：与**巨噬细胞**表面的 **FcR** 结合；
5. 是**唯一能穿过胎盘**保护胎儿的抗体（**IgG1、IgG3 及 IgG4**）；
6. 参与多种**自身免疫病**发生（**IgG1 及 IgG3**）。

## 三、功能与亚类的对应关系

讲义的亚类标注各不相同，逐条对应如下，不得混用：

| 功能 | 讲义标注的参与亚类 |
|------|--------------------|
| 激活补体（CDC） | IgG1～IgG3 |
| ADCC | IgG1 及 IgG3 |
| 调理作用 | IgG1 及 IgG3 |
| 穿过胎盘 | IgG1、IgG3 及 IgG4 |
| 参与自身免疫病发生 | IgG1 及 IgG3 |
| 中和效应 | 讲义未标注具体亚类 |

## Clinical Pearls

- IgG 是**唯一能穿过胎盘**保护胎儿的抗体，讲义标注的参与亚类为 **IgG1、IgG3 及 IgG4**。
- IgG **参与多种自身免疫病发生**，讲义标注的参与亚类为 **IgG1 及 IgG3**。
- IgG 于**出生后 3 个月**开始合成，这是与 IgM（胚胎发育晚期即可合成）相对照的时间点。
- 讲义把 IgG 称为机体抗感染的**「主力军」**，而把 IgM 称为**「先头部队」**。
- ADCC 与调理作用在讲义中都归为 IgG1 及 IgG3，区别在于前者结合 NK 细胞表面的 FcR，后者结合巨噬细胞表面的 FcR。
- 讲义未展开：具体自身免疫病病种、宫内感染与新生儿抗体判读的联合应用、各亚类半衰期差异的机制。本知识库不代为补充。
