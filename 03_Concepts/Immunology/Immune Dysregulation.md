# Immune Dysregulation（免疫异常与疾病）

> [!note] 用途
> 本节点是免疫学绪论中"免疫异常与疾病"的**总览节点**。具体疾病（哮喘、SLE、各类免疫缺陷病等）将随课程进展分别建立独立 Disease 节点。

## Definition

当免疫系统的**成分缺乏 / 功能缺陷**、**免疫应答水平过高或过低**、或**对自身抗原的免疫耐受被打破**、或**免疫调节功能发生紊乱**时，所出现的异常免疫应答可导致相关疾病的发生。

## Normal Physiology

参见 [[Immune System]]：

| 功能 | 英文 | 正常含义 |
|------|------|----------|
| 免疫防御 | immune defense | 防外敌、清除已入侵病原体 |
| 免疫监视 | immune surveillance | 清"非己"（突变细胞、衰老/死亡细胞） |
| 免疫自稳 | immune homeostasis | 免疫耐受 + 免疫调节 → 内环境稳定 |

## Pathological Mechanism

### 一、四大类免疫异常

| 异常类型 | 机制 | 后果 | 例子 |
|----------|------|------|------|
| **免疫缺陷**（immunodeficiency） | 免疫系统成分缺乏 / 功能缺陷（遗传或后天） | 防御不足 → 反复感染；监视不足 → 恶性肿瘤易感 | 原发性免疫缺陷病（X 连锁无丙种球蛋白血症、SCID、CGD）；HIV / AIDS；化疗后骨髓抑制 |
| **超敏反应**（hypersensitivity） | 对**无害物质**应答过度强烈 | 防御过强 → 组织损伤 | 食物过敏、哮喘、过敏性鼻炎、荨麻疹、过敏性休克 |
| **自身免疫病**（autoimmune disease） | **对自身抗原**应答（自身耐受被打破） | 自稳失败 → 自身组织损伤 | 系统性红斑狼疮（SLE）、类风湿关节炎（RA）、1 型糖尿病（T1DM）、多发性硬化（MS） |
| **肿瘤**（immune surveillance failure） | 免疫监视功能不足，无法清除突变细胞 | 突变细胞扩增 → 肿瘤 | 各种恶性肿瘤；EBV 相关淋巴瘤；HPV 相关肿瘤 |

### 二、对应到 PPT 主线图

```text
抗原 → T/B 活化 → 效应细胞 / 浆细胞 → 抗体 / Tm / Bm
        + 补体、细胞因子、MHC
                  ↓
              清除抗原
                ↙     ↘
          免疫防御    免疫监视 / 免疫自稳
            ↓              ↓
        不足 / 过强     异常 / 正常
            ↓              ↓
   免疫缺陷 / 超敏反应   肿瘤 / 自身免疫病
```

### 三、与其他概念节点的关系

- **超敏反应**分类（Coombs & Gell）详见后续课程 — 本节点仅做总览。
- **自身免疫耐受**建立失败机制：胸腺阴性选择缺陷（AIRE 突变 → APECED）、调节性 T 细胞（Treg）功能异常、分子模拟、隐蔽抗原释放等。
- **免疫缺陷**机制：原发性（遗传突变，如 BTK、IL2RG、ADA、 CYBB 等）；继发性（感染、营养、药物、肿瘤）。

## Clinical Consequences

| 异常 | 主要临床表现 |
|------|--------------|
| 免疫缺陷 | 反复感染（类型提示缺陷环节：胞外菌 → 体液免疫；胞内菌 / 真菌 / 病毒 → 细胞免疫；机会性感染 → 严重免疫缺陷） |
| 超敏反应 | 速发型（I 型）：荨麻疹、过敏性休克、哮喘；细胞毒型（II 型）：输血反应、新生儿溶血；免疫复合物型（III 型）：血清病、SLE 部分机制；迟发型（IV 型）：接触性皮炎、结核菌素试验 |
| 自身免疫病 | 多系统受累（SLE）、器官特异性（T1DM、桥本甲状腺炎、MS） |
| 肿瘤 | 取决于原发肿瘤 |
