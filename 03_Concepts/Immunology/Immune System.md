# Immune System（免疫系统）

## Definition

免疫系统是机体执行免疫功能的物质基础，由免疫器官和组织、免疫细胞、免疫分子三部分组成，承担**免疫防御、免疫监视、免疫自稳**三项基本功能。

## Normal Mechanism

### 一、免疫系统的组成

#### 1. 免疫器官与组织

| 类别 | 器官 / 组织 | 主要功能 |
|------|-------------|----------|
| 中枢免疫器官 | 胸腺（Thymus） | T 细胞发育、分化、成熟 |
| 中枢免疫器官 | 骨髓（Bone marrow） | 各类血细胞和免疫细胞发生；B 细胞、NK 细胞分化成熟；再次体液免疫应答场所 |
| 外周免疫器官 | 脾脏（Spleen） | T、B 细胞定居；血源性抗原免疫应答主要场所；过滤血液；合成补体、细胞因子 |
| 外周免疫器官 | 淋巴结（Lymph node） | T、B 细胞定居；免疫应答场所；过滤淋巴液；参与淋巴细胞再循环 |
| 免疫组织 | MALT（黏膜相关淋巴组织） | 局部黏膜免疫应答；产生分泌型 IgA |
| 免疫组织 | 皮肤相关淋巴组织 | 局部皮肤免疫 |
| 免疫组织 | 肝脏 | 兼具免疫耐受器官功能；库普弗细胞；NK/NKT 主要储存场所；含 LSEC、stellate cell、肝实质细胞等 APC |

##### 骨髓要点

- 造血位点：**卵黄囊 → 胎肝 → 骨髓**
- **造血干细胞（HSC）**：具有高度自我更新能力与多能分化潜能
- 人 HSC 主要表面标志：**CD34⁺、CD117⁺**，不表达成熟血细胞标志
- 骨髓造血微环境：①细胞外基质 ②骨髓基质细胞 ③多种细胞因子
- 功能：
  1. 各类血细胞和免疫细胞发生场所
  2. **B 细胞、NK 细胞**分化成熟场所
  3. **再次体液免疫应答**发生场所（浆细胞）

##### 胸腺要点

- 结构：皮质（cortex）+ 髓质（medulla）
- 细胞组成：胸腺细胞（thymocyte）+ 胸腺基质细胞（TSC = TEC、Mφ、DC、成纤维细胞等）
- 功能：
  1. T 细胞发育成熟场所
  2. 免疫调节（细胞因子 / 胸腺肽影响外周）
  3. **自身免疫耐受**的建立与维持（AIRE → TSA → autoreactive T cell deletion）

##### 淋巴结要点

- 结构：
  - **浅皮质区**（非胸腺依赖区）：B 细胞定居（~25%）
    - 初级淋巴滤泡（无生发中心）
    - 次级淋巴滤泡（生发中心 GC，抗原刺激后形成）
  - **深皮质区 / 副皮质区**（胸腺依赖区）：T 细胞定居（~75%）
    - 含 DC
    - **HEV（高内皮微静脉）**：沟通血液循环与淋巴循环
  - **髓质**：髓索（B 细胞、浆细胞、部分 T、Mφ）+ 髓窦（富含 Mφ）
- 功能：①成熟 T、B 细胞定居场所 ②免疫应答场所 ③过滤作用 ④参与淋巴细胞再循环

##### 脾脏要点

- 实质：**白髓**（密集淋巴组织）+ **红髓**（脾索、脾血窦，衰老 RBC / 血小板清除与储藏）
- 白髓分区：
  - **动脉周围淋巴鞘（PALS）**：T 细胞区（~40%）
  - **脾小结 / 淋巴滤泡**：B 细胞区（非胸腺依赖区），受抗原刺激后出现生发中心
- 功能：①T、B 细胞定居场所 ②免疫应答场所（**血源性抗原主战场**）③合成补体、细胞因子 ④过滤作用（约 90% 循环血液流经脾）

##### MALT（黏膜相关淋巴组织）

- 包括：呼吸道、消化道、泌尿生殖道黏膜上皮与固有层的淋巴细胞 + 扁桃体、派尔集合淋巴结（PP）、阑尾
- 肠相关淋巴组织（GALT）：
  - 派尔集合淋巴结（PP）+ 孤立淋巴滤泡
  - 上皮内淋巴细胞（IEL）：~40% αβT、~60% γδT
- **M 细胞**：特化的抗原转运细胞，无微绒毛，不分泌消化酶和黏液
- 功能：①局部黏膜免疫应答（免疫屏障）②产生**分泌型 IgA**

#### 2. 免疫细胞（概览）

详见 [[Innate Immunity]] 与 [[Adaptive Immunity]]。

| 分类 | 代表细胞 |
|------|----------|
| 经典固有免疫细胞 | 中性粒细胞、嗜酸性粒细胞、嗜碱性粒细胞、单核/巨噬细胞、树突状细胞、肥大细胞 |
| 非经典固有免疫细胞 | ILCs（ILC1/ILC2/ILC3、NK）、B1、γδT |
| 适应性免疫细胞 | T 淋巴细胞、B 淋巴细胞 |

#### 3. 免疫分子

| 类别 | 代表成员 |
|------|----------|
| 膜型分子 | CD 分子、黏附分子、MHC 分子、细胞因子受体、TCR、BCR |
| 分泌型分子 | 免疫球蛋白（抗体）、补体、细胞因子 |

### 二、免疫系统的基本功能

| 功能 | 英文 | 含义 |
|------|------|------|
| **免疫防御** | immune defense | 防止外界病原体入侵；清除已入侵的病原体及其他有害物质 |
| **免疫监视** | immune surveillance | 发现并清除体内"非己"成分（基因突变产生的肿瘤细胞、衰老/死亡细胞） |
| **免疫自稳** | immune homeostasis | 通过自身免疫耐受 + 免疫调节维持内环境稳定 |

### 三、免疫功能异常的后果（与基本功能对照）

| 功能 | 不足 | 过强 | 异常（针对自身） |
|------|------|------|------------------|
| 免疫防御 | 免疫缺陷（反复感染、肿瘤易感） | 超敏反应（食物过敏、哮喘） | — |
| 免疫监视 | 肿瘤 | — | — |
| 免疫自稳 | — | — | 自身免疫病（如系统性红斑狼疮） |

## Key Components / Steps

```
免疫系统
├── 物质组成
│   ├── 免疫器官与组织（中枢 / 外周 / 免疫组织）
│   ├── 免疫细胞（固有 / 适应性）
│   └── 免疫分子（膜型 / 分泌型）
├── 基本功能
│   ├── 免疫防御
│   ├── 免疫监视
│   └── 免疫自稳
└── 异常 → 免疫缺陷 / 超敏反应 / 肿瘤 / 自身免疫病
```

## Physiological Significance

- 免疫系统是机体抵御病原体、维持内环境稳态的核心系统。
- 三大功能互相补充：防御管"外敌"、监视管"内变"、自稳管"秩序"。
- 任一功能过度或不足均可导致疾病（见 [[Immune Dysregulation]]）。

## Clinical Relevance

- 骨髓移植与 HSC 标志（CD34、CD117）是血液 / 免疫重建的核心。
- 胸腺的自身耐受建立（AIRE）是理解自身免疫病的关键（见 [[Immune Dysregulation]]）。
- 脾切除后易发生**脾切除后凶险感染（OPSI）**——提示脾对血源性抗原免疫应答的核心地位。
- MALT 是黏膜疫苗（口服、吸入）作用的主要场所；分泌型 IgA 是黏膜免疫的核心效应分子。
- 肝脏的"免疫耐受"特性是肝移植成功率高的原因之一，也是口服耐受、口服抗原治疗自身免疫病的机制基础。
