# Immunogenicity Factors（影响抗原免疫原性的因素）

## Definition

决定抗原**能否诱导免疫应答**及**应答强度**的因素。包括**抗原自身性质、宿主因素、抗原进入机体的方式**三大方面。

## Pathological Mechanism

### （一）抗原自身性质（7 大因素）

| 因素 | 影响 |
|------|------|
| **1. 异物性** | 抗原与机体的亲缘**越远**，组织结构差异**越大**，免疫原性**越强** |
| **2. 化学属性** | 大分子有机物和蛋白质免疫原性最强（蛋白 > 多糖 > 脂类 > 核酸） |
| **3. 分子量** | 分子量**越大**，含抗原表位**越多**，免疫原性**越强**（一般 < 4 kDa 弱；> 10 kDa 强） |
| **4. 分子结构** | **复杂**分子结构免疫原性强（如含**苯环**氨基酸） |
| **5. 分子构象** | 构象表位是决定**中和抗体**诱生与否及抗体强度的关键 |
| **6. 可及性** | 抗原表位在空间上被 BCR **接近的程度**，显著影响免疫原性 |
| **7. 物理性状** | **聚合态、颗粒性**抗原免疫原性强 |

### （二）宿主因素

| 因素 | 影响 |
|------|------|
| **遗传因素** | **MHC 基因**高度多态性，决定个体对抗原的应答与否及程度 |
| **年龄** | 幼/老年免疫应答**弱** |
| **性别** | 雌性诱导抗体能力强，**自身免疫病发生率高** |
| **健康状态** | 免疫功能受损 → 应答下降 |

### （三）抗原进入机体的方式

| 因素 | 影响 |
|------|------|
| **抗原量** | 适量诱导应答；过低/过高可诱导**免疫耐受** |
| **接种途径** | **皮内 / 皮下**最易诱导免疫应答；**静脉 / 口服**易诱导免疫耐受 |
| **接种次数** | 多次接种 + 适当间隔可增强应答 |
| **佐剂** | 可显著改变免疫应答的**强度和类型** |

**接种途径强度排序**：**皮内 > 皮下 > 肌内 > 腹腔 > 静脉**
