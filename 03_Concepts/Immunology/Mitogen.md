# Mitogen（丝裂原）

## Definition

能够**非特异性刺激多克隆 T、B 淋巴细胞**发生有丝分裂的物质。属于非特异性淋巴细胞多克隆激活剂。

> [!info] 来源
> - [[02_Raw/Lectures/Medical Immunology/第三章 抗原(1).pdf]] — p44-45
> - 来源登记：[[Source-Registry#S-LEC-010]]

## Pathological Mechanism

### 机制

丝裂原直接与静息淋巴细胞表面的相应丝裂原受体结合 → **母细胞转化 + 有丝分裂** → 激活体内具有相应丝裂原受体的淋巴细胞克隆

### 常见丝裂原

| 丝裂原 | 缩写 | 来源 | 靶细胞 |
|--------|------|------|--------|
| **植物血凝素** | **PHA** | 红豆（菜豆）| **T 细胞** |
| **刀豆蛋白 A** | **ConA** | 刀豆 | **T 细胞** |
| **美洲商陆丝裂原** | **PWM** | 美洲商陆 | **T + B 细胞** |
| **脂多糖** | **LPS** | 革兰阴性菌细胞壁 | **B 细胞**（小鼠 B 细胞） |

### 临床应用：**淋巴细胞转化实验**

- 体外检测机体**细胞免疫功能**
- 步骤：分离淋巴细胞 → 加入丝裂原（PHA/ConA）→ 培养 3 天 → 检测 **³H-胸苷掺入** 或 **MTT**（反映增殖水平）
- 临床意义：
  - 评价细胞免疫功能
  - 诊断免疫缺陷病
  - 评估移植免疫状态
