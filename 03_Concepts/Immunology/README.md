# Immunology — 免疫学

免疫学相关知识节点。本目录按"学科（Discipline）"组织，**不按知识类型**拆分；同一目录下可有 `type: physiology` 与 `type: pathophysiology` 节点。

## 节点清单

- [[Immune System]] — 免疫系统组成与基本功能（type: physiology）
- [[Innate Immunity]] — 固有免疫（type: physiology）
- [[Adaptive Immunity]] — 适应性免疫（type: physiology）
- [[Immune Dysregulation]] — 免疫异常与疾病（type: pathophysiology）

## 待建节点（Knowledge Gaps）

见各节点"Related Concepts"列表中的"待建"标注：

### 细胞与分子

- Antigen（抗原）
- Antibody / Immunoglobulin（抗体 / 免疫球蛋白）
- Complement（补体）
- Cytokine（细胞因子）
- Cell Adhesion Molecule（细胞黏附分子）
- MHC（Major Histocompatibility Complex）
- TCR（T cell receptor）
- BCR（B cell receptor）

### 免疫细胞

- Neutrophil / Eosinophil / Basophil（粒细胞）
- Macrophage / Monocyte（单核/巨噬细胞）
- Dendritic Cell（DC）
- NK Cell
- Mast Cell（肥大细胞）
- T Cell / B Cell / Plasma Cell
- Regulatory T Cell（Treg）
- γδT Cell / B1 Cell

### 病理与疾病

- Hypersensitivity（超敏反应 — Coombs & Gell 分型）
- Autoimmunity（自身免疫）
- Immunodeficiency（免疫缺陷）
- Immune Tolerance（免疫耐受）
- Hypersensitivity Type I/II/III/IV（I/II/III/IV 型超敏反应）
- Asthma / SLE / RA / T1DM / MS 等具体 Disease 节点
