# Superantigen（超抗原，SAg）

## Definition

只需**极低浓度（1–10 ng/mL）**即可**非特异性**激活人体总 T 细胞库中 **2%–20%** T 细胞克隆、产生极强免疫应答的一类抗原物质。其效应并非针对超抗原本身，而是通过**非特异性激活免疫细胞，分泌大量炎性细胞因子**，导致**中毒性休克、多器官衰竭**。

## Pathological Mechanism

### 类别

| 类型 | 例子 |
|------|------|
| **外源性 SAg** | 金黄色葡萄球菌的 **SEA–SEE、TSST-1**、A 族链球菌致热外毒素等 |
| **内源性 SAg** | 小鼠乳腺肿瘤病毒蛋白等 |

### T 细胞超抗原 vs 普通抗原

| 维度 | T 细胞超抗原 | 普通抗原 |
|------|-------------|----------|
| 化学性质 | 细菌外毒素等 | 普通蛋白质、多糖等 |
| **MHC 结合部位** | **抗原结合槽外部** | **抗原结合槽内部** |
| **TCR 结合部位** | **Vβ 链 CDR3 外侧区域** | Vα、Jα 及 Vβ、Dβ、Jβ |
| **MHC 限制性** | **无** | 有 |
| 应答特点 | 直接激活**大量** T 细胞 | APC 加工后激活**特异性** T 细胞 |
| 反应细胞 | **CD4⁺ T 细胞** | T、B 细胞 |
| **T 细胞反应频率** | **1/50–1/5** | 1/10⁶–1/10⁴ |

### 致病机制

1. SAg 与 **MHC Ⅱ类分子外部** + **TCR Vβ 链**结合
2. **绕过抗原加工与提呈**，绕过普通抗原的特异性识别
3. 大量 T 细胞被激活 → 释放**大量细胞因子**（TNF-α、IL-1、IL-6、IFN-γ）
4. → **细胞因子风暴** → 中毒性休克、多器官衰竭

### 临床相关疾病

| 病原体 | 超抗原 | 疾病 |
|--------|--------|------|
| **金黄色葡萄球菌** | TSST-1 | **中毒性休克综合征（TSS）** |
| **A 族链球菌** | 致热外毒素 | **链球菌 TSS**、猩红热 |
| **金黄色葡萄球菌** | SEA、SEB 等 | **食物中毒**（催吐毒素） |
