# TD-Ag vs TI-Ag（胸腺依赖性 vs 胸腺非依赖性抗原）

## Definition

按抗原诱生抗体时**是否需要 Th 细胞辅助**进行分类的两类抗原：
- **TD-Ag（Thymus-Dependent Antigen）**：需要 T 细胞辅助
- **TI-Ag（Thymus-Independent Antigen）**：无需 T 细胞辅助

## Pathological Mechanism

### 对比

| 特性 | **TD-Ag** | **TI-Ag** |
|------|----------|----------|
| 化学组成 | **蛋白质** | **多糖** |
| 结构特点 | 复杂、含多种表位 | 简单、含单一表位 |
| 表位组成 | **B 细胞 + T 细胞表位** | **重复 B 细胞表位** |
| **T 细胞辅助** | **必需** | **无需** |
| **MHC 限制性** | 有 | 无 |
| 激活的 B 细胞 | B2 | B1 |
| 免疫应答类型 | 体液免疫 **+ 细胞免疫** | 仅**体液免疫** |
| 抗体类型 | IgG、IgM、IgA 等 | **仅 IgM** |
| **免疫记忆** | **有** | **无** |

### 例子

| 类型 | 例子 |
|------|------|
| **TD-Ag** | 绝大多数蛋白质抗原（白蛋白、BSA、OVA 等） |
| **TI-Ag** | **细菌脂多糖（LPS）**、**荚膜多糖**、聚合鞭毛素 |

### 临床意义

- **疫苗设计**：
  - **多糖疫苗**对儿童（< 2 岁）免疫原性弱（因 B1 细胞不成熟） → 需**结合蛋白载体**转化为 **TD-Ag**（如 **Hib 疫苗、肺炎球菌结合疫苗**）
  - **蛋白疫苗**可诱导 T 细胞依赖性应答与免疫记忆 → 长期保护
- **感染免疫**：
  - **胞外菌**（含荚膜多糖）→ 主要诱导 TI-Ag 应答（IgM 为主）
  - **病毒感染** → 主要诱导 TD-Ag 应答（IgG、CTL）
