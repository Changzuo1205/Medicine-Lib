# Medical Microbiology（医学微生物学）

## Definition

研究与医学有关的**病原微生物的生物学特性**和**致病机制**，**人体的抗感染免疫机制**，以及建立这些微生物所致**人类感染及感染性疾病**（含传染病）、**超敏反应性疾病**和**肿瘤**等的**病原学诊断方法**和**防治措施**的一门学科，以控制和消灭感染和相关疾病，达到保障和提高人类健康水平的目的。

## Normal / Pathological Concept

### 学科位置

医学微生物学是**基础医学与临床医学的桥梁学科**：
- 上游：微生物学（Microbiology）→ 普通生物学、化学、生物化学
- 下游：感染病学 / 临床各科感染性疾病

### 研究对象（病原体三大类）

| 类别 | 代表 |
|------|------|
| **非细胞型** | 病毒 |
| **原核细胞型** | 细菌、放线菌、支原体、衣原体、立克次体、螺旋体 |
| **真核细胞型** | 真菌 |

### 学科任务（三大方面）

1. **病原学（病因学）**：研究病原微生物的生物学特性（形态、结构、代谢、遗传变异）
2. **致病机制（发病学）**：研究病原微生物的致病性 + 人体抗感染免疫机制
3. **诊断与防治**：建立感染性疾病（含传染病）、超敏反应性疾病、肿瘤的病原学诊断方法和防治措施
