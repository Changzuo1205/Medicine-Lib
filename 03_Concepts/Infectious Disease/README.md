# Infectious Disease — 病原与感染性疾病 Ⅰ

> **学科全名**：病原与感染性疾病 Ⅰ（Medical Microbiology & Infectious Diseases I）
> **注册日期**：2026-09-07
> **学科层次**：基础医学 + 临床医学桥梁（病原生物学 → 感染性疾病诊疗）
> **关联导航**：
> - 专科导航：[[06_Specialties/Infectious Disease/README|06_Specialties/Infectious Disease]]
> - MOC：[[Infectious Disease MOC]]

## 学科范围

本学科涵盖以下知识域（按"病原 → 宿主防御 → 疾病 → 治疗"主线）：

### 1. 病原生物学（Pathogen Biology）

| 类别 | 代表病原 |
|------|----------|
| **细菌学** | 球菌（葡萄球菌、链球菌、肺炎球菌、脑膜炎奈瑟菌）、杆菌（大肠杆菌、伤寒沙门菌、志贺菌、霍乱弧菌、结核分枝杆菌、布鲁菌）、螺形菌（幽门螺杆菌、空肠弯曲菌）、厌氧菌（破伤风梭菌、肉毒梭菌、产气荚膜梭菌）等 |
| **病毒学** | RNA 病毒（流感、麻疹、风疹、腮腺炎、乙肝、丙肝、HIV、狂犬病、埃博拉、冠状病毒）、DNA 病毒（水痘、单纯疱疹、巨细胞、HPV、EBV）等 |
| **真菌学** | 浅部真菌（皮肤癣菌）、深部真菌（念珠菌、隐球菌、曲霉、肺孢子菌）等 |
| **寄生虫学** | 蠕虫（血吸虫、绦虫、线虫）、原虫（疟原虫、阿米巴、弓形虫、利什曼原虫）等 |

### 2. 感染与免疫（Infection & Immunity）

- 病原的致病性（毒力、侵袭力、毒素）
- 宿主抗感染免疫机制（与 [[03_Concepts/Immunology|Immunology]] 高度重叠）
- 感染的发生与发展：病原体 → 侵入 → 繁殖 → 损伤宿主 → 转归

### 3. 各系统感染性疾病（Infectious Diseases by System）

| 系统 | 代表疾病 |
|------|----------|
| **呼吸系统** | 肺炎（社区获得性 / 医院获得性）、肺结核、流感、COVID-19、百日咳、白喉 |
| **消化系统** | 感染性腹泻（细菌性痢疾、霍乱、伤寒、病毒性胃肠炎）、幽门螺杆菌感染、病毒性肝炎 |
| **泌尿生殖系统** | 尿路感染、肾盂肾炎、STD（淋病、梅毒、衣原体、HIV、生殖器疱疹、HPV） |
| **中枢神经系统** | 化脓性脑膜炎、病毒性脑膜炎/脑炎（HSV、HIV、日脑）、结核性脑膜炎 |
| **皮肤软组织** | 蜂窝织炎、丹毒、破伤风、皮肤癣菌病、单纯疱疹、带状疱疹 |
| **血流 / 心血管** | 感染性心内膜炎、败血症、感染性休克 |
| **全身 / 综合征** | 发热待查（FUO）、EBV / HIV / 疟疾等 |

### 4. 抗感染药物（Anti-infective Agents）

- 抗菌药物：β 内酰胺类（青霉素、头孢、碳青霉烯）、氨基糖苷类、大环内酯类、喹诺酮类、四环素类、糖肽类、磺胺类、抗结核药
- 抗病毒药物：核苷类（阿昔洛韦、更昔洛韦）、蛋白酶抑制剂、整合酶抑制剂、神经氨酸酶抑制剂等
- 抗真菌药物：唑类、棘白菌素、多烯类
- 抗寄生虫药物：青蒿素衍生物、氯喹、吡喹酮、阿苯达唑、甲硝唑

> 药物剂量与配伍**必须以权威指南为准**（详见 [[Infectious Disease MOC#Sources]]），本知识库**不存储具体剂量**，仅记录分类与机制。

### 5. 诊断与监测

- 微生物学检查（涂片、培养、药敏、血培养）
- 分子诊断（PCR、NGS）
- 免疫学检查（抗原 / 抗体检测，如 Widal、HBsAg、HIV Ab）
- 影像学（胸片 / CT 评估肺部感染）

## 待建节点（Knowledge Gaps）

### 病原（Pathogen）

按上述 4 大类别建立：

- 细菌：Staphylococcus aureus · Streptococcus pneumoniae · Mycobacterium tuberculosis · Escherichia coli · Salmonella typhi · Helicobacter pylori · Clostridium tetani/perfringens · …
- 病毒：Influenza virus · HBV / HCV · HIV · SARS-CoV-2 · HSV / VZV · HPV · EBV · 狂犬病毒 · …
- 真菌：Candida albicans · Cryptococcus neoformans · Aspergillus · Pneumocystis jirovecii · …
- 寄生虫：Plasmodium · Schistosoma · Entamoeba histolytica · Toxoplasma gondii · …

### 疾病（Disease）

- Pneumonia（肺炎） · Tuberculosis（肺结核） · Bacterial Meningitis · Infective Endocarditis · Sepsis · FUO
- 病毒性肝炎（A / B / C / D / E） · HIV / AIDS · COVID-19 · 流感 · 麻疹 / 风疹 / 腮腺炎 / 水痘
- 感染性腹泻（菌痢 / 霍乱 / 伤寒 / 病毒性胃肠炎）
- STD：Gonorrhea · Syphilis · Chlamydia · HPV · Genital Herpes
- 寄生虫病：Malaria · Schistosomiasis · Toxoplasmosis

### 药物（Drug）

按 4 大类别分别建立（详见模板 [[05_Drug]]）：

- 抗菌：Penicillin · Cephalosporins · Carbapenems · Aminoglycosides · Macrolides · Fluoroquinolones · Tetracyclines · Vancomycin · Metronidazole · Anti-TB drugs
- 抗病毒：Aciclovir · Ganciclovir · Oseltamivir · NRTIs · NNRTIs · PIs · INSTIs
- 抗真菌：Fluconazole · Voriconazole · Amphotericin B · Echinocandins
- 抗寄生虫：Artemisinin · Chloroquine · Praziquantel · Albendazole

### 机制（Pathophysiology）

- 病原致病性（Virulence / Invasion / Toxins）
- 抗感染免疫（与 [[03_Concepts/Immunology|Immunology]] 交叉）
- 脓毒症与感染性休克机制

### 检查（Test）

- 血培养 · 痰培养 · 尿培养 · 大便培养
- Widal 反应 · HBsAg / Anti-HBs / Anti-HCV · HIV Ab / Ag（第四代）
- PCR 检测 · 药敏试验 · G 试验 / GM 试验
- 胸片 / 胸部 CT（肺炎 / 肺结核特征）

### 临床推理（Clinical Algorithm）

- 发热待查（FUO）诊断思路
- 社区获得性肺炎（CAP）经验性治疗路径
- 医院获得性肺炎（HAP/VAP）管理

## 使用规则

1. **本目录定位**：本目录存放**病原 + 感染性疾病**的**整合性 Concept 节点**（即与感染直接相关的 Disease / Drug / Pathogen / Pathophysiology / Test）。
2. **Drug 节点归属**：抗感染药物原则上放 `03_Concepts/Infectious Disease/Drugs/`（详见后续规划），而不是 `03_Concepts/Drugs/`（后者留给非抗感染药物如心血管 / 内分泌药物）。
3. **与 [[03_Concepts/Immunology|Immunology]] 协作**：免疫学概念放 Immunology；本学科只放**感染相关**的免疫应用（如病原免疫逃逸、疫苗等）。
4. **来源优先**：所有感染性疾病、药物剂量必须以权威指南为准（UpToDate、IDSA、WHO、中华医学会指南等）。
5. **新节点链接**：建立 Disease 节点时，应建立与对应病原 + 药物 + 检查的双向链接。
