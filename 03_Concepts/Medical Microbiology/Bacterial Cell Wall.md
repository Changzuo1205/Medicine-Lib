# Bacterial Cell Wall（细菌细胞壁）

## Definition

包绕在细胞膜外的一层坚韧膜状结构，组成较复杂，随不同细菌而异。

## 革兰阳性菌与革兰阴性菌细胞壁结构比较

讲义比较表（数值与结论原样保留）：

| 细胞壁 | 革兰阳性菌 | 革兰阴性菌 |
|--------|------------|------------|
| 强度 | 较坚韧 | 较疏松 |
| 厚度 | 厚，20~80nm | 薄，10~15nm |
| 肽聚糖结构 | 聚糖骨架、四肽侧链、五肽交联桥 | 聚糖骨架、四肽侧链 |
| 肽聚糖层数 | 多，可达50层 | 少，1~2层 |
| 肽聚糖含量 | 多，占细胞壁干重50%~80% | 少，占细胞壁干重5%～20% |
| 糖类含量 | 多，约45% | 少，15%～20% |
| 脂类含量 | 少，1%～4% | 多，11%～22% |
| 磷壁酸 | + | − |
| 外膜 | − | + |

## 细胞壁厚度（讲义示意图标注）

讲义 p28 示意图的文字标注依次为：外膜（2-3nm）、肽聚糖（7-13nm）、20-80nm、10~15nm；其中 20~80nm 与 10~15nm 在 p27 表格中分别对应革兰阳性菌与革兰阴性菌的细胞壁厚度。

- 革兰阴性菌：外膜 2-3nm，肽聚糖 7-13nm，细胞壁厚度 10~15nm
- 革兰阳性菌：细胞壁厚度 20~80nm（即厚肽聚糖层）

## 主要功能及医学意义

1. 保护细菌和维持菌体形态：外部低渗环境，内部 5-25 个大气压
2. 物质交换：小孔、转运蛋白
3. 致病性：SPA（金黄色葡萄球菌 A 蛋白）、乙型链球菌 M 蛋白、LPS
4. 与耐药性有关：缺失、通透性改变
5. 与静电性有关：负电（磷壁酸、LPS）
6. 诱发机体免疫应答、与抗原性有关：磷壁酸、LPS

## Clinical Pearls

- 细胞壁与**耐药性**有关，机制涉及细胞壁**缺失**与**通透性改变**。
- 细胞壁成分参与**致病性**：SPA（金黄色葡萄球菌 A 蛋白）、乙型链球菌 M 蛋白、LPS。
- 细胞壁与**抗原性**及**免疫应答**诱发有关，代表性成分为**磷壁酸**与 **LPS**。
- 细胞壁为细菌提供**负电荷**（磷壁酸、LPS），并支撑外部低渗环境与内部 5-25 个大气压的压差。
- 革兰阳性菌细胞壁**较坚韧**（厚 20~80nm），革兰阴性菌细胞壁**较疏松**（薄 10~15nm）—— 该差异是 [[Peptidoglycan]]、[[Teichoic Acid]]、[[Outer Membrane]] 等结构差异的总和。
