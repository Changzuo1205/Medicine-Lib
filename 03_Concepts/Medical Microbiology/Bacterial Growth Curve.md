# Bacterial Growth Curve（细菌的生长曲线）

## Definition

细菌的生长曲线（growth curve）是把一定数量的细菌接种于培养基后，以**培养时间（小时）**为横轴、以**细菌数目的对数**为纵轴所绘制的曲线，反映细菌**群体**生长繁殖的规律；讲义将其分为**迟缓期、对数期、稳定期、衰亡期**四期，并在同一张图中同时画出**活菌数**与**总菌数**两条曲线。

> [!info] 来源
> - [[02_Raw/Lectures/Medical Microbiology/3 第2章 细菌的生理 .pdf|《第2章 细菌的生理》（赵巍，2026 秋）]] — p16–p19
> - 来源登记：[[Source-Registry#S-LEC-017]]

## 曲线的坐标与两条曲线

- **纵轴**：**细菌数目的对数**（讲义 p16 图纵轴标注为 6.0～9.0）
- **横轴**：**培养时间（小时）**（讲义 p16 图横轴标注为 0～30）
- 讲义 p16 图**同时画出两条曲线**：**活菌数**与**总菌数**
- 讲义 p16 图中四期依次标注为迟缓期、对数生长期、稳定期、衰亡期（p17 与 p19 正文称「对数期」）

## 四期的特点（讲义 p17）

| 分期 | 特点 |
|------|------|
| **迟缓期** | 细菌被接种培养基的**最初一段时间**，主要是**适应新环境**，同时为**分裂繁殖作物质准备** |
| **对数期** | **活菌数以恒定的几何级数增长** |
| **稳定期** | 由于**营养物质的消耗、代谢产物的堆积**，**繁殖数与死亡数几乎相等**；**活菌数保持相对稳定** |
| **衰亡期** | **活菌数减少** |

## 四期的特点与意义（讲义 p19）

> 讲义 p19 标题为「细菌的生长曲线：特点和意义」，是本章「掌握」层级的内容。

| 分期 | 特点与意义 |
|------|------------|
| **迟缓期** | **代谢活跃，分裂迟缓** |
| **对数期** | 活菌数以恒定的几何级数增长；**研究最佳时期：形态、生化反应、药敏** |
| **稳定期** | 活菌数保持相对稳定；**芽胞及代谢产物如外毒素和抗生素等产生** |
| **衰亡期** | 活菌数减少，死菌数增多（**衰退型**），**难以鉴定** |

> [!warning] 讲义未给出各期持续时间的具体数值
> 讲义 p16–p19 只给出曲线形状与各期特点，**未给出**迟缓期、对数期、稳定期、衰亡期各自的**持续时间数值**；本节点不代为补充。

## Clinical Pearls

- **对数期是研究最佳时期**：形态观察、生化反应、药敏试验均取此期（p19）。
- **稳定期是代谢产物的收获期**：**芽胞**及**外毒素、抗生素**等代谢产物在稳定期产生（p19）。
- **衰亡期菌体呈衰退型**，**难以鉴定**（p19）。
