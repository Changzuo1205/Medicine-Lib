# Bacterial Physicochemical Properties（细菌的理化性状）

## Definition

细菌是一类**代谢旺盛、代谢类型多样化**的生物，通过**摄取营养物质和合成所需物质**维持其生命活动。

> [!info] 来源
> - [[02_Raw/Lectures/Medical Microbiology/3 第2章 细菌的生理 .pdf|《第2章 细菌的生理》（赵巍，2026 秋）]] — p3–p6
> - 来源登记：[[Source-Registry#S-LEC-017]]

## 总体代谢特点（p3）

讲义以两条要点概括细菌的代谢特点：

- **代谢旺盛，代谢类型的多样化**
- **摄取营养物质和合成所需物质**

## 化学组成（p5）

细菌的化学组成包括三部分：

| 类别 | 成分 |
|------|------|
| **水** | — |
| **有机物** | **蛋白质、糖类、脂质和核酸** |
| **无机盐** | 参与**组成**、**酶活**、**跨膜梯度** |

**原核细胞特有成分**（讲义列出五项）：**肽聚糖**、**胞壁酸**、**磷壁酸**、**二氨基庚二酸（DAP）**、**吡啶二羧酸（DPA）**。

**成分比例**（讲义 p5 标注）：

| 比例 | 讲义对应内容 |
|------|--------------|
| **水 75%~90%** | 水 |
| **10%~25%** | **蛋白质 / 核酸 / 糖类 / 脂类** |
| 少量 | **维生素和无机盐** |
| — | **特有成分** |

> [!warning] 讲义未说明
> - 讲义**未说明** 10%~25% 是**全部干物质**还是**仅指有机物**（蛋白质/核酸/糖类/脂类是否全部落在这一档内，讲义未交代）。
> - 讲义**未给出** 蛋白质、核酸、糖类、脂类**各自的比例**，仅将其并列于同一档。

## 物理性状（p6）

讲义列出五项物理性状：

| 性状 | 内容 |
|------|------|
| **① 光学性质** | **半透明**（**吸收、折射**）—— 可用「**比浊法**」 |
| **② 表面积大** | 利于**物质交换**；**代谢旺盛，繁殖迅速** |
| **③ 带电现象** | **G⁺ 等电点（pI）为 2～3**、**G⁻ pI 为 4～5** —— 影响**染色反应、杀菌**等 |
| **④ 半透性** | 细胞**壁、膜**具半透性 —— **吸收营养，排出代谢产物** |
| **⑤ 内部渗透压高** | **G⁺ 20～25 个大气压**；**G⁻ 5～6 个大气压** |

> [!warning] 讲义未说明
> - 讲义**未给出**细菌**等电点的测定方法**。
> - 讲义**未说明** G⁺ 等电点（pI 2～3）**低于** G⁻（pI 4～5）的**原理**。

## Clinical Pearls

- **比浊法**直接建立在细菌**半透明**的光学性质（吸收、折射）之上，是讲义给出的性状—方法对应。
- **带电现象**影响**染色反应**与**杀菌** —— [[Gram Stain]] 与消毒灭菌效果的差异均与此相关。
- **内部渗透压高**（G⁺ 20～25 个大气压、G⁻ 5～6 个大气压）与细胞壁共同维持菌体形态；这一高压由 [[Bacterial Cell Wall]] 承受。
- **半透性**是细菌**吸收营养、排出代谢产物**的结构基础，与 [[Bacterial Nutrient Uptake]] 的转运机制衔接。
- **原核细胞特有成分**中的 **肽聚糖、胞壁酸、磷壁酸、DAP、DPA** 是细菌区别于真核细胞的化学标志 —— 其中 [[Peptidoglycan]] 与 [[Teichoic Acid]] 位于 [[Bacterial Cell Wall]]，**DPA** 与 [[Spore]] 的耐热性相关。
