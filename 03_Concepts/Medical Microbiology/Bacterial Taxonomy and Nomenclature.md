# Bacterial Taxonomy and Nomenclature（细菌的分类与命名）

## Definition

在**界/域**之下，把细菌按**门 → 纲 → 目 → 科 → 属 → 种**的层级逐级归类（**分类**），并按**拉丁文双名法**给每个菌种一个**属名 + 种名**的学名（**命名**）。

本节点处理的是**细菌内部**的分类层级与命名规则。与之相邻但**不同**的是 [[Microbial Classification]] —— 后者按**大小、有无细胞的基本结构、细胞核的分化程度和核酸组成**把微生物分为**非细胞型、原核细胞型、真核细胞型三大类**（[[Microbial Classification]] 依据《绪论》），而本节点依据讲义 p48–p50，处理的是**原核生物内部**的门、属、种与学名。本节点是讲义 p2 学习目标第 5 条「**描述细菌的分类及命名体系**」对应的内容。

## 分类依据与参考手册

- **伯杰氏系统细菌学手册（Bergey's Manual of Systemic Bacteriology）第 9 版** —— 讲义以「古老传统又现代」开篇介绍该手册。
- **鉴定和分类方法（讲义 p48，三类）**：

| 方法 | 依据 |
|------|------|
| **表型分类** | **形态、生理特性** |
| **分析分类** | **菌体组分、代谢产物组成与图谱特征** |
| **基因型分类** | **G+Cmol%、16S rＲＮＡ** |

- **新细菌的发表与公布**：新细菌命名在《**国际细菌杂志**》*International Journal of Systematic Bacteriology* 发表，由**国际细菌命名裁定委员会**公布。

## 分类层级与单位

**层级（p49）**：门 → 纲 → 目 → 科 → **属（genera）** → **种（species）**。

| 单位 | 讲义要点 |
|------|----------|
| **属（genera）** | 由**特色相近、密切相关的种**组成 —— 如**金黄色葡萄球菌、表皮葡萄球菌属于葡萄球菌属** |
| **种（species）** | 细菌的**基本分类单位**，**特性基本相同**；判据为 **DNA 同源性 ≥ 70%、⊿Tm 值 ≤ 5 ℃** |
| **亚种、型（type）** | **差异顺序大小**；同一种细菌基本性状相同而某些方面特征稍有不同便可分为不同的型别，如**血清型、生物型** |
| **菌株（strain）** | 对不同来源的同一菌种的细菌；有**标准菌株（如 ATCC）**、**模式菌株** |

**界/域（p48）**：原核生物 = **古生菌域（2 个门）** + **细菌域（24 个门）**；**550 多个属，细菌 2500 多个种**。

> [!warning] 讲义未标明
> 讲义 p48 把「**界/域**」并写为一个层级，p50 的表头写作「**界（域）：细菌域**」，但**未标出「界」与「域」是否为同一层级**，也未给出「界」在本分类体系中的具体名称。

## 命名规则

**拉丁文双名法（斜体）**：**属名**（**名词**，**首字母大写**）+ **种名**（**形容词**，**小写**）。

命名依据：

| 名称部分 | 依据 |
|----------|------|
| **属名** | **形态／发现者** |
| **种名** | **性状、疾病、寄居部位** |

## 大肠埃希菌的完整分类学位置（讲义 p50）

**中文名称**：大肠埃希菌　**外文名称**：*Escherichia coli*

| 层级 | 内容 |
|------|------|
| 界（域） | 细菌域 |
| 门 | 变形菌门（Bacteria） |
| 纲 | γ-变形菌纲（Proteobacteria） |
| 目 | 肠杆菌目（Enterobacteriales） |
| 科 | 肠杆菌科（Enterobacteriaceae） |
| 属 | 埃希氏菌属（*Escherichia*） |
| 种 | 大肠埃希菌（*E. coli*） |

## Clinical Pearls

- 讲义 p2 学习目标第 5 条要求「**描述细菌的分类及命名体系**」—— 复习时按「**依据（三类方法）→ 层级（门纲目科属种）→ 单位（属/种/亚种与型/菌株）→ 命名（双名法）**」四段串起来。
- **种是基本分类单位**，其判据是**分子层面**的：**DNA 同源性 ≥ 70%** 且 **⊿Tm 值 ≤ 5 ℃** —— 与表型分类（形态、生理特性）互为补充。
- **属名首字母大写、种名小写、学名斜体** —— 写作 *Escherichia coli* 或 *E. coli*；这是文献与试卷中的书写规范。
- 同一菌种**来源不同**即为不同**菌株**；标准菌株（如 **ATCC**）与**模式菌株**是分类与鉴定工作中的**参照物**。
- **葡萄球菌属**是讲义给出的「属」的示例：**金黄色葡萄球菌**与**表皮葡萄球菌**同属一个属，靠**型别／种**层面的差异区分 —— 与 [[Bacterial Morphology]] 中的形态与排列特征配合记忆。
