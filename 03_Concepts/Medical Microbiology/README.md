> **学科全名**：医学微生物学（Medical Microbiology）
> **注册日期**：2026-09-07（2026-09-08 从"病原与感染性疾病 Ⅰ"拆分独立）

> - 专科导航：[[06_Specialties/Infectious Disease/README|06_Specialties/Infectious Disease]]

## 学科范围

本学科涵盖**病原生物中的微生物部分**（病毒、细菌、真菌、支原体、衣原体、立克次体、螺旋体、放线菌）的：

### 1. 病原生物学（Pathogen Biology）

| 类别 | 代表病原 |
|------|----------|
| **病毒学** | RNA 病毒（流感、麻疹、风疹、腮腺炎、乙肝、丙肝、HIV、狂犬病、冠状病毒）、DNA 病毒（水痘、单纯疱疹、巨细胞、HPV、EBV）等 |
| **细菌学** | 球菌（葡萄球菌、链球菌、肺炎球菌、脑膜炎奈瑟菌）、杆菌（大肠杆菌、伤寒沙门菌、志贺菌、霍乱弧菌、结核分枝杆菌、布鲁菌）、螺形菌（幽门螺杆菌、空肠弯曲菌）、厌氧菌（破伤风梭菌、肉毒梭菌、产气荚膜梭菌）等 |
| **其他原核型** | 支原体、衣原体、立克次体、螺旋体、放线菌 |
| **真菌学** | 浅部真菌（皮肤癣菌）、深部真菌（念珠菌、隐球菌、曲霉、肺孢子菌）等 |

### 2. 感染与免疫（Infection & Immunity）

- 病原的致病性（毒力、侵袭力、毒素）
- 宿主抗感染免疫机制（与 [[03_Concepts/Immunology|Immunology]] 高度重叠）
- 感染的发生与发展：病原体 → 侵入 → 繁殖 → 损伤宿主 → 转归

### 3. 各系统感染性疾病（Infectious Diseases by System）

| 系统 | 代表疾病 |
|------|----------|
| **呼吸系统** | 肺炎（社区获得性 / 医院获得性）、肺结核、流感、COVID-19、百日咳、白喉 |
| **消化系统** | 感染性腹泻（细菌性痢疾、霍乱、伤寒、病毒性胃肠炎）、幽门螺杆菌感染、病毒性肝炎 |
| **泌尿生殖系统** | 尿路感染、肾盂肾炎、STD（淋病、梅毒、衣原体、HIV、生殖器疱疹、HPV） |
| **中枢神经系统** | 化脓性脑膜炎、病毒性脑膜炎/脑炎（HSV、HIV、日脑）、结核性脑膜炎 |
| **皮肤软组织** | 蜂窝织炎、丹毒、破伤风、皮肤癣菌病、单纯疱疹、带状疱疹 |
| **血流 / 心血管** | 感染性心内膜炎、败血症、感染性休克 |
| **全身 / 综合征** | 发热待查（FUO）、EBV / HIV / 疟疾等 |

### 4. 抗微生物药物（Anti-microbial Agents）

- **抗菌药物**：β 内酰胺类（青霉素、头孢、碳青霉烯）、氨基糖苷类、大环内酯类、喹诺酮类、四环素类、糖肽类、磺胺类、抗结核药
- **抗病毒药物**：核苷类（阿昔洛韦、更昔洛韦）、蛋白酶抑制剂、整合酶抑制剂、神经氨酸酶抑制剂等
- **抗真菌药物**：唑类、棘白菌素、多烯类

> 药物剂量与配伍**必须以权威指南为准**（详见 [[Infectious Disease MOC#Sources]]），本知识库**不存储具体剂量**，仅记录分类与机制。

### 5. 诊断与监测

- 微生物学检查（涂片、培养、药敏、血培养）
- 分子诊断（PCR、NGS）
- 免疫学检查（抗原 / 抗体检测，如 Widal、HBsAg、HIV Ab）
- 影像学（胸片 / CT 评估肺部感染）

### 细菌学 · 形态与结构（第 1 章）（20）

**总论（3）**

- [[Bacterium]] — 细菌定义（原始核质 + 肽聚糖）+ 广义 vs 狭义 + 6 类原核细胞型微生物
- [[Bacterial Morphology]] — 细菌的大小（μm）+ 三种基本形态 + 球菌排列 + 螺形菌 4 属
- [[Bacterial Structure]] — 基本结构 + 特殊结构总览（**枢纽节点**，链向下列全部子节点）

**细胞壁（6）**

- [[Bacterial Cell Wall]] — 定义 + G⁺/G⁻ 结构比较（厚度 / 层数 / 含量 / 糖脂比 / 磷壁酸 / 外膜）+ 6 项功能与医学意义
- [[Peptidoglycan]] — 聚糖骨架（N-乙酰葡糖胺 + N-乙酰胞壁酸，β-1,4 糖苷键）+ 四肽侧链 + 五肽交联桥；G⁺ 三维 15~50 层 vs G⁻ 二维 1~2 层；DAP 仅存于原核细胞；溶菌酶与青霉素作用位点
- [[Teichoic Acid]] — G⁺ 特殊组分；壁磷壁酸 / 膜磷壁酸（LTA 黏附素）；约占细胞壁干重 50%；负电荷与黏附性、抗原性
- [[Outer Membrane]] — G⁻ 特殊组分三部分：脂蛋白（稳定外膜）+ 脂质双层（OMP）+ 脂多糖
- [[Lipopolysaccharide]] — G⁻ 菌**内毒素**；脂质 A（无种属特异性）/ 核心多糖（属特异性）/ 特异多糖（O 抗原，种特异性）；S→R 变异；LOS 与免疫逃逸
- [[Bacterial L-Form]] — 细胞壁缺陷型；形成条件 3 条；原生质体 vs 原生质球；高度多形性、荷包蛋样菌落；慢性反复感染、常规培养阴性

**细胞膜 · 细胞质 · 核质（5）**

- [[Bacterial Cell Membrane]] — 厚约 7.5nm、占细胞干重 10~30%、**不含胆固醇**；物质转运 / 呼吸链 / 生物合成（PBP）/ 分泌系统 I~VII
- [[Bacterial Cytoplasm]] — 含核糖体、质粒、胞质颗粒；异染颗粒（白喉棒状杆菌鉴定）
- [[Bacterial Ribosome]] — 50S + 30S（真核 40S / 60S）；链霉素作用于 30S、红霉素作用于 50S
- [[Plasmid]] — 染色体外闭合环状双链 DNA；F / R / Vi / Col 质粒；接合传递
- [[Nucleoid]] — 核质（拟核）；无核膜核仁、单一闭合环状 dsDNA、单倍体

**特殊结构（4）**

- [[Capsule]] — 多糖（少数多肽）；大荚膜 ≥200nm / 微荚膜 <200nm / 黏液层；抗吞噬、黏附（生物被膜）、抗有害物质；荚膜肿胀反应
- [[Flagellum]] — 蛋白质丝状物；单毛菌 / 丛毛菌 / 周毛菌；运动 + 分类鉴定
- [[Pilus]] — 普通菌毛（黏附、致病力）vs 性菌毛（F 质粒编码、传递遗传物质与耐药性）
- [[Spore]] — 休眠形式；一个细菌只形成一个芽胞（**非繁殖方式**）；抵抗力强（DPA）→ 灭菌指标；厌氧梭菌与需氧芽胞杆菌

**检查法（2）**

- [[Gram Stain]] — 结晶紫 + 碘液 → 95% 乙醇脱色 → 复红复染；鉴别 / 选药 / 致病性三大意义
- [[Acid-Fast Stain]] — 抗酸细菌（分枝杆菌属）；苯酚复红加热 → 3% 盐酸乙醇 → 亚甲蓝；阳性红色

## 使用规则

1. **本目录定位**：存放**微生物相关**的 Concept 节点（Disease / Drug / Pathogen / Pathophysiology / Test）。
2. **寄生虫相关节点** → [[../Human Parasitology/README|Human Parasitology]] 学科目录（已拆分独立）。
3. **Drug 节点归属**：抗感染药物原则上放在本目录的 `Drugs/` 子目录（待建立）；非抗感染药物放 `[[03_Concepts/Drugs/README|Drugs]]`。

5. **来源优先**：所有感染性疾病、药物剂量必须以权威指南为准（UpToDate、IDSA、WHO、中华医学会指南等）。
