# Amyloidosis（淀粉样变）

## Definition

**Amyloidosis（淀粉样变）**，讲义作 **amyloid change**：**细胞间质内淀粉样蛋白质和黏多糖复合物的蓄积**，具特征性淀粉样染色反应。

> 鉴别要点：形态上与 [[Hyaline Degeneration]] 相似（HE 染色均质红染），但**化学成分不同**，需**特染证实**。

## Pathological Mechanism

```text
免疫球蛋白轻链 / 激素 / 降钙素前体蛋白等
   ↓
缺乏酶消化
   ↓
在细胞间质中沉积
```

## Pathological Changes

- **镜下**：**淡红均质**物质；沉积部位：
  - 细胞间质
  - **小血管基膜下**
  - **沿网状纤维支架**

## Special Stains（诊断关键）

| 染色 | 阳性表现 | 备注 |
|------|----------|------|
| **碘液 → 稀硫酸** | 棕褐色 → **蓝色** | 经典淀粉样反应 |
| **刚果红** | 橘红色 → **苹果绿（偏振光下）** | 临床病理最常用 |

## Clinical Forms

| 类型 | 部位 / 病因 |
|------|-------------|
| **局部性** | 皮肤、舌、喉、肺、脑；**多发性骨髓瘤**、**髓样癌** |
| **全身性** | **原发性**（血清 — 多与免疫球蛋白轻链沉积相关）；**继发性**（常见于**肝脏**慢性疾病） |

## Clinical Consequences / Outcomes

- 沉积于实质器官间质 → 器官结构受压、功能障碍
- 累及小血管基膜下 → **血管壁增厚、管腔狭窄 → 缺血**
- 诊断依赖特染（刚果红 + 偏振光苹果绿）
