# Apoptosis（凋亡）

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—组织细胞适应与损伤.docx|《病理学》第一章 笔记（优课联盟 UOOC，2026 秋）]] — 第四节（凋亡）
> - 来源登记：[[99_System/Source-Registry#S-LEC-011|S-LEC-011]]
> - evidence_level: C（医学教育资料）；source_status: needs_review

## Definition

**Apoptosis（凋亡）**：**活体局部组织中单个细胞程序性细胞死亡的形态表现**，**触发细胞内预存的死亡程序**而导致的**细胞主动性死亡**，**以质膜完整、凋亡小体形成为特征，不引起周围炎症反应**。

又称 **Programmed Cell Death, PCD（程序性细胞死亡）**。

属于 **调节性细胞死亡**（参见 [[Cell Death]]），形态和生化特征与 [[Necrosis]] 不同。

## Physiological & Pathological Context

凋亡在以下情境中发挥作用：

- **胚胎发育**
- **萎缩老化**
- **炎症**
- **自身免疫病**
- **肿瘤进展**

## Morphological Features（形态学特征）

### 1. 细胞皱缩

- **胞质致密**
- **水分减少**
- 呈**高度嗜酸性**
- 与周围细胞**分离**

### 2. 染色质凝聚

- **核染色质固缩或边集**
- **核碎裂**

### 3. 凋亡小体（Apoptosis Body）— **重要形态学标志**

```
胞质生出芽突并脱落
            ↓
形成含核碎片和/或细胞器的膜包小体
            ↓
被巨噬细胞和相邻实质细胞吞噬降解
```

### 4. 质膜完整

- **不引起周围炎症反应**
- **不引起增生修复反应**

> [!example] 经典举例
> **病毒性肝炎** → 肝细胞凋亡 → **嗜酸性小体**（Councilman body）

## Biochemical Mechanism（生化机制）

| 关键酶 / 通路 | 作用 |
|---------------|------|
| **凋亡蛋白酶**（**天冬氨酸蛋白酶 / caspase**） | **破坏细胞骨架及核骨架** |
| **核酸内切酶** | **DNA 规律降解片段（180–200 bp）**，电泳呈**梯状带**（DNA ladder） |

> [!note] 经典生化证据
> **DNA 梯状带**（180–200 bp）是凋亡区别于坏死（弥散降解）的关键生化特征。

## Gene Regulation（基因调控）

| 调控方向 | 代表基因 |
|----------|----------|
| **促进凋亡** | **TP53** |
| **抑制凋亡** | **BCL2** |
| **双向调节** | **CMYC** |

## Signal Pathways（信号传导）

### ① 凋亡信号传导（外源性 / 死亡受体通路）

- **肿瘤坏死因子受体（TNF-α）**
- **Fas-FasL** 通路

### ② 中央线粒体调控（内源性通路）

- **线粒体通透性改变**
- **促凋亡分子激活**

### ③ 结构改变

- **酶促级联反应**
- **凋亡小体形成**

## Disease Associations（疾病关联）

### 凋亡不足 → 肿瘤发生

- **TP53 基因突变 / 失活** → **不能诱导凋亡** → DNA 损伤细胞**瘤性转化**

### 凋亡过度 → 组织损伤

- **神经变性**（如阿尔茨海默病、帕金森病 — 讲义未涉及细节）
- **缺血损伤**
- **病毒感染** → **大量细胞凋亡过度**

## Comparison: Apoptosis vs Necrosis（凋亡 vs 坏死）

| 特征 | 凋亡（Apoptosis） | 坏死（Necrosis） |
|------|-------------------|-------------------|
| 触发 | 基因调控的程序 | 病理性损伤 |
| 范围 | **单个细胞** | **成片细胞** |
| 质膜 | **完整** | 破裂 |
| 细胞 | **皱缩** | **肿胀** |
| 细胞核 | **染色质凝聚 / 碎裂** | 核固缩 / 核碎裂 / 核溶解 |
| 结局 | **凋亡小体**被吞噬 | 酶溶性溶解 |
| 炎症反应 | **无** | **有** |
| 干预 | **可加速或延缓** | 不可控 |
