## Definition

**Atrophy（萎缩）**：已发育正常的细胞、组织或器官的**体积缩小**，可伴有**实质细胞数量的减少**。

> 与"未发育 / 发育不全"区别：后者为器官完全性未发育或先天性部分未发育，不属于萎缩。

## Etiology / Causes

| 类别 | 亚型 | 典型举例 |
|------|------|----------|
| **生理性萎缩** | — | 青春期**胸腺**萎缩；更年期**性腺**萎缩 |
| **病理性萎缩**（6 种） | 营养不良性 | 全身：慢性消耗 → 恶病质；局部：脑动脉粥样硬化 |
|  | **压迫性** | 长期受压缺氧缺血 → 肾盂积水、肾实质受压萎缩 |
|  | **失用性** | 长期负荷功能代谢低下 → 肌肉萎缩、骨质疏松 |
|  | **去神经性** | 运动神经元或轴突损伤 → 骨骼肌萎缩 |
|  | **内分泌性** | 下丘脑、垂体损伤 → 甲状腺、肾上腺、性腺萎缩 |
|  | **老化与损伤性** | 退行性变、慢性炎症、细胞凋亡（如阿尔茨海默病） |

**复合型举例**：骨折后肌肉萎缩 = **神经性 + 营养性 + 失用性 + 压迫性** 共同作用。

## Pathological Mechanism

- **合成代谢降低**
- **能量需求降低**
- **原有功能下降**

本质上是细胞主动下调自身合成与功能以适应不良环境的过程。

## Pathological Changes

| 维度 | 表现 |
|------|------|
| **大体** | 体积缩小、重量减轻、色泽加深；心、肝等可呈**褐色萎缩（brown atrophy）** |
| **光镜** | 细胞数量和体积减少；胞浆内可见**脂褐素（lipofuscin）颗粒** |
| **电镜** | 未被彻底消化、富含磷脂的**膜包被细胞器残体** |

## Clinical Consequences / Outcomes

- **病因去除后，轻度萎缩可恢复**。
- **持续萎缩 → 细胞最终死亡**。
- 临床意义：早期识别并去除致萎缩因素（如康复训练、神经修复、血供恢复）是组织功能恢复的关键。
