# Caseous Necrosis（干酪样坏死）

> [!info] 来源

## Definition

**Caseous Necrosis（干酪样坏死）**：一种特殊类型的坏死，**水解酶活性受到抑制**，坏死物**不易溶解、不易被吸收**。

讲义原文写作"干酪样**样**坏死"（typo）。属于 [[Necrosis]] 类型之一。

## Pathological Mechanism

```
（水解酶活性受到抑制）
            ↓
坏死物不易溶解 + 不易被吸收
            ↓
形成质软细腻、似干酪的坏死物
```

## Pathological Changes

### 大体（Gross）

- **淡黄色**
- **质软、细腻似干酪**

### 镜下（Microscopic）

- **红染无结构颗粒状物**
- **原有组织结构消失**
- 讲义评价：**彻底的凝固性坏死**

## Common Settings（典型疾病）

- **结核**最常见
- 偶见于：**梗死、肿瘤、结核样麻风**等

> [!note] 与凝固性坏死的关系
> 干酪样坏死属于一种**彻底的凝固性坏死**（讲义），但因水解酶受抑制，组织结构完全消失、不保留轮廓，这与典型 [[Coagulative Necrosis]] 短期保留轮廓的特征不同。
