## Definition

**Cell Injury（细胞和组织损伤）**：当内外环境的病理性刺激**超出细胞、组织的适应能力**时，受损细胞和细胞间质出现的**异常变化**（代谢、结构和功能）。

是介于 [[Cellular Adaptation and Injury|第一章 MOC]]（适应 → 可逆 → 代偿） 与 [[Cell Death]] 之间的关键阶段。

## Etiology / Causes

| # | 类别 | 英文 | 典型举例 / 备注 |
|---|------|------|------------------|
| 1 | **缺氧** | Hypoxia | 心肺功能衰竭、贫血、CO 中毒；**最常见、最重要的中心环节** |
| 2 | **生物** | Biological | 细菌、病毒、支原体、真菌等；**最常见** |
| 3 | **物理** | Physical | 冷热、辐射、电流、机械力 |
| 4 | **化学** | Chemical | 无机/有机毒物、生物毒素、代谢产物、药物 |
| 5 | **营养失衡** | Nutritional | 缺乏 VitD、蛋白、碘、微量元素；高热量 |
| 6 | **神经内分泌** | Neuroendocrine | 原发性高血压、溃疡病、甲亢、糖尿病 |
| 7 | **免疫** | Immunologic | 哮喘、过敏性休克、SLE、HIV（免疫缺陷） |
| 8 | **其他** | Other | 遗传性缺陷、社会心理疾病、医源性损伤 |

## Pathological Mechanism

| 机制 | 关键点 |
|------|--------|
| **细胞膜损伤** | 通透性和完整性破坏 |
| **线粒体损伤** | ATP 生成下降；**不可逆损伤的重要早期标志** |
| **活性氧类物质（ROS）** | O₂⁻·、·OH、·ClO、NO·、H₂O₂ |
| **自由基** | 原子最外层偶数电子失去一个形成的基团，强氧化活性 |
| **胞质内游离钙损伤** | 游离钙增多→酶活化→降解破坏 |
| **缺血缺氧损伤** | **最常见、最重要的中心环节** |
| **化学性损伤** | 药物、毒物、代谢产物 |
| **遗传变异** | 先天遗传、胚胎发生期、出生后获得 |

## Pathological Changes

> 讲义未单列形态学总览；具体可逆 / 不可逆损伤的形态学特征见：
> - 可逆性损伤 → [[Cellular Swelling]]、[[Fatty Change]]、[[Hyaline Degeneration]]、[[Amyloidosis]]、[[Mucoid Degeneration]]、[[Pathologic Pigmentation]]、[[Pathologic Calcification]]
> - 不可逆性损伤 → [[Cell Death]]、[[Necrosis]]、[[Apoptosis]]

## Clinical Consequences / Outcomes

- **较轻损伤**：消除病因后→恢复正常 → 可逆
- **严重损伤**：超出耐受 → [[Cell Death|不可逆性损伤]]（坏死 / 凋亡）
- 损伤与适应、修复共同构成细胞对病理性刺激的完整反应谱
