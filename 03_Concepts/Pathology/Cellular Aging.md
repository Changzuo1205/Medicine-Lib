# Cellular Aging（细胞老化）

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—组织细胞适应与损伤.docx|《病理学》第一章 笔记（优课联盟 UOOC，2026 秋）]] — 第一节 · 五、细胞老化（paragraphs 102–107）

> - evidence_level: C（医学教育资料）；source_status: needs_review

## Definition

**Cellular Aging（细胞老化）**：**生物体年龄增长**而发生的**细胞退行性变化**。

## Pathological Mechanism

- **复制能力降低**
- **DNA 损伤**累积
- **蛋白质结构等变化**

## Features / 特征

| 特征 | 含义 |
|------|------|
| **普遍性** | 所有细胞类型在生命后期都会出现退行性变 |
| **不可逆性** | 一旦进入老化阶段，无法逆转回年轻细胞 |
| **内在基因决定性** | 受基因程序调控 |
| **有害性** | 削弱组织储备与应激能力 |

## Pathological Changes

| 维度 | 表现 |
|------|------|
| **细胞** | 体积缩小 |
| **细胞器** | 数量减少 |
| **色素** | **脂褐素（lipofuscin）沉着** |
| **器官** | 重量减轻、间质硬化 |

> 脂褐素沉着是细胞老化的**形态学标志**，与[[Atrophy]]的褐色萎缩形态类似但成因不同（前者时间依赖、后者由功能需求下降所致）。

## Clinical Consequences / Outcomes

- **功能代谢降低，储备不足**
- **似生理性萎缩**

> [!info] Clinical Reasoning
> 讲义（PARA 102–107）只给出特征的**名称**（普遍性 / 不可逆性 / 内在基因决定性 / 有害性）与结局「似生理性萎缩」，
> **未给出机制**（如端粒缩短、氧化损伤）也未给出"叠加损伤性、营养性因素"的说法。
> 原稿曾把这两处写成确定事实，与本文其他位置"讲义未涉及细节"的标注口径不一致 → 已删除；
> 如需补充机制请另找来源并标注 `evidence_level` / `source_status`（AGENTS.md §26/§32）。
- 临床意义：储备功能下降 → 老年人对应激、药物、损伤的耐受能力减退
