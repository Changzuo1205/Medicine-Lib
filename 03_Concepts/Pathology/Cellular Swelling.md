# Cellular Swelling（细胞水肿 / 水变性）

## Definition

**Cellular Swelling（细胞水肿）**，又称 **Hydropic Degeneration（水变性）**：**最早出现的可逆性损伤**形态学改变，表现为细胞内 Na⁺、水含量增多所致的细胞肿胀。

## Pathological Mechanism

讲义所列机制链：

```text
缺血 / 缺氧 / 感染 / 中毒
   ↓
线粒体受损
   ↓
ATP 生成减少
   ↓
膜 Na⁺-K⁺ 泵功能障碍
   ↓
细胞内 Na⁺ 积聚
   ↓
细胞吸水 → 肿胀
```

## Common Sites

- **肝、肾、心**等器官的**实质细胞**

## Pathological Changes

| 层面 | 改变 |
|------|------|
| **电镜** | 线粒体、内质网等细胞器肿胀 |
| **光镜** | 细胞肿胀；胞浆内见**红染细颗粒样物**，胞核居中；明显肿胀时胞浆疏松淡染呈空泡状，核肿胀 → **气球样变**（ballooning degeneration） |
| **肉眼** | 器官**体积增大、边缘圆钝、包膜紧张、切面外翻、颜色变淡** |

## Clinical Consequences / Outcomes

- **可逆性**：病因去除、ATP 供应恢复后→细胞恢复正常
- 若损伤持续加重 → 进入 [[Cell Death]] 阶段（坏死 / 凋亡）
