# Coagulative Necrosis（凝固性坏死）

## Definition

**Coagulative Necrosis（凝固性坏死）**：坏死组织**蛋白质变性凝固，溶酶体酶水解作用弱**，因此组织结构在一段时间内仍可保留轮廓。

为坏死最常见的类型之一（参见 [[Necrosis]]）。

## Pathological Mechanism

```
缺血缺氧 / 毒素
       ↓
结构蛋白和酶蛋白变性
       ↓
溶酶体酶水解作用被抑制（弱）
       ↓
延缓分解过程 → 组织结构轮廓短期保留
```

## Pathological Changes

### 大体（Gross）

- **灰白或灰黄**
- **干燥、质实**
- 与健康组织**分界较明显**
- 周边围绕暗红条带（充血、出血、炎症反应）

### 镜下（Microscopic）

- 坏死细胞**微细结构消失**
- **组织结构轮廓仍可保留一段时间**（特征性表现）
- 周围**充血、出血和炎症反应带**

## Common Sites（好发部位）

**心、肝、肾、脾等实质器官**（多为缺血性梗死后的典型表现）
