# Congestion（淤血）

## Definition

**Congestion（淤血）**：**静脉回流受阻** → **毛细血管和小静脉内血液淤积** → **局部血量增加**。

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—血障.docx|《病理学》第三章 笔记（优课联盟 UOOC，2026 秋）]] — 第一节 · 二、淤血（paragraphs 006–007、023–037）
> - 来源登记：[[99_System/Source-Registry#S-LEC-015|S-LEC-015]]

## 本节共同特点与分类

讲义在本节开篇给出**充血与淤血共同**的前提：**特点**为**局部组织血管内血液含量增多**；**分类**依据**发生的部位、原因、病变和机体影响**不同。

## 特点：被动过程

- 淤血是**被动**过程。
- 可**局部**或**全身**发生。

## 原因（3 类）

| 类别 | 举例 |
|------|------|
| **1、静脉受压** | **肿瘤**、**妊娠子宫**、**肝硬化**、**肠疝或扭转**等 |
| **2、静脉腔阻塞** | **下肢深静脉血栓形成**、**静脉内瘤栓** |
| **3、心力衰竭** | **心腔内血液滞留、压力增高、阻碍静脉回流** |

## 举例：从心衰到淤血部位

| 上游病变 | 中间环节 | 淤血部位 |
|----------|----------|----------|
| **二尖瓣或主动脉瓣狭窄、高血压后期** | **左心衰** | **肺淤血** |
| **肺源性心脏病** → **肺动脉高压** | **右心衰** | **体循环淤血** |

> 肺淤血的形态与转归见 [[Pulmonary Congestion]]；肝淤血见 [[Hepatic Congestion]]。

## 形态改变

- **大体**：**肿胀暗红**，**重量增加**，**包膜紧张**，**边缘变钝**，**体表温度下降**。
- **发绀（cyanosis）**：**还原血红蛋白↑** → **体表淤血呈紫蓝色**。
- **镜下**：**细静脉及毛细血管扩张**，**过多红细胞（RBC）积聚**。

## 后果（5 类）

| 后果 | 发生基础 |
|------|----------|
| **淤血性水肿** | **流体静压和通透性增加** → **组织内漏出液潴留** |
| **淤血性积液** | **浆膜腔内漏出液积聚** |
| **淤血性出血** | **红细胞（RBC）漏出** ＋ **巨噬细胞吞噬** → **含铁血黄素** |
| **实质细胞萎缩、变性及坏死** | **缺氧** ＋ **营养不足** ＋ **代谢产物** |
| **淤血性硬化** | **间质纤维增生** ＋ **网状纤维胶原化** |

## Clinical Pearls

- **充血 vs 淤血一句话鉴别**：充血是**主动**、动脉输入血量增多、**鲜红**、**温度升高**；淤血是**被动**、静脉回流受阻、**暗红**、**体表温度下降**，可呈**紫蓝色**即**发绀（cyanosis）**。发绀的分子解释是**还原血红蛋白↑**。
- **三大原因的记忆顺序**：**外面被压（肿瘤、妊娠子宫、肝硬化、肠疝或扭转）→ 里面被堵（下肢深静脉血栓形成、静脉内瘤栓）→ 源头泵不动（心力衰竭）**。
- **慢性淤血 ≠ 良性可逆**：五大后果中，**实质细胞萎缩、变性及坏死**（缺氧 ＋ 营养不足 ＋ 代谢产物）与**淤血性硬化**（间质纤维增生 ＋ 网状纤维胶原化）提示长期淤血会造成**器官实质丧失与纤维化**。
- **淤血性出血的色素**：红细胞漏出后被**巨噬细胞吞噬**形成**含铁血黄素** —— 这是肺淤血中**心衰细胞（heart failure cells）**的同一机制（见 [[Pulmonary Congestion]]）。
- **肝硬化的因果关系方向要注意**：讲义把**肝硬化**列在淤血的**原因（静脉受压）**之中，而不是把淤血当作肝硬化的结果。
