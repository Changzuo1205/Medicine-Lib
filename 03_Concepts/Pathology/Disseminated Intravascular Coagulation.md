# Disseminated Intravascular Coagulation（弥散性血管内凝血）

> [!warning] 讲义覆盖度
> 本讲义（《病理学》第三章 笔记，优课联盟 UOOC，2026 秋）**没有 DIC 的专节**，讲义**未给出** DIC 的：定义、诊断标准、分期、实验室指标、治疗。本节点**仅汇总讲义中实际出现过的两类信息** ——（一）透明血栓与 DIC；（二）DIC 作为血栓对机体影响的后果（广泛性出血），并列出讲义中的交叉引用段落。凡讲义未讲到的内容，本节点一律不予补充。

## Definition

讲义未给出独立的 DIC 定义，只在两处提及：（一）**弥散性血管内凝血（disseminated intravascular coagulation, DIC）**是**透明血栓（微血栓）的形成原因**；（二）在血栓对机体影响中，DIC 对应**广泛性出血**，其结局为**凝血因子大量消耗 → 血液凝固障碍 → 出血性休克**。

## 一、透明血栓与弥散性血管内凝血（讲义 150–153 段）

- **透明血栓（hyaline thrombus）**
  - **部位**：**微循环毛细血管**内，又称**微血栓（microthrombus）**。
  - **形成**：**弥散性血管内凝血（disseminated intravascular coagulation, DIC）**。
  - **镜下**：由**纤维蛋白**构成，**均质红染**，又称**纤维蛋白性血栓（fibrinous thrombus）**。
- 类型归属：透明血栓是讲义所列血栓四种类型中的第四种（白色血栓、混合血栓、红色血栓、透明血栓），前三型的部位与形态见 [[Thrombus Types]]。

## 二、弥散性血管内凝血作为血栓的后果（讲义 182–186 段）

- **触发因素与凝血途径**：
  - **严重创伤 / 烧伤 / 羊水栓塞 / 肿瘤**等 → **促凝↑** → **外源凝血（+）**。
  - **感染 / 缺氧 / 酸中毒**等 → **广泛内皮损伤** → **内源凝血（+）**。
- **特点**：**微血管内形成透明血栓**（肺 / 肾 / 脑等）→ **广泛坏死及出血**。
- **后果**：**凝血因子大量消耗 → 血液凝固障碍 → 出血性休克**。

## 三、讲义中的其他交叉引用

讲义在三处病因清单中列出了 DIC，可作为定位该概念的旁证：

- **漏出性出血 · 血小板异常**（讲义 072 段）：讲义把 **DIC** 与再障、白血病、紫癜、药物或毒素并列为血小板异常的原因。→ 见 [[Hemorrhage]]
- **漏出性出血 · 凝血因子缺乏**（讲义 073 段）：讲义把 **DIC** 与血友病、肝脏疾病并列为凝血因子缺乏的原因。→ 见 [[Hemorrhage]]
- **血流状态异常（血栓形成条件二）· 原因**（讲义 111 段）：讲义把 **DIC** 与内膜炎、心梗、动脉粥样硬化、缺氧、败血症、毒素并列为血流状态异常的原因。→ 见 [[Thrombosis]]

## Clinical Pearls

- **透明血栓三要点（高频考点）**：**部位**为微循环毛细血管内 → 又称**微血栓**；**形成**原因为 **DIC**；**镜下**为纤维蛋白构成、**均质红染** → 又称**纤维蛋白性血栓**。
- **后果链**：**凝血因子大量消耗 → 血液凝固障碍 → 出血性休克**（出血的机制是凝血因子被**消耗**）。
- **受累器官举例**：讲义举**肺 / 肾 / 脑**等，表现为**广泛坏死及出血**。
- **触发因素两类**：创伤 / 烧伤 / 羊水栓塞 / 肿瘤等走**外源凝血**；感染 / 缺氧 / 酸中毒等经**广泛内皮损伤**走**内源凝血**。
- **交叉引用定位**：讲义在**漏出性出血**（血小板异常、凝血因子缺乏，072–073 段）与**血流状态异常**（111 段）的原因中都列有 DIC，可用于串联出血与血栓形成两节内容。
- **覆盖度提醒**：讲义**未**涉及 DIC 的诊断标准、分期、实验室指标与治疗，复习时不要从本节点外推这些内容。
