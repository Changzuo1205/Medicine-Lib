# Embolism（栓塞）

## Definition

**栓塞（embolism）**：循环血液中出现**不溶异物**，随血运行阻塞血管腔的现象。

阻塞血管的异物称为**栓子（embolus）**。

> - 来源登记：[[99_System/Source-Registry#S-LEC-015|S-LEC-015]]

## 栓子的性状分类

讲义按**性状**把栓子分为三类：

| 性状 | 栓子 |
|------|------|
| **固体** | 血栓 / 瘤栓 |
| **液体** | 脂滴 / 羊水 |
| **气体** | 空气 / 氮气 |

## 一、栓子的运行途径

讲义共列出 **5 种**运行途径。

### ① 体静脉系统和右心腔栓子

- 主要结局：栓塞肺 A 主干及分支 → **肺栓塞**
- 特殊情形：栓子小且有弹性 → 可通过肺泡壁 cap → 左心 → 体循环细小 A 栓塞

### ② 主动脉系统和左心腔栓子

- 去向：脑、脾、肾、四肢等动脉分支栓塞

### ③ 门静脉系统栓子

- 路径：胃肠、脾静脉回流 → 门静脉 → 肝内门静脉分支栓塞

### ④ 交叉性栓塞（crossed embolism）

- 又称**反常性栓塞**
- 病因：**先天性房或室间隔缺损，肺动脉导管未闭**
- 过程：右心腔压力高 → 穿过房或室间隔缺损 → 左心及动脉系统

### ⑤ 逆行性栓塞（retrograde embolism）

- 概念：胸腹压突然升高（咳嗽或深呼吸）→ 下腔静脉栓子短暂逆流
- 结局：栓塞下腔静脉回流分支（**肝、肾、髂静脉**）

## 二、栓塞的类型（总览）

讲义原文列举 4 类：

**血栓栓塞（99%）**、脂肪栓塞、气体栓塞、羊水栓塞。

其中**血栓栓塞**为最常见的类型，又可分两支，各自有独立节点：

| 血栓栓塞的分支 | 节点 |
|----------------|------|
| 肺动脉栓塞 | [[Pulmonary Embolism]] |
| 体循环动脉栓塞 | [[Systemic Arterial Embolism]] |

非血栓栓塞的 3 类亦各自建节点：

- [[Fat Embolism]] —— 液体栓子（脂滴）
- [[Gas Embolism]] —— 气体栓子（空气 / 氮气）
- [[Amniotic Fluid Embolism]] —— 液体栓子（羊水）

## （五）其他栓塞

讲义在 4 类栓塞之后另列**其他栓塞**：

- **细胞栓塞**：肿瘤、胎盘滋养叶、骨折骨髓细胞
- **胆固醇结晶**
- **寄生虫及虫卵**
- **菌栓**
- **异物**

## Clinical Pearls

- **规律性记忆点**：全身静脉系统的栓子（体静脉、右心腔，以及门静脉系统以外的路径）→ 肺；左心与主动脉系统的栓子 → 体循环器官；门静脉系统栓子 → 肝内门静脉分支。
- **交叉性栓塞**的前提是**先天性房或室间隔缺损、肺动脉导管未闭** —— 这是栓子能从右心侧越过到左心侧的解剖基础。
- **逆行性栓塞**的触发条件是**胸腹压突然升高**（咳嗽或深呼吸），使下腔静脉栓子发生**短暂逆流**，故栓塞部位是下腔静脉的回流分支（肝、肾、髂静脉），而不是肺。
- **数量与占比**：讲义写明**血栓栓塞占 99%**，是栓塞类型中绝对主要的一类。
- 栓子的**性状**（固体 / 液体 / 气体）只决定栓子来源分类；**运行途径**才决定栓塞发生在哪个器官 —— 两者不可混为一谈。
