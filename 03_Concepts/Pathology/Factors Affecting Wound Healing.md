# Factors Affecting Wound Healing（影响创伤愈合的因素）

## Definition

影响创伤愈合的因素包括：**损伤程度、再生能力、坏死、异物及感染**等（[146]）。

**治疗原则**：缩小创面，防止再损伤和感染，促进组织再生修复（[147]）。

## Systemic Factors

| 因素 | 作用 |
|------|------|
| **年龄** | 青少年再生能力强、愈合快；老年人愈合慢（血供减少）（[149]） |
| **营养** | 蛋白质、维生素 C、锌 → 形成胶原纤维，促进创伤愈合（[150]） |

## Local Factors

| 因素 | 作用 |
|------|------|
| **感染与异物** | 清创术 + 伤口缝合 → 可将二期愈合变为一期愈合（[152]） |
| **局部血液循环** | 动脉粥样硬化或静脉曲张等 → 伤口愈合迟缓（[153]） |
| **神经支配** | 麻风引起神经性营养不良 → 溃疡不易愈合（[154]） |
| **电离辐射** | 损伤细胞和小血管、抑制再生（[155]） |

## Factors Affecting Fracture Healing

| 要点 | 说明 |
|------|------|
| **1. 骨折断端复位需及时正确** | 错位或嵌塞 → 延迟或不能愈合（[157]） |
| **2. 骨折断端固定需及时牢靠** | 石膏 / 夹板 / 髓腔钢针固定（[158]） |
| **3. 早日全身和局部功能锻炼** | 保持局部良好供血（[159]） |

功能锻炼条目下讲义列出需**预防**的情况（[160]–[162]）：

- 病理性萎缩（压迫性、失用性）
- 赘生骨痂（新骨形成过多）
- 假关节（纤维性骨痂不能变成骨性骨痂并出现裂隙）
