# Fat Embolism（脂肪栓塞）

## Definition

循环血液内出现**较大脂肪滴**并阻塞小血管。

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—血障.docx|《病理学》第三章 笔记（优课联盟 UOOC，2026 秋）]] — 第四节 栓塞 ·（二）脂肪栓塞（paragraphs 226–233）
> - 来源登记：[[99_System/Source-Registry#S-LEC-015|S-LEC-015]]

## 脂滴的来源

讲义给出两条来源途径：

| 途径 | 内容 |
|------|------|
| **（一）组织损伤释放脂滴** | **长骨骨折**、**脂肪挫伤**、**烧伤**、**脂肪肝撞击** → 破裂脂滴入血 |
| **（二）血脂游离融合** | **高血脂** + **应激状态** → 血脂游离融合形成脂肪滴 |

## 后果的决定因素

讲义明确指出：脂肪栓塞的后果**取决于脂滴大小和数量、栓塞部位**。

## 四种后果

1. **直径 > 20 µm** → 栓塞肺 A（肺动脉）小分支或毛细血管
2. **直径 < 20 µm** → 肺泡壁 cap（毛细血管）→ 肺 V（肺静脉）→ 左心体循环 → **脑水肿、点状出血**
3. **少量脂滴入血** → **巨噬细胞吞噬** + **脂酶分解**（被清除，不产生严重后果）
4. **大量脂滴快速入血** → 肺循环**大面积受阻** → **窒息、右心衰猝死**

> [!note] 脂滴大小的分水岭
> **20 µm** 是讲义给出的**唯一分界值**：大于此值被肺血管床拦下（栓塞肺动脉侧），小于此值可穿过肺泡壁 cap 进入左心，造成**体循环**（脑）栓塞。

## Clinical Pearls

- **长骨骨折 / 烧伤 / 脂肪肝撞击**是讲义点名的四大诱因，均为「**组织内脂滴破裂入血**」这一机制。
- **高血脂 + 应激状态**是**非创伤性**途径：无骨折也可发生脂肪栓塞。
- 脂滴 **< 20 µm** 时，栓塞的临床表现落在**脑**（脑水肿、点状出血），而非肺 —— 这是与肺栓塞鉴别的关键线索。
- **少量脂滴可被机体自清**（巨噬细胞 + 脂酶），因此并非所有脂滴入血都产生临床后果。
- 「**肺循环大面积受阻 → 窒息、右心衰猝死**」提示脂肪栓塞可以是**猝死**原因之一，与 [[Gas Embolism]] 的急性右心衰机制平行。
