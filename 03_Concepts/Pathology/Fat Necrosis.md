# Fat Necrosis（脂肪坏死）

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—组织细胞适应与损伤.docx|《病理学》第一章 笔记（优课联盟 UOOC，2026 秋）]] — 第四节（脂肪坏死）
> - 来源登记：[[99_System/Source-Registry#S-LEC-011|S-LEC-011]]
> - evidence_level: C（医学教育资料）；source_status: needs_review

## Definition

**Fat Necrosis（脂肪坏死）**：发生在脂肪组织中的坏死，主要包括**酶解性脂肪坏死**与**创伤性脂肪坏死**两类。

讲义明确指出：**脂肪坏死属于液化性坏死**（参见 [[Liquefactive Necrosis]]）。

## Pathological Mechanism

| 类型 | 英文 | 触发事件 | 机制 |
|------|------|----------|------|
| **酶解性脂肪坏死** | **Enzymatic fat necrosis** | **急性胰腺炎** | 释放**胰酶分解脂肪酸** |
| **创伤性脂肪坏死** | **Traumatic fat necrosis** | **乳房创伤** | 脂肪细胞破裂 |

> [!note] 急性胰腺炎的双重坏死
> 急性胰腺炎时的坏死 = **凝固性坏死 + 脂肪坏死**（二者并存，机制不同）— 讲义特别强调。

## Pathological Changes

- **脂肪酸 + Ca²⁺** → 形成 **灰白色钙皂（calcium soap）**

```
脂肪细胞破裂 / 胰酶分解
            ↓
释放脂肪酸
            ↓
脂肪酸 + Ca²⁺ → 灰白色钙皂
```

## Clinical Examples

- **急性胰腺炎**：胰酶释放 → 脂肪酶分解脂肪 → 钙皂形成（**大网膜、肠系膜脂肪皂化**经典表现）
- **乳房创伤**：脂肪细胞破裂 → 创伤性脂肪坏死 → 局部肿块（鉴别诊断意义）
