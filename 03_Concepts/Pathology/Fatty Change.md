# Fatty Change（脂肪变 / steatosis）

## Definition

**Fatty Change（脂肪变）**，又称 **Steatosis**：**甘油三酯蓄积于非脂肪细胞的胞浆中**。

## Etiology / Causes

- 感染
- 酗酒
- 中毒
- 缺氧
- 营养不良
- 糖尿病、肥胖

## Common Sites

- **肝**（最常见）
- **心**（心肌细胞）
- **肾小管上皮**
- **骨骼肌细胞**

## Pathological Mechanism

讲义总结为 **"来多去少"**：

| 方向 | 机制 |
|------|------|
| 来多 | 肝**脂肪酸增多**、甘油三酯**合成过多** |
| 去少 | **脂蛋白 / 载脂蛋白减少** → 脂质外运障碍 |
| 吞噬 | 吞噬脂质的**泡沫细胞**（动脉粥样硬化、高脂血症） |
| 重吸收 | **肾近曲小管上皮细胞**过量重吸收原尿脂蛋白 |

## Pathological Changes

| 层面 | 改变 |
|------|------|
| **电镜** | 胞质内**膜包绕的脂质小体**，融合成脂滴 |
| **光镜** | 胞质内出现**大小不等的球形空泡**（脂滴已被溶解）；大空泡可充满胞浆，将胞核挤至一侧，类似脂肪细胞 |
| **特染** | **冰冻切片** Sudan III / Sudan IV 染色呈**橘红色**（判断脂肪变程度） |
| **肉眼** | 体积逐渐增大、**淡黄色、边缘圆钝、切面油腻感** |

## Special Forms

### 肝脂肪变（脂肪肝）

| 病因 / 状态 | 部位 | 备注 |
|-------------|------|------|
| 慢性肝淤血早期 | **小叶中央区** | 中央区缺氧较重 |
| 慢性肝淤血后期 | **小叶周边区** | 中央区严重缺氧→中央区肝细胞萎缩消失；周边区缺氧相对较轻 |
| **磷中毒** | **小叶周边区** | 周边区受累较重，中央区减轻 |
| **发展** | 重度脂肪肝 → **肝坏死和肝硬化** |

### 心肌脂肪变

| 类型 | 部位 | 大体 / 镜下 |
|------|------|---------------|
| **虎斑心** | **左心室内膜下和乳头肌** | 大体：黄色（脂变）与暗红色（正常）相间排列呈**斑纹状**；镜下：心肌细胞胞浆内出现**串珠状空泡** |
| **脂肪心**（心肌脂肪浸润） | **右心室、心尖区**；高度肥胖或酗酒者多见 | 大体：心外膜脂肪组织增生，可沿间质**在心肌之间穿插**；镜下：心肌细胞**萎缩**，成熟脂肪组织**充填其间** |

## Clinical Consequences / Outcomes

- **可逆性**：去除病因后脂滴可被代谢清除
- **持续 / 重度脂肪肝** → 肝坏死 → [[Cirrhosis|肝硬化]]（待建；[[Necrosis]] 节点不含肝硬化内容）
- 心肌脂肪变（特别是脂肪心）可影响心功能
