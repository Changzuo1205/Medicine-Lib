# Fibrinoid Necrosis（纤维蛋白样坏死）

## Definition

**Fibrinoid Necrosis（纤维蛋白样坏死）**：**结缔组织及小血管壁的崩解坏死**，形成**细丝、颗粒或小条块状无结构物**，**红染似纤维蛋白**。

旧称"**纤维蛋白样变性**"（fibrinoid degeneration）。

属于 [[Necrosis]] 类型之一，但严格而言病变主体是**结缔组织 / 血管壁**崩解，而非典型实质细胞坏死。

## Pathological Mechanism

| 机制 | 描述 |
|------|------|
| **免疫复合物介导** | **Ag-Ab 免疫复合物**引发**胶原纤维肿胀崩解** |
| **免疫球蛋白沉积** | 结缔组织**免疫球蛋白沉积** |
| **血浆蛋白渗出变性** | 血浆**纤维蛋白渗出变性** |

## Pathological Changes

### 镜下（Microscopic）

- 形成**细丝状、颗粒状或小条块状无结构物**
- **红染**（HE 染色）**似纤维蛋白**

## Common Settings（典型疾病）

- **超敏反应性疾病**
  - **风湿病**
  - **新月体性肾小球肾炎**
- **急进型高血压**（恶性高血压）
- **胃溃疡底部小血管**

> [!note] 临床关联
> 纤维蛋白样坏死是**超敏反应 III 型**（免疫复合物型）的典型组织学表现，与 [[../Immunology/Immune Dysregulation]]密切相关。
