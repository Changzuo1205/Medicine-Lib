# Fibrous Tissue Regeneration（纤维组织再生）

## Definition

**Fibrous Tissue Regeneration（纤维组织再生）**：纤维组织损伤后，由**静止的纤维细胞或未分化间叶细胞**转变为**成纤维细胞**，进而合成分泌形成**胶原纤维**，最终形成**纤维瘢痕**的修复过程。

## Pathological Mechanism

再生通路（讲义原文顺序）：

```
静止的纤维细胞 / 未分化间叶细胞
        ↓
    成纤维细胞
        ↓  合成分泌
   胶原纤维 + 纤维细胞
        ↓
     纤维瘢痕
```

| 环节 | 内容 |
|------|------|
| **细胞来源** | 静止的纤维细胞；未分化间叶细胞 |
| **关键细胞** | 成纤维细胞 |
| **产物** | 胶原纤维 + 纤维细胞 |
| **结局** | 纤维瘢痕 |

## Exam Pearls

- 纤维组织再生的**细胞来源有两个**：静止的纤维细胞、未分化间叶细胞。
- 中间的**关键细胞是成纤维细胞**，其功能是**合成分泌胶原纤维**。
- 纤维组织再生的**终末结局是纤维瘢痕**，而非恢复原有组织的结构与功能。
