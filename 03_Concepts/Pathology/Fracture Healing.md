## Definition

**Fracture Healing（骨折愈合）**：骨折后断端之间通过血肿机化、骨痂形成与骨痂改建而重新连接的过程，属于创伤愈合的一种特殊形式（[139]）。

## Classification

依据骨折类型分为（[140]）：

- **外伤性骨折**
- **病理性骨折**

## Pathological Mechanism

骨折愈合的**四个阶段**（[141]–[144]）：

| 阶段 | 主要事件 |
|------|----------|
| 1. **血肿形成** | 出血，骨髓坏死，死骨片（[141]） |
| 2. **纤维性骨痂形成** | 肉芽组织取代、机化、纤维化（[142]） |
| 3. **骨性骨痂形成** | 成骨细胞形成**类骨质** + 钙盐沉积 → **编织骨**（[143]） |
| 4. **骨痂改建或再塑** | 破骨细胞 + 成骨细胞 → 成熟的**板层骨**（[144]） |
