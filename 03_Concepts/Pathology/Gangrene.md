## Definition

**Gangrene（坏疽）**：**局部组织坏死并继发腐败菌感染**的特殊类型坏死。

按发生条件与表现分为 **3 类**：干性、湿性、气性。

## Classification

### ① 干性坏疽（Dry Gangrene）

| 维度 | 内容 |
|------|------|
| **条件** | 动脉阻塞，**静脉回流通畅** |
| **部位** | **四肢末端** |
| **大体** | **干燥皱缩呈黑色，界清，腐败较轻** |
| **镜下** | **凝固性坏死** |
| **机制** | **血红蛋白 Fe²⁺ + 腐败组织 H₂S → FeS（硫化铁）→ 黑色** |

### ② 湿性坏疽（Moist Gangrene）

| 维度 | 内容 |
|------|------|
| **条件** | **与外界相通的内脏**；动脉阻塞且**静脉回流受阻** |
| **部位** | **肺、肠、子宫、阑尾、胆囊**，肢体 |
| **大体** | **肿胀呈蓝绿色，界不清，腐败较重** |
| **镜下** | **凝固性坏死 + 液化性坏死** |
| **机制** | 水分多 → 腐败菌易繁殖 |

### ③ 气性坏疽（Gas Gangrene）

| 维度 | 内容 |
|------|------|
| **条件** | **深达肌肉的开放性创伤** + **产气荚膜杆菌等厌氧菌感染** |
| **大体** | 坏死并**产生大量气体呈蜂窝状**，**按压坏死区有捻发感** |
| **镜下** | 凝固性坏死 + 大量气体空腔 |
| **特点** | **全身中毒症状**（严重感染中毒） |

## Comparison Summary

| 特征 | 干性坏疽 | 湿性坏疽 | 气性坏疽 |
|------|----------|----------|----------|
| 病因 | 动脉阻塞，静脉通畅 | 内脏 + 动静脉均阻 | 深部开放伤 + 厌氧菌 |
| 部位 | 四肢末端 | 肺、肠、子宫、阑尾、胆囊、肢体 | 深部肌肉 |
| 形态 | 干、黑、皱缩、界清 | 肿、蓝绿、界不清 | 蜂窝状、捻发感 |
| 镜下 | 凝固性坏死 | 凝固 + 液化 | 凝固性坏死 + 气体 |
| 腐败 | 较轻 | 较重 | 重（厌氧菌产气） |
| 中毒症状 | 轻 | 中 | **重**（全身中毒） |
