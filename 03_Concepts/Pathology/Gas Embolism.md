# Gas Embolism（气体栓塞）

## Definition

**大量空气迅速进入血液循环**，或**原溶于血液的气体迅速游离**，形成**气泡阻塞心血管** —— 分别称为**空气栓塞**和**减压病**。

## 一、空气栓塞（air embolism）

### 原因

**手术或创伤**、**正压静脉输液**、**人工气胸或气腹**、**分娩或流产**。

即：任何使**空气经破损静脉或操作通道迅速进入血液循环**的情形。

### 后果（三种情形）

| 情形 | 后果 |
|------|------|
| **（1）少量** | **血液溶解**（被血液吸收，不产生栓塞后果） |
| **（2）> 100 ml** | **右心泡沫血** → 阻断**体循环静脉回流**和**肺动脉输出** → **急性右心衰、呼吸衰竭、DIC** → **猝死** |
| **（3）部分气泡** | → **肺小动脉栓塞**，或**通过 cap（毛细血管）** → **左心体循环栓塞** |

> [!note] 为什么是「泡沫血」
> 大量空气进入右心后与血液混合形成**泡沫血**，泡沫的可压缩性使心脏无法有效泵血 —— 同时阻断**回心（体循环静脉回流）**与**排血（肺动脉输出）**两端，故后果为**急性右心衰 + 呼吸衰竭**，并伴 **DIC**。

## 二、减压病

### 概念

从**高压**迅速进入**常压或低压**时，已溶于**血液、组织液和脂肪组织**的**气体迅速游离形成气泡**。

各气体的转归不同：

- **O₂ 和 CO₂** —— **再溶**（重新溶解，不形成持续气泡）
- **N₂** —— **溶解缓慢，融合成气泡** → **氮气栓塞**

故减压病又称**沉箱病**和**潜水员病（caisson and diver disease）**。

### 临床

| 受累部位 | 表现 |
|----------|------|
| **富含脂肪的皮下组织** | **皮下气肿** |
| **肌肉、肌腱、韧带** | **关节和肌肉疼痛** |
| **小血管阻塞** | **股骨头无菌性坏死**、**肠痉挛性疼痛** |
| **大量气泡形成阻塞多数血管及冠状动脉** | **猝死** |

## Clinical Pearls

- **> 100 ml** 是讲义给出的空气栓塞**关键数值**：达到此量级即出现右心泡沫血，可致猝死；少量空气则可被血液溶解。
- **空气栓塞**的入口是**静脉 / 操作通道**（手术创伤、正压输液、人工气胸气腹、分娩流产）；**减压病**的成因不是「空气进入」，而是**已溶解气体的逸出** —— 两者的机制方向相反。
- **氮气（N₂）是减压病的致病气体**，不是 O₂ 或 CO₂ —— 因为 O₂、CO₂ 可再溶，N₂ 溶解缓慢。这是高频考点。
- 减压病的临床表现按**气泡所在组织**分级理解：皮下（皮下气肿）→ 肌肉肌腱韧带（疼痛）→ 小血管（股骨头无菌性坏死、肠痉挛）→ 多数血管及冠状动脉（猝死）。
- **股骨头无菌性坏死**是减压病中讲义点名的特异性后果。
- 空气栓塞与减压病**都可导致猝死**，且都有**右心 / 冠状动脉**受累机制。
