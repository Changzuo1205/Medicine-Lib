# Hepatic Congestion（肝淤血）

## Definition

**Hepatic Congestion（肝淤血）**：静脉回流受阻（**肺源性心脏病 → 肺动脉高压 → 右心衰 → 体循环淤血**）导致血液淤积于肝的**中央静脉及肝窦**，致**肝局部血量增加**，并以**小叶中央区重于周边区**为特征。

## 发生前提

**肺源性心脏病** → **肺动脉高压** → **右心衰** → **体循环淤血**，肝是体循环淤血的重要受累器官（讲义「举例」一条）。

## 一、急性肝淤血

| 层面 | 表现 |
|------|------|
| **大体** | **体积增大**，**暗红色** |
| **镜下 · 中央区** | **中央静脉及肝窦扩张，充满红细胞（RBC）**；**肝细胞脂变或萎缩** |
| **镜下 · 周围区** | **缺氧较轻**，**肝细胞病变不明显**，**仅见少量脂变** |

## 二、慢性肝淤血 —— 槟榔肝

| 区域 | 大体表现 |
|------|----------|
| **中央区** | **严重淤血呈暗红色** |
| **周边区** | **肝细胞脂变呈黄色** |
| **切面** | **红黄相间的网纹** → **槟榔肝（nutmeg liver）** |

> 槟榔肝的「红」= 中央区**严重淤血**；「黄」= 周边区**肝细胞脂变**。两者相间构成网纹。

## 三、进一步进展（讲义续）

讲义在急性、慢性两型之后，又按**小叶中央区 / 小叶周边区 / 间质**三层继续描述更重的病变：

| 区域 | 病变 |
|------|------|
| **1. 小叶中央区**（**淤血较重**） | **肝窦高度扩张淤血、出血**；**肝细胞萎缩、消失** |
| **2. 小叶周边区**（**淤血较轻**） | **肝细胞脂肪变性，似脂肪细胞**；**灶性坏死** |
| **3. 间质纤维组织明显增生** | ① **网状纤维支架塌陷后胶原化**；② **肝星状细胞增生、合成胶原增多**；③ **汇管区纤维组织增生** |

> [!warning] 命名提示
> 讲义**未使用**「淤血性肝硬化」这一名称，只在淤血的后果一节中提出「**淤血性硬化**」（见 [[Congestion]]）。本节点如实保留讲义表述：**间质纤维组织明显增生**（后果一节称之为**淤血性硬化**），**不代讲义命名该病变为肝硬化**。

## Clinical Pearls

- **槟榔肝的「红黄网纹」是考试高频形态描述**：**中央区严重淤血（暗红）＋ 周边区肝细胞脂变（黄）**。红黄分布的方向不能颠倒 —— 淤血在**中央**，脂变在**周边**。
- **为什么中央区先受损**：讲义用「**缺氧**」解释 —— 急性肝淤血时**周围区缺氧较轻**故病变不明显，中央区则出现**肝细胞脂变或萎缩**；进展期**小叶中央区淤血较重** → 肝窦高度扩张淤血、出血，肝细胞**萎缩、消失**。
- **「肝细胞似脂肪细胞」是脂肪变的形态学描述**：小叶周边区肝细胞脂肪变性，胞浆被脂滴充满以致**似脂肪细胞**，并出现**灶性坏死**（可与 [[Fatty Change]] 互参）。
- **纤维化的三条路径要能分开复述**：**网状纤维支架塌陷后胶原化** · **肝星状细胞增生、合成胶原增多** · **汇管区纤维组织增生**。
- **长期肝淤血不是单纯的「血多了」**：从急性（脂变/萎缩）→ 慢性（槟榔肝）→ 进展（肝细胞消失、灶性坏死、间质纤维增生）是一条连续加重的过程。
