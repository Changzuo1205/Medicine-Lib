## Definition

**Hyaline Degeneration（玻璃样变）**，又称**透明变性**：**细胞内或间质中出现半透明状蛋白质蓄积**；HE 染色呈**嗜伊红均质状**（均质红染）。

> 鉴别要点：本病与 [[Amyloidosis]] 均属"蛋白蓄积"，但**淀粉样变**需经 I₂ / 刚果红特染证实（详见该节点）。

## Pathological Mechanism

讲义所述机制：

```text
合成增多 / 结构变异
   ↓
变性胶原蛋白、血浆蛋白、免疫球蛋白
   ↓
在细胞内或间质中蓄积
```

## Subtypes（3 类）

### 1. 细胞内玻璃样变

| 项目 | 内容 |
|------|------|
| 镜下 | 胞浆内见**均质红染的圆形小体** |
| 举例 1 | 肾小管上皮细胞**重吸收原尿蛋白质** → **玻璃样小滴** |
| 举例 2 | 浆细胞胞浆**粗面内质网**中免疫球蛋白蓄积 → **Rusell 小体** |
| 举例 3 | **酒精性肝病**肝细胞胞浆中**中间丝前角蛋白变性** → **Mallory 小体** |

### 2. 纤维结缔组织玻璃样变

| 项目 | 内容 |
|------|------|
| 机制 | 纤维组织老化，**胶原蛋白交联、变性、融合** |
| 镜下 | 胶原纤维**增粗融合**，均质红染，少许血管和纤维细胞 |
| 肉眼 | **灰白、质韧、半透明** |
| 举例 | 萎缩的子宫和乳腺间质、**瘢痕组织**、动脉粥样硬化斑块、**机化** |

### 3. 细小动脉壁玻璃样变

| 项目 | 内容 |
|------|------|
| 机制 | **血浆蛋白渗入** + **基底膜代谢物质沉积** |
| 镜下 | 管壁**增厚、均质红染、管腔狭窄**；又称"细小动脉硬化" |
| 举例 | **缓进型高血压**、**糖尿病**的肾、脑、脾等细小动脉壁 |
| 后果 | 动脉壁**弹力减弱、脆性增加**，因扩张易**破裂出血** |

## Clinical Consequences / Outcomes

- 多数为**可逆性**改变（去除病因后部分可吸收）
- **细小动脉壁玻璃样变** → 管腔狭窄 → 器官慢性缺血（如高血压肾损害、糖尿病微血管病变），破裂风险升高
- 与 [[Amyloidosis]] 在形态上类似但本质不同（特染可鉴别）
