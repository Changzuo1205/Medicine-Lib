## Definition

**Hyperplasia（增生）**：**有丝分裂活跃 → 细胞数量增多**，导致组织、器官体积增大和功能活跃。

> 与[[Hypertrophy]]区别：肥大是**细胞体积增大**，增生是**细胞数量增多**。两者常合并出现（见下"与肥大的关系"）。

## Pathological Mechanism

- **激素过多刺激**
- **生长因子及受体过度表达**
- → 静止期细胞重新进入细胞周期 → 有丝分裂增加

## Etiology / Causes

| 类别 | 亚型 | 典型举例 |
|------|------|----------|
| **生理性增生** | **代偿性** | **部分肝切除**后肝细胞增生；**高海拔 → 红细胞**增多 |
|  | **内分泌性** | **青春期乳腺**增生；**经期子宫内膜**增生；**妊娠子宫**平滑肌增生 |
| **病理性增生** | **代偿性** | 损伤或炎症 → **肉芽组织及细胞** 增生修复 |
|  | **内分泌性** | **雌激素过多** → 乳腺、子宫内膜腺体增生 |

## Pathological Changes

- **细胞数量增多**（光镜下可见分裂象、核分裂相增多）
- 组织、器官**体积增大**
- **功能活跃**（如激素水平的下游效应增强）

## Clinical Consequences / Outcomes

- **刺激消除 → 增生停止**（可逆性适应）。
- **持续刺激 → 增生过度失控 → 肿瘤**（病理性增生与肿瘤性增生的桥梁）。
- 病理性激素依赖性增生（如子宫内膜增生过长）是癌前病变风险来源。

## 与肥大的关系（讲义"强调"）

| 细胞分裂能力 | 反应类型 |
|--------------|----------|
| **分裂能力活跃**（如肝细胞、子宫内膜、乳腺） | **增生 + 肥大** 可同时出现 |
| **分裂能力较低**（如心肌、骨骼肌） | **仅有肥大**（参见 [[Hypertrophy]]） |
