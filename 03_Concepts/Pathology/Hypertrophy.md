## Definition

**Hypertrophy（肥大）**：**功能及合成代谢增强 → 细胞、组织或器官体积增大**；通常由**实质细胞体积增大**所致，可伴有数量增加。

## Etiology / Causes

| 类别 | 亚型 | 典型举例 |
|------|------|----------|
| **生理性肥大** | **代偿性** | 运动员**骨骼肌**肥大 |
|  | **内分泌性** | **妊娠子宫平滑肌**肥大 |
| **病理性肥大** | **代偿性** | **高血压** → 左心室肥大；一侧肾切除 → 对侧肾肥大 |
|  | **内分泌性** | **甲亢** → 滤泡上皮肥大；**垂体腺瘤** → 肾上腺皮质细胞肥大 |

## Pathological Mechanism

- 在功能负荷 / 激素刺激下，**合成代谢增强**。
- **实质细胞体积增大**，可伴细胞数量增加。
- 与[[Hyperplasia]]的关系：若细胞分裂能力活跃 → **肥大 + 增生**；若分裂能力较低 → **仅有肥大**（参见[[Hyperplasia]] 的"强调"）。

## Pathological Changes

| 维度 | 表现 |
|------|------|
| **细胞** | 体积增大 |
| **细胞核** | **核大、深染** |
| **化学成分** | **DNA、蛋白含量增多** |
| **细胞器** | 数量增多（如线粒体、肌原纤维） |

> **假性肥大（pseudohypertrophy）**：**实质细胞萎缩**，**间质脂肪细胞增生** → 器官看似增大、功能反而下降。须与真性肥大鉴别。

## Clinical Consequences / Outcomes

- **心肌过度肥大 → 收缩蛋白变性、溶解 → 诱发失代偿心力衰竭**（高血压性心脏病由代偿走向失代偿的关键机制）。
- 妊娠子宫、运动员骨骼肌等生理性肥大在刺激去除后可恢复至原大小。
