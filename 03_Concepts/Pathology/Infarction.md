# Infarction（梗死）

## Definition

**Infarction（梗死）**：器官局部组织**血管阻塞、血流停滞导致缺氧**而发生的**坏死**。

> [!info] 来源
> - 主来源：[[02_Raw/Lectures/Pathology/笔记—血障.docx|《病理学》第三章 笔记（优课联盟 UOOC，2026 秋）]] — 第五节 梗死（infarction）（paragraphs 256–273、304–310）
> - 来源登记：[[99_System/Source-Registry#S-LEC-015|S-LEC-015]]

## 区别与病因

**动脉阻塞与静脉阻塞的区别**：

| 阻塞类型 | 后果 |
|----------|------|
| **动脉阻塞** | **缺血坏死** |
| **静脉阻塞** | **缺氧坏死** |

**病因（讲义列 4 条）**：

| 序号 | 原因 | 讲义举例 |
|------|------|----------|
| 1 | **血栓形成** | 动脉粥样硬化、闭塞性脉管炎、肠系膜静脉 |
| 2 | **动脉栓塞** | 血栓、气体、羊水、脂肪 |
| 3 | **动脉痉挛** | 粥样硬化的冠状动脉持续收缩 |
| 4 | **血管受压闭塞** | 肿瘤、肠系膜、卵巢囊肿及睾丸扭转等 |

## 影响梗死发生的因素

- **双重血液循环**的器官：**肺、肝**
- **吻合支丰富**的部位：**前臂、手**
- **缺血敏感性**：**神经 < 心肌 < 骨骼肌/纤维**（讲义原记法）
- **血氧含量过低**

## 梗死灶形态的三组决定因素

| 形态要素 | 决定因素 | 讲义内容 |
|----------|----------|----------|
| **形状** | 器官血管分布 | **肾、脾、肺**：**锥形或三角形**，**尖端指向门部**，**底部为器官表面**；**心肌梗死呈不规则地图状**；**肠梗死呈节段形** |
| **质地** | 坏死类型 | **凝固性坏死**：新鲜肿胀渗出，陈旧干燥质硬、表面下陷；**液化性坏死**：新鲜质软疏松，逐渐液化成囊状 |
| **颜色** | 病灶含血量 | 含血少**灰白色** → **贫血性/白色梗死**（anemic or white infarction）；含血多**暗红色** → **出血性/红色梗死**（hemorrhagic or red infarction） |

## 分型

讲义在「第五节 梗死」下按（一）（二）（三）列出三型：

| 讲义分型 | 讲义定性 | 节点 |
|----------|----------|------|
| （一）**贫血性梗死**（anemic infarct） | 含血少、灰白色（白色梗死） | [[Anemic Infarction]] |
| （二）**出血性梗死**（hemorrhagic infarct） | 含血多、暗红色（红色梗死） | [[Hemorrhagic Infarction]] |
| （三）**败血性梗死**（septic infarct） | 梗死灶内可见菌团和大量炎细胞浸润 → 脓肿形成 | [[Septic Infarction]] |

## 影响与结局

**影响**：取决于**梗死器官、病变范围及有无细菌感染**等。

| 情形 | 后果 |
|------|------|
| 重要器官的**大面积梗死**（**心、脑**） | **死亡或瘫痪** |
| **肾、脾、肺** | **局部症状，功能尚存** |
| 梗死后**继发腐败菌感染**（**肺、肠、四肢**） | **坏疽** |

**结局**：

- **肉芽组织完全机化** → **胶原纤维瘢痕**
- **不能完全机化** → **纤维包裹、钙化**
- **脑梗死** → **胶质细胞和胶质纤维增生** → **胶质瘢痕**

## Clinical Pearls

- 梗死灶的**颜色看含血量**（白色 / 红色梗死）、**形状看血管分布**（锥形 / 地图状 / 节段形）、**质地看坏死类型**（凝固性 / 液化性）—— 讲义把三组决定因素并列陈述。
- **双重血液循环**（肺、肝）与**吻合支丰富**（前臂、手）是这些器官/部位不易发生梗死的解剖基础。
- **缺血敏感性**按讲义记法为**神经 < 心肌 < 骨骼肌/纤维**。
- 重要器官的**大面积梗死（心、脑）**后果最重，可致**死亡或瘫痪**；**肾、脾、肺**梗死多为**局部症状、功能尚存**。
- 梗死后**继发腐败菌感染**（肺、肠、四肢）可发展为**坏疽**，是梗死需要警惕的后果。
