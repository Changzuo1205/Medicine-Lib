# Liquefactive Necrosis（液化性坏死）

> [!info] 来源

> - evidence_level: C（医学教育资料）；source_status: needs_review

## Definition

**Liquefactive Necrosis（液化性坏死）**：坏死组织**可凝固的蛋白质少**，**坏死细胞及中性粒细胞等释放大量水解酶**，或组织富含水分和磷脂，细胞组织坏死后**易溶解液化**。

为 [[Necrosis]] 的常见类型之一。

## Pathological Mechanism

```
可凝固蛋白少 + 水解酶多 / 富含水分和磷脂
                ↓
坏死细胞及中性粒细胞释放大量水解酶
                ↓
组织迅速溶解液化
```

## Typical Settings（典型场景）

| 场景 | 机制 | 临床举例 |
|------|------|----------|
| **化脓性感染** | 细菌或真菌感染 → 局限性化脓性炎 | **脓肿** |
| **脑缺血缺氧** | 脑组织富含水分和磷脂 | **筛孔状软化灶 → 脑软化** |
| **细胞水肿** | 持续水肿 → 气球样变 → 溶解坏死 | 肝细胞气球样变进展为溶解坏死 |

## Pathological Changes

### 镜下（Microscopic）

- 死亡细胞**完全被消化**
- 局部组织**快速被溶解**

### 大体（Gross）

- 形成含液体或半流体的腔隙（如脓肿、脑软化灶）
- 与 [[Coagulative Necrosis]] 不同：组织结构轮廓**很快丧失**
