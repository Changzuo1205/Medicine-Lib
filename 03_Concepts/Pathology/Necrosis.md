# Necrosis（坏死）

> [!info] 来源

> - evidence_level: C（医学教育资料）；source_status: needs_review

## Definition

**Necrosis（坏死）**：**活体内局部组织中细胞的死亡，以酶溶性变化为主**。

属于 **意外性细胞死亡**（参见 [[Cell Death]]），多由可逆性损伤发展而来，较强损伤可直接导致坏死。

## Etiology / Causes

- 多由 [[Cell Injury|可逆性细胞损伤]]发展而来
- 较强损伤（如严重缺血缺氧、强酸强碱、毒素等）可直接导致坏死
- 坏死细胞及中性粒细胞（N）释放**溶酶体酶** → 引起局部多个实质细胞**溶解**

> 注：讲义中"N"为中性粒细胞（neutrophil）的缩写。

## Pathological Mechanism

```
坏死细胞 / 中性粒细胞
       ↓ 释放溶酶体酶（水解酶）
       ↓
局部多个实质细胞溶解 → 组织结构破坏
```

## Pathological Changes

### 1. 细胞核（**主要形态学标记**）

| 类型 | 英文 | 形态特点 |
|------|------|----------|
| **核固缩** | **Pyknosis** | 染色质浓聚，核皱缩体积减小，嗜碱性增强 |
| **核碎裂** | **Karyorrhexis** | 核膜破裂，染色质崩解成碎片 |
| **核溶解** | **Karyolysis** | 酶激活分解 DNA 及核蛋白，染色质变淡消失 |

> [!note] 强调
> 核的三种变化**不一定是循序渐进过程**，可由正常直接发生（任一形态均可作为坏死的形态学证据）。

### 2. 细胞质

- 核糖体减少丧失、变性蛋白增多、糖原减少 → **嗜酸性增强**
- 电镜下：线粒体、内质网肿胀形成空泡，钙致密物沉积，溶酶体释放

### 3. 间质

- 间质可耐受，出现较晚
- 细胞外基质崩解液化 → **片状模糊的无结构物**

### 4. 大体表现（活体表现）

- **苍白**、**失去弹性**、**感觉运动丧失**
- **无血管搏动和鲜血流出**

## Clinical Consequences / Outcomes（坏死结局）

坏死物质有 **4 种转归**：

### ① 溶解吸收

```
坏死细胞 + 中性粒细胞 → 释放水解酶 → 溶解液化
                                            ↓
                          ┌─────────── 淋巴管/血管吸收
                          └─────────── 不能吸收的碎片 → 巨噬细胞（Mφ）吞噬清除
```

### ② 分离排出（坏死灶较大、不易溶解吸收时）

| 类型 | 英文 | 定义 |
|------|------|------|
| **糜烂** | **Erosion** | **皮肤、黏膜的浅表组织缺损** |
| **溃疡** | **Ulcer** | **较深的组织缺损** |
| **窦道** | **Sinus** | **只开口于皮肤黏膜表面的深在性盲管** |
| **瘘管** | **Fistula** | **连接两个内脏或从内脏通向体表的通道样缺损** |
| **空洞** | **Cavity** | **坏死物液化经自然管道排出后残留的空腔** |

### ③ 机化与包裹

| 类型 | 英文 | 机制 |
|------|------|------|
| **机化** | **Organization** | 新生肉芽组织长入并取代坏死物、血栓、脓液、异物等 → **纤维瘢痕** |
| **包裹** | **Encapsulation** | 坏死组织太大难以完全长入或吸收 → 周围肉芽组织增生包绕 → **纤维包膜** |

### ④ 钙化

坏死 + 钙盐沉积 → **营养不良性钙化**（参见 [[Pathologic Calcification]]）

## Subtypes（坏死类型）

| 类型 | 关键特征 |
|------|----------|
| [[Coagulative Necrosis]] 凝固性坏死 | 蛋白质变性凝固；心肝肾脾等实质器官 |
| [[Liquefactive Necrosis]] 液化性坏死 | 水解酶多，组织溶解液化；脑、脓肿 |
| [[Caseous Necrosis]] 干酪样坏死 | 结核最常见；似干酪，细腻 |
| [[Fat Necrosis]] 脂肪坏死 | 急性胰腺炎 / 乳房创伤；钙皂 |
| [[Fibrinoid Necrosis]] 纤维蛋白样坏死 | 变态反应 / 急进型高血压；红染似纤维蛋白 |
| [[Gangrene]] 坏疽 | 继发腐败菌感染；干 / 湿 / 气性 |
