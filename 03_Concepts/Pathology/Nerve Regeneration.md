# Nerve Regeneration（神经组织再生）

## Definition

**Nerve Regeneration（神经组织再生）**：神经组织损伤后的修复过程。**中枢**与**周围**神经的再生结局截然不同：中枢神经细胞破坏后由**胶质瘢痕**代替，周围神经纤维在**神经细胞存活**的前提下可**完全再生**。

## Classification

| 部位 / 情况 | 过程 | 结局 |
|-------------|------|------|
| **脑和脊髓神经细胞破坏** | **胶质细胞 + 胶质纤维** → **胶质瘢痕** | 胶质瘢痕（非神经性修复） |
| **神经纤维受损 + 神经细胞存活** | **施万细胞增生 + 轴突延伸** | **完全再生** |
| **断端相隔太远 / 瘢痕等阻隔 / 截肢失去远端** | 再生轴突不能到达远端，与增生的结缔组织混杂并**卷曲成团** | **创伤性神经瘤 → 顽固性疼痛** |

## Pathological Mechanism

**1. 中枢神经（脑和脊髓）**

中枢神经细胞属**永久性细胞**，**出生后不能分裂增生，一旦破坏即为永久缺失**（paragraphs 036–040）。因此脑和脊髓神经细胞破坏后不能由神经元再生补充，而由**胶质细胞 + 胶质纤维**增生形成**胶质瘢痕**。

**2. 周围神经纤维（神经细胞存活时）**

```
神经纤维受损（神经细胞仍存活）
        ↓
   施万细胞增生
        ↓
     轴突延伸
        ↓
     完全再生
```

**3. 再生受阻的情况**

满足以下任一条件即无法完成再生：

- 断端相隔太远
- 瘢痕等阻隔
- 截肢失去远端

结果：再生轴突不能到达远端，与**增生的结缔组织混杂并卷曲成团** → **创伤性神经瘤（traumatic neuroma）** → **顽固性疼痛**。详见 [[Traumatic Neuroma]]。

## Clinical Consequences

- **胶质瘢痕**：中枢神经损伤后的修复形式，由胶质细胞与胶质纤维构成。
- **完全再生**：仅在神经细胞存活、轴突能到达远端时实现。
- **创伤性神经瘤**：再生轴突与结缔组织混杂卷曲成团，临床表现为**顽固性疼痛**。

## Exam Pearls

- 神经再生的**决定性前提**是**神经细胞是否存活**：神经元存活 → 神经纤维可完全再生；神经元破坏 → 只能形成胶质瘢痕。
- **中枢神经细胞属永久性细胞，不能分裂增生** —— 这是中枢神经损伤后功能难以恢复的根本原因。
- 周围神经纤维再生的两个关键参与者：**施万细胞增生**、**轴突延伸**。
- **创伤性神经瘤形成的三个前提**要记全：断端相隔太远、瘢痕等阻隔、截肢失去远端。
- 创伤性神经瘤的临床特征是**顽固性疼痛**。
