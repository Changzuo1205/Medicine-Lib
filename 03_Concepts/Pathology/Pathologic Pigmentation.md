## Definition

**Pathologic Pigmentation（病理性色素沉着）**：**内源性或外源性色素增多并积聚于细胞内外**。

## Types（4 种色素）

### 1. 含铁血黄素（Hemosiderin）

| 项目 | 内容 |
|------|------|
| 机制 | 巨噬细胞**吞噬、降解血红蛋白** → **铁蛋白微粒** |
| 镜下 | **金黄色或褐色颗粒** |
| 特染 | **普鲁士蓝呈蓝色** |
| 临床意义 | **陈旧性出血**、**溶血性疾病** |

### 2. 脂褐素（Lipofuscin）

| 项目 | 内容 |
|------|------|
| 来源 | **自噬溶酶体内未被消化的细胞器碎片残体**；又称**消耗性色素** |
| 镜下 | **黄褐色微细颗粒状**（磷脂 + 蛋白混合物 → 自由基脂质过氧化） |
| 正常少量分布 | 附睾管上皮、睾丸间质细胞、神经节细胞 |
| 病理性大量沉积 | **老年器官萎缩**、**营养耗竭**（心肌、肝细胞） |

### 3. 黑色素（Melanin）

| 项目 | 内容 |
|------|------|
| 形态 | **黑褐色细颗粒** |
| 分布 | 黑色素细胞、基底层及巨噬细胞 |
| 临床 | **色素痣**、**黑色素瘤**、**基底细胞癌**、**肾上腺皮质功能低下** |

### 4. 胆红素（Bilirubin）

| 项目 | 内容 |
|------|------|
| 来源 | **红细胞衰老破坏**释放出的**不含铁的血红蛋白**衍生物 |
| 形态 | **粗糙、金黄色颗粒** |
| 临床意义 | **皮肤黏膜黄染**（黄疸） |

## Clinical Consequences / Outcomes

- 不同色素的临床意义差别大：
  - 含铁血黄素 → 提示陈旧出血 / 溶血
  - 脂褐素 → 提示细胞老化 / 消耗（**消耗性色素**）
  - 黑色素 → 提示色素性病变或肾上腺皮质功能低下
  - 胆红素 → 提示红细胞破坏增多或胆红素代谢障碍
