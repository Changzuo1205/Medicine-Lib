# Pulmonary Congestion（肺淤血）

## Definition

**Pulmonary Congestion（肺淤血）**：左心衰（如**二尖瓣或主动脉瓣狭窄、高血压后期**）导致静脉回流受阻，血液淤积于肺的**毛细血管和小静脉**，致**肺局部血量增加**。

## 发生前提

**二尖瓣或主动脉瓣狭窄、高血压后期** → **左心衰** → **肺淤血**（讲义「举例」一条）。

## 一、急性肺淤血

| 层面 | 表现 |
|------|------|
| **镜下** | **肺泡壁毛细血管扩张充血**，**肺泡壁增厚**，**肺泡间隔水肿**；**肺泡腔内充满水肿液**，可见**少量红细胞** |
| **大体** | **体积增大**，**重量增加**，**暗红色**，**质地开始变实**，**切面流出泡沫状红色血性液体** |

## 二、慢性肺淤血

| 层面 | 表现 |
|------|------|
| **镜下** | **肺泡壁毛细血管明显扩张充血**，**肺泡间隔纤维性增厚**；**肺泡腔见水肿液、红细胞（RBC）和大量心衰细胞（heart failure cells）** |
| **大体** | **质地变硬呈棕褐色** → **肺褐色硬化（brown induration）** |
| **临床** | **气促发绀**，**咳粉红色泡沫痰或铁锈色痰**，**呼吸困难**，**心肺衰竭** |

**与急性期的差别**（讲义用词）：毛细血管扩张充血由「扩张充血」变为「**明显**扩张充血」；肺泡间隔由「**水肿**」变为「**纤维性增厚**」；肺泡腔内容物由「水肿液 ＋ **少量**红细胞」变为「水肿液 ＋ 红细胞 ＋ **大量心衰细胞**」；大体由「暗红、质地**开始**变实」变为「**棕褐色、质地变硬**」。

## 心衰细胞的来源

**巨噬细胞吞噬红细胞（RBC）** → **血红蛋白降解** → **含铁血黄素细胞**（即**心衰细胞 / heart failure cells**）。

> 这与淤血后果中的**淤血性出血**（红细胞漏出 ＋ 巨噬细胞吞噬 → 含铁血黄素）是同一机制（见 [[Congestion]]）。

## Clinical Pearls

- **「泡沫状红色血性液体 / 粉红色泡沫痰」是急性肺淤血的标志**：大体切面流出**泡沫状红色血性液体**，临床**咳粉红色泡沫痰或铁锈色痰**，两者要能对应起来记。
- **心衰细胞不是心衰的原因，而是心衰的证据**：它是**吞噬了红细胞、胞浆含含铁血黄素的巨噬细胞**，只出现在**慢性肺淤血**，是**左心衰**的形态学标志之一。
- **棕褐色 + 质地变硬 = 肺褐色硬化（brown induration）**：慢性肺淤血时肺泡间隔**纤维性增厚**是「硬化」的组织学基础，**含铁血黄素**是「棕褐色」的颜色来源。
- **急性期与慢性期的切面液体颜色都是红色系**，但急性期为**泡沫状红色血性液体**（水肿液 ＋ 少量红细胞），慢性期临床表现为**粉红色泡沫痰或铁锈色痰**。
- 讲义把**气促发绀、呼吸困难、心肺衰竭**一并列为慢性肺淤血的临床表现 —— 肺淤血与临床心衰表现是同一病程的两个侧面。
