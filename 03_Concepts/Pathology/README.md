### 第一章 细胞和组织的适应与损伤（Chapter 1）

章节文件：[[01 组织细胞适应与损伤]]（Lecture）— **22 个概念节点**

#### 一、适应（Adaptation） — 5 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Atrophy]] 萎缩 | pathophysiology | 6 种病理性类型 + 质量变化 + 脂褐素沉着 |
| [[Hypertrophy]] 肥大 | pathophysiology | 代偿性与内分泌性；假性肥大；过度肥大 → 失代偿心衰 |
| [[Hyperplasia]] 增生 | pathophysiology | 分裂能力与组织对应；持续刺激 → 肿瘤 |
| [[Metaplasia]] 化生 | pathophysiology | 上皮与间叶；持续化生 → 恶变（鳞癌、腺癌） |
| [[Cellular Aging]] 细胞老化 | pathophysiology | 不可逆、普遍性；脂褐素沉着 |

#### 二、可逆性损伤（变性） — 8 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Cell Injury]] 细胞损伤（总论） | pathophysiology | 损伤 8 类原因 + 8 种机制（线粒体、膜、活性氧、清除、钙超载等） |
| [[Cellular Swelling]] 细胞水肿 | pathophysiology | 最早出现的可逆损伤；ATP↓ → Na⁺ → 肿胀；气球样变 |
| [[Fatty Change]] 脂肪变 | pathophysiology | "来多去少"；虎斑心、脂肪心；Sudan III/IV 橘红 |
| [[Hyaline Degeneration]] 玻璃样变 | pathophysiology | 3 型：细胞内（玻璃小滴 / Rusell / Mallory）、结缔组织、细动脉壁 |
| [[Amyloidosis]] 淀粉样变 | pathophysiology | 刚果红橙红 → 苹果绿（偏振光）；局部 + 全身型 |
| [[Mucoid Degeneration]] 黏液样变 | pathophysiology | 间质内黏多糖（透明质酸）和蛋白质的蓄积 |
| [[Pathologic Pigmentation]] 病理性色素沉着 | pathophysiology | 4 种：Hemosiderin / Lipofuscin / Melanin / Bilirubin |
| [[Pathologic Calcification]] 病理性钙化 | pathophysiology | 营养不良性（局部）vs 转移性（高血钙） |

#### 三、不可逆性损伤 → 细胞死亡（Cell Death） — 9 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Cell Death]] 细胞死亡（总论） | pathophysiology | 总论：意外性 vs 调节性；早期诊断依据酶活性变化（LDH/CK/AST/ALT/淀粉酶等） |
| [[Necrosis]] 坏死 | pathophysiology | 坏死总论：核固缩 / 核碎裂 / 核溶解；4 种结局（溶解吸收 / 分离排出 / 机化与包裹 / 钙化） |
| [[Coagulative Necrosis]] 凝固性坏死 | pathophysiology | 心肝肾脾缺血；灰白干燥质实；结构轮廓保留 |
| [[Liquefactive Necrosis]] 液化性坏死 | pathophysiology | 脑软化 / 脓肿；水解酶超多 → 快速溶解 |
| [[Caseous Necrosis]] 干酪样坏死 | pathophysiology | 结核最常见；水解酶受抑，不易吸收 |
| [[Fat Necrosis]] 脂肪坏死 | pathophysiology | 急性胰腺炎 + 乳房创伤；脂肪酸 + Ca²⁺ → 钙皂；属液化性 |
| [[Fibrinoid Necrosis]] 纤维蛋白样坏死 | pathophysiology | 结缔组织小血管壁；变态反应、急进型高血压 |
| [[Gangrene]] 坏疽 | pathophysiology | 干性 / 湿性 / 气性；坏死 + 腐败菌感染 |
| [[Apoptosis]] 凋亡 | pathophysiology | 程序性死亡；凋亡小体；不引起炎症；TP53 / BCL2 / CMYC |

### 第二章 损伤的修复（Chapter 2）

章节文件：[[02 损伤的修复]]（Lecture）— **26 个概念节点**

#### 总论与再生基础 — 7 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Repair]] 损伤的修复（总论） | pathophysiology | 概念：缺损修补恢复，可完全或部分恢复；成分 = 细胞 + 细胞外基质；两形式 = 再生 / 纤维性修复 |
| [[Regeneration]] 再生 | pathophysiology | 生理性（表皮、消化道黏膜上皮、子宫内膜、血细胞）vs 病理性；再生能力一般规律"低等>高等、幼稚>高分化" |
| [[Cell Cycle]] 细胞周期 | physiology | 间期（G1 DNA 合成前期 / S DNA 合成期 / G2 分裂前期）+ 分裂期（M 期） |
| [[Stem Cell]] 干细胞 | physiology | 无限或较长时间自我更新 + 多向分化；非对称分裂；胚胎干细胞 vs 成体干细胞；转分化 |
| [[Labile Cells]] 不稳定细胞 | pathophysiology | 持续分裂代替衰亡细胞；表皮、呼吸道/消化道黏膜、生殖道黏膜、淋巴造血细胞、间皮细胞 |
| [[Stable Cells]] 稳定细胞 | pathophysiology | 静止细胞（G0）；刺激时进入 G1；腺体及腺样器官实质细胞、平滑肌、肝（部分切除后快速再生） |
| [[Permanent Cells]] 永久性细胞 | pathophysiology | 非分裂细胞，出生后不能分裂增生，破坏后永久缺失；中枢神经细胞、神经节细胞、骨骼肌与心肌 |

#### 组织再生的机制和过程 — 6 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Epithelial Regeneration]] 上皮组织再生 | pathophysiology | 被覆上皮（基底层细胞 + 组织干细胞）；腺上皮（基底膜完整可完全恢复）；肝细胞再生三种情况 → 肝硬化 |
| [[Fibrous Tissue Regeneration]] 纤维组织再生 | pathophysiology | 静止纤维细胞 / 未分化间叶细胞 → 成纤维细胞 → 胶原纤维 + 纤维瘢痕 |
| [[Cartilage Regeneration]] 软骨组织再生 | pathophysiology | 软骨膜增生 → 软骨基质 + 陷窝内静止软骨细胞；缺损较大 → 纤维组织修复 |
| [[Angiogenesis]] 血管再生 | pathophysiology | 毛细血管出芽式 / 套叠式血管生成；大血管需手术吻合 + 内皮平滑肌增生 + 纤维瘢痕 |
| [[Muscle Regeneration]] 肌组织再生 | pathophysiology | 横纹肌：肌膜未破坏可恢复，肌膜破坏 → 纤维瘢痕；平滑肌 → 再生或纤维瘢痕 |
| [[Nerve Regeneration]] 神经组织再生 | pathophysiology | 中枢：胶质细胞 + 胶质纤维 → 胶质瘢痕；周围：施万细胞增生 + 轴突延伸 → 完全再生 |

#### 细胞再生的影响因素 — 3 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Extracellular Matrix]] 细胞外基质 | pathophysiology | 连接支撑 + 调节再生细胞生物学行为 + 调控发育/重建/愈合/肿瘤侵袭；胶原蛋白、弹力蛋白、黏附性糖蛋白与整合素、基质细胞蛋白、蛋白多糖与透明质酸 |
| [[Growth Factor]] 生长因子 | pathophysiology | 同类/同一胚层细胞增生、损伤重建、刺激与抑制动态平衡；多肽类最关键（PDGF、FGF、EGF、TGF、VEGF、IL-1、TNF） |
| [[Chalone and Contact Inhibition]] 抑素与接触抑制 | pathophysiology | 抑素：组织特异性，抑制本身增殖；接触抑制：细胞相互接触或达原有大小即停止生长、不堆积 |

#### 纤维性修复 — 3 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Fibrous Repair]] 纤维性修复 | pathophysiology | 过程：实质细胞再生 + 肉芽组织增生 → 溶解吸收坏死及异物、填补缺损 → 胶原纤维为主的瘢痕组织 |
| [[Granulation Tissue]] 肉芽组织 | pathophysiology | 组成 = 新生薄壁毛细血管 + 成纤维细胞增生 + 炎细胞浸润；肉眼鲜红颗粒状柔软湿润；作用（抗感染、填补缺损、机化或包裹）；结局 → 瘢痕 |
| [[Scar Tissue]] 瘢痕组织 | pathophysiology | 肉芽组织改建成熟形成；灰白质韧半透明；有利（填补连接、韧性）；缺乏弹性可膨出（室壁瘤）；不利（收缩致狭窄、粘连、瘢痕疙瘩） |

#### 创伤愈合 — 5 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Wound Healing]] 创伤愈合 | pathophysiology | 依据损伤程度及有无感染分为一期愈合与二期愈合 |
| [[Healing by First Intention]] 一期愈合 | pathophysiology | 缺损少、创缘整齐、无感染、对合严密；第 3 天肉芽填满，5–7 天胶原连接可拆线，2 周变白 |
| [[Healing by Second Intention]] 二期愈合 | pathophysiology | 缺损大、创缘不整、哆开、无法整齐对合或伴感染；坏死多、需多量肉芽充填、时间长、瘢痕大而不规则 |
| [[Fracture Healing]] 骨折愈合 | pathophysiology | 四阶段：血肿形成 → 纤维性骨痂形成 → 骨性骨痂形成 → 骨痂改建或再塑；外伤性 / 病理性 |
| [[Factors Affecting Wound Healing]] 影响创伤愈合的因素 | pathophysiology | 全身（年龄、营养：蛋白质/维生素 C/锌）；局部（感染与异物、局部血液循环、神经支配、电离辐射）；骨折特有（复位、固定、功能锻炼） |

|------|------|------|
| [[Traumatic Neuroma]] 创伤性神经瘤 | pathophysiology | 断端相隔太远 / 瘢痕阻隔 / 截肢失去远端 → 再生轴突与增生结缔组织混杂卷曲成团 → 顽固性疼痛 |
| [[Keloid]] 瘢痕疙瘩 | pathophysiology | 瘢痕过度增生 → 肥大突起不规则 |
### 第三章 局部血液循环障碍（Chapter 3）

章节文件：[[03 局部血液循环障碍]]（Lecture）— **21 个概念节点**

#### 第一节 充血和淤血 — 4 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Hyperemia]] 充血 | pathophysiology | **动脉性充血**，主动性；机制 = 血管舒张神经 + 舒血管活性物质 → 细动脉/毛细血管扩张；生理性 vs 病理性（炎症性 / 减压后）；鲜红、温度升高 |
| [[Congestion]] 淤血 | pathophysiology | **被动**过程；原因 3 类（静脉受压 / 静脉腔阻塞 / 心力衰竭）；还原血红蛋白↑ → **发绀**；后果 5 类（淤血性水肿 / 积液 / 出血 / 实质细胞萎缩变性坏死 / 硬化） |
| [[Pulmonary Congestion]] 肺淤血 | pathophysiology | 急性（肺泡腔水肿液 + 少量 RBC）vs 慢性（肺泡间隔纤维性增厚 + **心衰细胞**）→ **肺褐色硬化**；临床咳**粉红色泡沫痰或铁锈色痰** |
| [[Hepatic Congestion]] 肝淤血 | pathophysiology | 中央区暗红 + 周边区脂变黄 → **槟榔肝（nutmeg liver）**；进展为小叶中央区肝窦扩张出血、周边区脂变、间质纤维组织增生（讲义称**淤血性硬化**） |

#### 第二节 出血 — 1 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Hemorrhage]] 出血 | pathophysiology | **破裂性** vs **漏出性**（血管壁损害 / 血小板异常 / 凝血因子缺乏）；内出血（体腔积血、血肿）vs 外出血（自然管道、皮肤粘膜：瘀点/紫癜/瘀斑）；影响取决于出血量、速度、部位及类型 |

#### 第三节 血栓形成 — 6 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Thrombosis]] 血栓形成 | pathophysiology | 活体心血管内血液凝固形成**固体质块**；凝血 ⇄ 纤溶动态平衡；形成过程 5 步（**水泥 = 血小板黏集堆，钢筋 = 纤维蛋白**） |
| [[Virchow's Triad]] 血栓形成三要素 | pathophysiology | ① **心血管内皮细胞损伤（最重要、最常见）** ② 血流状态异常 ③ 血液凝固性增加；含完整内皮的抗凝（PGI2 / NO / ADP 酶 / 凝血酶调节蛋白 / 蛋白 S / t-PA）与损伤内皮的促凝（组织因子 III / vWF / PAI） |
| [[Thrombus Types]] 血栓类型 | pathophysiology | **白色**（头，疣状赘生物）· **混合**（体，层状，含附壁血栓）· **红色**（尾，无粘连、易脱落）· **透明**（微循环，DIC，纤维蛋白性血栓） |
| [[Thrombus Outcome]] 血栓的结局 | pathophysiology | 软化溶解吸收 · **机化（约 2 周）与再通** · 钙化（静脉石 / 动脉石） |
| [[Thrombosis Consequences]] 血栓对机体的影响 | pathophysiology | 有利（止血）vs 不利：阻塞血管（梗死 / 坏疽）· 血栓栓塞 · **心瓣膜变形**（狭窄 / 关闭不全）· 广泛性出血 |
| [[Disseminated Intravascular Coagulation]] DIC | pathophysiology | 微循环内**透明血栓**（微血栓）；凝血因子大量消耗 → 血液凝固障碍 → **出血性休克**；讲义仅零散提及，**无专节** |

#### 第四节 栓塞 — 6 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Embolism]] 栓塞 | pathophysiology | 循环血液中**不溶异物**阻塞血管腔；栓子运行途径 5 种（体静脉右心 / 主动脉左心 / 门静脉 / **交叉性（反常性）** / **逆行性**）；血栓栓塞占 **99%** |
| [[Pulmonary Embolism]] 肺动脉栓塞 | pathophysiology | 来源 **95% 下肢深静脉**；后果 4 种（中小栓子无严重后果 / 出血性梗死 / 骑跨性栓塞猝死 / 广泛小分支栓塞猝死）；**猝死机制 3 条**（急性右心衰 · 迷走反射痉挛 · 血小板 5-HT、TXA₂） |
| [[Systemic Arterial Embolism]] 体循环动脉栓塞 | pathophysiology | 来源（左心腔 / 动脉 / 腔静脉）；后果取决于侧支循环与缺血耐受性：有侧支无梗死（肝、上肢）· 无侧支梗死（**脑、心、肾、脾**） |
| [[Fat Embolism]] 脂肪栓塞 | pathophysiology | 长骨骨折 / 脂肪挫伤 / 烧伤 / 高血脂 + 应激；**> 20 µm 阻肺**，**< 20 µm 经肺入体循环 → 脑水肿、点状出血**；大量入血 → 窒息、右心衰猝死 |
| [[Gas Embolism]] 气体栓塞 | pathophysiology | **空气栓塞**（> 100 ml → 右心泡沫血 → 猝死）· **减压病**（N₂ 溶解缓慢 → 氮气栓塞，又称**沉箱病 / 潜水员病**；股骨头无菌性坏死） |
| [[Amniotic Fluid Embolism]] 羊水栓塞 | pathophysiology | 羊水经子宫壁破裂静脉窦入血 → 栓塞肺细小分支；光镜见**角化鳞状上皮、胎毛、胎脂、胎粪、黏液**；后果含**过敏性休克 + DIC** → 猝死 |

#### 第五节 梗死 — 4 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Infarction]] 梗死 | pathophysiology | 血管阻塞、血流停滞导致缺氧性**坏死**；原因 4 类；形状看血管分布（锥形 / 地图状 / 节段形）· 质地看坏死类型 · 颜色看含血量 |
| [[Anemic Infarction]] 贫血性梗死 | pathophysiology | 条件 = 组织致密 + 侧支不丰富；部位**脾、肾、心**；灰白锥形 + 褐色充血出血带；镜下**凝固性坏死**；另含**脑梗死**（液化性坏死 → 胶质瘢痕） |
| [[Hemorrhagic Infarction]] 出血性梗死 | pathophysiology | 条件 = **严重淤血 + 组织疏松**；**肺**（下叶肋膈缘，锥形/楔形）· **肠**（节段性暗红 → 麻痹性梗阻 → 穿孔 → 腹膜炎） |
| [[Septic Infarction]] 败血性梗死 | pathophysiology | 急性感染性心内膜炎赘生物含菌脱落 → 体循环栓塞；镜下**菌团 + 大量炎细胞 → 脓肿形成** |

## 使用规则

1. **本目录定位**：存放**病理学科**相关的 Concept 节点（Pathophysiology / Disease / Test 等），不与其他学科重复（参考 §11）。
2. **节点类型**：本学科以 `pathophysiology` 为主（机制 / 过程），少量 `disease` 节点（具体疾病）；不存在 `Physiology/` 或 `Pathophysiology/` 子目录（V2 规则）。
3. **来源标识**：所有节点的 `frontmatter.tags` 应包含 `medicine/pathology`；`source_status` 默认 `needs_review`，待与权威教材（人卫版《病理学》第 9/10 版、Robbins）逐句核对。
4. **剂量 / 治疗原则**：本目录不存储具体药物剂量或治疗方案，仅记录分类、机制与病理变化。
5. **与 [[../Immunology/README|Immunology]] 协作**：免疫病理学相关节点同时挂 `medicine/immunology` 标签，避免重复创建。
