# Stem Cell（干细胞）

## Definition

**Stem cells（干细胞）**：**个体发育过程中产生的**、具有**无限或较长时间自我更新**和**多向分化能力**的一类细胞（paragraphs 43–44）。

干细胞是组织**不断更新的必要条件**（paragraph 26）。

## Characteristics

讲义的四个特点（paragraph 45）：

| 特点 | 含义 |
|------|------|
| **无限增殖分裂** | 具有（无限或较长时间的）自我更新能力 |
| **静止状态** | 可处于静止状态 |
| **缺乏标志物** | 缺乏标志物 |
| **非对称分裂** | 分裂产生的两个子代细胞命运不同 |

### 非对称分裂过程

分裂后**一个子代细胞保持原有特性**（维持干细胞自身），**另一个分化为成熟细胞**（paragraph 27）。

## Classification

讲义将干细胞分为两型（paragraphs 46–49）：

| 类型 | 定义 |
|------|------|
| **胚胎干细胞** | **着床前胚胎内细胞群**的**全能干细胞**，具有向**三个胚层**分化能力，可分化为**成体所有类型成熟细胞** |
| **成体干细胞** | **各组织器官**中具有**自我更新**和**一定分化潜能**的**不成熟细胞** |

### 成体干细胞的举例

造血、表皮、间充质、肌肉、肝脏、神经干细胞等（paragraph 54）。

## Role in Regeneration and Applications

### 胚胎干细胞

- **全能分化** → **修复替代功能丧失的组织和器官**（paragraph 51）。
- **应用举例**（paragraph 52）：**神经变性（[[Parkinson Disease|帕金森病]] / [[Alzheimer Disease|阿尔茨海默病]]）、[[Diabetes Mellitus|糖尿病]]、[[Myocardial Infarction|心肌梗死]]**等。

### 成体干细胞

- 可向**本身及无关组织类型**的成熟细胞分化 → **转分化**（paragraph 53）。
- **应用**（paragraph 55）：**诱导自体健康干细胞**分化增殖；**体外基因转染**获得多能干细胞。
- **意义**（paragraph 56）：**克服异体移植的免疫排斥**，**避免胚胎干细胞的伦理问题**。

## Exam Pearls

- 干细胞 = **不断更新的必要条件**（对应 [[Labile Cells]] 的持续更新）。
- 区分两型的核心词：胚胎干细胞 —— **全能**、**三个胚层**；成体干细胞 —— **一定分化潜能**、**转分化**。
- 成体干细胞应用的两条优势：**避免免疫排斥**（自体）与**避免伦理问题**（不用胚胎）。
