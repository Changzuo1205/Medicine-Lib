# Thrombosis Consequences（血栓对机体的影响）

## Definition

血栓对机体的影响分为**有利**与**不利**两方面：有利的一面是**破裂血管止血，避免大出血**；不利影响则取决于血栓的**部位、大小、类型、阻塞程度、侧支循环**，讲义列出四项 —— **（一）阻塞血管；（二）血栓栓塞；（三）心瓣膜变形；（四）广泛性出血**。

## 一、有利与不利（讲义 163–164 段）

- **有利**：**破裂血管止血，避免大出血**。
- **不利**：取决于**部位、大小、类型、阻塞程度、侧支循环**。

## 二、阻塞血管（讲义 165–170 段）

- **不完全阻塞** → 实质细胞**萎缩**（营养不良性）。
- **动脉完全阻塞且无有效侧支** → **梗死**（心肌、脑）。
- 坏死继发**腐败菌感染** → **坏疽**。
- **浅表**部位：**侧支循环丰富** → 症状不明显。
- **深部**部位：**无有效侧支循环** → **淤血、出血、坏死**。

## 三、血栓栓塞（讲义 172–176 段）

- **原因**：血栓**黏着不牢固**或**软化碎裂** → 脱落形成**栓子**。
- **举例**：
  - **深部静脉延续性血栓（体尾部）**脱落 → **肺动脉栓塞**。
  - **左心腔、瓣膜及动脉附壁血栓**脱落 → **体循环动脉栓塞**。
  - 栓子内**细菌（+）** → **败血性梗死或脓肿形成**。

## 四、心瓣膜变形（讲义 178–181 段）

- **原因**：**心内膜炎** → 瓣膜**内皮细胞受损** → **反复形成血栓并机化**。
- **特点**：
  - 瓣膜**增厚变硬**、**瓣叶之间粘连** → **瓣膜口狭窄**。
  - 瓣膜**增厚卷缩**、**腱索增粗短缩** → **瓣膜关闭不全**。

## 五、广泛性出血（讲义 182–186 段）

- **触发**：**严重创伤 / 烧伤 / 羊水栓塞 / 肿瘤**等 → **促凝↑** → **外源凝血（+）**；**感染 / 缺氧 / 酸中毒**等 → **广泛内皮损伤** → **内源凝血（+）**。
- **特点**：**微血管内形成透明血栓**（肺 / 肾 / 脑等）→ **广泛坏死及出血**。
- **后果**：**凝血因子大量消耗** → **血液凝固障碍** → **出血性休克**。
- 讲义把此项列为血栓对机体影响的第四项，其本质即**弥散性血管内凝血（DIC）**；机制、透明血栓的镜下特点与讲义的其他交叉引用详见 [[Disseminated Intravascular Coagulation]]，本节点不再重复。

## Clinical Pearls

- **判断不利影响程度的五个因素**：部位、大小、类型、阻塞程度、侧支循环。
- **动脉完全阻塞且无有效侧支循环 → 梗死**，讲义举例为**心肌、脑**。
- **坏死继发腐败菌感染 → 坏疽**。
- **侧支循环决定临床表现**：浅表部位侧支丰富者症状不明显，深部无有效侧支者出现淤血、出血、坏死。
- **栓塞方向两分法**：深部静脉延续性血栓（体尾部）脱落 → **肺动脉栓塞**；左心腔、瓣膜及动脉附壁血栓脱落 → **体循环动脉栓塞**；栓子含细菌 → **败血性梗死或脓肿形成**。
- **心瓣膜变形**由**心内膜炎**反复形成血栓并机化所致，可造成**瓣膜口狭窄**与**瓣膜关闭不全**。
- **广泛性出血**即讲义语境下的 **DIC**，终点为**出血性休克**。
