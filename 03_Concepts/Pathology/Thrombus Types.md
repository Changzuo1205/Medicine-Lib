# Thrombus Types（血栓类型）

## Definition

按形成部位与形态，讲义把血栓分为**白色血栓、混合血栓、红色血栓、透明血栓**四型；前三型依次构成**静脉延续性血栓**的头部、体部与尾部，透明血栓则见于**微循环毛细血管**内，又称**微血栓（microthrombus）**。

## 四型对照表

| 类型 | 部位 | 形成 | 大体 | 镜下 |
|------|------|------|------|------|
| **1. 白色血栓**（white thrombus） | 急性风湿性心内膜炎、静脉延续性血栓的**起始部** | 内皮损伤 → PLT + 纤维蛋白 → **血栓头部** | 小结节或**疣状赘生物**，灰白质实，附着牢固，**不易脱落** | PLT + 少量纤维蛋白 —— 血小板或析出性血栓 |
| **2. 混合血栓**（mixed thrombus） | 静脉内延续性血栓的**体部**；左心房的**球状混合血栓**；动脉粥样硬化斑块、动脉瘤内**附壁血栓（mural thrombus）** | 位于白色血栓下游，构成延续性血栓的体部 | 灰白和暗红（固定呈黑色）相间的**层纹状结构 → 层状血栓**；粗糙、干燥、圆柱状，与血管壁粘连 | **白** —— PLT 梁：淡红染无结构，不规则珊瑚状，附着 N（趋化）；**红** —— PLT 梁间：纤维蛋白网 + 充满 RBC（若崩解呈网格状） |
| **3. 红色血栓**（red thrombus） | 静脉内延续性血栓的**尾部** | 混合血栓逐渐增大阻塞管腔 → 下游局部血流停滞、血液凝固 | 暗红，新鲜湿润有弹性，与血管壁**无粘连**，类似血凝块；陈旧干燥无弹性，质脆易碎，**脱落形成血栓栓塞** | 纤维蛋白网 + 充满血细胞（RBC 为主 + 少量 WBC 均匀分布） |
| **4. 透明血栓**（hyaline thrombus） | **微循环毛细血管**内，又称**微血栓**（microthrombus） | **弥散性血管内凝血（disseminated intravascular coagulation, DIC）** | 讲义未列（位于微循环，不在大体标本层面） | 纤维蛋白构成，**均质红染**，又称**纤维蛋白性血栓**（fibrinous thrombus） |

## 静脉延续性血栓的三段：头白 · 体混合 · 尾红

白 → 混合 → 红不是三种互不相干的病变，而是**同一条静脉延续性血栓**沿血流方向的三个部位：

| 段 | 类型 | 定位 |
|----|------|------|
| **头部** | 白色血栓 | 起始部，由内皮损伤 → PLT + 纤维蛋白形成，附着牢固 |
| **体部** | 混合血栓 | 白色血栓下游增生，呈灰白与暗红相间的层纹状 |
| **尾部** | 红色血栓 | 混合血栓阻塞管腔后，下游血流停滞、血液凝固而成 |

这条顺序与血栓形成的过程（水泥 + 钢筋 5 步）完全对应：过程第 3、4、5 步分别以（白色）（混合）（红色）标注。详见 [[Thrombosis]]。

## 另一条线索：透明血栓

透明血栓**不在这条「头—体—尾」线索上**：它位于**微循环毛细血管**内，是**弥散性血管内凝血（DIC）**的表现，镜下由纤维蛋白构成、**均质红染**，因而又称**纤维蛋白性血栓（fibrinous thrombus）**。它不在肉眼可见的大血管腔内，因此讲义没有给出大体形态。

## 逐型要点

### 白色血栓（white thrombus）

- **部位**：急性风湿性心内膜炎、静脉延续性血栓的起始部
- **形成**：内皮损伤 → PLT + 纤维蛋白 → 血栓头部
- **大体**：小结节或**疣状赘生物**，灰白质实，附着牢固，**不易脱落**
- **镜下**：PLT + 少量纤维蛋白 —— 又称血小板或析出性血栓

### 混合血栓（mixed thrombus）

- **部位**：静脉内延续性血栓的体部；左心房的球状混合血栓；动脉粥样硬化斑块、动脉瘤内**附壁血栓（mural thrombus）**
- **大体**：灰白和暗红（固定呈黑色）相间的**层纹状结构 → 层状血栓**；粗糙、干燥、圆柱状，与血管壁粘连
- **镜下**：**白** —— PLT 梁：淡红染无结构，不规则珊瑚状，附着 N（趋化）；**红** —— PLT 梁间：纤维蛋白网 + 充满 RBC（若崩解呈网格状）

### 红色血栓（red thrombus）

- **部位**：静脉内延续性血栓的尾部
- **形成**：混合血栓逐渐增大阻塞管腔 → 下游局部血流停滞、血液凝固
- **大体**：暗红，新鲜湿润有弹性，与血管壁**无粘连**，类似血凝块；陈旧则干燥无弹性，质脆易碎，**脱落形成血栓栓塞**
- **镜下**：纤维蛋白网 + 充满血细胞（RBC 为主 + 少量 WBC 均匀分布）

### 透明血栓（hyaline thrombus）

- **部位**：微循环毛细血管内，又称**微血栓（microthrombus）**
- **形成**：**弥散性血管内凝血（DIC）**
- **镜下**：纤维蛋白构成，**均质红染**，又称**纤维蛋白性血栓（fibrinous thrombus）**

## Clinical Pearls

- **附着性差别是重要对照**：白色血栓附着牢固、**不易脱落**（如心内膜炎的疣状赘生物）；红色血栓新鲜时与血管壁**无粘连**、类似血凝块，陈旧后质脆易碎、**脱落形成血栓栓塞**。
- **混合血栓的镜下是「白 + 红」两部分**：白为 PLT 梁（珊瑚状，附着 N），红为梁间纤维蛋白网内的 RBC；这种相间结构正对应大体上的层纹状与「层状血栓」命名。
- **命名规则**：白色血栓又叫血小板或析出性血栓；透明血栓又叫微血栓，镜下即纤维蛋白性血栓。
- **附壁血栓（mural thrombus）** 的讲义举例在混合血栓项下：动脉粥样硬化斑块与动脉瘤内。
- 讲义在混合血栓的部位中单列**左心房的球状混合血栓**（与二尖瓣狭窄相关，见 [[Virchow's Triad]] 的血流状态异常部位）。
- 红色血栓的「类似血凝块」是讲义对形态的描写，不等于概念上等同 —— 血栓与血凝块的鉴别见 [[Thrombosis]]。
