# Virchow's Triad（血栓形成三要素）

## Definition

**Rudolf Virchow** 提出的血栓形成三个条件 —— ① 心血管内皮细胞损伤；② 血流状态异常；③ 血液凝固性增加；三者**同时存在，相辅相成**，其中**心血管内皮损伤最重要、最常见**。

## 三条件的总览

| 条件 | 讲义要点 |
|------|----------|
| **① 心血管内皮细胞损伤** | 最重要、最常见；完整内皮抗凝 vs 损伤内皮促凝，并触发血小板活化 |
| **② 血流状态异常** | 血流缓慢与漩涡 → PLT 进入边流、接触并黏附内膜 |
| **③ 血液凝固性增加** | PLT 和凝血因子↑ + 纤溶系统活性↓ → **血液高凝状态** |

**总结（讲义原文）**：三者同时存在，相辅相成 —— 心血管内皮损伤最重要最常见。

## 条件 ① 心血管内皮细胞损伤

### 内皮细胞的特性

**抗凝和促凝两种功能，生理以抗凝为主，保持血液流动。**

### 1. 完整内皮细胞的抗凝作用

| 机制 | 内容 |
|------|------|
| **屏障作用** | 分隔 PLT、凝血因子和内皮下促凝的细胞外基质 |
| **抗血小板黏集** | 合成 **PGI2、NO、ADP 酶** |
| **合成抗凝物质** | **凝血酶调节蛋白、肝素样分子、蛋白 S** |
| **促进纤维蛋白溶解** | 合成**组织型纤溶酶原激活物（t-PA）** |

### 2. 损伤内皮细胞的促凝作用

| 机制 | 链条 |
|------|------|
| **胶原暴露** | XII（+）+ PLT（+）→ **内源性凝血（+）** → 纤维蛋白 |
| **释放组织因子 III** | VII（+）→ **外源性凝血（+）** → 纤维蛋白 |
| **释放 vWF** | 介导 PLT 与胶原粘附 → PLT 激活、释放、黏集 |
| **分泌纤溶酶原激活物抑制物 PAI** | 抑制纤维蛋白溶解 |

**总结**：内皮损伤或被激活 → 促进局部凝血。

### 3. 血小板的活化

| 反应 | 内容 |
|------|------|
| **黏附反应** | vWF 介导 PLT 表面整合素与内皮下胶原结合 |
| **释放反应** | 多种因子颗粒：**PDGF、血栓素 A2（TXA₂）、ADP、Ca²⁺** |
| **黏集反应** | 可逆的 PLT 黏集堆 |

**发展**：凝血酶（+）→ 纤维蛋白 + PLT 紧密交织 → **血栓形成牢固起始点**。

## 条件 ② 血流状态异常

- **原因**：内膜炎、心梗、动脉粥样硬化、缺氧、败血症、毒素、DIC 等
- **特点**：血流缓慢和产生漩涡 → PLT 进入边流 → 接触并黏附内膜
- **机制**：
  - 导致内皮缺氧损伤 → 凝血激活 + PLT 黏集
  - 凝血因子及凝血酶浓度↑ → 局部凝血活性↑
- **部位**：
  1. **静脉**：下肢深 V、盆腔 V —— 静脉瓣、涡流、壁薄受压、血液黏性增加
  2. **心脏**：二尖瓣狭窄的左心房、心肌梗死
  3. **动脉**：粥样硬化斑块、动脉瘤

## 条件 ③ 血液凝固性增加

- **特点**：PLT 和凝血因子↑ + 纤溶系统活性↓ → **血液高凝状态**
- **类型**：
  1. **遗传性（原发性）高凝状态**：V 因子基因突变、先天性缺乏抗凝血酶 III、蛋白 S 或 C
  2. **获得性（继发性）高凝状态**：
     - 促凝因子↑：晚期恶性肿瘤、多发血栓游走性脉管炎
     - PLT 数量和黏性↑：烧伤、大失血、高脂血症、吸烟等

## 三要素的相互关系

讲义强调三者**同时存在、相辅相成**，并明确**心血管内皮损伤最重要、最常见**。从讲义展开的内容看，内皮是三者交汇的枢纽：完整内皮以抗凝为主，损伤或被激活后转为促凝，并同时触发血小板活化（黏附 → 释放 → 黏集）；血流状态异常通过造成内皮缺氧损伤与局部凝血因子、凝血酶浓度升高来放大这一过程；血液凝固性增加则从血液成分一端同时抬高 PLT 与凝血因子、压低纤溶活性。

> [!info] Clinical Reasoning
> 上述「相互关系」一段为**依据讲义三处内容的归纳**（内皮抗凝/促凝对照、血流异常的机制两条、高凝状态的特点），不是讲义原文的整段陈述（AGENTS.md §26）。

## Clinical Pearls

- **最重要的条件只有一个**：心血管内皮损伤 —— 讲义在总结中明确「最重要最常见」，是选择题常见落点。
- 完整内皮的四组抗凝机制可归为「挡（屏障）、黏（抗血小板黏集）、抗（抗凝物质）、溶（促纤溶）」四类，讲义给出的分子为 PGI2、NO、ADP 酶、凝血酶调节蛋白、肝素样分子、蛋白 S、t-PA。
- 损伤内皮的促凝链条是**两条凝血途径并行**：胶原暴露经 XII 走**内源性**，组织因子 III 经 VII 走**外源性**，两者终点都是纤维蛋白；此外 vWF 负责把 PLT 拉到胶原上，PAI 负责压住纤溶。
- 血小板活化三步（黏附 · 释放 · 黏集）中，讲义特别标注黏集反应为**可逆的** PLT 黏集堆，其「牢固化」需要凝血酶与纤维蛋白参与。
- 讲义明确高凝状态的临床举例分两类：遗传性看 V 因子基因突变与抗凝血酶 III、蛋白 S 或 C 缺乏；获得性看晚期恶性肿瘤、多发血栓游走性脉管炎、烧伤、大失血、高脂血症、吸烟等。
- 血流状态异常的血栓好发部位顺序为**静脉 > 心脏 > 动脉**，静脉以下肢深静脉与盆腔静脉为代表。
