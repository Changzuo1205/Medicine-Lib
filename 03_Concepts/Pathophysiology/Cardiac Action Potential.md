# Cardiac Action Potential

## Definition

心室肌（工作细胞）动作电位，由 5 个期相组成：0 期快速去极化、1 期早期快速复极化、2 期平台期、3 期晚期快速复极化、4 期静息期。从 0 期去极化开始到 3 期复极化完毕的时程称为动作电位时程（Action Potential Duration, APD）。

## Ion Mechanisms of the 5 Phases

| 期 | 名称 | 电位变化 | 时间 | 离子机制 |
|----|------|----------|------|----------|
| 0 | 快速去极化 | -90 → +30 mV | 1-2 ms | Na⁺ 快钠通道内流（幅度约 120 mV；速度 200-400 V/s） |
| 1 | 早期快速复极化 | +30 → 0 mV | 约 10 ms | K⁺ 瞬时外向电流 I_to 外流 |
| 2 | 平台期 | 约 0 mV | 100-150 ms | Ca²⁺（I_Ca-L）内流与 K⁺（I_K、I_K1）外流平衡 |
| 3 | 晚期快速复极化 | 0 → -90 mV | 100-150 ms | K⁺（I_K、I_K1）外流 |
| 4 | 静息期 | -90 mV | — | Na⁺-K⁺ 泵与 Na⁺-Ca²⁺ 交换恢复离子浓度梯度 |

- 记忆口诀（讲义原意）：去极化 = 钠内流；早期快速复极 = 钾外流；平台期 = 钙内流 + 钾外流；晚期快速复极 = 钾外流
- APD：心室肌约 200-300 ms

## Key Values

- 静息电位约 -90 mV（心室肌）
- 0 期幅度约 120 mV，去极速度 200-400 V/s
- 平台期 100-150 ms，3 期 100-150 ms

## Atrial vs Ventricular

心房肌（与心室肌相比）：I_K1 密度稍低，静息电位约 -80 mV；I_to 较发达，平台期不明显，复极化快，APD 约 150-200 ms（短于心室肌）；ACh 敏感的钾通道（I_K-ACh）激活时 K⁺ 外流增强，APD 缩短。

## Fast vs Slow Response Cells

- 快反应细胞（心房肌、心室肌、浦肯野细胞）：0 期由 I_Na 介导，有 1、2 期
- 慢反应细胞（窦房结、房室结）：0 期由 I_Ca-L 介导，无 1 期和 2 期，4 期自动去极化
- 详细对比见 [[Pacemaker Activity]]
