# Cardiac Conduction System

## Definition

心肌细胞传导兴奋的能力（传导性）。兴奋经特殊传导系统由窦房结传至心室肌：窦房结 → 心房肌 → 房室结 → 房室束 → 左右束支 → 浦肯野纤维 → 心室肌。

## Components & Characteristics

| 部位 | 特点 |
|------|------|
| 窦房结（SAN） | 心脏起搏点，无收缩性；直接传递兴奋到心房肌纤维；经优势传导通路传递到房室结 |
| 房室结（AVN） | 直径小、闰盘处缝隙连接少、分化程度低 → 传导兴奋能力低；心房传心室的唯一通道；产生房室延搁 |
| 房室束 / 左右束支 | 传导路径 |
| 浦肯野纤维 | 兴奋传导速度最快（约 4 m/s），迅速传到心室肌 |

## Atrioventricular Delay（房室延搁）

- 房室结区传导速度缓慢，且是兴奋由心房传向心室的唯一通道
- 兴奋经过房室结出现约 100 ms 的时间延搁
- 生理意义：保证心房先收缩、心室后收缩的序贯性（atrial-ventricular contraction sequence）

## Rapid Purkinje Conduction

- 浦肯野系统快速传导使兴奋几乎同时到达全部心室肌
- 生理意义：同步化整个心室的收缩（synchronize contraction of entire ventricles）

## Factors Affecting Conductivity

### 解剖因素

- 心肌细胞直径：直径增大 → 传导电阻减小 → 传导性升高
- 缝隙连接：心肌缺血时可关闭（→ 传导减慢）
- 细胞分化程度

### 生理因素

1. **0 期去极化的速度和幅度（最重要因素）**：
   - 0 期去极速度快、幅度大 → 局部电流形成快、电位差大、扩布距离大 → 传导快
   - 奎尼丁抑制 I_Na → 0 期去极化速度慢 → 传导慢（I 类抗心律失常药机制）
2. **膜电位水平**：受刺激前膜电位较小 → Na⁺ 通道不在最佳状态 → 0 期去极化的速度和幅度降低 → 传导减慢（期前兴奋传导减慢）
3. **邻旁未兴奋区的兴奋性**：邻旁未兴奋区兴奋性降低或处于有效不应期 → 达阈电位时间长或不能兴奋 → 传导速度减慢或传导阻滞
