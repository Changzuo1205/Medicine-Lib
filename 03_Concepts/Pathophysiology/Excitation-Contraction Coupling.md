# Excitation-Contraction Coupling

## Definition

心肌兴奋（动作电位）与收缩之间的耦联过程，核心为钙诱导钙释放（Calcium-Induced Calcium Release, CICR）。心肌收缩依赖细胞外 Ca²⁺。

## Mechanism（CICR，钙诱导钙释放）

1. 动作电位 2 期平台期 Ca²⁺ 经 L 型钙通道内流（见 [[Cardiac Action Potential]]）
2. 少量 Ca²⁺ 内流触发肌质网上钙释放通道（ryanodine 受体）大量释放 Ca²⁺（钙诱导钙释放）
3. 胞质 Ca²⁺ 浓度升高 → 触发收缩
4. 舒张期 Ca²⁺ 被 SERCA（肌质网 Ca²⁺-ATP 酶）回摄肌质网；质膜 Ca²⁺-ATP 酶将 Ca²⁺ 泵出细胞

## Key Proteins（讲义图示）

- L 型钙通道（触发）
- 钙释放通道（ryanodine 受体，CICR 释放）
- SERCA（回摄 Ca²⁺）
- 质膜 Ca²⁺-ATP 酶（PPT 标注为 PCA-ATP，可能为 PMCA 之误，待核对）

## Clinical Consequence Link

- 心肌收缩依赖细胞外 Ca²⁺ → 细胞外 Ca²⁺ 变化可影响收缩力（讲义内容，未展开病理部分）
