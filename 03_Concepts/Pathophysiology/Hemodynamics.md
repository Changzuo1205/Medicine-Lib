# Hemodynamics

## Definition

血流动力学基本概念：血流量、血流速度、血流阻力与血压的关系。体循环总血流量（Q）与心输出量相等。

- 血流量（Blood Flow, Q）：单位时间内流过血管某一横截面积的血量（容积速度），单位 ml/min 或 L/min
- 血流速度（Blood Velocity）：血液中某一质点（如红细胞）在血管内移动的线速度

## Poiseuille's Law（泊肃叶定律）

Q = π(P1 - P2) r⁴ / 8ηL

- 流量取决于压力差 ΔP（而非绝对压力）
- 与血管半径 r 的 4 次方成正比
- 与黏度 η 和血管长度 L 成反比

## Resistance of Blood Flow（血流阻力）

R = 8ηL / πr⁴；Q = ΔP / R

- **影响血流阻力的最主要因素：血管半径 r**（r⁴ 反比）
- 各部位阻力分布（体循环）：主动脉和大动脉 9%、小动脉 16%、微动脉 41%、毛细血管 27%、静脉 7%
- 血流阻力最大的部位：微动脉（前阻力血管，口径窄）

## Blood Viscosity（血液黏度）影响因素

1. 血细胞比容（Hematocrit）——**最重要因素**
2. 切率（Shear rate）：层流中相邻两层血液流速差与液层厚度的比值；非牛顿液，切率越高黏滞度越低、阻力越低
3. 口径：小微动脉切率足够高时，口径小 → 黏滞度低
4. 温度：温度降低 → 黏滞度升高

## Laminar vs Turbulent Flow

- 层流：各质点流动方向一致、与血管长轴平行，但各质点流速不同
- 湍流：血流速度加速到一定程度后，各质点流动方向不一致
- 生理意义：湍流有利于血液充分混合（心室腔/主动脉）
- 病理意义：杂音（如瓣膜狭窄）
