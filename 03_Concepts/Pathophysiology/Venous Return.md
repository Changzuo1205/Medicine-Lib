# Venous Return

## Definition

单位时间内由静脉回流心脏的血量（Venous Return = Cardiac Output）。静脉系统阻力很小（约占体循环阻力 7%），微静脉至右心房的压力差仅约 15 mmHg，利于保证静脉回心血量。

## Central Venous Pressure（中心静脉压，CVP）

- 定义：右心房和胸腔内大静脉血压，正常约 4-12 cmH₂O
- 取决于：心脏射血能力 + 静脉回心血量
- 变化：心力衰竭时 CVP ↑；静脉回流增多时 CVP ↑；外周静脉压升高时 CVP ↑
- 意义：心血管功能指标；临床补液监测指标

## Peripheral Venous Pressure & Gravity

- 外周静脉压约 15-20 mmHg，压力低、受重力影响大
- 每 cm 距离产生 0.77 mmHg 静水压变化；平卧转直立时动脉和静脉静水压增高程度相同（约 80 mmHg），但静脉壁薄 → 重力对静脉影响更大
- 跨壁压 = 血压 - 血管外组织对管壁的压力；跨壁压为负时静脉塌陷；一定跨壁压是保持血管充盈扩张的必要条件

## Factors Affecting Venous Return（影响静脉回流 5 因素）

| 因素 | 静脉回流量 | 备注 |
|------|-----------|------|
| 体循环平均充盈压（循环血量）↑ | ↑ | 失血 → 静脉回流 ↓ |
| 心肌收缩力（心泵）↑ | ↑ | 心衰 → 静脉回流 ↓ |
| 骨骼肌收缩（肌肉泵）↑ | ↑ | 长期站立 + 静脉瓣膜薄弱 → 下肢静脉曲张 |
| 呼吸运动（呼吸泵）↑ | ↑ | 吸气助回流 |
| 体位：卧→立 | ↓ | 直立时血液滞留下肢；立→卧 ↑ |

- 心衰（讲义简列）：左心衰 → 肺淤血/肺水肿；右心衰 → 颈静脉怒张、肝充血肿大、下肢水肿
