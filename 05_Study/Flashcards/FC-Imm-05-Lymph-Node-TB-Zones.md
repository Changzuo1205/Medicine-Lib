# FC-Imm-05 — 淋巴结 T/B 细胞区

## Front

淋巴结中 T 细胞和 B 细胞分别定居于哪个区域？

## Back

| 细胞 | 区域 |
|------|------|
| **B 细胞**（~25%） | **浅皮质区**（非胸腺依赖区，含淋巴滤泡） |
| **T 细胞**（~75%） | **深皮质区 / 副皮质区**（胸腺依赖区，含 HEV） |
