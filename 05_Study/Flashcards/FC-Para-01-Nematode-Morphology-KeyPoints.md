# FC-Para-01 — 线虫成虫与虫卵的核心形态要点

## Front

线虫成虫与虫卵的核心形态要点？

## Back

**成虫**

- **圆柱形、不分节、两侧对称**，**线状，乳白色**
- **雌雄异体，♀ 大 ♂ 小**；**♂ 虫尾端多向体腹面卷曲或膨大**
- 大小约 **1–15 cm**
- **原体腔（protocoele）**：**体壁与消化管之间**的腔隙，**无体腔膜覆盖**

**体壁三层**：① **角皮层**　② **皮下层**　③ **纵肌层**

**内部四大系统**：① **消化**　② **生殖**　③ **神经**　④ **排泄**

**虫卵**

- **无卵盖**（与吸虫卵的卵盖相反）
- 结构 = **蛋白质膜 + 卵壳 + 内含物**；多为**卵圆形**
- **卵壳 3 层**：**外**为卵黄膜 / **中**为壳质层 / **内**为脂层
- **内含物**可为**单细胞**、**多细胞**或**幼虫**
