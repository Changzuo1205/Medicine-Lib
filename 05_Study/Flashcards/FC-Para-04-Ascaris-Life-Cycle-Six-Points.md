# FC-Para-04 — 蛔虫生活史的六个必背要素

## Front

蛔虫生活史的六个必背要素？

## Back

**生活史为直接型**（不需要中间宿主）

1. **感染阶段** = **感染期蛔虫卵**
2. **感染途径与方式** = 通过污染的食物、饮水，**经手-口途径**感染
3. **体内移行** = 口 → 小肠 → 门静脉 → 肝脏 → 右心 → **肺脏** → 气管 → 咽 → 食管 → 胃 → 小肠
4. **寄生部位（成虫）** = **小肠**
5. **寿命** = **1 年**
6. **在外界发育** 约 **60–75 天**，适宜温度 **21–30 ℃**

**传染源** = 粪便内含**受精**蛔虫卵的人

> 幼虫需经**肺**移行，故有肺蛔虫症（见 [[Loeffler Syndrome]]）；只有**受精卵**才能发育，故传染源定义强调「受精」。
