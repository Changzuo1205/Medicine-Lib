# FC-Para-05 — 蛔虫的并发症及其发生机制

## Front

蛔虫的并发症有哪些？发生机制是什么？

## Back

**蛔虫的特性（机制基础）**：**钻孔习性、喜酸厌碱、扭曲成团**。

**诱因**：**寄生环境改变** —— 发热、胃肠病变、食用辛辣食物以及**不当的驱虫治疗**。

**发生机制**：上述诱因 → 刺激虫体**活动力增强** → 容易钻入**胆管、胰管和阑尾**等**开口于肠壁上的各种管道**。

**5 项并发症**：

1. **胆道蛔虫症**（详见 [[Biliary Ascariasis]]）
2. **肠梗阻**
3. **蛔虫性胰腺炎**
4. **蛔虫性阑尾炎**
5. **肝蛔虫病**

**定位提示**：讲义将「并发症」单列为第三部分，与「一、幼虫致病」「二、成虫致病」并列。幼虫移行经肺脏所致者为**肺蛔虫症（Loeffler 综合征）**，不属本组并发症范畴（见 [[Loeffler Syndrome]]）。
