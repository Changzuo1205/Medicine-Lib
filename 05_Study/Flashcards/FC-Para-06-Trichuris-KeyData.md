# FC-Para-06 — 鞭虫成虫、虫卵与生活史核心数据

## Front

鞭虫成虫、虫卵与生活史的核心数据？

## Back

**分类位置**：**无尾感器纲**（与蛔虫所属**小杆纲**不同）；**土源性线虫**，生活史为**直接型**，不需要中间宿主。

**成虫形态**：**形似马鞭** —— **前 3/5 细长（为食管所占）**、**后 2/5 较粗**（内有肠管及生殖器官）；活时**淡灰色**。

| 性别 | 长度 | 生殖系统 | 尾端 |
|------|------|----------|------|
| **雌虫** | **30–50 mm** | 单管 | 尾端**垂直钝圆** |
| **雄虫** | **30–45 mm** | 单管 | 尾端向腹面作**环状卷曲**，有**一根交合刺** |

**虫卵**：

- 大小 **50–54 μm × 22–23 μm**
- **纺锤形**，**黄褐色**
- 卵壳**较厚**，**两端各具一透明栓**（最具鉴别意义）
- 内含**一卵细胞**

**生活史（直接型）**：

| 要素 | 内容 |
|------|------|
| 外界发育 | 约 **60 天** |
| **成虫寄生部位** | **盲肠** |
| **感染阶段** | **感染期虫卵** |
| **感染方式** | **经口**食入污染的食物、水 |
| **寿命** | **3–5 年** |
| **每日产卵量** | **5 000–20 000 个** |

**流行**：世界性分布，多见于**热带、温带地区**；我国**南方多于北方**；**严重感染者虫数可达 4 千条以上**；常与**蛔虫感染并存**；**儿童感染多于成人**；**人是唯一传染源**。

**防治**：防治原则、治疗药物**与蛔虫相同**（治疗药物为丙硫咪唑 / 肠虫清等 —— 按本知识库规则不收录具体剂量）。
