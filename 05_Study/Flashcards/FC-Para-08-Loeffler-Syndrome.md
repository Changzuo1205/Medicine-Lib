# FC-Para-08 — 肺蛔虫症（Loeffler 综合征）要点

## Front

肺蛔虫症（Loeffler 综合征）的要点？

## Back

**概念**：**肺蛔虫症亦称 Loeffler 综合征（蛔蚴性肺炎）**。讲义另一处表述：**肺部的炎性浸润和血中嗜酸性细胞增多通常称之为肺蛔虫症**。

**归属**：属蛔虫**幼虫致病** —— 幼虫在**体内移行必经肺脏**（口 → 小肠 → 门静脉 → 肝脏 → 右心 → **肺脏** → 气管 → 咽 → 食管 → 胃 → 小肠）。

**临床表现**：

- **发热、咳嗽、哮喘、血痰**等
- 血中**嗜酸性粒细胞可增多**

**影像**：**X 线见肺部阴影、常有游走现象**，多在 **1–2 周内自行消失**。

**诊断**：可用**痰中查蛔蚴**（讲义列为用于**肺蛔虫症**或蛔虫幼虫引起的**过敏性肺炎**的诊断）。

**名称的四种写法**：讲义在本章中同时使用 —— **肺蛔虫症** / **Loeffler 综合征** / **Loffler's syndrome** / **蛔蚴性肺炎**；检索时四种写法均指向同一疾病概念。

> [!warning] 讲义未给出
> **讲义未给出**该综合征的**诊断标准**、**发生率**、以及**与其他嗜酸性粒细胞肺浸润（如过敏性肺炎）的鉴别** —— 不要替讲义补充。
