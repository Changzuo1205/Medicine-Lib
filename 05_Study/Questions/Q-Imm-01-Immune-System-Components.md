# Q-Imm-01 — 免疫系统的组成（多选）

## Stem

下列哪些**正确**描述了免疫系统的组成？（多选）

## Options

- A. 免疫细胞、黏膜免疫系统、中枢免疫器官
- B. 免疫器官、免疫细胞、免疫分子
- C. 中枢免疫器官、免疫细胞、皮肤免疫系统
- D. 免疫分子、黏膜免疫系统、皮肤免疫系统
- E. 中枢免疫器官、外周免疫器官

## Correct Answer

**B、E**（并参考 A、C、D 的部分内容）

> **正确答案解析**（按 PPT 框架）：
> - **B** 完全正确 — 免疫系统 = 免疫器官 + 免疫细胞 + 免疫分子（三部分）
> - **E** 完全正确 — 按器官分类 = 中枢免疫器官 + 外周免疫器官
> - A、C、D 是干扰项，但部分内容真实（黏膜/皮肤免疫系统属于"免疫组织"分类），但在"免疫系统组成"的严格定义下不如 B、E 完整

## Explanation

按 PPT p9 框架：

```
免疫系统的组成
├── 免疫器官和组织
│   ├── 中枢（胸腺、骨髓）
│   └── 外周（脾、淋巴结）+ 免疫组织（MALT、皮肤、肝脏）
├── 免疫细胞（淋巴细胞、DC、NK、Mφ、粒细胞、肥大细胞…）
└── 免疫分子
    ├── 膜型（CD、黏附、MHC、细胞因子受体、TCR、BCR）
    └── 分泌型（免疫球蛋白、补体、细胞因子）
```

**关键提示**：题目问"组成"而非"分类"，B 是最规范的三组分答案；E 是器官分类的另一视角。

## Knowledge Point

免疫系统由**免疫器官/组织、免疫细胞、免疫分子**三部分组成。
