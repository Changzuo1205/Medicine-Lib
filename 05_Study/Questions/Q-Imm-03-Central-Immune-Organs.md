# Q-Imm-03 — 中枢免疫器官与组织（多选）

## Stem

下列关于**中枢免疫器官和组织**的叙述，**正确的是**？（多选）

## Options

- A. 是免疫细胞发生、分化、成熟的场所
- B. 人类中枢免疫器官包括胸腺、骨髓
- C. 骨髓是诱导 B 淋巴细胞分化、成熟的场所
- D. 骨髓是诱导 T 淋巴细胞分化、成熟的场所

## Correct Answer

**A、B、C**

## Explanation

| 选项 | 判断 | 理由 |
|------|------|------|
| A | ✅ | 中枢免疫器官 = 初级淋巴器官，是免疫细胞发生 / 分化 / 发育 / 成熟的场所（PPT p19） |
| B | ✅ | 人类中枢免疫器官 = **胸腺 + 骨髓**（PPT p9、p19） |
| C | ✅ | B 细胞在骨髓中分化、成熟（PPT p24） |
| D | ❌ | **T 细胞在胸腺**而非骨髓中分化、成熟 |

**易错点**：骨髓是 HSC 起源地，T 细胞前体也来源于骨髓 HSC，但 T 细胞的**分化、成熟**发生在**胸腺**（不是骨髓）。

## Knowledge Point

| 细胞类型 | 分化成熟场所 |
|----------|--------------|
| HSC（造血干细胞） | 骨髓 |
| B 细胞 | **骨髓** |
| NK 细胞 | **骨髓** |
| T 细胞 | **胸腺** |
