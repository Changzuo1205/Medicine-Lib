# Q-Imm-06 — 免疫系统的三大基本功能（Recall）

## Stem

请列出免疫系统的**三大基本功能**，并各举一个**典型异常后果**。

## Options

（简答题）

## Correct Answer

| 功能 | 英文 | 典型异常（不足 / 过强 / 异常） |
|------|------|------------------------------|
| 免疫防御 | immune defense | 免疫缺陷（不足）/ 超敏反应（过强） |
| 免疫监视 | immune surveillance | 肿瘤（监视不足） |
| 免疫自稳 | immune homeostasis | 自身免疫病（自稳失败） |

## Explanation

这是医学免疫学的"主线索"——任何免疫学现象都可以归结到这三项功能：

```
                ┌→ 免疫防御 → 防 / 清病原体（外敌）
抗原进入机体 ──→ ┼→ 免疫监视 → 清"非己"（肿瘤 / 衰老细胞）
                └→ 免疫自稳 → 自身耐受 + 调节（内环境稳定）
```

**记忆技巧**：**外 / 内 / 己** — 防外敌、查内变、稳自身。

## Knowledge Point

免疫系统的三大功能 = 免疫防御 + 免疫监视 + 免疫自稳。
