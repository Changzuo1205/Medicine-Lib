# Q-Imm-07 — 适应性免疫的三大特点（Recall）

## Stem

适应性免疫的**三大特点**是什么？分别对应 B / T 细胞上的哪种分子基础？

## Correct Answer

| 特点 | 含义 | 分子基础 |
|------|------|----------|
| **特异性** | 针对特定抗原 | **BCR / TCR** 多样性 |
| **耐受性** | 不攻击自身抗原 | 中枢耐受（胸腺 / 骨髓阴性选择）+ 外周耐受（Treg 等） |
| **记忆性** | 二次应答更快更强 | **记忆细胞**（Tm / Bm） |

## Explanation

**为什么这三点重要**：

- **特异性** → 解释为什么一种疫苗只防一种病
- **耐受性** → 解释为什么免疫系统通常不攻击自身（耐受被打破 → 自身免疫病）
- **记忆性** → 解释为什么疫苗有效、二次感染症状轻

**对比固有免疫**（PPT p13）：固有免疫**无记忆、无耐受（针对自身）、无特异性**，所以"先天的、不升级的"。

## Knowledge Point

适应性免疫 = 特异性 + 耐受性 + 记忆性，依赖 BCR / TCR 多样性与阴性选择。
