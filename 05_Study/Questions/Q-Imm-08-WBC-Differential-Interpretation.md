# Q-Imm-08 — 解读外周血白细胞构成（Interpretation）

## Stem

一名健康成年人外周血白细胞分类计数如下：

| 细胞 | 比例 |
|------|------|
| 中性粒细胞 | 65% |
| 嗜酸性粒细胞 | 4% |
| 嗜碱性粒细胞 | 0.5% |
| 单核细胞 | 7% |
| 淋巴细胞 | 23.5% |

下列解读**哪一项最合适**？

## Options

- A. 该患者嗜酸性粒细胞增多，可能提示寄生虫感染
- B. 该患者嗜碱性粒细胞增多，可能提示 I 型超敏反应
- C. 该患者中性粒细胞绝对增多，提示细菌感染
- D. 各项均在正常范围内，无明显异常

## Correct Answer

**D**

## Explanation

按 PPT p50-51：

| 细胞 | 讲义所述占比（PPT p50–52） | 该患者 |
|------|------------------------------|--------|
| 中性粒细胞 | 60–70% | 65% |
| 嗜酸性粒细胞 | 5–6% | 4% |
| 嗜碱性粒细胞 | 0.2%（外周血最少） | 0.5% |
| 单核细胞 | 3–8% | 7% |

**该患者各项百分比均属正常波动，故选 D**（判定口径见下方警示）。

> [!warning] 2026-09-14 修正（原答案表自相矛盾）
> 原表把讲义所述**典型占比**当作「正常范围」，却给低于 5–6% 的 4% 与高于 0.2% 的 0.5% 都打了 ✅，
> 并与下方干扰项分析「4% 并未升高（应在 ≥5% 才考虑升高）」的口径冲突 → **同一文件内两套阈值**。
> 现将该列改标为「讲义所述占比」、去掉了自相矛盾的 ✅。
> **判定阈值（嗜酸性 <5% 为正常、嗜碱性 0.5% 不高）与讲义数值存在出入，待教材核对**（`source_status: needs_review`）。

**干扰项分析**：
- A 错在患者嗜酸性比例 4% 并未升高（应在 ≥5% 才考虑升高）
- B 错在嗜碱性比例 0.5% 也不高
- C 错在不能仅看百分比，需结合**绝对计数**与**临床背景**

## Knowledge Point

外周血白细胞比例解读：中性粒 60–70% 最多；嗜碱最少（0.2%）；解读需结合**百分比 + 绝对值 + 临床**。
