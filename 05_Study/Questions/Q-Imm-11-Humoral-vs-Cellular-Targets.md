# Q-Imm-11 — 体液免疫 vs 细胞免疫的微生物针对性（Differential）

## Stem

一名巨噬细胞吞噬了结核分枝杆菌但**仍存活**。下列哪一类适应性免疫**最关键**地清除这一感染？

## Options

- A. 体液免疫（抗体介导）
- B. 细胞免疫（CD4⁺ Th1）
- C. 细胞免疫（CD8⁺ CTL）
- D. 补体旁路途径

## Correct Answer

**B**

## Explanation

按 PPT p15：

| 微生物类型 | 主要针对免疫 |
|------------|--------------|
| 胞外病原体 / 毒素 | **体液免疫（B 细胞 → 浆细胞 → 抗体）** |
| 被巨噬细胞吞噬但仍存活的胞内菌 | **细胞免疫（CD4⁺ Th1）** |
| 能在细胞内复制的病毒 | **细胞免疫（CD8⁺ CTL）** |

**结核分枝杆菌**典型属于第二类：被 Mφ 吞噬但能逃逸吞噬体、继续在胞内存活。需要：
- CD4⁺ Th1 → 分泌 IFN-γ → 激活 Mφ → 增强杀菌能力
- CTL 在某些阶段也参与

**为什么 A 错**：抗体对胞内菌效果有限（抗体不能进入细胞内）。
**为什么 C 不最佳**：CTL 主要针对在细胞质复制的病毒（如流感、HIV）。

## Knowledge Point

"胞内菌"≠ "病毒"：胞内菌更依赖 Th1 + 激活的 Mφ；病毒更依赖 CTL。
