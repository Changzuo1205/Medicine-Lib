# Q-Imm-12 — 脾切除后凶险感染（Clinical Reasoning）

## Stem

一名 35 岁患者因外伤性脾破裂行脾切除术。术后 3 年，突发高热、休克，血培养检出**肺炎链球菌**。最可能的诊断与机制是？

## Options

- A. 普通菌血症，与脾切除无关
- B. **脾切除后凶险感染（OPSI, Overwhelming Post-Splenectomy Infection）**，因脾是血源性抗原免疫应答主战场
- C. 肺炎链球菌对脾切除患者天然耐药
- D. 脾切除导致 T 细胞缺乏

## Correct Answer

**B**

## Explanation

**机制（PPT p30）**：
- 脾是人体最大的外周免疫器官
- 体内约 **90% 的循环血液流经脾**
- 脾内的 Mφ 与 DC 对**血源性抗原**（细菌 / 毒素）产生强吞噬与免疫应答
- 失去脾 → 对血源**包膜菌**（肺炎链球菌、脑膜炎奈瑟菌、流感嗜血杆菌）的清除能力显著下降

**OPSI 临床特征**：
- 起病急骤（数小时内）
- 高热、休克、DIC
- 病死率高达 **50–70%**
- 主要致病菌：**肺炎链球菌（50–70%）**

**预防**：
- 脾切除前接种 pneumococcal / meningococcal / Hib 疫苗
- 术后警惕发热 → 立即就诊 + 经验性抗生素

## Knowledge Point

脾是对**血源性抗原**免疫应答的主要场所；脾切除 → OPSI 风险，核心致病菌为肺炎链球菌。
