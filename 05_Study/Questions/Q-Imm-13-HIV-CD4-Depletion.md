# Q-Imm-13 — HIV 感染为何导致免疫崩溃？（Clinical Reasoning）

## Stem

HIV 病毒主要感染哪类免疫细胞？由此最直接引发的免疫功能崩溃是哪一类？常见的后果是什么？

## Correct Answer

- **靶细胞**：HIV 主要感染 **CD4⁺ T 细胞**（Th 细胞）— 通过 gp120 + CD4 + CCR5 / CXCR4 共受体进入
- **直接后果**：**细胞免疫**严重缺陷（CD4⁺ T 是辅助所有适应性免疫应答的核心细胞）
- **典型表现**：机会性感染（卡氏肺孢子菌肺炎、弓形虫、巨细胞病毒等）、恶性肿瘤（Kaposi 肉瘤、淋巴瘤）

## Explanation

**为什么 CD4⁺ T 缺失会引发广泛免疫崩溃**：

- CD4⁺ Th 是"指挥中心"：
  - **Th1** → 激活 Mφ（细胞免疫）
  - **Th2** → 辅助 B 细胞（体液免疫）
  - **Th17** → 中性粒细胞募集（炎症 / 黏膜免疫）
- 失去 CD4⁺ T → 几乎所有适应性免疫分支都受累

**记忆要点**：**CD4⁺ T 是免疫系统的"中枢指挥官"** — HIV 攻击指挥官，导致整个军队瘫痪。

## Knowledge Point

HIV 感染 CD4⁺ T → 细胞免疫缺陷为主 → 机会性感染 + 恶性肿瘤。
