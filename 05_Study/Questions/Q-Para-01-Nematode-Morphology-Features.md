# Q-Para-01 — 线虫纲的主要形态特征（Recall）

## Stem

线虫纲有哪些主要形态特征？

## Options

（简答题）

## Correct Answer

按 [[Nematode]]，线虫的形态特征分**成虫**、**体壁**、**内部器官**、**虫卵**四个层面作答。

### 一、成虫形态

| 特征 | 内容 |
|------|------|
| 外形 | **圆柱形**、**不分节**、**两侧对称**、**线状**、**乳白色** |
| 性别 | **雌雄异体** |
| 大小 | **♀ 大 ♂ 小**；**♂ 虫尾端多向体腹面卷曲或膨大** |
| 体长 | 约 **1–15 cm** |
| 体腔 | 具**原体腔（protocoele）** —— 位于**体壁与消化管之间**，**无体腔膜覆盖** |

### 二、体壁三层

1. **角皮层**
2. **皮下层**
3. **纵肌层**

### 三、内部器官四大系统

| 系统 | 讲义标注 |
|------|----------|
| 消化系统 | D |
| 生殖系统 | M / F |
| 神经系统 | N |
| 排泄系统 | E |

### 四、虫卵形态

- **无卵盖**
- 结构 = **蛋白质膜 + 卵壳 + 内含物**
- 多为**卵圆形**
- **卵壳 3 层**：**外** 卵黄膜 / **中** 壳质层 / **内** 脂层
- **内含物**可为**单细胞**、**多细胞**或**幼虫**

> 生理与分类可作为补充（不是本题的形态特征主项）：成虫期行**糖类代谢**、**无呼吸器官**、氧多数经**体壁**吸收、体表可进行水的交换；按尾感器有无分**小杆（有尾感器）纲**与**无尾感器纲**。

## Explanation

本题是线虫概论的**总纲式回忆题**，考的是「把散点归纳成有层次的框架」的能力。建议按**成虫 → 体壁 → 内部器官 → 虫卵**四段作答，每段给出可判分的硬指标（数字、层数、颜色、对称性）。

**常见失分点：**

- **原体腔的限定词漏写**：只说「有体腔」不得分，关键限定是「**无体腔膜覆盖**」，且位置在**体壁与消化管之间**。
- **体壁三层顺序颠倒**：正确顺序为**角皮层 → 皮下层 → 纵肌层**。
- **雌雄差异只答「异体」**：应补充 **♀ 大 ♂ 小** 与 **♂ 尾端向腹面卷曲或膨大**。
- **虫卵混入吸虫特征**：线虫虫卵 **无卵盖**（卵盖是吸虫卵的特征）；卵壳是**三层**而非一层。
- **把「有尾感器/无尾感器」当成形态特征主线**：它是**分类**依据，本题问形态特征，写成补充即可。

## Knowledge Point

线虫成虫的形态口诀是「**圆柱、不分节、两侧对称、雌雄异体**」，外加**原体腔（无体腔膜覆盖）**；体壁三层、内部四大系统；虫卵**无卵盖、卵壳三层**。
