# Q-Para-02 — 蛔虫与鞭虫生活史的异同（Differential）

## Stem

蛔虫与鞭虫的生活史有何异同？

## Options

（简答题）

## Correct Answer

本题的答题骨架是「**先列相同点，再做逐项对照表**」。依据 [[Ascaris lumbricoides]] 与 [[Trichuris trichiura]]。

### 一、相同点

| 相同点 | 内容 |
|--------|------|
| 生活史类型 | 均为**土源性线虫**、**直接型**，**不需要中间宿主** |
| 感染阶段 | 均为**感染期虫卵** |
| 感染途径 | 均**经口**感染 —— 食入被感染期虫卵污染的食物、水 |
| 传染源 | 均为**人**（鞭虫讲义明确「**人是唯一传染源**」；蛔虫为粪便内含**受精蛔虫卵**的人） |
| 防治原则 | 相同 |
| 治疗药物 | 相同（药物名称见下） |

### 二、不同点（对照表）

| 项目 | 蛔虫（[[Ascaris lumbricoides]]） | 鞭虫（[[Trichuris trichiura]]） |
|------|----------------------------------|----------------------------------|
| **纲** | **小杆（有尾感器）纲** | **无尾感器纲** |
| **成虫寄生部位** | **小肠** | **盲肠** |
| **寿命** | **1 年** | **3–5 年** |
| **虫卵在外界发育** | 约 **60–75 天**，适宜温度 **21–30 ℃** | 约 **60 天** |
| **体内移行** | **有**组织内移行：口 → 小肠 → 门静脉 → 肝脏 → 右心 → 肺脏 → 气管 → 咽 → 食管 → 胃 → 小肠 | **不经过组织内移行**，虫卵在土壤中发育为感染期虫卵后经口进入人体 |
| **每日产卵量** | 讲义未给出数值 | **5 000–20 000 个** |
| **虫卵形态** | 受精卵**宽椭圆形**，平均 **60 × 45 μm**，卵壳较厚三层、外有**凹凸不平的蛋白质膜**，内含**一大而圆的卵细胞**并见**新月形空隙**；未受精卵**长椭圆形**，**90 × 40 μm**，内含**折光性颗粒**、**无蛔甙层** | **纺锤形**，**50–54 μm × 22–23 μm**，**黄褐色**，卵壳较厚，**两端各具一透明栓**，内含**一卵细胞** |
| **成虫形态** | 圆柱形，粉红色，死后灰白色，**3 个唇瓣呈「品」字形**围绕口孔；♀ 20–35 cm / ♂ 15–31 cm，♂ 尾端向腹面弯曲、有**交合刺一对** | 形似**马鞭**，**前 3/5 细长为食管所占、后 2/5 较粗**；♀ 30–50 mm / ♂ 30–45 mm，♂ 尾端作**环状卷曲**、有**一根交合刺** |
| **致病特点** | 以**并发症**著称（胆道蛔虫症、肠梗阻等）；幼虫期有**肺蛔虫症（Loeffler 综合征）** | 以**慢性失血 → 贫血**、儿童**直肠脱垂**为特征 |
| **诊断侧重** | 生理盐水直接涂片法为主；另有**改良加藤法**、**痰中查蛔蚴**、**驱虫治疗性诊断** | 直接涂片法 + **饱和盐水浮聚法**；**虫卵小易漏检 → 连续粪检三次以上** |

### 三、治疗药物（仅名称，不写剂量）

两虫防治原则与治疗药物相同：**丙硫咪唑（阿苯哒唑 / 肠虫清）**、**甲苯咪唑**、**左旋咪唑**等。

> [!warning] 本知识库不存储具体剂量
> 实际用药须核对最新权威指南（如 WHO 寄生虫病治疗指南）与药品说明书，并结合患者年龄、妊娠状态与肝肾功能由临床医师决定。

## Explanation

本题是本讲的**主线题**：讲义与课堂笔记都把「蛔虫与鞭虫的同与不同」列为重点，因为两虫在**传播环节高度重叠、在寄生部位与后果上明显分道**。

**判分要点（易丢分的四处）：**

1. **纲**：蛔虫属**小杆（有尾感器）纲**，鞭虫属**无尾感器纲** —— 这是最容易被记反的一项（口诀：**蛔在小杆，鞭在无尾感器**）。
2. **寄生部位**：蛔虫 **小肠** vs 鞭虫 **盲肠**。部位差异直接解释了两者症状不同（脐周痛 / 营养障碍 vs 慢性失血、贫血、直肠脱垂）。
3. **体内移行**：蛔虫**必经肺脏**（故有肺蛔虫症），鞭虫**不经过组织内移行** —— 这一项决定了蛔虫有「幼虫致病」阶段而鞭虫没有。
4. **寿命与产卵量**：蛔虫 **1 年**，鞭虫 **3–5 年**；产卵量数值**只在鞭虫项下有记载**（5 000–20 000 个/日），蛔虫项讲义未给出数值，**不要凭印象补一个数**。

另一常见失分是把「传染源」写成差异点：两虫**都是人**（鞭虫「人是唯一传染源」；蛔虫为粪便内含受精蛔虫卵的人），只是表述口径不同。

## Knowledge Point

蛔虫与鞭虫**同为土源性、直接型、经口感染感染期虫卵、防治原则与药物相同**；区别集中在**纲（小杆 vs 无尾感器）、寄生部位（小肠 vs 盲肠）、寿命（1 年 vs 3–5 年）、有无组织内移行、虫卵形态**。
