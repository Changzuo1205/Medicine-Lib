# Q-Para-03 — 蛔虫的致病机理与主要并发症（Recall）

## Stem

蛔虫的致病机理？有哪些主要并发症？

## Options

（简答题）

## Correct Answer

按 [[Ascariasis]]，蛔虫致病分**幼虫致病**、**成虫致病**、**并发症**三部分。

### 一、幼虫致病

幼虫在体内移行，经**肺脏**时引起**肺蛔虫症**，亦称 **Loeffler 综合征**（蛔蚴性肺炎）。

| 项目 | 内容 |
|------|------|
| 症状 | **发热、咳嗽、哮喘、血痰**等 |
| 血象 | 血中**酸性（嗜酸性）粒细胞可增多** |
| 影像 | X 线见**肺部阴影**，常有**游走现象**，多在 **1–2 周内自行消失** |
| 异位损害 | 幼虫也可引起**肝、脑、肾、甲状腺、脾**等器官的**异位损害（Ectopic lesion）** |

> 肺蛔虫症指肺部的炎性浸润和血中嗜酸性细胞增多，详见 [[Loeffler Syndrome]]。

### 二、成虫致病

**（1）掠夺营养与破坏肠黏膜影响吸收**

蛔虫以人体肠腔内**半消化物**为食，**代谢产物毒性刺激**，损伤肠黏膜，导致**消化和吸收障碍**。

- 临床表现：**食欲不振、恶心、呕吐、间歇性脐周疼痛、营养不良**等
- **重度感染的儿童可引起发育障碍**

**（2）超敏反应**

- 症状：**荨麻疹、皮肤瘙痒、血管神经性水肿、结膜炎、过敏性紫癜**等
- 机制：**蛔虫变应原被人体吸收后，引起 IgE 介导的变态反应**

### 三、主要并发症（机制 + 清单）

**机制** —— 蛔虫的特性为「**钻孔习性，喜酸厌碱，扭曲成团**」。**寄生环境改变**（如**发热、胃肠病变、食用辛辣食物以及不当的驱虫治疗**）常可刺激虫体**活动力增强**，容易钻入**胆管、胰管和阑尾**等**开口于肠壁上的各种管道**，由此产生：

| 并发症 | 说明 |
|--------|------|
| **胆道蛔虫症** | 详见 [[Biliary Ascariasis]] |
| **肠梗阻** | 与「扭曲成团」相关 |
| **蛔虫性胰腺炎** | 钻入胰管 |
| **蛔虫性阑尾炎** | 钻入阑尾 |
| **肝蛔虫病** | — |

## Explanation

本题是蛔虫一节**信息量最大**的回忆题，答题关键是**分层不乱**：幼虫致病（肺部 + 异位损害）／成虫致病（营养与肠黏膜 + 超敏反应）／并发症（机制 + 5 条清单）。

**常见失分点：**

1. **把肺蛔虫症错记成成虫致病** —— 讲义明确把肺蛔虫症（Loeffler 综合征）归入**幼虫致病**，是幼虫移行经过肺脏所致。
2. **超敏反应漏写机制** —— 答「荨麻疹、皮肤瘙痒」只是现象，**IgE 介导的变态反应**才是得分点；它与虫体造成的机械损伤是**两套不同机制**。
3. **并发症只罗列名称、不写机制** —— 讲义特意给出「**钻孔习性、喜酸厌碱、扭曲成团**」这一行为学基础，以及**诱因**（发热、胃肠病变、辛辣食物、**不当的驱虫治疗**）。诱因一项常被忽略，但它有临床意义：**驱虫本身不规范即可诱发并发症**。
4. **漏掉「异位损害」** —— 幼虫可致**肝、脑、肾、甲状腺、脾**的异位损害。注意：这是**人体蛔虫自身幼虫**的致病表现，**不要与「幼虫移行症」混为一谈**（后者讲义专指**动物寄生线虫**的幼虫，见 [[Larva Migrans]]）。
5. **并发症数量答不全** —— 应为 5 条：胆道蛔虫症、肠梗阻、蛔虫性胰腺炎、蛔虫性阑尾炎、肝蛔虫病。

## Knowledge Point

蛔虫致病 = **幼虫期肺蛔虫症 / Loeffler 综合征 + 异位损害**，**成虫期掠夺营养破坏肠黏膜 + IgE 介导超敏反应**，**并发症源于「钻孔习性、喜酸厌碱、扭曲成团」→ 胆道蛔虫症、肠梗阻、蛔虫性胰腺炎、蛔虫性阑尾炎、肝蛔虫病**。
