# Q-Para-08 — 蛔虫幼虫的体内移行路线及其对应临床表现（Recall）

## Stem

请按顺序完整写出**蛔虫幼虫在人体内的移行路线**，并指出这条路线可以解释**哪一个临床表现**。

## Options

- A. 口 → 小肠 → **淋巴管 → 胸导管 → 左心** → 肺 → 气管 → 咽 → 食管 → 胃 → 小肠；解释**肠梗阻**
- B. 口 → 小肠 → **门静脉 → 肝脏 → 右心 → 肺脏 → 气管 → 咽 → 食管 → 胃 → 小肠**；因幼虫**必经肺脏**，故有**肺蛔虫症（Loeffler 综合征 / 蛔蚴性肺炎）**
- C. 口 → **结肠 → 盲肠** → 门静脉 → 肝 → 右心 → 肺 → 小肠；解释**直肠脱垂**
- D. 皮肤 → 淋巴管 → 右心 → 肺 → 气管 → 咽 → 食管 → 胃 → 小肠；解释**钩蚴性皮炎**

## Correct Answer

**B**

**移行路线（依据 [[Ascaris lumbricoides]] 生活史表，讲义 slide 18–19）**：

> **口 → 小肠 → 门静脉 → 肝脏 → 右心 → 肺脏 → 气管 → 咽 → 食管 → 胃 → 小肠**

**可解释的临床表现（依据 [[Loeffler Syndrome]]）**：

- 幼虫**必经肺脏**，经过肺脏时引起**肺蛔虫症**，亦称 **Loeffler 综合征**（蛔蚴性肺炎），属蛔虫**幼虫致病**（见 [[Ascariasis]] 致病机制「一、幼虫致病」）
- 临床表现：**发热、咳嗽、哮喘、血痰**等
- 血象：血中**酸性粒细胞（嗜酸性粒细胞）可增多**
- 影像：**X 线见肺部阴影，常有游走现象**，多在 **1–2 周内自行消失**
- 诊断途径：**痰中查蛔蚴**，用于肺蛔虫症或蛔虫幼虫引起的过敏性肺炎的诊断（见 [[Stool Egg Examination]]）

**同表其余生活史要素（便于整体回忆）**：

| 要素 | 内容 |
|------|------|
| 虫卵在外界发育 | 约 **60–75 天**，适宜温度 **21–30 ℃** |
| 感染阶段 | **感染期蛔虫卵** |
| 感染途径与方式 | 经污染的**食物、饮水**，**经手-口途径** |
| 寄生部位（成虫） | **小肠** |
| 寿命 | **1 年** |

## Explanation

**考点**：生活史体内移行路线（必背）+ 幼虫致病（肺蛔虫症）的因果串联。

**常见失分点**：

1. **把移行路线写成经淋巴 / 左心**（选项 A）—— 蛔虫幼虫走的是**门静脉 → 肝脏 → 右心**这条**血行**通路，不是淋巴通路；「淋巴管 → 胸导管」是**钩虫**等虫种的路线。同时「肠梗阻」属蛔虫**成虫**并发症（钻孔习性、扭曲成团），与幼虫移行无关。
2. **把寄生部位写成盲肠**（选项 C）—— **盲肠**是**鞭虫**（[[Trichuris trichiura]]）的寄生部位；蛔虫成虫寄生于**小肠**。直肠脱垂也是鞭虫病重度感染的表现（见 [[Trichuriasis]]）。
3. **把感染途径写成「皮肤」**（选项 D）—— 蛔虫是**经口**感染（经手-口途径、误食感染期蛔虫卵污染的食物和水）；「皮肤 → 淋巴管 → 右心 → 肺」的移行与**钩蚴性皮炎**是**钩虫**的线索（讲义在 [[Nematode]] 致病节以「钩蚴性皮炎、哮喘」举例）。
4. **漏掉「经肺」这一环的临床意义** —— 路线的价值不只在背诵，而在于它直接解释了**为什么会有肺蛔虫症**。
5. **把肺蛔虫症归为成虫致病** —— 肺蛔虫症属**幼虫致病**（[[Loeffler Syndrome]] 明确记载讲义使用「幼虫致病」的归属）。

**易混淆点提醒**：幼虫在移行中还可引起**肝、脑、肾、甲状腺、脾**等器官的**异位损害（Ectopic lesion）**（[[Ascariasis]]）。这不等于讲义所说的**幼虫移行症** —— 后者定义限定为「**动物寄生线虫**」的幼虫（如**犬弓首线虫**）在人体内移行，详见 [[Larva Migrans]]，两者不可混为一谈。

## Knowledge Point

蛔虫幼虫移行路线为**口 → 小肠 → 门静脉 → 肝脏 → 右心 → 肺脏 → 气管 → 咽 → 食管 → 胃 → 小肠**；因**幼虫必经肺脏**，故产生**肺蛔虫症（Loeffler 综合征 / 蛔蚴性肺炎）**。
