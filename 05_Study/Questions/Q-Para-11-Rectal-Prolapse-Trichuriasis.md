# Q-Para-11 — 儿童慢性腹泻、贫血伴直肠脱垂（Clinical Reasoning）

## Stem

一名 **6 岁**儿童，来自**南方农村**。长期**慢性腹泻**、**消瘦**、**贫血**；家长诉其排便时有**直肠黏膜脱出**。粪便检查发现**纺锤形、两端各具一透明栓**的虫卵。

关于本例**最可能的诊断**及其**直肠脱出**的机制，下列哪一项**最恰当**？

## Options

- A. 蛔虫病；直肠脱出是蛔虫「钻孔习性、喜酸厌碱、扭曲成团」钻入肠壁管道所致
- B. 鞭虫病；重度感染时肠壁黏膜呈现充血、水肿或出血等慢性炎症反应并有慢性失血，儿童可因腹泻、直肠套叠导致直肠脱垂
- C. 鞭虫病；直肠脱出是鞭虫**幼虫**经肺移行后造成肺外**异位损害**的结果
- D. 蛔虫病；直肠脱出是蛔虫成虫在肠道内**扭曲成团**引起肠梗阻后的表现

## Correct Answer

**B**

**1. 诊断：鞭虫病（trichuriasis）**

- **病原学依据（决定性）**：虫卵**纺锤形**、**两端各具一透明栓**，是鞭虫（毛首鞭形线虫 *Trichuris trichiura*）虫卵**最具鉴别意义的特征**，也是讲义列出的必考形态要点（虫卵 50–54 μm × 22–23 μm、黄褐色、卵壳较厚、内含一个卵细胞）。
- 鞭虫成虫**寄生于盲肠**，鞭虫病即由鞭虫成虫寄生于人体**盲肠**所引起。
- **流行病学相符**：鞭虫**主要分布在南方**，常与**蛔虫感染并存**，**儿童感染多于成人**。

**2. 直肠脱出与全身表现的机制链条（依据 [[Trichuriasis]] 与 [[Trichuris trichiura]]）**

| 环节 | 讲义内容 |
|------|----------|
| 致病机理 | **机械性损伤**（虫体前端细长部钻入肠黏膜）+ **分泌物刺激** + **虫体以组织液和血液为食** |
| 病理 | 肠壁黏膜**充血、水肿或出血**等**慢性炎症反应**；**重度感染可有慢性失血** |
| 重度感染表现 | **头晕、腹痛、慢性腹泻、消瘦及贫血** |
| 儿童重度感染 | **发育迟缓**；可因**腹泻、直肠套叠导致直肠脱垂** |

即：重度感染 → 黏膜慢性炎症 + 慢性失血 / 慢性腹泻 → 消瘦、贫血，并在儿童因**直肠套叠**而出现**直肠脱垂**。

**3. 干扰项分析**

- **A、D 错**：蛔虫病的并发症为**胆道蛔虫症、肠梗阻、蛔虫性胰腺炎、蛔虫性阑尾炎、肝蛔虫病**，其机制是蛔虫**钻孔习性、喜酸厌碱、扭曲成团**；讲义**未把直肠脱垂列为蛔虫的表现**。且本例虫卵形态也不符蛔虫卵（受精卵**宽椭圆形**、壳外蛋白质膜凹凸不平；未受精卵**长椭圆形**、内含折光性颗粒）。
- **C 错在两点**：① 鞭虫生活史为**直接型**，**不经过组织内移行**（虫卵在土壤中发育为感染期虫卵后**经口**进入人体，成虫直接寄生于盲肠），讲义未给鞭虫任何「幼虫经肺移行」的表述；② **异位损害（Ectopic lesion）** 是讲义描述**蛔虫自身幼虫**的表述（肝、脑、肾、甲状腺、脾等），与鞭虫无关。

## Explanation

> [!warning] 自构病例，用于综合讲义所述机制
> 本题为**自构病例**，用于综合讲义所述机制 —— **不是讲义原文病例**（讲义末页病例为以黄疸、瘙痒为主要表现的**胆道蛔虫病**）。

**考点**：把「特征性虫卵形态」与「特征性临床后果（儿童直肠脱垂）」两端连起来。

**常见失分点**：

1. **把直肠脱垂记成蛔虫的表现** —— 直肠脱垂属于**鞭虫**（儿童）重度感染的特点；蛔虫以**并发症**（胆道蛔虫症、肠梗阻等）著称。
2. **看到「慢性腹泻 + 消瘦 + 贫血」只想到钩虫** —— 本讲（第二讲 蛔鞭）**未展开钩虫**；只依据本章内容作答时，应以**虫卵形态**作为定种依据。
3. **忽略「儿童 + 南方」两个提示** —— 鞭虫**儿童感染多于成人**、**南方多于北方**。
4. **把鞭虫说成有幼虫移行期** —— 鞭虫为**土源性线虫**、生活史**直接型**，**无需中间宿主、无组织内移行**。

> [!warning] 讲义未展开
> 讲义**未给出**鞭虫病的**虫负荷分级阈值**（轻 / 中 / 重度如何界定）、**贫血程度与虫负荷的关系**，也**未给出**本病与**阿米巴痢疾 / 细菌性痢疾**的鉴别要点。上述内容不应据本节点推断，需另核教材或指南。
> 另：本例以「**重度**感染」描述，是按讲义所列**重度感染表现**反向归类；讲义**未提供**量化分级标准，不得据此推断虫负荷数值。

## Knowledge Point

**纺锤形、两端各具一透明栓**的虫卵 = 鞭虫；鞭虫成虫寄生于**盲肠**，儿童**重度感染**可因**腹泻、直肠套叠**导致**直肠脱垂**。
