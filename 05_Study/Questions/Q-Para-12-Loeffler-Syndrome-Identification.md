# Q-Para-12 — 发热、哮喘、血痰伴游走性肺部阴影（Differential）

## Stem

一名患者近期出现**发热、咳嗽、哮喘、血痰**；血中**嗜酸性粒细胞增多**；胸片见**肺部片状阴影**，该阴影在 **1–2 周内自行消失**、且**位置有游走现象**。结合流行病学史（来自蛔虫感染流行区，有经手-口摄入被**感染期蛔虫卵**污染的食物、水的可能）。

**最应考虑**下列哪一项？又**必须与哪些情况鉴别**？

## Options

- A. 肺蛔虫症（Loeffler 综合征 / 蛔蚴性肺炎），属蛔虫**幼虫**致病
- B. 内脏幼虫移行症，由**似蚓蛔线虫**（人体蛔虫）的幼虫在人体内移行引起
- C. 蛔虫**成虫**异位寄生于肺部所致
- D. 鞭虫**幼虫**经肺移行引起的过敏性肺炎

## Correct Answer

**A**

**1. 为什么最应考虑肺蛔虫症（Loeffler 综合征 / 蛔蚴性肺炎）**

- **临床表现完全对应**讲义所列：**发热、咳嗽、哮喘、血痰**等；血中**酸性粒细胞可增多**；**X 线见肺部阴影，常有游走现象**，多在 **1–2 周内自行消失**。
- **归属**：讲义在本症的归属上使用的是**幼虫致病** —— 即蛔虫**幼虫在体内移行经过肺脏**时所致的表现（蛔虫体内移行路线：口 → 小肠 → 门静脉 → 肝脏 → 右心 → **肺脏** → 气管 → 咽 → 食管 → 胃 → 小肠）。讲义另有一处表述：**肺部的炎性浸润和血中嗜酸性细胞增多通常称之为肺蛔虫症**。
- **诊断途径**：讲义在【诊断】中把**痰中查蛔蚴**列为该症的诊断方法，用于**肺蛔虫症或蛔虫幼虫引起的过敏性肺炎**的诊断。
- 讲义在本章同时使用**肺蛔虫症 / Loeffler 综合征 / Loffler's syndrome / 蛔蚴性肺炎**四种写法，均指同一疾病概念。

**2. 流行病学史的支撑（讲义内容）**

蛔虫**感染阶段为感染期蛔虫卵**，**经手-口途径**感染；使用**未经处理的人粪施肥**或**随地大便**是造成蛔虫卵污染环境的主要方式，**误食被感染期蛔虫卵污染的食物和水**而感染。

**3. 必须鉴别 / 易混淆之处**

| 需鉴别者 | 与本题的区别 |
|----------|--------------|
| **幼虫移行症（Larva Migrans）** | 讲义的定义是**动物寄生线虫的幼虫**在人体内移行所引起的病变。讲义给出的具体例子是**犬弓首线虫（*Toxocara canis*）** —— **犬类**常见寄生虫，其**幼虫能在人体内移行**，引起**内脏幼虫移行症**。本例病原是**人体蛔虫（似蚓蛔线虫）**，**不符合**该定义 → **B 错** |
| **蛔虫幼虫的异位损害（Ectopic lesion）** | 讲义 **slide 20** 在「幼虫致病」项下记载幼虫也可引起**肝、脑、肾、甲状腺、脾**等器官的异位损害。该表述出自**蛔虫**一节、描述的是**蛔虫自身幼虫**，**不得与幼虫移行症混同**；也**不是**「成虫异位寄生」 → **C 错**（肺蛔虫症是**幼虫移行经肺**，不是成虫寄生） |
| **鞭虫所致肺部病变** | 鞭虫寄生于**盲肠**、生活史为**直接型**、**不经过组织内移行**；讲义**没有**鞭虫幼虫致肺炎或肺部游走性阴影的任何表述 → **D 错** |
| **其他嗜酸性粒细胞肺浸润（如过敏性肺炎）** | 讲义**未给出**与该综合征的鉴别要点 |

> [!warning] 讲义未展开
> 本讲义**未给出**该综合征的**诊断标准**、**与其他嗜酸性粒细胞肺浸润（如过敏性肺炎）的鉴别**，也**未给出发生率**。以上内容不得据本节点推断，需另核教材或指南（AGENTS.md §22 / §32）。

## Explanation

**考点**：肺蛔虫症属蛔虫**幼虫致病**；「**幼虫移行症**」在讲义中专指**动物寄生线虫**的幼虫在人体内移行 —— 两个概念的关键词分别是「**人体蛔虫自身幼虫**」与「**动物寄生线虫的幼虫**」。

**常见失分点**：

1. **把肺蛔虫症直接写成「幼虫移行症」** —— 讲义对幼虫移行症的定义冠以「**动物寄生**线虫」，犬弓首线虫是讲义给出的唯一具体虫种；人体蛔虫的幼虫致病**不属**此概念。
2. **把 slide 20 的「异位损害」与幼虫移行症混为一谈** —— 异位损害是**蛔虫自身幼虫**的表述（肝、脑、肾、甲状腺、脾），仅作交叉引用。
3. **把肺蛔虫症归为成虫致病** —— 它是**幼虫移行经过肺脏**所致；成虫致病表现为掠夺营养 / 破坏肠黏膜与超敏反应，并发症为胆道蛔虫症、肠梗阻、蛔虫性胰腺炎、蛔虫性阑尾炎、肝蛔虫病。
4. **忽略影像的时间与位置特点** —— 「**1–2 周内自行消失**」与「**游走现象**」是讲义强调的影像特点，也是本例的定位线索。
5. **忘了痰检** —— 该阶段**粪检虫卵可能查不到**，讲义把**痰中查蛔蚴**列为肺蛔虫症 / 蛔虫幼虫引起之过敏性肺炎的诊断方法。

## Knowledge Point

肺蛔虫症（Loeffler 综合征 / 蛔蚴性肺炎）= 蛔虫**幼虫**移行经肺，表现为发热、咳嗽、哮喘、血痰 + 血中嗜酸性粒细胞增多 + 肺部阴影**游走**、**1–2 周自行消失**，**痰中查蛔蚴**可诊断；「**幼虫移行症**」特指**动物寄生线虫**的幼虫在人体内移行（如犬弓首线虫 → 内脏幼虫移行症），二者不可混同。
