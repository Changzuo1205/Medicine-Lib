# 临床流行病学（Clinical Epidemiology）

## Course Overview

研究**人群疾病与健康状况的分布及其影响因素**，探讨**防制疾病与促进健康的策略与措施**，评估临床干预效果。涵盖方法学核心：研究设计、偏倚控制、诊断试验评价、治疗效果评价、预后研究、系统综述、循证医学。

本课程是基础医学 → 临床医学 → 公共卫生的**方法学桥梁学科**。
