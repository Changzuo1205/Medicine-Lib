# 医学免疫学（Medical Immunology）

## Course Overview

研究人体免疫系统的结构和功能的科学，重点阐明免疫系统识别抗原和危险信号后发生免疫应答及其清除抗原的规律，探讨免疫功能异常所致疾病及其发生机制，为这些疾病的预防、诊断和治疗提供理论基础和技术方法。

课程主线：

```text
Ag（抗原） → T / B 活化 → 效应细胞 / 浆细胞 → Ab / Tm / Bm
                  ↓
            补体、细胞因子、MHC
                  ↓
              清除抗原
            ↙        ↘
     免疫防御      免疫监视 / 免疫自稳
       ↓                ↓
    不足 / 过强 / 异常 / 正常
       ↓                ↓
  免疫缺陷 / 超敏反应 / 肿瘤 / 自身免疫病
       ↓
  疾病预防 / 诊断 / 治疗
```
