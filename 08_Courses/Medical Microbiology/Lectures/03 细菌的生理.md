## Lecture Overview

医学微生物学第 2 章。第一章回答「细菌长什么样」，本章回答「细菌怎么活」—— 从**理化性状**（第一节）到**营养与生长繁殖**（第二节）、**代谢**（第三节）、**人工培养**（第四节），最后收在**分类与命名**（第五节）。

全章的落点是**医学意义**：细菌的代谢产物既是**鉴别细菌**的依据（生化反应），也是**致病**的物质（内毒素、外毒素、侵袭性酶），还是**药品安全**的红线（热原质）。因此本章的重点不是「细菌的化学」，而是「这些性质在临床上怎么用、怎么防」。

## 第一节 细菌的理化性状

详见 [[Bacterial Physicochemical Properties]]。

**总体特点（p3）**：代谢旺盛，代谢类型多样化；摄取营养物质并合成所需物质。

### 一、化学组成（p5）

- 包括**水**、有机物（**蛋白质、糖类、脂质和核酸**）、**无机盐**（参与组成、酶活、跨膜梯度）
- **原核细胞特有成分**：**肽聚糖、胞壁酸、磷壁酸、二氨基庚二酸（DAP）、吡啶二羧酸（DPA）**

成分比例：**水 75%～90%**、**10%～25%**（蛋白质 / 核酸 / 糖类 / 脂类）、少量维生素和无机盐，另有特有成分。

### 二、物理性状（p6）

| 性状 | 内容 |
|------|------|
| **光学性质** | 半透明（吸收、折射）→ 可用「**比浊法**」 |
| **表面积大** | 利于物质交换；代谢旺盛、繁殖迅速 |
| **带电现象** | **G⁺ 等电点（pI）为 2～3、G⁻ 为 4～5** → 影响**染色反应、杀菌**等 |
| **半透性** | 细胞壁与细胞膜具半透性 → 吸收营养、排出代谢产物 |
| **内部渗透压高** | **G⁺ 20～25 个大气压**；**G⁻ 5～6 个大气压** |

## 第二节 细菌的营养与生长繁殖

### 一、细菌的营养物质

详见 [[Bacterial Nutritional Requirements]]。

| 营养物质 | 作用 |
|----------|------|
| **水** | 重要溶剂 |
| **碳源（糖）** | 菌体成分 + 能源 |
| **氮源（氨基酸、蛋白胨）** | 菌体成分原料 |
| **无机盐** | 菌体及酶的组分、能量储存及转运、调节渗透压 —— 常用元素 **P、S、K、Na、Mg、Ca、Fe**；微量元素 **Zn、Cu、Mn、钴** |
| **生长因子** | 细菌**自身不能合成**、需外界供给；与繁殖及致病相关 |

### 二、细菌摄取营养物质的机制

详见 [[Bacterial Nutrient Uptake]]。

- **被动扩散**：从浓度高向浓度低扩散，驱动力是**浓度梯度**，**不需要能量** —— 简单扩散、**易化扩散**（需细菌组分）
- **主动转运系统**：细菌吸收营养物质的**主要方式**，从浓度低向浓度高转运，**需要能量** —— ① **ABC 转运**（ATP-binding cassette-type carrier）② **离子偶联转运** ③ **基团转移**（转运与代谢相结合，如大肠埃希菌摄入葡萄糖需要的磷酸转移酶系统）④ **特异性转运**（**载铁体 siderophore** 转运铁）

### 三、细菌营养类型

详见 [[Bacterial Nutritional Types]]。

| 类型 | 特点 |
|------|------|
| **自养菌（autotroph）** | 以**无机物**为原料合成菌体，以无机物或光合作用为能源 —— 化能自养菌、光能自养菌 |
| **异养菌（heterotroph）** | 以**有机物**为原料合成菌体成分、获得能量 —— 腐生菌、寄生菌（在活体内寄生） |

> **所有病原菌都是异养菌**，且大部分为寄生菌。

### 四、影响细菌生长的因素

详见 [[Factors Affecting Bacterial Growth]] · [[Bacterial Oxygen Requirements]]。

| 因素 | 要点 |
|------|------|
| **1. 营养物质** | 原料和能量 —— 水、氮源、碳源、无机盐、生长因子等 |
| **2. 氢离子浓度（pH）** | 多数细菌生长 pH 范围 **6.0～8.0**；多数病原菌**最适 7.2～7.6**；**结核分枝杆菌最适 6.5～6.8**；**霍乱弧菌最适 8.4～9.2** |
| **3. 温度** | **嗜温菌**最适 **20～40 ℃**（多数病原菌最适 **37 ℃**）；**嗜冷菌**最适 **10～20 ℃**；**嗜热菌**最适 **50～60 ℃** |
| **4. 气体** | 见下方「对氧需求的分类」；**CO₂** 对细菌生长也很重要 —— 大部分细菌自身代谢产生的 CO₂ 可满足需要，个别细菌**初次分离**时需人工供给 **5%～10% CO₂** |
| **5. 渗透压** | 一般培养基渗透压适于大多数细菌；**嗜盐菌**需 **30 g/L NaCl** |

**对氧需求的分类（讲义 p12）**：

| 类型 | 特点 | 例 |
|------|------|-----|
| **专性需氧菌** | 具有完善的呼吸酶系统，**仅能在有氧环境下生长** | 结核分枝杆菌 |
| **微需氧菌** | **低氧压（5%～6%）**生长最好 | 空肠弯曲菌、幽门螺杆菌 |
| **兼性厌氧菌** | 有氧、无氧环境**均能生长**，但**以有氧时生长较好** | **大多数病原菌** |
| **专性厌氧菌** | 缺乏完善的呼吸酶系统，**必须在低氧分压、无氧环境中生长** —— 缺乏氧化还原电势高的呼吸酶（**细胞色素氧化酶**）、缺乏分解有毒氧基团的酶（**SOD、触酶、过氧化物酶**） | 破伤风梭菌（O₂ 对其有害） |

### 五、细菌的生长繁殖

详见 [[Bacterial Growth and Reproduction]]。

- **方式**：**二分裂**，**无性繁殖**
- **速度**：一般 **20～30 分钟一代**（代时）；但**结核分枝杆菌 18～20 小时**才分裂一次

### 六、细菌的生长曲线

详见 [[Bacterial Growth Curve]]。

**细菌群体的生长繁殖**呈**生长曲线（growth curve）**，分四期：

| 分期 | 特点 | 意义 |
|------|------|------|
| **迟缓期**（lag phase） | 接种后的最初一段时间，主要**适应新环境**，同时为分裂繁殖作物质准备；**代谢活跃，分裂迟缓** | — |
| **对数期**（logarithmic phase） | 活菌数以**恒定的几何级数增长** | **研究最佳时期**：形态、生化反应、药敏 |
| **稳定期**（stationary phase） | 因营养物质消耗、代谢产物堆积，**繁殖数与死亡数几乎相等**，活菌数保持相对稳定 | **芽胞及代谢产物**（如外毒素和抗生素等）产生 |
| **衰亡期**（decline phase） | **活菌数减少**，死菌数增多（**衰退型**） | 难以鉴定 |

> 讲义 p16 的生长曲线图同时画出**活菌数**与**总菌数**两条曲线（纵轴为细菌数目的对数，横轴为培养时间/小时）。

## 第三节 细菌的代谢

**细菌新陈代谢的显著特点（p20）**：**代谢旺盛，代谢类型多样化**。能量和少数几种简单的前体用于合成菌细胞组分。

### 一、细菌的能量代谢

详见 [[Bacterial Energy Metabolism]]。

- 细菌能量代谢以 **ATP 形式的化学能**；基本生化反应是**生物氧化**（大多数是**脱氢或氢传递**）
- **葡萄糖的能量代谢**：

| 途径 | 产物 / 产能 |
|------|-------------|
| **1. EMP 途径（糖酵解）** | 1 分子葡萄糖可生成 **2 分子丙酮酸**，产生 **2 分子 ATP** |
| **2. 戊糖磷酸途径** | 糖酵解的**分支**，**产能少** |
| **需氧呼吸** | 丙酮酸脱羧产生**乙酰辅酶 A** 后进入**三羧酸循环**彻底氧化；1 分子葡萄糖在有氧条件下彻底氧化，产生 **30～32 分子 ATP** |
| **厌氧呼吸** | 1 分子葡萄糖经厌氧糖酵解只能产生 **2 分子 ATP**（厌氧菌） |

> 讲义以「**受氢体**是有机物还是无机物」区分发酵与呼吸。

### 二、分解代谢产物和细菌的生化反应

详见 [[Bacterial Biochemical Reactions]]。

**原理（p23）**：各种细菌所具有的**酶不完全相同**，对糖、蛋白质等营养物质的**分解能力不同**，因而**代谢产物各异** —— 利用生物化学方法**鉴别不同细菌**，称为**细菌的生化反应**。

| 试验 | 原理 / 结果要点 |
|------|-----------------|
| **1. 糖发酵试验** | 糖（葡萄糖/乳糖）→ 丙酮酸等酸性产物 → pH↓ → 指示剂呈酸性变色；葡萄糖 → 甲酸 → **CO₂ + H₂**。指示剂：**酚红、溴甲酚紫**等。结果：培养基呈酸性变色、产气。应用：**常用于肠道杆菌的鉴定** |
| **2. VP 试验** | 细菌分解葡萄糖产生丙酮酸；**产气杆菌**能使丙酮酸脱羧成**乙酰甲基甲醇**，后者在**强碱**环境下被空气中氧氧化为**二乙酰**，二乙酰与蛋白胨中的**胍基**生成**红色**化合物 → V-P（+）。**大肠杆菌（−），产气杆菌（+）** |
| **3. 甲基红试验** | 葡萄糖 → 丙酮酸 → **大量混合酸** → **pH < 4.5** → 甲基红试剂使培养基**变红**；产气杆菌走乙酰甲基甲醇路线 → **pH > 5.4** → 培养基**橙黄色**。应用：肠道杆菌常用生化反应，**主要区别大肠杆菌与产气肠杆菌** |
| **4. 靛基质（吲哚）试验** | 色氨酸 —（**色氨酸酶**）→ **靛基质（吲哚）** → 与**对二甲基氨基苯甲醛**生成**玫瑰靛基质（玫瑰吲哚）** |
| **5. 枸橼酸盐利用 / 硫化氢 / 尿素酶** | 产气杆菌以**枸橼酸盐**为碳源、以**铵盐**为氮源 → 分解铵盐产氨（碱性）→ 指示剂**淡绿变深蓝**为阳性；细菌分解蛋白质中的**含硫氨基酸**产生**硫化氢** → 遇铅或铁离子生成**黑色**硫化物；**变形杆菌**有**尿素酶**，分解尿素产生氨 → 培养基变碱 → **酚红**指示剂显**红色** |

**IMViC 试验（p30）**：**I** 吲哚试验 · **M** 甲基红试验 · **Vi** VP 试验 · **C** 枸橼酸盐利用 —— 常用于鉴定肠道杆菌：

| 菌 | I | M | Vi | C |
|----|---|---|----|---|
| **大肠埃希菌** | + | + | − | − |
| **产气杆菌** | − | − | + | + |

**编码鉴定系统（p31）**：肠道杆菌生化实验按「葡萄糖、赖氨酸、鸟氨酸、硫化氢、靛基质、乳糖、卫矛醇、苯丙氨酸、尿素、枸橼酸盐」等多项**产酸/产气**结果编码（如 A G 4 2 1 4 2 1），**查表得到结果**，必要时做补充试验；现已有**全自动细菌鉴定及药敏分析仪**。

### 三、合成代谢产物及医学意义

详见 [[Bacterial Anabolic Products]]。

| 产物 | 要点 |
|------|------|
| **1. 热原质（pyrogen）** | 细菌合成的一种**注入人体内引起发热反应**的物质，**大多数是 G⁻ 菌的脂多糖**。**耐高温** —— 高压蒸汽灭菌（**121 ℃，20 min**）**不能破坏**，**250 ℃ 高温干烤**才能破坏；也可用**吸附剂、石棉过滤、蒸馏**去除。**注射药品制备和使用需严格无菌操作！** |
| **2. 内毒素（endotoxin）** | **G⁻ 菌的脂多糖** → 详见 [[Lipopolysaccharide]] |
| **3. 外毒素（exotoxin）** | **G⁺ 菌和少数 G⁻ 菌**产生的**蛋白质** |
| **4. 侵袭性酶** | 损伤机体组织，**促进细菌侵袭和扩散** —— 如**卵磷脂酶**（产气荚膜梭菌）、**透明质酸酶**（链球菌） |
| **5. 抗生素** | 如**多粘菌素、杆菌肽** |
| **6. 细菌素** | 只能**杀伤有亲缘关系**的细菌，如**大肠菌素**；可用于**细菌分型和流行病学调查** |
| **7. 维生素** | 某些**肠道菌**合成，如 **B 族维生素、维生素 K** |

## 第四节 细菌的人工培养

### 一、细菌的培养方法

详见 [[Bacterial Culture Methods]]。

| 方法 | 内容 |
|------|------|
| **分离培养** | **划线接种**在固体培养基表面，借划线的分散作用使混杂的细菌在表面散开；一般经 **18～24 小时**培养后，单个细菌分裂繁殖成**一堆肉眼可见的细菌集团** |
| **纯培养（pure culture）** | **挑取一个菌落**，移种到另一培养基中，可生长出**大量的纯种细菌** |
| **发酵培养** | 在适宜条件下，**发酵罐**中大量培养微生物细胞和生产代谢产物的工艺过程 |

**人工培养细菌的用途（p47）**：在医学中 —— ① 感染性疾病的**病原学诊断及治疗**；② **细菌学的研究**；③ **生物制品的制备**。此外在**工农业生产**与**基因工程**中也有应用。

### 二、培养基

详见 [[Culture Medium]]。

- **定义**：由**人工方法配制**而成的、专供微生物生长繁殖使用的**混合营养物制品**

| 种类 | 内容 |
|------|------|
| **基础培养基** | 含基本营养成分 |
| **增菌 / 营养培养基** | 含特殊营养物质 |
| **选择培养基** | 具有使混合菌样中的**劣势菌变成优势菌**的功能（**加入选择性抑制的化学物质**） |
| **鉴别培养基** | **区分相近细菌**（**加入特定的底物和指示剂**） |
| **厌氧培养基** | 如**庖肉培养基** |

**物理状态（p42）**：**液体** · **固体（15 g/L 琼脂）** · **半固体（3～5 g/L 琼脂）**。

### 三、细菌在培养基中的生长现象

详见 [[Bacterial Growth in Culture]] · [[Colony]]。

| 培养基 | 生长现象 |
|--------|----------|
| **液体** | **混浊**：大多数细菌；**沉淀**：链状生长的细菌；**菌膜**：**专性需氧菌**，如结核杆菌、枯草杆菌 |
| **固体** | 形成**菌落（colony）** —— 参见 [[Colony]] |
| **半固体** | **有鞭毛细菌**：可自由游动，沿穿刺线呈**羽毛状或云雾状**生长，周围**浑浊**；**无鞭毛细菌**：沿穿刺线呈明显的**线状**生长，周围**透明** |

**菌落特征（p45）**：**大小、形状、颜色、气味、边缘、光泽、质地、湿润和透明程度，及溶血情况**等；**菌落计数法：cfu**；另有**菌落类型**之分。

## 第五节 细菌的分类与命名

详见 [[Bacterial Taxonomy and Nomenclature]]。

### 一、分类

- **伯杰氏系统细菌学手册（Bergey's Manual of Systemic Bacteriology）第 9 版**是重要参考
- **鉴定和分类方法**：**表型分类**（形态、生理特性）· **分析分类**（菌体组分、代谢产物组成与图谱特征）· **基因型分类**（**G+C mol%、16S rRNA**）
- 新细菌命名在《**国际细菌杂志**》（*International Journal of Systematic Bacteriology*）发表，由**国际细菌命名裁定委员会**公布
- **界/域**：原核生物 = **古生菌域（2 个门）** + **细菌域（24 个门）**；**550 多个属，细菌 2500 多个种**

**分类层级与单位（p49）**：门 → 纲 → 目 → 科 → **属（genera）** → **种（species）**，另有以下单位：

| 单位 | 含义 |
|------|------|
| **属（genera）** | 由特色相近、密切相关的种组成 —— 如金黄色葡萄球菌、表皮葡萄球菌同属**葡萄球菌属** |
| **种（species）** | 细菌的**基本分类单位**，特性基本相同；判据 **DNA 同源性 ≥ 70%、⊿Tm 值 ≤ 5℃** |
| **亚种、型（type）** | 同一种细菌基本性状相同而某些方面特征稍有不同 —— 如**血清型、生物型** |
| **菌株（strain）** | 对不同来源的同一菌种的细菌；有**标准菌株**（如 **ATCC**）、**模式菌株** |

### 二、命名

**拉丁文双名法（斜体）**：**属名**（名词，**首字母大写**）+ **种名**（形容词，**小写**）。命名依据 = **形态 / 发现者**（属名）与**性状、疾病、寄居部位**（种名）。

以**大肠埃希菌**为例（讲义 p50 的完整分类学位置）：

| 层级 | 内容 |
|------|------|
| 界（域） | **细菌域** |
| 门 | 变形菌门（Bacteria） |
| 纲 | γ-变形菌纲（Proteobacteria） |
| 目 | 肠杆菌目（Enterobacteriales） |
| 科 | 肠杆菌科（Enterobacteriaceae） |
| 属 | 埃希氏菌属（*Escherichia*） |
| 种 | 大肠埃希菌（*E. coli*） |

> [!teacher]
> 老师强调（讲义 p51「本章重点与难点」）：
> - **三个「掌握」**：① 生长繁殖的**条件 + 生长曲线**；② 与医学有关的**合成代谢产物**的种类及意义；③ **菌落**概念及意义
> - **生长曲线要能对着曲线讲出四期**：迟缓期（适应 + 备料）→ 对数期（几何级数增长，**实验研究最佳期**）→ 稳定期（繁殖 = 死亡，**芽胞与外毒素、抗生素在此产生**）→ 衰亡期（活菌减少、衰退型）
> - **对氧需求的四分类要能各举一例**：专性需氧（结核分枝杆菌）· 微需氧（空肠弯曲菌、幽门螺杆菌）· 兼性厌氧（**大多数病原菌**）· 专性厌氧（破伤风梭菌）
> - **热原质与灭菌的「温度红线」**：**121 ℃ 20 min 高压蒸汽灭菌破坏不了它，250 ℃ 干烤才能破坏** —— 这就是注射药品必须严格无菌操作的原因
> - **IMViC 的「+/−」是肠道杆菌鉴别的经典对照**：大肠埃希菌 `+ + − −`，产气杆菌 `− − + +`
> - **菌落是「纯培养」的操作单位**：挑一个菌落 → 移种 → 纯种细菌
