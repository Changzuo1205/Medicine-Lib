## Lecture Overview

病理学第一章。介绍细胞和组织对内外环境变化的适应机制、可逆性损伤（变性）的各种类型、以及不可逆性损伤导致的细胞死亡（坏死与凋亡）。这些是后续所有各论疾病的共同病理基础。

## 章节结构

```
正常细胞和组织
   ↓ 生理性刺激 / 轻度病理性刺激
适应 (Adaptation)         ← 可逆、代偿性
   ↓ 超过耐受能力
轻度可逆性损伤 (变性)       ← 形态学异常，可恢复
   ↓ 严重损伤
严重不可逆性损伤 → 细胞死亡
   ├── 意外性 → 坏死 (Necrosis)
   └── 调节性 → 凋亡 (Apoptosis)
```

## 第一节 适应（Adaptation）

### 概念

细胞、组织和器官对内外环境中的持续性刺激和各种有害因子产生的非损伤性应答反应。

机制：基因表达及调控 → 受体结合信号转导 → 蛋白质合成和转运 → 细胞生长分化达到代谢、功能和形态结构的新平衡。

五种类型：**萎缩、肥大、增生、化生、老化**。

### 重点要点（考试高频）

- **萎缩**（[[../../../03_Concepts/Pathology/Atrophy|Atrophy]]）：6 种病理性类型—营养不良/压迫/失用/去神经/内分泌/老化；脂褐素沉着；例：骨折后肌肉萎缩（多因素）
- **肥大**（[[../../../03_Concepts/Pathology/Hypertrophy|Hypertrophy]]）：代偿性 vs 内分泌性；假性肥大；过度肥大 → 失代偿心衰
- **增生**（[[../../../03_Concepts/Pathology/Hyperplasia|Hyperplasia]]）：分裂能力与组织对应 — 分裂能力高→增生+肥大；分裂能力低→仅肥大；持续刺激 → 肿瘤
- **化生**（[[../../../03_Concepts/Pathology/Metaplasia|Metaplasia]]）：鳞状化生最常见；肠上皮化生、假幽门腺化生、宫颈“糜烂”；持续化生 → 鳞癌/腺癌
- **细胞老化**（[[../../../03_Concepts/Pathology/Cellular Aging|Cellular Aging]]）：不可逆、普遍性、内在基因决定性；脂褐素沉着

## 第二节 损伤的原因与机制

> 详见 [[../../../03_Concepts/Pathology/Cell Injury|Cell Injury]]（总论节点）

### 8 类原因

| # | 类别 | 例 |
|---|------|------|
| 1 | 缺氧 | 心肺功能衰竭、贫血、一氧化碳中毒 |
| 2 | 生物（最常见） | 细菌、病毒、支原体、真菌 |
| 3 | 物理 | 冷热、辐射、电流、机械力 |
| 4 | 化学 | 无机有机毒物、生物毒素、代谢产物、药物 |
| 5 | 营养失衡 | 缺乏 VitD、蛋白、碘、微量元素；高热量 |
| 6 | 神经内分泌 | 原发高血压、溃疡病、甲亢、糖尿病 |
| 7 | 免疫 | 哮喘、过敏性休克、SLE、HIV |
| 8 | 其他 | 遗传性缺陷、社会心理疾病、医源性损伤 |

### 8 种机制

- **线粒体损伤**：ATP 生成下降，不可逆损伤的重要早期标志
- **细胞膜损伤**：通透性和完整性破坏
- **活性氧类物质**（ROS）：O₂⁻·、·OH、·ClO、NO·、H₂O₂；自由基
- **胞质内游离钙损伤**：清除障碍 → 酶活化并降解破坏
- **缺血缺氧损伤**：最常见、最重要的中心环节
- **化学性损伤**：药物、毒物、代谢产物
- **遗传变异**：先天遗传、胚胎发生期、出生后获得

## 第三节 可逆性损伤（变性）

变性是损伤导致代谢障碍→细胞或细胞间质内出现异物或正常物质异常蓄积的形态学变化，常伴细胞功能低下。

进展：生化代谢变化 → 超微结构变化 → 光镜和肉眼变化。

### 七种变性

| 变性 | 细胞水肿 / [[../../../03_Concepts/Pathology/Cellular Swelling]] | 脂肪变 / [[../../../03_Concepts/Pathology/Fatty Change]] | 玻璃样变 / [[../../../03_Concepts/Pathology/Hyaline Degeneration]] | 淀粉样变 / [[../../../03_Concepts/Pathology/Amyloidosis]] | 黏液样变 / [[../../../03_Concepts/Pathology/Mucoid Degeneration]] | 色素沉着 / [[../../../03_Concepts/Pathology/Pathologic Pigmentation]] | 钙化 / [[../../../03_Concepts/Pathology/Pathologic Calcification]] |
|------|------|------|------|------|------|------|------|
| **蓄积物质** | Na⁺ / 水 | 甘油三酯 | 蛋白质 | 淀粉样蛋白 | 黏多糖+蛋白 | 4 种色素 | 钙盐 |
| **关键鉴别** | 最早出现、气球样变 | 虎斑心、脂肪心 | 3 型（细胞内/结缔组织/细动脉壁） | 刚果红 → 苹果绿 | 星芒状纤维细胞 | Hemo/Lipo/Melano/Bili | 营不良 vs 转移 |

重点要点：

- **细胞水肿**：ATP → Na⁺-K⁺ 泵障碍 → Na⁺ 积聚 → 吸水肿胀；肝、肾、心实质细胞最明显
- **脂肪变**："来多去少"；虎斑心（左心室内膜下和乳头肌）；脂肪心（右心室心外膜脂肪组织增生、心肌萎缩）；Sudan III/IV 染色橙红
- **玻璃样变**：3 型—细胞内（玻璃小滴 / Rusell 小体、骨里細里重吸收原尿蛋白质；Mallory 小体、酒精性肝病肝细胞中间丝前角蛋白变性）、结缔组织、细动脉壁（缓进型高血压、糖尿病）
- **淀粉样变**：刚果红 → 苹果绿（偏振光）；I₂ 染色棕褚色 → 稀 H₂SO₄ 变蓝色；局部（皮肤、舌、喘、肺、脑、骨髓瘤、髓样癌）+全身（原发/继发）
- **色素沉着**：4 种—含铁血黄素（普鲁士蓝、陈旧出血、溶血）、脂褐素（老年、营养耗竭）、黑色素（色素痣、黑色素瘤）、胆红素（黄疸）
- **钙化**：营养不良性（坏死组织中、钙磷代谢正常：结核、血栓、动脉粥样硬化斑块、心瓣膜病、瘙痖） vs 转移性（高血钙、正常组织沉钙：甲旁上、VitD 过多、肾衰、骨肿瘤）

## 第四节 不可逆性损伤·细胞死亡（Cell Death）

### 总论（[[../../../03_Concepts/Pathology/Cell Death|Cell Death]]）

- 致死性代谢、结构和功能障碍 → 不可逆性损伤
- 两大类型：意外性（坏死）vs 调节性（凋亡）
- 早期临床诊断依据：细胞内和血清中酶活性变化

### 坏死（[[../../../03_Concepts/Pathology/Necrosis|Necrosis]]）

活体内局部组织中细胞的死亡，以酶溶性变化为主。

**核的三种形态变化**（主要形态学标记）：

- 核固缩 pyknosis — 染色质浓聚、核皱缩
- 核碎裂 karyorrhexis — 核膜破裂、染色质崩解
- 核溶解 karyolysis — 酶激活分解 DNA、染色质消失

注意：进展顺序不固定，可以从正常直接发生。

### 6 种坏死亚型（重点）

| 亚型 | 节点 | 部位/病因 | 大体特征 |
|------|------|----------|------|
| 凝固性 | [[../../../03_Concepts/Pathology/Coagulative Necrosis]] | 心、肝、肾、腮（缺血） | 灰白、干燥、质实、边界清 |
| 液化性 | [[../../../03_Concepts/Pathology/Liquefactive Necrosis]] | 脑 / 脓肿 | 溶解、液化 |
| 干酪样 | [[../../../03_Concepts/Pathology/Caseous Necrosis]] | 结核 | 似干酪、细腻 |
| 脂肪 | [[../../../03_Concepts/Pathology/Fat Necrosis]] | 急性胰腺炎 / 乳房创伤 | 钙皂（脂肪酸+Ca²⁺） |
| 纤维蛋白样 | [[../../../03_Concepts/Pathology/Fibrinoid Necrosis]] | 结缔组织小血管壁 / 超敏反应 | 红染丝状、颗粒状 |
| 坏疽 | [[../../../03_Concepts/Pathology/Gangrene]] | 四肢 / 内脏 | 干性 / 湿性 / 气性 |

### 坏死结局（4 种）

1. 溶解吸收 — 坏死细胞+中性粒细胞 → 水解酶溶解液化 → 淋巴/血管吸收；碎片 → 巨噬细胞吞噬清除
2. 分离排出 — 不易溶解吸收时 → 糜烂/溃疡/窦道/瘘管/空洞
3. 机化与包裹 — 新生肉芽组织长入替代 → 纤维瘢痕
4. 钙化 — 坏死+钙盐沉积 → 营养不良性钙化

### 临床酶学线索（坏死早期诊断）

| 器官 | 标志性血清酶 |
|------|--------------|
| 心 | 乳酸脱氢酶（LDH）、肌酸激酶（CK） |
| 肝 | 天冬氨酸转氨酶（AST）、丙氨酸转氨酶（ALT） |
| 胰 | 淀粉酶、脂肪酶 |

### 凋亡（[[../../../03_Concepts/Pathology/Apoptosis|Apoptosis]]）

- 别名：程序性细胞死亡（PCD）
- 特征：质膜完整、**凋亡小体**（apoptosis body）形成、不引起周围细胞炎症反应
- 形态学特征：细胞皱缩、染色质凝聚、凋亡小体、质膜完整
- 生化特征：caspase（天冬氨酸蛋白酶）→破坏细胞骨架及核骨架；核酸内切酶→DNA 梯状带（180-200 bp）
- 基因：促进凋亡 TP53、抑制凋亡 BCL2、双向调节 CMYC
- 例：病毒性肝炎肝细胞凋亡 → 嗜酸性小体
