## 章节结构

```
正常细胞和组织
   ↓ 损伤造成细胞、组织、丧失
修复 (repair)                       ← 机体对缺损的修补恢复过程
   ├── 再生 (regeneration)          ← 损伤周围同种细胞修复 → 完全修复
   └── 纤维性修复                    ← 纤维结缔组织修复 → 瘢痕修复
         └── 肉芽组织 → 瘢痕组织
   ↓
多数情况下两种形式同时存在，常伴炎症
```

| [[Regeneration]] 再生 | pathophysiology | 生理性（表皮、消化道黏膜上皮、子宫内膜、血细胞）vs 病理性；再生能力一般规律"低等>高等、幼稚>高分化" |

| [[Labile Cells]] 不稳定细胞 | pathophysiology | 持续分裂代替衰亡细胞；表皮、呼吸道/消化道黏膜、生殖道黏膜、淋巴造血细胞、间皮细胞 |
| [[Stable Cells]] 稳定细胞 | pathophysiology | 静止细胞（G0）；刺激时进入 G1；腺体及腺样器官实质细胞、平滑肌、肝（部分切除后快速再生） |

### 二、组织再生的机制和过程 — 6 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Epithelial Regeneration]] 上皮组织再生 | pathophysiology | 被覆上皮（基底层细胞 + 组织干细胞）；腺上皮（基底膜完整可完全恢复）；肝细胞再生三种情况 → 肝硬化 |
| [[Fibrous Tissue Regeneration]] 纤维组织再生 | pathophysiology | 静止纤维细胞 / 未分化间叶细胞 → 成纤维细胞 → 胶原纤维 + 纤维瘢痕 |
| [[Cartilage Regeneration]] 软骨组织再生 | pathophysiology | 软骨膜增生 → 软骨基质 + 陷窝内静止软骨细胞；缺损较大 → 纤维组织修复 |
| [[Angiogenesis]] 血管再生 | pathophysiology | 毛细血管出芽式 / 套叠式血管生成；大血管需手术吻合 + 内皮平滑肌增生 + 纤维瘢痕 |
| [[Muscle Regeneration]] 肌组织再生 | pathophysiology | 横纹肌：肌膜未破坏可恢复，肌膜破坏 → 纤维瘢痕；平滑肌 → 再生或纤维瘢痕 |
| [[Nerve Regeneration]] 神经组织再生 | pathophysiology | 中枢：胶质细胞 + 胶质纤维 → 胶质瘢痕；周围：施万细胞增生 + 轴突延伸 → 完全再生 |

### 三、细胞再生的影响因素 — 3 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Extracellular Matrix]] 细胞外基质 | pathophysiology | 连接支撑 + 调节再生细胞生物学行为 + 调控发育/重建/愈合/肿瘤侵袭；胶原蛋白、弹力蛋白、黏附性糖蛋白与整合素、基质细胞蛋白、蛋白多糖与透明质酸 |
| [[Growth Factor]] 生长因子 | pathophysiology | 同类/同一胚层细胞增生、损伤重建、刺激与抑制动态平衡；多肽类最关键（PDGF、FGF、EGF、TGF、VEGF、IL-1、TNF） |
| [[Chalone and Contact Inhibition]] 抑素与接触抑制 | pathophysiology | 抑素：组织特异性，抑制本身增殖；接触抑制：细胞相互接触或达原有大小即停止生长、不堆积 |

### 四、纤维性修复 — 3 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Fibrous Repair]] 纤维性修复 | pathophysiology | 过程：实质细胞再生 + 肉芽组织增生 → 溶解吸收坏死及异物、填补缺损 → 胶原纤维为主的瘢痕组织 |
| [[Granulation Tissue]] 肉芽组织 | pathophysiology | 组成 = 新生薄壁毛细血管 + 成纤维细胞增生 + 炎细胞浸润；肉眼鲜红颗粒状柔软湿润；作用（抗感染、填补缺损、机化或包裹）；结局 → 瘢痕 |
| [[Scar Tissue]] 瘢痕组织 | pathophysiology | 肉芽组织改建成熟形成；灰白质韧半透明；有利（填补连接、韧性）；缺乏弹性可膨出（室壁瘤，来源 [125] 列于有利项下）；不利（收缩致狭窄、粘连、瘢痕疙瘩） |

### 五、创伤愈合 — 5 个节点

| 概念 | type | 要点 |
|------|------|------|
| [[Wound Healing]] 创伤愈合 | pathophysiology | 依据损伤程度及有无感染分为一期愈合与二期愈合 |
| [[Healing by First Intention]] 一期愈合 | pathophysiology | 缺损少、创缘整齐、无感染、对合严密；第 3 天肉芽填满，5–7 天胶原连接可拆线，2 周变白 |
| [[Healing by Second Intention]] 二期愈合 | pathophysiology | 缺损大、创缘不整、哆开、无法整齐对合或伴感染；坏死多、需多量肉芽充填、时间长、瘢痕大而不规则 |
| [[Fracture Healing]] 骨折愈合 | pathophysiology | 四阶段：血肿形成 → 纤维性骨痂形成 → 骨性骨痂形成 → 骨痂改建或再塑；外伤性 / 病理性 |
| [[Factors Affecting Wound Healing]] 影响创伤愈合的因素 | pathophysiology | 全身（年龄、营养：蛋白质/维生素 C/锌）；局部（感染与异物、局部血液循环、神经支配、电离辐射）；骨折特有（复位、固定、功能锻炼） |

| 概念 | type | 要点 |
|------|------|------|

| [[Keloid]] 瘢痕疙瘩 | pathophysiology | 瘢痕过度增生 → 肥大突起不规则 |

## 第一节 再生（regeneration）


### 修复总论

- 概念：损伤造成机体部分细胞和组织丧失后，机体对所形成缺损进行**修补恢复**的过程，可完全或部分恢复原组织的结构和功能
- 成分：各种细胞和**细胞外基质**
- 两种形式：1 **再生**（损伤周围同种细胞修复 → 完全修复）2 **纤维性修复**（纤维结缔组织修复 → 瘢痕修复）
- 多数情况下两种同时存在，常伴炎症

### 再生的类型

- **生理性**：生理过程中细胞组织不断老化消耗，由新生的同种细胞不断补充，保持原有结构和功能 —— 表皮、消化道黏膜上皮、子宫内膜、血细胞
- **病理性**：病理状态下细胞、组织缺损后发生的再生

### 细胞周期

| 分期 | 内容 |
|------|------|
| 间期 interphase | G1 期（DNA 合成前期）· S 期（DNA 合成期）· G2 期（分裂前期） |
| 分裂期 mitotic phase（M 期） | —— |

### 不同类型细胞的再生潜能

一般规律：低等 > 高等，幼稚 > 高分化，易受损及常更新则再生能力较强。
过程：多数组织含保持分裂能力的**静止细胞**，接受刺激进入细胞周期。

| 类型 | 特点 | 举例 |
|------|------|------|
| **不稳定细胞** labile cells | 持续分裂、不断增殖以代替衰亡或破坏的细胞，再生能力强 | 表皮，呼吸道及消化道粘膜，生殖器官管腔粘膜被覆细胞，淋巴及造血细胞，间皮细胞 |
| **稳定细胞** stable cells | 静止细胞（quiescent cell），生理增殖不明显（静止 G0 期），刺激时进入 G1 期；再生能力较强 | 腺体或腺样器官的实质细胞（胰腺、唾液腺、内分泌腺、汗腺、皮脂腺、肾小管上皮）；原始间叶细胞及分化的平滑肌细胞；肝脏（部分切除后快速再生） |
| **永久性细胞** permanent cells | 非分裂细胞，出生后不能分裂增生，一旦破坏永久缺失 | 中枢神经细胞；周围神经的神经节细胞；骨骼肌和心肌细胞 |

特殊：神经细胞存活时，受损**神经纤维**再生能力活跃。

### 干细胞及其在再生中的作用

- 定义：个体发育过程中产生的具有**无限或较长时间自我更新和多向分化能力**的一类细胞
- 特点：无限增殖分裂、静止状态、缺乏标志物、**非对称分裂**（分裂后一个子代细胞保持原有特性，另一个分化为成熟细胞）
- 举例：表皮基底细胞，胃肠道黏膜隐窝细胞；造血、表皮、间充质、肌肉、肝脏、神经干细胞等

| 类型 | 内容 |
|------|------|
| **胚胎干细胞** | 着床前胚胎内细胞群的**全能干细胞**，具有向三个胚层分化能力、成体所有类型成熟细胞；全能分化 → 修复替代功能丧失的组织和器官；应用：神经变性（帕金森病 / 阿尔茨海默病）、糖尿病、心肌梗死等 |
| **成体干细胞** | 各组织器官中具有自我更新和一定分化潜能的**不成熟细胞**；可向本身及无关组织类型的成熟细胞分化 → **转分化**；应用：诱导自体健康干细胞分化增殖，体外基因转染获得多能干细胞；意义：克服异体移植的免疫排斥，避免胚胎干细胞的伦理问题 |

### 组织再生的机制和过程

| 组织 | 再生过程 |
|------|----------|
| **上皮组织** | 被覆上皮：基底层细胞分裂增生，组织干细胞分化增殖。腺上皮：腺体基底膜完整 → 残存细胞分裂补充 → 完全恢复；腺体及基底膜完全破坏 → 难以再生 |
| **纤维组织** | 静止的纤维细胞或未分化间叶细胞 → 成纤维细胞 → 合成分泌形成胶原纤维 + 纤维细胞 → 纤维瘢痕 |
| **软骨组织** | 软骨膜增生 → 软骨基质 + 陷窝内静止的软骨细胞；缺损较大 → 纤维组织修复 |
| **血管** | 毛细血管 → 出芽式和套叠式血管生成；大血管修复 → 手术吻合 → 内皮及平滑肌增生 + 纤维瘢痕 |
| **肌组织** | 横纹肌肌膜未破坏 → 残存肌细胞分裂、肌原纤维分化 → 恢复；肌膜破坏或肌纤维完全断开 → 纤维瘢痕修复；平滑肌 → 再生或纤维瘢痕修复 |
| **神经组织** | 脑和脊髓神经细胞破坏 → 胶质细胞 + 胶质纤维 → 胶质瘢痕；神经纤维受损 + 神经细胞存活 → 施万细胞增生 + 轴突延伸 → 完全再生；断端相隔太远 / 瘢痕等阻隔 / 截肢失去远端 → 再生轴突不能到达远端，与增生的结缔组织混杂并卷曲成团 → 创伤性神经瘤 → 顽固性疼痛 |

**肝细胞损伤再生的三种情况**（重点）：

| 情况 | 结局 |
|------|------|
| 部分切除 | 分裂增生 → 短期内恢复原有大小 |
| 肝小叶网状支架完整 | 周边肝细胞沿支架延伸 → 恢复正常 |
| 网状支架塌陷 / 胶原化 / 纤维增生 | 结构紊乱肝细胞团 → **肝硬化** |

### 细胞再生的影响因素

| 因素 | 内容 |
|------|------|
| **细胞外基质（ECM）** | 作用：连接细胞、支撑和维持组织的生理结构和功能；调节再生细胞的生物学行为、重新构建正常组织结构；调控胚胎发育、组织重建、修复愈合、肿瘤侵袭等。成分：胶原蛋白、弹力蛋白、黏附性糖蛋白和整合素、基质细胞蛋白、蛋白多糖和透明质酸 |
| **生长因子**（growth factor） | 机制：同类或同一胚层细胞增生、损伤重建、刺激与抑制动态平衡；种类：**多肽类最关键**，如 PDGF、FGF、EGF、TGF、VEGF、IL-1、TNF 等 |
| **抑素**（chalone） | 具有**组织特异性**，任何组织都可产生，抑制本身增殖 |
| **接触抑制**（contact inhibition） | 皮肤损伤周围上皮细胞分裂、增生、迁移，因覆盖创面相互接触时，或肝部分切除后肝细胞增生达到原有肝脏大小时，细胞停止生长不堆积；细胞**缝隙连接 / 桥粒**参与调控 |

## 第二节 纤维性修复

> [!warning] 讲义结构说明
> 讲义中**未出现"第二节"标题**；本节划分依据原文内的编号与内容边界推断。

过程：实质细胞再生 + 肉芽组织增生 → 溶解吸收坏死及异物、填补缺损 → **胶原纤维为主的瘢痕组织**。

### 一、肉芽组织（granulation tissue）

- 组成：新生薄壁毛细血管 + 成纤维细胞增生 + 炎细胞浸润
- 肉眼：鲜红色，颗粒状，柔软湿润，形似鲜嫩的肉芽
- 镜下：
  1. 内皮细胞：实性细胞索 + 毛细血管扩张 → 垂直创面、袢状弯曲
  2. 成纤维细胞：胞质中含肌动蛋白并可收缩 → **肌成纤维细胞**
  3. 炎细胞：**巨噬细胞为主**，中性粒及淋巴细胞，渗出液

**作用**：抗感染保护创面；填补创口及其他组织缺损；机化或包裹坏死、血栓、炎性渗出物及其他异物。

**进展**：损伤后 2–3 天 → 自下向上、从周围向中心填补创口或机化异物。

**结局**：间质水分减少，炎细胞减少逐渐消失；毛细血管闭塞、减少，部分管壁增厚改建为小动静脉；成纤维细胞产生胶原纤维、融合玻璃样变成为纤维瘢痕。

### 二、瘢痕组织的形态及作用

- 特点：肉芽组织改建成熟形成的纤维结缔组织
- 大体：灰白、质韧、半透明
- 镜下：平行或交错的胶原纤维束，均质红染玻璃样变；纤维细胞稀少，血管减少

| 有利 | 不利 |
|------|------|
| 填补连接创损，完整性和韧性 | 缺乏弹性可膨出（**室壁瘤**） |
| | 瘢痕收缩 → 关节活动受限、腔道狭窄梗阻 |
| | 瘢痕粘连 → 缩窄性胸膜炎 / 心包炎、器官硬化 |
| | 过度增生 → 肥大突起不规则 → **瘢痕疙瘩（keloid）** |

## 第三节 创伤愈合

> [!warning] 讲义结构说明
> 讲义中**未出现"第三节"标题**；依据原文编号（"二、骨折愈合"、"三、影响创伤愈合的因素"）与内容边界推断。

### 一、皮肤创伤愈合

依据损伤程度及有无感染，分为两类：

| | **一期愈合**（healing by first intention） | **二期愈合**（healing by second intention） |
|---|---|---|
| 伤口 | 组织缺损少、创缘整齐、无感染、对合严密 | 组织缺损大、创缘不整、哆开、无法整齐对合，或伴感染 |
| 愈合 | 第 3 天肉芽长出并填满伤口，5–7 天胶原连接，可拆线临床愈合 | 坏死多，需多量肉芽组织充填、控制感染、清除坏死 → 时间长 |
| 瘢痕 | 2 周变白，数月后一条白色线状瘢痕 | 较大且形状不规则 |

### 二、骨折愈合

类型：外伤性和病理性骨折。

| 阶段 | 内容 |
|------|------|
| 血肿形成 | 出血，骨髓坏死，死骨片 |
| 纤维性骨痂形成 | 肉芽组织取代、机化、纤维化 |
| 骨性骨痂形成 | 成骨细胞形成类骨质 + 钙盐沉积 → 编织骨 |
| 骨痂改建或再塑 | 破骨细胞 + 成骨细胞 → 成熟的板层骨 |

### 三、影响创伤愈合的因素

一般影响因素：损伤程度、再生能力、坏死、异物及感染等。
治疗原则：缩小创面，防止再损伤和感染，促进组织再生修复。

**（一）全身因素**

- 年龄：青少年再生能力强、愈合快；老年人愈合慢（血供减少）
- 营养：蛋白质、维生素 C、锌 → 形成胶原纤维促进创伤愈合

**（二）局部因素**

- 感染与异物：清创术 + 伤口缝合 → 变二期为一期愈合
- 局部血液循环：动脉粥样硬化或静脉曲张等 → 伤口愈合迟缓
- 神经支配：麻风引起神经性营养不良 → 溃疡不易愈合
- 电离辐射：损伤细胞和小血管、抑制再生

**（三）影响骨折愈合的因素**

- 骨折断端复位需及时正确：错位或嵌塞 → 延迟或不能愈合
- 骨折断端固定需及时牢靠：石膏 / 夹板 / 髓腔钢针固定
- 早日全身和局部功能锻炼，保持局部良好供血
- 讲义所列预防关注点：病理性萎缩（压迫性、失用性）· 赘生骨痂（新骨形成过多）· 假关节（纤维性骨痂不能变成骨性骨痂并出现裂隙）
