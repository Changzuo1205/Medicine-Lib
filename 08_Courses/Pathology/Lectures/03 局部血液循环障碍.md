## 局部血液循环障碍总论

- **组成**：心脏、各级动静脉、毛细血管
- **功能**：动态循环、物质运输、维持内环境稳定
- **类型**：全身性、局部性（本章讲局部性）

---

## 第一节 充血和淤血

> 讲义开篇给出本节共同的**特点**与**分类**：
> - 特点：局部组织血管内血液含量增多
> - 分类：发生的部位、原因、病变和机体影响不同

### 一、充血（hyperemia）

详见 [[Hyperemia]]。

- **概念**：动脉输入血量增多 → 局部器官或组织血管内血液含量增多
- **特点**：**动脉性充血（arterial hyperemia）**，**主动性**过程
- **机制**：神经体液 → 血管舒张神经兴奋性↑ + 舒血管活性物质↑ → 小动脉和毛细血管扩张 → 血流加快、输入血量增加
- **类型**：
  - **生理性充血**：胃肠道、骨骼肌、妊娠子宫
  - **病理性充血**：炎症性充血（致炎因子、神经轴突反射、炎症介质）· 减压后充血（长期受压、突然解除、细动脉反射性扩张）
- **形态**：大体 —— 体积增大，**鲜红色**（氧合血红蛋白），温度升高（代谢增强）；镜下 —— 局部细动脉、毛细血管扩张充血
- **影响**：短暂的血管反应，病因消除可恢复正常。但**高血压、动脉粥样硬化**可致血管破裂、出血；**减压后充血**可致血压突降、心脑缺血

### 二、淤血（congestion）

详见 [[Congestion]]。

- **概念**：静脉回流受阻 → 毛细血管和小静脉内血液淤积 → 局部血量增加
- **特点**：**被动**过程，可局部或全身
- **原因**：① 静脉受压（肿瘤、妊娠子宫、肝硬化、肠疝或扭转等）；② 静脉腔阻塞（下肢深静脉血栓形成、静脉内瘤栓）；③ 心力衰竭（心腔内血液滞留、压力增高、阻碍静脉回流）
- **举例**：二尖瓣或主动脉瓣狭窄、高血压后期 → 左心衰 → **肺淤血**；肺源性心脏病 → 肺动脉高压 → 右心衰 → **体循环淤血**
- **形态**：大体 —— 肿胀暗红、重量增加、包膜紧张、边缘变钝、体表温度下降；还原血红蛋白↑ → 体表淤血呈紫蓝色 → **发绀（cyanosis）**；镜下 —— 细静脉及毛细血管扩张，过多红细胞积聚
- **后果（5 类）**：① **淤血性水肿**（流体静压和通透性增加 → 组织内漏出液潴留）；② **淤血性积液**（浆膜腔内漏出液积聚）；③ **淤血性出血**（红细胞漏出 + 巨噬细胞吞噬 → 含铁血黄素）；④ **实质细胞萎缩、变性及坏死**（缺氧 + 营养不足 + 代谢产物）；⑤ **淤血性硬化**（间质纤维增生 + 网状纤维胶原化）

### 三、重要器官的淤血

#### （一）肺淤血

详见 [[Pulmonary Congestion]]。

| | 急性肺淤血 | 慢性肺淤血 |
|---|---|---|
| **镜下** | 肺泡壁毛细血管扩张充血，肺泡壁增厚，肺泡间隔水肿，肺泡腔内充满水肿液，可见**少量红细胞** | 肺泡壁毛细血管**明显**扩张充血，肺泡间隔**纤维性增厚**；肺泡腔见水肿液、红细胞和大量**心衰细胞（heart failure cells）** |
| **大体** | 体积增大，重量增加，暗红色，质地开始变实，切面流出**泡沫状红色血性液体** | 质地变硬呈**棕褐色** → **肺褐色硬化（brown induration）** |

**心衰细胞的来源**：巨噬细胞吞噬红细胞 → 血红蛋白降解 → 含铁血黄素细胞。

**临床**：气促发绀，咳**粉红色泡沫痰或铁锈色痰**，呼吸困难，心肺衰竭。

#### （二）肝淤血

详见 [[Hepatic Congestion]]。

| | 急性肝淤血 | 慢性肝淤血 |
|---|---|---|
| **大体** | 体积增大，暗红色 | 中央区严重淤血呈**暗红色**；周边区肝细胞脂变呈**黄色** → 切面**红黄相间的网纹 → 槟榔肝（nutmeg liver）** |
| **镜下** | **中央区**：中央静脉及肝窦扩张，充满红细胞，肝细胞脂变或萎缩；**周围区**：缺氧较轻，肝细胞病变不明显，仅见少量脂变 | — |

**进一步进展（讲义续）**：

1. **小叶中央区**（淤血较重）：肝窦高度扩张淤血、出血，肝细胞萎缩、消失
2. **小叶周边区**（淤血较轻）：肝细胞脂肪变性，似脂肪细胞，灶性坏死
3. **间质纤维组织明显增生**：网状纤维支架塌陷后胶原化；肝星状细胞增生、合成胶原增多；汇管区纤维组织增生

## 第二节 出血

详见 [[Hemorrhage]]。

- **概念**：血液从血管或心腔溢出
- **类型**：生理性（月经期子宫内膜）· 病理性出血

| 机制 | 内容 |
|------|------|
| **1. 破裂性** | 机械性损伤、室壁瘤、主动脉瘤、动脉粥样硬化破裂；病变侵蚀（肿瘤、结核、溃疡）；静脉曲张；毛细血管 |
| **2. 漏出性** | 微循环通透性增高 —— **血管壁损害**（缺氧、感染、中毒、VitC↓、免疫反应）· **血小板异常**（再障、白血病、紫癜、药物或毒素、DIC）· **凝血因子缺乏**（血友病、肝脏疾病、DIC） |

**病变（按部位）**：

| 分类 | 表现 |
|------|------|
| **1. 内出血** | **体腔积血**：心包、胸腔、腹腔、关节腔；**血肿**：硬脑膜下、皮下、腹膜后 |
| **2. 外出血** | **自然管道**：鼻出血、咯血、呕血、便血、尿血；**皮肤粘膜**：瘀点、紫癜、瘀斑 |

- **结局**：血凝块止血、吸收、机化或纤维包裹
- **影响**：取决于**出血量、速度、部位及类型** —— 出血性休克、心包积血、脑干或内囊出血、缺铁性贫血

## 第三节 血栓形成

### 一、概念与机制基础

详见 [[Thrombosis]]。

- **概念**：活体的心血管内血液凝固或有形成分凝集形成**固体质块**的过程
- **血栓（thrombus）**：区别于血凝块、血肿
- **机制**：凝血系统 ⇄ 纤维蛋白溶解系统的动态平衡
  - **可凝固性**：凝血因子（+）→ 凝血酶 → 纤维蛋白沉着
  - **流动性**：纤溶酶（+）→ 纤维蛋白溶解
  - 动态平衡保证血液的**可凝固性**和**流体状态**
- **总结**：血液流动状态 → 血小板（+）和凝血因子（+）→ 血液发生凝固

### 二、血栓形成的条件和机制

详见 [[Virchow's Triad]]。

**Rudolf Virchow 提出的三个条件**：① 心血管内皮细胞损伤　② 血流状态异常　③ 血液凝固性增加

**总结**：三者**同时存在，相辅相成** —— **心血管内皮损伤最重要、最常见**。

讲义对三个条件分别展开：

- **条件 1 · 内皮细胞**：完整内皮**抗凝**（屏障作用；抗血小板黏集：合成 PGI2、NO、ADP 酶；合成抗凝物质：凝血酶调节蛋白、肝素样分子、蛋白 S；促进纤维蛋白溶解：合成 t-PA）vs 损伤内皮**促凝**（胶原暴露 → XII（+）+ 血小板（+）→ 内源性凝血（+）→ 纤维蛋白；释放组织因子 III → VII（+）→ 外源性凝血（+）；释放 vWF → 介导血小板与胶原粘附；分泌 PAI → 抑制纤维蛋白溶解）。**内皮损伤或被激活 → 促进局部凝血**
- **条件 1 续 · 血小板的活化**：黏附反应（vWF 介导血小板表面整合素与内皮下胶原结合）· 释放反应（PDGF、血栓素 A2、ADP、Ca²⁺）· 黏集反应（可逆的血小板黏集堆）→ 凝血酶（+）→ 纤维蛋白 + 血小板紧密交织 → **血栓形成牢固起始点**
- **条件 2 · 血流状态异常**：原因 —— 内膜炎、心梗、动脉粥样硬化、缺氧、败血症、毒素、DIC 等；特点 —— 血流缓慢和产生漩涡 → 血小板进入边流 → 接触并黏附内膜；机制 —— 导致内皮缺氧损伤（凝血激活 + 血小板黏集）、凝血因子及凝血酶浓度↑（局部凝血活性↑）；部位 —— **静脉**（下肢深静脉、盆腔静脉；静脉瓣、涡流、壁薄受压、血液黏性增加）> **心脏**（二尖瓣狭窄的左心房、心肌梗死）> **动脉**（粥样硬化斑块、动脉瘤）
- **条件 3 · 血液凝固性增加**：特点 —— 血小板和凝血因子↑ + 纤溶系统活性↓ → **血液高凝状态**；类型 —— **遗传性（原发性）**：V 因子基因突变、先天性缺乏抗凝血酶 III、蛋白 S 或 C；**获得性（继发性）**：促凝因子↑（晚期恶性肿瘤、多发血栓游走性脉管炎）、血小板数量和黏性↑（烧伤、大失血、高脂血症、吸烟等）

> **讲义思考题（原文）**：术后久卧，如何预防下肢静脉血栓形成？

### 三、血栓形成的过程

讲义用「水泥 + 钢筋」比喻串起全过程（原文 5 步）：

1. 内皮损伤、胶原暴露 → 血小板黏附 + 释放 + 黏集 → **血小板黏集堆（水泥）**
2. 内源和外源凝血途径激活 → 凝血酶 → **纤维蛋白（钢筋）**
3. 血小板黏集堆 + 纤维蛋白 → 牢固交织 → **血栓起始（白色）**
4. 血小板小梁 + 梁间纤维蛋白网 + 充满红细胞 → **血栓体部（混合）**
5. 血管腔阻塞 → 局部血流停滞 → 血液凝固 → **血栓尾部（红色）**

### 四、血栓的类型

详见 [[Thrombus Types]]。

| 类型 | 部位 | 形成 | 大体 | 镜下 |
|------|------|------|------|------|
| **1. 白色血栓**（white thrombus） | 急性风湿性心内膜炎；静脉延续性血栓的**起始部** | 内皮损伤 → 血小板 + 纤维蛋白 → **血栓头部** | 小结节或**疣状赘生物**，灰白质实，附着牢固，**不易脱落** | 血小板 + 少量纤维蛋白 —— 血小板或析出性血栓 |
| **2. 混合血栓**（mixed thrombus） | 静脉内延续性血栓的**体部**；左心房的球状混合血栓；动脉粥样硬化斑块、动脉瘤内**附壁血栓**（mural thrombus） | — | 灰白和暗红（固定呈黑色）相间的**层纹状结构 → 层状血栓**；粗糙、干燥、圆柱状，与血管壁粘连 | 白 —— 血小板梁：淡红染无结构，不规则珊瑚状，附着 N（趋化）；红 —— 梁间：纤维蛋白网 + 充满红细胞（若崩解呈网格状） |
| **3. 红色血栓**（red thrombus） | 静脉内延续性血栓的**尾部** | 混合血栓逐渐增大阻塞管腔 → 下游局部血流停滞、血液凝固 | **暗红**，新鲜湿润有弹性，与血管壁**无粘连**，类似血凝块；陈旧则干燥无弹性，质脆易碎，**脱落形成血栓栓塞** | 纤维蛋白网 + 充满血细胞（红细胞为主 + 少量白细胞均匀分布） |
| **4. 透明血栓**（hyaline thrombus） | **微循环毛细血管**内，又称**微血栓**（microthrombus） | **弥散性血管内凝血（DIC）** | — | 纤维蛋白构成，**均质红染**，又称**纤维蛋白性血栓**（fibrinous thrombus） |

### 五、血栓的结局

详见 [[Thrombus Outcome]]。

| 结局 | 机制 / 表现 |
|------|-------------|
| **（一）软化、溶解、吸收** | 血栓内纤溶酶激活 + 白细胞释放溶蛋白酶 |
| **（二）机化（organization）、再通（recanalization）** | **机化**：纤溶酶活性不足 → 肉芽组织自血管壁长入并逐渐取代血栓；较大血栓约 **2 周**可完全机化 → 紧密粘着血管壁不再脱落。**再通**：干燥收缩或部分溶解出现裂隙 → 内皮覆盖表面形成新血管并相互吻合沟通 → 被阻塞的血管部分重建血流 |
| **（三）钙化（calcification）** | 长期血栓或机化玻璃样变 + 钙盐沉积 → **静脉石、动脉石** |

### 六、血栓对机体的影响

详见 [[Thrombosis Consequences]]。

- **有利**：破裂血管止血，避免大出血
- **不利**：取决于部位、大小、类型、阻塞程度、侧支循环

| 影响 | 内容 |
|------|------|
| **（一）阻塞血管** | 不完全阻塞 → 实质细胞萎缩（营养不良性）；动脉完全阻塞且无有效侧支 → **梗死**（心肌、脑）；坏死继发腐败菌感染 → **坏疽**；浅表侧支循环丰富 → 症状不明显；深部无有效侧支循环 → 淤血、出血、坏死 |
| **（二）血栓栓塞** | 原因：黏着不牢固或软化碎裂 → 脱落形成栓子。举例：深部静脉延续性血栓（体尾部）脱落 → **肺动脉栓塞**；左心腔、瓣膜及动脉附壁血栓脱落 → **体循环动脉栓塞**；栓子内细菌（+）→ **败血性梗死或脓肿形成** |
| **（三）心瓣膜变形** | 心内膜炎 → 瓣膜内皮细胞受损 → 反复形成血栓并机化 → 瓣膜增厚变硬、瓣叶之间粘连 → **瓣膜口狭窄**；瓣膜增厚卷缩、腱索增粗短缩 → **瓣膜关闭不全** |
| **（四）广泛性出血** | 严重创伤 / 烧伤 / 羊水栓塞 / 肿瘤等 → 促凝↑ → 外源凝血（+）；感染 / 缺氧 / 酸中毒等 → 广泛内皮损伤 → 内源凝血（+）→ 微血管内形成**透明血栓**（肺 / 肾 / 脑等）→ 广泛坏死及出血 → **凝血因子大量消耗 → 血液凝固障碍 → 出血性休克**（即 DIC）→ 见 [[Disseminated Intravascular Coagulation]] |

## 第四节 栓塞

详见 [[Embolism]]。

- **概念**：循环血液中出现**不溶异物**，随血运行阻塞血管腔的现象
- **栓子（embolus）**：阻塞血管的异物
- **类型（按性状）**：**固体** —— 血栓 / 瘤栓；**液体** —— 脂滴 / 羊水；**气体** —— 空气 / 氮气

### 一、栓子的运行途径

| 途径 | 去向 |
|------|------|
| **1. 体静脉系统和右心腔栓子** | 栓塞肺动脉主干及分支 → **肺栓塞**；栓子小且有弹性 → 经肺泡壁毛细血管 → 左心 → 体循环细小动脉栓塞 |
| **2. 主动脉系统和左心腔栓子** | → 脑、脾、肾、四肢等动脉分支栓塞 |
| **3. 门静脉系统栓子** | 胃肠、脾静脉回流 → 门静脉 → 肝内门静脉分支栓塞 |
| **4. 交叉性栓塞**（crossed embolism，**反常性栓塞**） | 病因：先天性房或室间隔缺损、肺动脉导管未闭；过程：右心腔压力高 → 穿过房或室间隔缺损 → 左心及动脉系统 |
| **5. 逆行性栓塞**（retrograde embolism） | 胸腹压突然升高（咳嗽或深呼吸）→ 下腔静脉栓子短暂逆流 → 栓塞下腔静脉回流分支（肝、肾、髂静脉） |

### 二、栓塞的类型

> 讲义原文：**血栓栓塞（99%）**、脂肪栓塞、气体栓塞、羊水栓塞。

#### （一）血栓栓塞（thromboembolism）

**1. 肺动脉栓塞（pulmonary embolism）**

详见 [[Pulmonary Embolism]]。

- **来源**：下肢深静脉 **95%**（腘、股和髂总），盆腔静脉，右心附壁血栓
- **影响**：大小、数量、双重血供的侧支代偿能力
- **后果**：
  1. 中小栓子 → 肺动脉小分支栓塞（肺动脉-支气管动脉吻合支可代偿）→ 栓子被溶解、吸收或机化 → **无严重后果**
  2. 严重肺淤血 → 微循环压力↑ → 支气管动脉供血受阻失去代偿 → 肺动脉分支栓塞 → 淤血区缺氧坏死并出血 → **出血性梗死**
  3. 栓子大 → 栓塞肺动脉主干或大分支 → **骑跨性栓塞 → 猝死**
  4. 栓子小且数量多 → 广泛栓塞肺动脉小分支 → **猝死**

**肺动脉栓塞引起猝死的机制（3 条）**：① 肺动脉阻力急剧↑ → 急性右心衰 → 回心血量↓ → 冠状动脉灌注↓ → 心肌缺血；② 迷走神经（+）→ 肺动脉、冠状动脉、支气管动脉、支气管的平滑肌痉挛 → 心肌缺血、窒息 → 急性右心衰、呼吸困难；③ 新鲜血栓受挤压 → 血小板释放 **5-HT、TXA₂** → 血管痉挛。

**2. 体循环动脉栓塞**

详见 [[Systemic Arterial Embolism]]。

- **来源**：**左心腔** —— 心内膜炎瓣膜赘生物、左心房及心梗的附壁血栓；**动脉** —— 粥样硬化溃疡、动脉瘤的附壁血栓；**腔静脉** —— 交叉性栓塞
- **后果**：取决于部位、侧支循环、缺血耐受性 —— 有侧支 → 无梗死（上肢动脉吻合支、肝动脉和门静脉双重供血）；无侧支 → 局部组织梗死（**脑、心、肾、脾**）

#### （二）脂肪栓塞

详见 [[Fat Embolism]]。

- **概念**：循环血液内出现较大脂肪滴并阻塞小血管
- **来源**：长骨骨折、脂肪挫伤、烧伤、脂肪肝撞击 → 破裂脂滴入血；高血脂 + 应激状态 → 血脂游离融合形成脂肪滴
- **后果**（取决于脂滴大小和数量、栓塞部位）：
  1. 直径 **> 20 µm** → 栓塞肺动脉小分支或毛细血管
  2. 直径 **< 20 µm** → 经肺泡壁毛细血管 → 肺静脉 → 左心体循环 → **脑水肿、点状出血**
  3. 少量脂滴入血 → 巨噬细胞吞噬 + 脂酶分解
  4. 大量脂滴快速入血 → 肺循环大面积受阻 → **窒息、右心衰猝死**

#### （三）气体栓塞

详见 [[Gas Embolism]]。

- **概念**：大量空气迅速进入血液循环，或原溶于血液的气体迅速游离，形成气泡阻塞心血管，分别称为**空气栓塞**和**减压病**

**1. 空气栓塞（air embolism）**

- **原因**：手术或创伤、正压静脉输液、人工气胸或气腹、分娩或流产
- **后果**：① 少量 → 血液溶解；② **> 100 ml** → 右心泡沫血 → 阻断体循环静脉回流和肺动脉输出 → 急性右心衰、呼吸衰竭、DIC → **猝死**；③ 部分气泡 → 肺小动脉栓塞或通过毛细血管 → 左心体循环栓塞

**2. 减压病**

- **概念**：从高压迅速进入常压或低压，已溶于血液、组织液和脂肪组织的气体迅速游离形成气泡；O₂ 和 CO₂ 再溶，**N₂ 溶解缓慢融合成气泡 → 氮气栓塞**，又称**沉箱病**和**潜水员病**（caisson and diver disease）
- **临床**：富含脂肪的皮下组织 → 皮下气肿；肌肉、肌腱、韧带 → 关节和肌肉疼痛；小血管阻塞 → **股骨头无菌性坏死**、肠痉挛性疼痛；大量气泡阻塞多数血管及冠状动脉 → **猝死**

#### （四）羊水栓塞

详见 [[Amniotic Fluid Embolism]]。

- **来源**：产道阻塞 → 强烈宫缩 → 宫内压将羊水压入子宫壁破裂的静脉窦 → 栓塞母体肺动脉细小分支 → 通过肺毛细血管 → 左心及体循环
- **光镜**：肺细小动脉、毛细血管或母体血涂片内见**羊水成分** —— 角化鳞状上皮、胎毛、胎脂、胎粪、黏液
- **后果**：广泛栓塞、过敏性休克、反射性血管痉挛、DIC、出血 → **猝死**

#### （五）其他栓塞

细胞栓塞（肿瘤、胎盘滋养叶、骨折骨髓细胞）· 胆固醇结晶 · 寄生虫及虫卵 · 菌栓 · 异物。

## 第五节 梗死（infarction）

详见 [[Infarction]]。

- **概念**：器官局部组织血管阻塞、血流停滞导致缺氧发生的**坏死**
- **区别**：**动脉阻塞 → 缺血坏死**；**静脉阻塞 → 缺氧坏死**
- **原因**：① **血栓形成**（动脉粥样硬化、闭塞性脉管炎、肠系膜静脉）；② **动脉栓塞**（血栓、气体、羊水、脂肪）；③ **动脉痉挛**（粥样硬化的冠状动脉持续收缩）；④ **血管受压闭塞**（肿瘤、肠系膜、卵巢囊肿及睾丸扭转等）
- **影响**：双重血液循环（肺、肝）、丰富吻合支（前臂、手）；缺血敏感性（**神经 < 心肌 < 骨骼肌/纤维**）；血氧含量过低

**梗死灶的三组决定因素**：

| 形态 | 决定因素 | 表现 |
|------|----------|------|
| **形状** | 器官血管分布 | 肾、脾、肺：**锥形或三角形**，尖端指向门部，底部为器官表面；心肌梗死呈**不规则地图状**；肠梗死呈**节段形** |
| **质地** | 坏死类型 | 凝固性坏死：新鲜肿胀渗出，陈旧干燥质硬、表面下陷；液化性坏死：新鲜质软疏松，逐渐液化成囊状 |
| **颜色** | 病灶含血量 | 含血少灰白色 → **贫血性/白色梗死**；含血多暗红色 → **出血性/红色梗死** |

### （一）贫血性梗死（anemic infarct）

详见 [[Anemic Infarction]]。

- **条件**：组织结构致密、侧支循环不丰富的实质器官
- **部位**：**脾、肾、心**
- **大体**：灰白色，锥形或不规则地图状，尖端指向血管阻塞部位，底部为器官表面，边界清楚，周围可见**褐色充血出血带**；浆膜面炎性渗出 → 干燥质实，表面下陷，充血出血带消失
- **镜下**：**凝固性坏死**（组织结构轮廓保存、细胞精细结构消失，可见核固缩、核碎裂、核溶解、胞浆红染）→ 肉芽组织长入机化 → 纤维瘢痕（灰白质韧半透明、均质红染玻璃样变）

**脑梗死**（讲义续）：大体 —— 坏死软化、液化成囊；镜下 —— **液化性坏死**；结局 —— 胶质细胞和胶质纤维增生 → **胶质瘢痕**。

### （二）出血性梗死（hemorrhagic infarct）

详见 [[Hemorrhagic Infarction]]。

- **条件**：① **严重淤血** —— 静脉和毛细血管压力升高，影响侧支循环代偿；② **组织疏松** —— 容纳多量漏出的血液，不易挤出

**1. 肺出血性梗死**：部位 —— 肺下叶，肋膈缘；大体 —— 锥形或楔形，尖端朝向肺门，底部紧邻肺膜，暗红质实，边界尚清，表面略隆起 → 灰白质韧，表面下陷；镜下 —— 早期为凝固性坏死，肺泡轮廓，腔内及间质充满红细胞；后期肉芽组织机化，纤维瘢痕形成

**2. 肠出血性梗死**：原因 —— 肠系膜动脉栓塞和静脉血栓形成；肠套叠、扭转、嵌顿疝、肿瘤压迫等；大体 —— **节段性暗红色（黑色）**，肠壁因淤血水肿及出血明显增厚，坏死质脆易破裂，浆膜炎性渗出，相应肠系膜出血坏死；临床 —— 缺血性痉挛 → 麻痹性梗阻 → 穿孔 → **腹膜炎**

### （三）败血性梗死（septic infarct）

详见 [[Septic Infarction]]。

- **原因**：急性感染性心内膜炎 → 赘生物含菌脱落 → 体循环动脉栓塞
- **镜下**：梗死灶内可见**菌团和大量炎细胞浸润 → 脓肿形成**

### （四）影响和结局

- **影响**：取决于梗死器官、病变范围及有无细菌感染等 —— 重要器官的大面积梗死（心、脑）→ 死亡或瘫痪；肾、脾、肺 → 局部症状，功能尚存；梗死后继发腐败菌感染（肺、肠、四肢）→ **坏疽**
- **结局**：肉芽组织完全机化 → 胶原纤维瘢痕；不能完全机化 → 纤维包裹、钙化；**脑梗死 → 胶质细胞和胶质纤维增生 → 胶质瘢痕**

## Class Notes

> [!teacher]
> 老师强调（讲义重点）：
> - **充血 vs 淤血**：一个**主动**（动脉输入增多，鲜红、温度升高），一个**被动**（静脉回流受阻，暗红、温度下降、发绀）—— 是本章第一组必背对照
> - **三要素的记忆钩子**：Virchow 三条件 = **管壁（内皮损伤）· 血流（状态异常）· 血液（凝固性增加）**；讲义明确 **内皮损伤最重要、最常见**
> - **「水泥 + 钢筋」**：血小板黏集堆 = 水泥，纤维蛋白 = 钢筋 —— 这个比喻串起血栓的头（白）→ 体（混合）→ 尾（红）
> - **透明血栓不在血管腔的「大血管」里**：它只出现在**微循环毛细血管**，是 **DIC** 的标志性病变
> - **肺动脉栓塞猝死**的 3 条机制要能分开复述（机械性右心衰 / 迷走反射痉挛 / 血小板 5-HT、TXA₂）
> - **梗死颜色看含血量，形状看血管分布，质地看坏死类型** —— 三句话记住三组决定因素
> - 出血性梗死的两个前提是「**严重淤血 + 组织疏松**」，所以肺（疏松、双重血供）和肠（疏松）是典型部位
