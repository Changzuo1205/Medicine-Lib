# Cardiac Excitability

## Definition

心肌细胞（以心室肌为例）的兴奋性，表现为随复极化进程出现的不同兴奋状态：有效不应期、相对不应期、超常期。心肌不应期长（约 200 ms），远长于神经元和骨骼肌纤维（约 2 ms）。

## Refractory Periods（以心室肌为例）

| 时期 | 电位范围 | 特征 |
|------|----------|------|
| 有效不应期 ERP | 0 → -60 mV | 无论多强刺激都不产生可传播兴奋 |
| ├ 绝对不应期 ARP | 0 → -55 mV | Na⁺ 通道完全失活，任何刺激均不引起去极化反应 |
| ├ 局部反应期 | -55 → -60 mV | 阈上刺激仅引起局部反应，不产生 AP；Na⁺ 通道仅少量复活 |
| 相对不应期 RRP | -60 → -80 mV | 阈刺激不足以引起兴奋，加强刺激可产生新 AP；相当数量 Na⁺ 通道恢复备用 |
| 超常期 | -80 → -90 mV | 阈下刺激即可引起 AP；大多数 Na⁺ 通道恢复备用，膜电位距阈电位较近，易兴奋 |

- 在相对不应期和超常期，膜电位低于静息电位水平，Na⁺ 通道开放的速率和数量低，0 期去极化的速度和幅度低于正常

## Factors Affecting Excitability

1. **静息/最大复极电位水平**：
   - 细胞外 K⁺ 轻度升高 → 膜电位轻度去极 → 兴奋性升高
   - 细胞外 K⁺ 明显升高 → 膜电位显著减小 → Na⁺ 通道失活 → 兴奋性降低
2. **阈电位水平**：
   - 低血钙促进 Na⁺ 内流 → 阈电位下移 → 兴奋性升高
   - 奎尼丁抑制 Na⁺ 内流 → 阈电位上移 → 兴奋性降低
   - 阈电位：能触发 AP 的膜电位临界值（约 -70 mV，去极化 10-20 mV）
3. **0 期去极化离子通道状态**：
   - 快反应细胞：Na⁺ 通道；慢反应细胞：Ca²⁺ 通道
   - Na⁺ 通道状态链：完全备用 → 失活 → 刚复活 → 渐复活 → 基本备用
   - 对应兴奋性：兴奋性正常 → 兴奋性无（绝对不应期）→ 局部反应期 → 兴奋性低于正常（相对不应期）→ 兴奋性高于正常（超常期）

## Extra Systole & Compensatory Pause

- 期前收缩（Extra systole / premature systole）：在有效不应期后、下一次窦房结兴奋到达前，心室受到一次外来刺激，可提前产生一次兴奋和收缩
- 代偿间歇（Compensatory pause）：心房和心室在一次期前收缩之后，出现较长时程的舒张期
