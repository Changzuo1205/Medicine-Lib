# Pacemaker Activity

## Definition

窦房结（SA Node）P 细胞（起搏细胞）的自动节律性电活动：最大复极电位约 -70 mV，无 1 期和 2 期，0 期去极化速度与幅度均较小（由 L 型钙通道介导），以 4 期自动去极化为特征。

## SA Node Action Potential Features

- 最大复极电位（Maximal Repolarization Potential, MRP）：约 -70 mV，代表静息电位
- 0 期：由 I_Ca-L（电压门控 Ca²⁺ 通道）介导，去极化速度和幅度较小；无 I_Na、无 I_to
- 无 1 期和 2 期
- 4 期：膜电位不稳定，立即开始自动去极化（Phase 4 spontaneous depolarization），达阈电位（约 -40 mV）时爆发动作电位

## Phase 4 Automatic Depolarization（4 期自动去极化）

- I_K 通道关闭（去激活），K⁺ 外流电流衰减（I_k decay）
- I_f（起搏电流，超极化激活的非选择性阳离子通道）缓慢激活开放，Na⁺/K⁺ 内流
- I_Ca-T（T 型钙通道）参与
- 在 -100 mV 时 I_f 充分激活；P 细胞 MRP 为 -70 mV，故 I_f 不如 I_k 重要（I_f : I_k ≈ 1:6）
- 4 期自动去极化速度：窦房结 P 细胞约 0.1 V/s

## Fast vs Slow Response Cells

| 特征 | 快反应细胞（心房/心室） | 慢反应细胞（窦房结/房室结） |
|------|------------------------|------------------------------|
| 0 期 | I_Na 通道开放 | I_Ca-L 通道开放 |
| 1 期 | I_to 开放 | 无 |
| 2 期 | I_Ca-L 内流与 I_K 外流平衡 | 无 |
| 3 期 | I_K、I_K1 开放 | I_K 开放 |
| 4 期 | 稳定 | 自动去极化（I_k 衰减、I_f 与 I_Ca-T 开放） |

## Purkinje Cells（相关对比）

- 与心室肌相比：MRP 更负（约 -90 mV，I_K1 密度高）、0 期去极化更快、1 期更明显、有 4 期自动去极化
- 与窦房结 P 细胞相比：I_f 在 4 期自动去极化中起主要作用，但去极速度慢（0.02 V/s）；动作电位时程最长的心肌细胞
