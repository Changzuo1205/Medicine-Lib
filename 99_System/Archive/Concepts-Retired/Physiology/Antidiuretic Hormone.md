# Antidiuretic Hormone

## Definition

抗利尿激素（Antidiuretic hormone, ADH），又称**精氨酸血管升压素**（Arginine vasopressin, AVP），是由下丘脑合成、神经垂体释放的九肽激素，主要作用是**增加集合管对水的通透性**，促进水重吸收，使尿量减少。

## Normal Mechanism

### 合成与分泌
- 合成部位：下丘脑**视上核（SON）** + **室旁核（PVN）**
- 运输：经下丘脑-垂体束（Hypothalamo-hypophysial tract）轴突运输
- 释放：神经垂体（neurohypophysis）后叶释放入血

### 受体
- **V1-R**（V1a）
- **V2-R**（集合管主细胞基底侧膜 → cAMP ↑）

### V2 作用机制（PPT p89-91）
ADH → V2-R → cAMP ↑ →
1. **短时程**：AQP2 囊泡向顶端膜插入 → 集合管水通透性 ↑
2. **长时程**：AQP2 转录增加 → 顶端膜水通道数量 ↑

→ 集合管水重吸收 ↑ → 尿量 ↓

### 分泌调节

#### a. 血浆晶体渗透压（最重要）
- **1-2% 变化即起效**
- **NaCl 最有效**；尿素、葡萄糖无效
- 感受器：下丘脑前部室周器（osmoreceptor）
- 大量出汗、呕吐、严重腹泻 → 渗透压 ↑ → ADH ↑

```
血浆渗透压 ↑
  ↓
下丘脑渗透压感受器细胞皱缩
  ↓
（+）SON/PVN
  ↓
ADH 释放 ↑
```

#### b. 循环血量
- 5-10% 变化才起效（**不如渗透压敏感**）
- 容量感受器（颈动脉窦、主动脉弓、心房）→ 迷走传入 → ADH 释放 ↓
- 血压感受器（baroreceptor）也参与

#### c. 其他因素
- 升高 ADH：疼痛、恶心、烟碱、吗啡、Ang II
- 降低 ADH：酒精

## Key Components / Steps

1. 下丘脑合成 → 神经垂体贮存
2. 血浆渗透压 / 血容量变化触发释放
3. V2-R → AQP2 ↑ → 集合管水重吸收 ↑
4. 尿量 ↓、尿渗透压 ↑

### 水利尿（Water diuresis）
- 大量饮水 → ECF 稀释 → 渗透压 ↓ → ADH ↓ → 尿量 ↑
- **30 min 起效，60 min 达峰**

## Physiological Significance

- 调节体液渗透压平衡（核心）
- 调节有效循环血量
- 与 RAAS 协同维持循环稳态

## Clinical Relevance

### 尿崩症（Diabetes insipidus）
- **中枢性**：下丘脑-神经垂体病变 → ADH 缺乏
- **肾性**：肾脏对 ADH 敏感性缺陷 → V2 受体缺陷
- 表现：多尿、低渗尿、多饮

### SIADH
- ADH 过多 → 水潴留 → 低钠血症

### 临床相关药物
- **去氨加压素（Desmopressin）**：ADH 类似物，治疗中枢性尿崩症
- **ADH V2 拮抗剂（托伐普坦）**：治疗低钠血症
