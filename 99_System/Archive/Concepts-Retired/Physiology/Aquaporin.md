# Aquaporin

## Definition

水通道蛋白（Aquaporin, AQP）是介导水分子跨生物膜快速转运的整合膜蛋白。肾脏多种 AQP 分布于不同节段，决定水的通透性。

## Normal Mechanism

### 各 AQP 的分布（PPT p60, p64）
| AQP | 分布 |
|-----|------|
| **AQP1** | 近端小管 + 髓袢降支细段（**顶端膜 + 基底侧膜**） |
| **AQP2** | 集合管主细胞**顶端膜**（**ADH 诱导**） |
| **AQP3** | 集合管主细胞基底侧膜 |
| **AQP4** | 集合管主细胞基底侧膜 |

### 关键发现史（PPT p61-62）
- 1988 年发现 CHIP28（Channel-like integral membrane protein，28 kDa）
- 1991 年：将 AQP1 mRNA 显微注射入非洲爪蟾卵母细胞 → 低渗培养基中快速膨胀（对照无变化），证实水通道功能
- **2003 年诺贝尔化学奖**：Peter Agre（约翰·霍普金斯大学），表彰「发现水通道」

### ADH 调节（PPT p89-91）
- **ADH 通过 V2 受体** → 集合管主细胞 AQP2 表达/插入顶端膜 ↑ → **水通透性 ↑** → 集合管水重吸收 ↑ → 尿量 ↓
- 长时程调节：AQP2 转录增加；短时程调节：AQP2 囊泡向顶端膜插入

## Key Components / Steps

近端小管水重吸收：
- 经 AQP1 跨细胞途径 + 旁细胞途径
- 渗透压差驱动 → 等渗性重吸收

集合管水重吸收（ADH 依赖）：
- 顶端膜 AQP2（ADH 调节）
- 基底侧膜 AQP3/AQP4
- 髓质高渗梯度驱动 → 水出集合管 → 直小血管带走

## Physiological Significance

- 决定肾脏对水的处理能力
- AQP2 是尿浓缩的关键限速分子
- 是 ADH 调节水重吸收的分子基础

## Clinical Relevance

- **尿崩症**：
  - 中枢性：ADH 缺乏
  - 肾性：**V2 受体缺陷** 或 AQP2 异常 → 集合管对 ADH 不敏感
- **SIADH**：ADH 过多 → AQP2 ↑ → 水潴留 → 低钠血症
- **锂中毒**：锂抑制 AQP2 → 肾性尿崩症
- SGLT2 抑制剂等新型利尿剂不直接影响 AQP
