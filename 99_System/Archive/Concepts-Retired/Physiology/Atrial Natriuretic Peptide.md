# Atrial Natriuretic Peptide

## Definition

心房钠尿肽（Atrial natriuretic peptide, ANP）是由心房肌细胞分泌的肽类激素，主要作用是**促进钠、水排出**。

## Normal Mechanism

### 分泌刺激（PPT p107）
- 主要：**心房壁受牵拉**
  - 血量过多
  - 头低足高位
  - 中心静脉压升高
- 其他：Ach、NE、降钙素基因相关肽、ADH、高血钾

### 分泌部位：心房肌

### 作用（PPT p108）
1. **舒张入球小动脉** → FF ↑ → GFR ↑
2. **舒张球内系膜细胞** → Kf ↑ → GFR ↑
3. **抑制集合管 Na⁺ 重吸收** → (−) Na⁺ 通道
4. **抑制肾素、醛固酮、ADH 分泌**

→ 整体：**尿量 ↑、尿钠 ↑**

## Key Components / Steps

1. 心房牵拉 → ANP 释放
2. ANP 入血 → 作用靶点
3. 肾血流动力学 + 肾小管 + RAAS 抑制
4. 排钠利尿 → 血容量 ↓

## Physiological Significance

- 与 RAAS、ADH 共同调节血容量与钠平衡
- 在心房压升高时快速响应
- 与交感神经张力相互拮抗

## Clinical Relevance

- **心力衰竭**：ANP / NT-proBNP 升高作为诊断与预后标志物
- **治疗应用**：重组 ANP（卡培立肽）用于急性失代偿心衰
- **抗心衰药物**：ARNIs（如沙库巴曲/缬沙坦）部分通过增强利钠肽系统
