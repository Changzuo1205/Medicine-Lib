# Autoregulation of Renal Blood Flow

## Definition

肾血流量的自身调节（Autoregulation of renal blood flow）是指**在没有外来神经、体液影响的情况下，当动脉血压在一定范围内变动时，肾血流量能保持恒定的现象**。

**调节范围**：动脉血压 **70-180 mmHg**（PPT p29）。

## Normal Mechanism

### 机制 1：肌源学说（Myogenic theory）
动脉血压 ↑ → 入球小动脉**血管壁张力 ↑** → **牵张激活阳离子通道（+）** → 平滑肌收缩 → 入球小动脉阻力 ↑ → RBF 维持稳定。

信号通路（PPT p31）：
```
动脉血压 ↑
  ↓
血管壁张力 ↑
  ↓
牵张激活阳离子通道（+）
  ↓
血管平滑肌收缩
  ↓
电压依赖性钙通道 → Ca²⁺ 内流
  ↓
细胞膜去极化
  ↓
入球小动脉阻力 ↑
```

### 机制 2：管-球反馈学说（Tubuloglomerular feedback, TGF）
「小管液流量变化影响 RBF 和 GFR 的现象」。

两条通路（PPT p32）：
1. **入球通路**：致密斑感受到小管液 NaCl ↓ → Adenosine ↓，NO/前列腺素 ↑ → **入球小动脉阻力 ↓** → RBF ↑ → GFR ↑
2. **出球通路**：肾素 ↑ → 局部 Ang II ↑ → **出球小动脉阻力 ↑** → RBF 维持

> [!note] 整合逻辑
> 当动脉血压 ↓ 时，RBF ↓ → GFR ↓ → 远端小管液 NaCl ↓ → 致密斑感知 → 通过 TGF 调整入/出球阻力，恢复 RBF 与 GFR。

## Key Components / Steps

1. 感受：入球 A 压力变化 / 致密斑 NaCl 变化
2. 传导：平滑肌机械通道 / Adenosine-NO-PG 信号
3. 效应：入球 A 阻力变化（主）/ 出球 A 阻力变化（辅）
4. 结果：RBF 与 GFR 在 70-180 mmHg 范围内保持相对稳定

## Physiological Significance

- 维持 GFR 稳定 → 滤过-重吸收平衡
- 保证尿生成不因日常血压波动而大起大落
- 防止高灌注对肾小球的损伤

## Clinical Relevance

- **自身调节范围被突破**：高血压（>180 mmHg）→ RBF ↑ → 肾小球高滤过 → 损伤
- **自身调节失效**：休克/低血压（<70 mmHg）→ RBF ↓ → GFR ↓ → 急性肾损伤
- 慢性高血压：自身调节曲线右移 → 降压过快可致肾缺血
- ACEI / ARB 通过降低出球阻力（部分依赖 Ang II 的出球张力）→ 减少肾小球内高压
