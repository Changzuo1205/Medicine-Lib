# Filtration Fraction

## Definition

滤过分数（Filtration fraction, FF）是**肾小球滤过率与肾血浆流量的比值**。

## Normal Mechanism

### 计算
FF = GFR / RPF

### 正常值
- **FF = 0.19**（≈19%）
- 即约 19% 的肾血浆流量经滤过膜进入鲍曼囊

### 推导示例（PPT p38）
- RBF = 1200 ml/min；血细胞比容 = 45%
- RPF = 1200 × (1 − 0.45) = **660 ml/min**
- GFR = 125 ml/min
- FF = 125 / 660 = **0.19**

## Key Components / Steps

FF = GFR / RPF

### 临床病理性升高
- RPF ↓ 较 GFR ↓ 更显著时
- 例：高血压早期 / 肾动脉狭窄 → 入球 A 阻力 ↑ → GFR 维持、RPF ↓ → FF ↑

### 临床病理性降低
- GFR ↓ 较 RPF ↓ 更显著时
- 例：肾小球肾炎 → Kf ↓ → GFR ↓ → FF ↓

## Physiological Significance

- 反映「滤过效率」：单位血浆中被滤过的比例
- 临床用于评估滤过功能 vs 血流功能
- 与出球 A 阻力密切相关：出球 A 收缩 → RPF ↓ 较多、GFR 维持 → FF ↑

## Clinical Relevance

- ACEI / ARB：舒张出球 A → RPF ↑ → FF ↓ → 降低肾小球内高压（糖尿病肾病保护机制）
- 高血压性肾硬化：早期 FF ↑；晚期 FF ↓
