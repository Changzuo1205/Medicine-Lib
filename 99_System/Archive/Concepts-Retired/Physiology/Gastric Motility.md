# Gastric Motility

## Definition

胃的运动形式与胃排空及其调节，包括紧张性收缩、容受性舒张、蠕动、胃排空和消化间期移行性复合运动（MMC）。

## Main Forms of Gastric Motility

| 形式 | 特点 | 功能 |
|------|------|------|
| 紧张性收缩 Tonic contraction | 胃壁平滑肌经常处于一定程度的缓慢持续收缩状态 | 保持胃的形状和位置（防胃下垂）；维持胃内压，利于胃液渗入食团；是其他运动的基础 |
| 容受性舒张 Receptive relaxation | 进食时食物刺激口腔、咽、食管感受器，反射性引起胃底和胃体（以头区为主）舒张；vago-vagal 长反射（NO 或 VIP）；胃容积可从 50 mL 增至 1.5 L | 容纳食物而不明显升高胃内压 |
| 蠕动 Peristalsis | 频率约 3 次/min；受 BER（基本电节律）控制；迷走/Ach 促进，交感/NE 抑制 | 混合、研磨食物，推进食糜 |

## Gastric Emptying（胃排空）

- 定义：食物由胃排入十二指肠的过程
- 食物性质对排空的影响：流体 > 黏稠；小颗粒 > 大颗粒；等渗 > 高渗/低渗；糖类 > 蛋白质 > 脂肪；混合食物约需 4-6 h

### 控制机制

- **促进**（胃内因素）：食物机械扩张 → 迷走-迷走反射、壁内神经丛反射 → 胃蠕动↑、紧张性↑ → 胃内压↑；食物化学成分 → G 细胞促胃液素 → 促进排空
- **抑制**（十二指肠因素）：十二指肠机械扩张 → 肠-胃反射 → 胃蠕动↓；盐酸、脂肪、高渗食糜 → 肠抑胃素（Enterogastrones）→ 暂时停止排空；食糜在肠内吸收后抑制因素解除 → 再次排空

## Interdigestive Motility（MMC）

- 消化间期移行性复合运动（Migrating Motor Complex）：空腹状态下以间歇性强力收缩伴较长静息期为特征的周期性运动，从胃体上部向肠道方向传播
- 周期：90-120 min
- 功能：消化间期"胃肠清道夫"
- 调节：胃动素（Motilin）
