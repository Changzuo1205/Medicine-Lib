# Glomerular Filtration Membrane

## Definition

肾小球滤过膜（Glomerular filtration membrane）是血浆成分滤过形成原尿所通过的**三层结构**，总面积约 **1.5 m²**。

## Normal Mechanism

### 三层结构
1. **毛细血管内皮层（Capillary endothelium）**
   - 含窗孔（Fenestrae），直径 **70-90 nm**
   - 通透水与小分子溶质
2. **基膜（Basement membrane）**
   - 孔径 **2-8 nm**
   - 含胶原、层黏连蛋白、蛋白多糖（**带负电荷**）
3. **足细胞层（Podocyte cell layer）**
   - 足突之间形成裂孔（**4-11 nm**），覆有裂孔膜（slit diaphragm）
   - 含**裂孔素 nephrin**

### 双重屏障
- **机械屏障（Mechanical barrier）**
  - 有效半径 **r < 2.0 nm**：自由通透
  - r = 2.0 - 4.2 nm：通透性随半径增大而下降
  - r > 4.2 nm：基本不通透
- **电荷屏障（Electrical barrier）**
  - 带正电荷物质：易通透
  - 带负电荷物质：难以通透（基膜负电荷排斥血浆白蛋白等负电荷蛋白）

### 电荷对滤过的影响
右旋糖酐实验显示（PPT p20）：相同分子半径下，**阳离子型 > 中性 > 阴离子型**的滤过率。

### 球内系膜细胞
- 收缩 → 调节滤过膜面积与肾小球滤过系数 Kf

## Key Components / Steps

1. 血浆经入球小动脉进入肾小球毛细血管
2. 三层膜选择性滤过 → 形成超滤液/原尿
3. 滤液进入鲍曼囊 → 近端小管

## Physiological Significance

- 决定 GFR 的「质」（成分）与「量」
- 保留血浆蛋白与血细胞，选择性滤过小分子
- 电荷屏障解释了正常情况下尿中几乎无蛋白

## Clinical Relevance

- **肾小球肾炎**：足细胞损伤（nephrin 异常）→ 蛋白尿
- **糖尿病肾病**：基膜负电荷减少 → 白蛋白尿
- **微小病变**：足突融合 → 选择性蛋白尿
- 球内系膜细胞收缩/舒张 → 影响 Kf → 改变 GFR
