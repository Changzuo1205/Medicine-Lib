# Glomerular Filtration Rate

## Definition

肾小球滤过率（Glomerular filtration rate, GFR）是**单位时间内（每分钟）两肾生成的超滤液量**。正常成人 ≈ **125 ml/min**；按 24h 计 ≈ **180 L**。

## Normal Mechanism

### 影响因素
- 体表面积（男性 > 女性）
- 运动、情绪激动、饮食、年龄、妊娠、昼夜节律

### 测定原理
菊粉（inulin）清除率 = GFR
- 菊粉可被自由滤过，且不被重吸收、不被分泌
- C_inulin = U_inulin × V / P_inulin = GFR = 125 ml/min（PPT p116）

### GFR = Kf × Pf
- Kf：滤过系数（通透系数 × 滤过面积）
- Pf：有效滤过压

### RPF 对 GFR 的影响
- RPF ↑ → 滤过平衡出现越晚 → GFR ↑
- RPF ↓ → 滤过平衡出现较早 → GFR ↓

## Key Components / Steps

1. 入球 A 阻力（主要）调节肾小球血流量与血压
2. 出球 A 阻力（次要）调节毛细血管内压
3. 滤过膜通透性与面积
4. 有效滤过压沿毛细血管的变化（血浆胶体渗透压递增）

## Physiological Significance

- GFR 是评估肾功能的核心指标
- 临床 eGFR 估算（基于肌酐）即源于 GFR 概念
- 与 FF（RPF）共同决定滤过效率

## Clinical Relevance

- GFR 持续 ↓ 是慢性肾病（CKD）分期的依据
- 急性肾损伤时 GFR 急剧 ↓ → 少尿 / 无尿 / 氮质血症
- ACEI / ARB：在糖尿病肾病中降低肾小球内高压 → 减轻高滤过损伤
