# Glomerular Filtration

## Definition

肾小球滤过（Glomerular filtration）是血浆经肾小球滤过膜进入鲍曼囊形成超滤液（原尿）的过程，是尿生成的第一步。

## Normal Mechanism

### 原尿 / 超滤液
- 又称 Ultrafiltrate / Primary urine
- 特征：**无细胞**，除血浆蛋白外成分接近血浆
- 流量：**125 ml/min**（两肾）；24h 共 **180 L**；终尿仅 ≈1.5 L → **99% 被重吸收**

### 成分比较（PPT p36，per 100 ml）
| 成分 | 血浆(g) | 原尿(g) | 终尿(g) |
|------|---------|---------|---------|
| 水 | 90-93 | 99 | 95-97 |
| 蛋白 | 7-9 | （痕量） | — |
| 葡萄糖 | 0.1 | 0.1 | — |
| 尿素 | 0.03 | 0.03 | 2 |
| 尿酸 | 0.002 | 0.002 | 0.005 |
| 肌酐 | 0.001 | 0.001 | 0.15 |
| 氯 | 0.37 | 0.37 | 0.6 |
| 钠 | 0.32 | 0.32 | 0.35 |
| 钾 | 0.02 | 0.02 | 0.15 |

### 影响因素：GFR = Kf × Pf
- **Kf（滤过系数）**：单位 EFP 下单位时间经滤过膜的滤液量
  - Kf = 有效通透系数 k × 滤过面积 s
  - 球内系膜细胞收缩可调节滤过面积
- **Pf（有效滤过压 EFP）**

## Key Components / Steps

1. 血浆经入球小动脉进入肾小球毛细血管（高压）
2. 经滤过膜三层选择性滤过
3. 超滤液进入鲍曼囊 → 近端小管
4. 出球端因水滤过 → 血浆胶体渗透压 ↑ → 滤过停止（**滤过平衡**）

## Physiological Significance

- 启动尿生成；提供大量原尿供下游选择性重吸收
- 滤过平衡的出现位置决定 GFR 大小：RPF 越高，滤过平衡出现越晚，GFR 越大
- 与球-管平衡共同决定尿量与尿成分

## Clinical Relevance

- **大失血**：血压 ↓ → 肾小球毛细血管血压 ↓ → GFR ↓ → 急性肾衰
- **结石/肿瘤压迫**：囊内压 ↑ → EFP ↓ → GFR ↓
- **快速输 NS / 低蛋白血症**：血浆胶体渗透压 ↓ → EFP ↑ → GFR ↑
- **肾炎**：滤过膜损伤 → 蛋白尿 / 血尿；Kf ↓ → GFR ↓
