# Glomerulotubular Balance

## Definition

球-管平衡（Glomerulotubular balance）是指**不论肾小球滤过率增加或减少，近端小管中水和 Na⁺ 的重吸收率总是占肾小球滤过率的 65-70%** 的现象，又称定比重吸收。

## Normal Mechanism

### 现象
- 近端小管 Na⁺ 和 H₂O 重吸收率 = GFR × 65-70%（恒定比例）

### 机制（PPT p80）
当 GFR 变化时，通过管周毛细血管的物理因素改变而调节重吸收：

```
肾血流量不变，GFR ↑
  ↓
流至管周毛细血管的血量 ↓
  ↓
管周毛细血管血压 ↓
  +
血浆胶体渗透压 ↑
  ↓
Na⁺ 和 H₂O 重吸收 ↑
```

反之亦然。

## Key Components / Steps

1. GFR 变化 → 滤过后血浆蛋白浓度变化
2. 血浆胶体渗透压沿管周毛细血管变化
3. 管周毛细血管血压变化
4. 跨上皮重吸收驱动力变化 → 定比重吸收

## Physiological Significance

- **意义（PPT p79）**：使尿中排出的溶质和水**不致因 GFR 的增减而出现大幅度的变化**
- 与肾血流自身调节一起，保证尿生成相对稳定
- 防止 GFR 波动时尿量/尿钠剧烈波动

## Clinical Relevance

- 当 GFR 显著改变时，球-管平衡保护机体不出现过度失水/失钠
- 病理情况下（如充血性心衰、有效循环血量 ↓）→ 球-管平衡参与钠水潴留
- 与渗透性利尿（破坏球-管平衡）相对应
