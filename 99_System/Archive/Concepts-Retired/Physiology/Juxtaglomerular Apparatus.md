# Juxtaglomerular Apparatus

## Definition

球旁器（Juxtaglomerular apparatus, JGA）是位于**远曲小管起始部贴附于入球与出球小动脉**处的特化结构，由三类细胞组成，是肾素分泌与管-球反馈的解剖基础。

## Normal Mechanism

### 三类细胞
1. **球旁细胞 / 颗粒细胞（Juxtaglomerular cells / Granule cells）**
   - 位于入球小动脉壁
   - 含分泌颗粒
   - 合成与释放**肾素（Renin）**
2. **致密斑（Macula densa）**
   - 远曲小管起始部管壁的上皮细胞特化
   - **感受小管液 NaCl 浓度**（管-球反馈的感受器）
3. **球外系膜细胞（Extraglomerular mesangial cells）**
   - 位于入/出球小动脉与致密斑之间的三角区
   - 功能：吞噬、收缩；可能参与信号传递

### 解剖关系
远曲小管起始部「贴（kiss）」于入球与出球小动脉 → 三类细胞在该区域形成功能单位。

## Key Components / Steps

1. 入球小动脉血压 ↓ → 牵张刺激 ↓ → 球旁细胞释放肾素 ↑
2. 致密斑感受小管液 NaCl ↓ → 信号传递 → 球旁细胞释放肾素 ↑
3. 肾素 → 血管紧张素原 → AT I → ACE → AT II → 全身与局部效应

## Physiological Significance

- **肾素-血管紧张素-醛固酮系统（RAAS）的关键启动结构**
- **管-球反馈（TGF）的核心**：致密斑感知远端 NaCl → 反馈调节入球/出球阻力 → 维持 GFR 稳定
- 是神经-体液调节与肾脏自身调节的整合点

## Clinical Relevance

- **Bartter 综合征**：髓袢升支粗段 / 球旁器功能异常 → 继发性 RAAS 激活 → 类似袢利尿剂效应
- ACE 抑制剂 / ARB 的肾脏作用位点之一
- 球旁细胞肿瘤（肾素瘤）→ 高肾素 → 高血压
