# Nephron

## Definition

肾单位（Nephron）是肾脏生成尿液的**基本功能单位**，由肾小体（Renal corpuscle）和肾小管（Renal tubule）组成。

- 肾小体 = 肾小球（Glomerulus，毛细血管球）+ 肾小囊（Bowman`s capsule）
- 肾小管 = 近端小管（Proximal tubule）+ 髓袢（Loop of Henle）+ 远端小管（Distal tubule）

## Normal Mechanism

### 数量与寿命
- 每个肾约 80–100 万个肾单位
- **40 岁后每十年功能性肾单位减少 10%**（PPT p6）

### 解剖分段
- **近端小管**：近曲小管 + 髓袢降支粗段
- **髓袢细段**：降支细段 + 升支细段
- **远端小管**：髓袢升支粗段 + 远曲小管

### 两类肾单位
| 特征 | 皮质肾单位 Cortical nephron | 近髓肾单位 Juxtamedullary nephron |
|------|---------------------------|-----------------------------------|
| 分布 | 外、中皮质层（皮质外 2/3） | 内皮质层（皮质层靠近髓质） |
| 数量 | **85-90%** | **10-15%** |
| 肾小球 | 体积小 | 体积大 |
| 入球口径 | 大于出球（PPT 表述） | 无差异（PPT 表述） |
| 髓袢 | 短 | **长，可深入内髓质层** |
| 直小血管 | 无 | 形成细、直而长的 U 形血管（直小血管） |
| 功能 | 滤过 + 重吸收 | 重吸收 + **浓缩与稀释** |

## Key Components / Steps

1. 入球小动脉 → 肾小球毛细血管网（高压，利于滤过）
2. 滤过 → 鲍曼囊 → 近端小管（等渗性重吸收 65-70%）
3. 髓袢（升支粗段 Na⁺-K⁺-2Cl⁻ 主动重吸收，建立髓质高渗）
4. 远曲小管（Na⁺-Cl⁻ 同向转运）
5. 集合管（受 ADH/醛固酮调节）

## Physiological Significance

- 肾单位是肾泌尿功能的结构与功能基础
- 两类肾单位的差异决定了**皮质以滤过-重吸收为主、近髓参与尿液浓缩稀释**
- 不可再生：随年龄/损伤丢失后无法新生，故肾脏储备能力随年龄下降

## Clinical Relevance

- 肾单位丢失 → 残存肾单位代偿性高滤过 → 长期加速肾损伤
- 急性肾损伤、慢性肾病的病理生理均围绕"功能性肾单位减少"
- 利尿剂作用位点均位于肾单位不同节段（呋塞米-髓袢升支粗；噻嗪-远曲；阿米洛利-集合管）
