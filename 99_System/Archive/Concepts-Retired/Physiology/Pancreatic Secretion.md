# Pancreatic Secretion

## Definition

胰液的性质、成分及其分泌调节。胰液是消化最全面、消化力最强的一种消化液；pH 7.8-8.4，等渗液体，分泌量 1-2 L/day。

## Components

| 成分 | 分泌细胞 | 功能 |
|------|----------|------|
| HCO₃⁻ | 胰腺导管细胞 | 保护小肠上段免受 HCl 侵蚀；提供胰酶最适 pH |
| 胰淀粉酶 | 腺泡细胞 | 分解糖类为二糖/三糖（α1,4 糖苷键；最适 pH 6.7-7.0） |
| 胰脂肪酶 | 腺泡细胞 | 三酰甘油 → 一酰甘油 + 脂肪酸 |
| 磷脂酶 A2 | 腺泡细胞 | 卵磷脂 → 溶血卵磷脂 |
| 胆固醇酯酶 | 腺泡细胞 | 胆固醇酯 → 胆固醇 + 脂肪酸 |
| 蛋白水解酶（酶原） | 腺泡细胞 | 胰蛋白酶原 →（肠激酶）→ 胰蛋白酶 → 激活糜蛋白酶原、羧基肽酶等；核糖核酸酶、脱氧核糖核酸酶 |

- 蛋白水解酶以酶原形式分泌，肠激酶启动激活级联（胰蛋白酶原 → 胰蛋白酶 → 激活其他酶原）
- **分泌障碍主要影响蛋白质和脂肪的消化**（淀粉酶活性相对较强）

## Regulation

### 神经调节

- 条件与非条件反射；迷走神经是主要反射神经（作用于腺泡细胞）

### 体液调节

| 激素 | 来源 | 主要刺激 | 作用 |
|------|------|----------|------|
| Secretin 促胰液素 | S 细胞（小肠上段） | HCl（主要，pH 4.5）、蛋白与脂肪产物 | 促 H₂O 与 HCO₃⁻ 分泌（水样分泌，cAMP）；抑制胃泌素与胃酸 |
| CCK 缩胆囊素 | I 细胞（小肠上段） | 蛋白（主要）、脂肪产物、HCl | 促胰消化酶分泌（Ca²⁺）；促胆囊收缩与 Oddi 括约肌舒张；促外分泌胰腺生长（tropic） |
| Gastrin、VIP | — | — | 辅助促胰液分泌 |
