# Renal Blood Flow

## Definition

肾血流量（Renal blood flow, RBF）是单位时间内流经双肾的血流量。正常成人安静时约 **1200 ml/min**（约占心输出量的 20-25%）。

## Normal Mechanism

### 血流通路
```
肾动脉 → 叶间动脉 → 弓状动脉 → 小叶间动脉
  → 入球小动脉 → 肾小球毛细血管网 → 出球小动脉
  → 肾小管周围毛细血管网 + 直小血管
  → 小叶间静脉 → 弓状静脉 → 叶间静脉 → 肾静脉
```

### 两套串联毛细血管网（PPT p24）
1. **肾小球毛细血管网**：高压（毛细血管血压高），利于滤过
2. **肾小管周围毛细血管网 + 直小血管**：低压，利于重吸收

### 沿程血压变化（PPT p25）
```
renal artery (≈100) → afferent arteriole → glomerular capillary (≈45-50)
→ efferent arteriole → peritubular capillary (低) → renal vein
```

### 分布不均（PPT p27）
| 部位 | 比例 |
|------|------|
| 皮质 | **94%** |
| 外髓 | 5% |
| 内髓 | **1%** |

### 神经支配
- **无副交感神经支配**
- 交感（T12-L2）→ 节后纤维 → 入/出球小动脉平滑肌、肾小管、颗粒细胞
- NE → 调节 RBF、GFR、肾小管重吸收、肾素释放

## Key Components / Steps

1. 高血流量为肾小球滤过提供充足的原料
2. 串联毛细血管设计：先滤过后重吸收
3. 皮髓质分布差异：皮质血流多（滤过-重吸收），髓质血流少（浓缩稀释需要稳定的髓质梯度）

## Physiological Significance

- 高 RBF 保证大量血浆被滤过（每日 ≈ 180 L 原尿）
- 直小血管维持髓质渗透梯度 → 浓缩稀释能力
- RBF 是肾脏三大调节（自身调节、神经调节、体液调节）的共同作用对象

## Clinical Relevance

- **大失血** → RBF ↓ → GFR ↓ → 急性肾衰
- **休克** → 交感强烈兴奋 → 入球 A 收缩 → GFR ↓
- **高血压**：RBF 自身调节范围被突破
- **ACEI / ARB**：舒张出球 A → 降低肾小球内高压 → 减缓糖尿病肾病进展
