# Renal Clearance

## Definition

肾清除率（Clearance Rate, Cₓ）是**单位时间（每分钟）内两肾能将一定毫升血浆中所含的某一物质完全清除出去**，这个能完全清除某物质的血浆毫升数即为该物质的清除率。单位：ml/min。

## Normal Mechanism

### 公式（PPT p113）
```
Cₓ = Uₓ × V / Pₓ
```
- Cₓ：肾清除率（ml/min）
- Pₓ：血浆中该物质的浓度（mg/dl）
- Uₓ：尿中该物质的浓度（mg/dl）
- V：每分钟尿量（ml/min）

### 反映意义
每分钟内所清除的某种物质的量来自多少毫升血浆，或相当于多少毫升血浆中所含的该物质的量。

### 排泄量 = 滤过量 − 重吸收量 + 分泌量
```
Uₓ × V = GFR × Pₓ − R + S
```

### 不同物质的清除率（PPT p110, p114-116）

| 物质 | 处理特点 | C |
|------|---------|---|
| **菊粉 (Inulin)** | 自由滤过，不被重吸收 / 分泌 | **= GFR = 125 ml/min** |
| **葡萄糖** | 全部被重吸收（正常血糖下） | **= 0** |
| 内生肌酐 | 接近 GFR（少量分泌） | 略 > GFR |
| PAH | 滤过 + 大量分泌 | ≈ RPF（660 ml/min） |
| 碘锐特 | 类似 PAH | ≈ RPF |

### 测定 GFR 的物质条件（PPT p115）
1. 能被肾小球自由滤过
2. 不被肾小管重吸收
3. 不被肾小管分泌

→ 菊粉满足全部条件 → 菊粉清除率 = GFR

## Key Components / Steps

1. 测量尿流速 V、尿浓度 Uₓ、血浆浓度 Pₓ
2. 应用公式 Cₓ = Uₓ × V / Pₓ
3. 选择合适物质 → 推断 GFR / RPF / 重吸收 / 分泌

## Physiological Significance

- 提供「肾处理某物质」的定量描述
- 是测定 GFR / RPF / FF 的方法学基础
- 临床上 eGFR 估算公式即源于此原理

## Clinical Relevance

- **临床 eGFR**：基于肌酐的估算公式（CKD-EPI、MDRD）
- **内生肌酐清除率**：经典肾功能测定方法
- **PAH 清除率**：用于测定 RPF（科研）
