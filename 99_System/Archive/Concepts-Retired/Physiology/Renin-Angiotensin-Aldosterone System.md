# Renin-Angiotensin-Aldosterone System

## Definition

肾素-血管紧张素-醛固酮系统（Renin-Angiotensin-Aldosterone System, RAAS）是调节**血压、血容量与水电解质平衡**的核心神经-体液系统。

## Normal Mechanism

### 级联通路（PPT p99）
```
血管紧张素原 (Angiotensinogen, 肝)
        ↓ 肾素 (Renin, 颗粒细胞)
血管紧张素 I (AT I)
        ↓ ACE (血管紧张素转换酶，肺/血浆)
血管紧张素 II (AT II)
        ↓
血管紧张素 III (AT III)
```

### 肾素释放的调节（PPT p100-101）

#### 1. 肾内机制（自身调节）
- 入球小动脉血压 ↓ → 牵张感受器受牵张程度 ↓
- GFR ↓ → 到达致密斑的 NaCl ↓
- → 肾素分泌 ↑

#### 2. 神经机制
- 肾交感神经 → β 受体（+）→ 肾素 ↑

#### 3. 体液机制
- **促进**：E、NE、PGE2、PGI2
- **抑制**：AT II、ADH、ANP、NO、内皮素

### Ang II 的作用（PPT p102-103）

#### 血流动力学
- **强缩血管** → RBF ↓
- **GFR 影响**：
  - **低浓度**：出球收缩 >> 入球收缩 → GFR 变化不大
  - **高浓度**：入球也强烈收缩 + Kf ↓ → GFR ↓
- **入球局部反馈**：Ang II → PGI2 / NO 释放 → 入球局部舒张（保护）

#### 肾小管作用
- 促进近端小管 NaCl 重吸收（近端小管上皮细胞有 AT II 受体）

### 醛固酮（Aldosterone，PPT p104-105）

#### 来源
- 肾上腺皮质**球状带（Zona glomerulosa）**

#### 作用
- **保 Na⁺ 排 K⁺**（集合管 + 远曲小管）
- 同时促进 Cl⁻ 重吸收

#### 机制
- 进入主细胞 → 与胞内受体结合 → 转录产生**醛固酮诱导蛋白** →
  1. 增加基底侧膜 Na⁺ 泵数量
  2. 增加顶端膜 Na⁺ 通道
  3. 增加线粒体 ATPase
- → Na⁺ 重吸收 ↑ → K⁺ 分泌 ↑（负电荷驱动）

## Key Components / Steps

1. 有效循环血量 ↓ / 血压 ↓ → 肾素释放 ↑
2. RAAS 激活 → Ang II ↑、醛固酮 ↑
3. Ang II 收缩血管 + 促进近端 NaCl 重吸收
4. 醛固酮保 Na⁺ 排 K⁺
5. 血容量与血压回升；K⁺ 排出 ↑

## Physiological Significance

- 维持血压与血容量
- 调节 Na⁺/K⁺ 平衡
- 在低血容量（失血、脱水、Na⁺ 缺失）时尤其关键
- 与交感、ADH 协同

## Clinical Relevance

### 高血压治疗靶点
- **ACEI**（如卡托普利）：抑制 ACE → AT II ↓
- **ARB**（如氯沙坦）：阻断 AT1-R
- **醛固酮拮抗剂**（如螺内酯）：保钾利尿、抗心衰

### 心力衰竭
- RAAS 过度激活 → 钠水潴留、心脏前负荷 ↑
- ACEI/ARB 是基础治疗

### 原发性醛固酮增多症
- 醛固酮自主分泌 → 高血压 + 低血钾

### 肾血管性高血压
- 肾动脉狭窄 → 肾灌注 ↓ → 肾素 ↑ → 高血压
