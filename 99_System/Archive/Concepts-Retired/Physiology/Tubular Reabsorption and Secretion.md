# Tubular Reabsorption and Secretion

## Definition

- **重吸收（Reabsorption）**：物质从小管液转运至血液的过程。
- **分泌（Secretion）**：物质跨肾小管上皮向小管液转运（方向与重吸收相反）的过程。

**肾排泄** = 滤过但未被重吸收的物质 + 肾小管分泌的物质（PPT p47）。

## Normal Mechanism

### 转运途径
- **跨细胞途径（Transcellular route）**
  - 经管腔膜（Luminal / apical membrane）
  - 经基底侧膜（Basolateral membrane）
- **旁细胞途径（Paracellular route）**
  - 经紧密连接（Tight junction）
  - 经细胞间隙（Intercellular space）

### 转运方式（PPT p49）
1. **被动转运（Passive transport）**
   - 单纯扩散（simple diffusion）
   - 易化扩散（facilitated diffusion）
2. **主动转运（Active transport）**
   - 原发性主动转运：Na⁺-K⁺ 泵（ATP 驱动）
   - 继发性主动转运：Na⁺-同向转运体（symporter）；Na⁺-反向转运体（antiporter）
3. **入胞（Endocytosis）**

### Na⁺/Cl⁻/H₂O 重吸收的节段分布（PPT p51）
| 节段 | NaCl | H₂O | 关键机制 / 利尿剂位点 |
|------|------|-----|---------------------|
| 近端小管 | **65-70%** | **65-70%** | Na⁺-H⁺ 交换、Na⁺-葡萄糖/AA 同向、Cl⁻-HCO3⁻ 交换；等渗性重吸收 |
| 髓袢降支细 | 0 | 通透 | H₂O 出 |
| 髓袢升支细 | 通透 | 0 | Na⁺ 被动易化扩散 |
| 髓袢升支粗 | **20%** | 0 | Na⁺-K⁺-2Cl⁻ 同向转运 → **呋塞米（速尿）** |
| 远曲小管 | 12% | 0 | Na⁺-Cl⁻ 同向转运 → **噻嗪类** |
| 集合管 | (Na⁺ 通道) | ADH 调节 | Na⁺ 通道 → **阿米洛利**；负电荷驱使 K⁺ 分泌 / Cl⁻ 重吸收 |

### HCO3⁻ 重吸收与 H⁺ 分泌（PPT p65-67）
- **近端小管重吸收 80% HCO3⁻**，**以 CO₂ 形式进行，优先于 Cl⁻ 重吸收**
- 近端小管是 H⁺ 分泌主要部位（Na⁺-H⁺ 交换为主）
- 髓袢升支粗段亦重吸收 HCO3⁻
- A 型闰细胞：顶端膜 H⁺-ATPase（与 K⁺-ATPase 交换）
- **乙酰唑胺**：碳酸酐酶抑制剂

### NH3/NH4⁺ 分泌（PPT p68-69）
- 近端小管：谷氨酰胺 → 谷氨酸 → α-酮戊二酸 + NH4⁺
- NH4⁺ 经 Na⁺-H⁺（NH4⁺）antiporter 分泌
- 集合管：NH3 高度通透（脂溶性）、NH4⁺ 通透性差
- **肾分泌的 H⁺ 约 50% 由 NH3 缓冲**

### 葡萄糖与氨基酸（PPT p70-73）
- 仅在近端小管（尤其前半段）
- 管腔膜：与 Na⁺ 偶联的**继发性主动转运**
- 基底侧膜：**GLUT2** 易化扩散
- **肾糖阈**：180 mg/100ml
- **葡萄糖 Tm**：300 mg/100ml（男 375 mg/min、女 300 mg/min）

### Ca²⁺ 重吸收（PPT p74-75）
- 近端小管 70%（旁细胞 80%，溶剂拖曳；跨细胞 20%）
- 髓袢升支粗段 20%
- 远曲 + 集合管 9%（跨细胞为主）
- 终尿排出 1%

## Key Components / Steps

1. 滤液进入近端小管 → 等渗性重吸收 65-70%
2. 髓袢建立髓质高渗梯度（升支粗段 NaCl 主动重吸收）
3. 远曲 + 集合管：神经-体液精细调节（醛固酮、ADH、ANP）
4. 终尿排出

## Physiological Significance

- 决定尿的成分与渗透压
- 通过选择性重吸收保留必需物质（水、Na⁺、葡萄糖、AA、HCO3⁻）
- 通过分泌排出代谢废物与外源物质
- 是神经-体液调节尿生成的主要靶点

## Clinical Relevance

- **渗透性利尿**：糖尿病多尿（葡萄糖不完全重吸收）；甘露醇用于脑水肿、青光眼
- **利尿剂作用位点**（参见上表）
- **碳酸酐酶抑制剂**（乙酰唑胺）：青光眼、代谢性碱中毒、高山病
- **肾性糖尿**：近端小管葡萄糖重吸收障碍（SGLT2 突变 / 药物）
- **肾小管酸中毒**：H⁺ 分泌 / HCO3⁻ 重吸收障碍
