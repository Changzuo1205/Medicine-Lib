## Key Points

> [!note] AI 整理（基于 PPT 讲授内容搬运）
>
> **肾脏四大功能**（p2）
> - 排出代谢废物与外来物质
> - 调节水、电解质平衡
> - 维持酸碱平衡
> - 分泌激素：肾素、促红素、1,25-(OH)₂-D₃
>
> **肾单位（p6-12）**
> - 基本功能单位；40 岁后每十年功能性肾单位减少 10%；每肾 80-100 万
> - = 肾小体（肾小球 + 肾小囊）+ 肾小管（近端小管 + 髓袢 + 远端小管）
> - 两类：皮质肾单位（85-90%，外/中皮质层，髓袢短）vs 近髓肾单位（10-15%，内皮质层，髓袢长深入内髓）
>
> **球旁器 JGA（p13-14）**
> - 球旁细胞（颗粒细胞）→ 肾素
> - 致密斑 → 感受小管液 NaCl
> - 球外系膜细胞 → 吞噬/收缩
>
> **滤过膜三层（p15-20）**
> - 毛细血管内皮、基膜、足细胞层；总面积 1.5 m²
> - 机械屏障：r<2 nm 通透；2-4.2 nm 部分通透；>4.2 nm 不通透
> - 电屏障：正电荷易通透，负电荷难通透（基膜含胶原、层黏连蛋白、蛋白多糖带负电）
>
> **肾血流特点（p25-27）**
> - 1200 ml/min；两套串联毛细血管（肾小球毛细血管 + 肾小管周围毛细血管）
> - 分布不均：皮质 94%、外髓 5%、内髓 1%
>
> **肾血流自身调节（p29-32）**
> - 70-180 mmHg 范围内血压变化，RBF 保持恒定
> - 机制：肌源学说（牵张激活阳离子通道 → 平滑肌收缩）+ 管-球反馈（小管液 NaCl 变化反馈入球/出球阻力）
>
> **GFR / FF（p37-38）**
> - GFR：单位时间（每分）两肾超滤液量，正常 125 ml/min；24h 共 180 L
> - FF = GFR/RPF = 0.19（≈19%）
> - 受体表面积、性别、年龄、昼夜节律等影响
>
> **有效滤过压 EFP（p39-41）**
> - =（肾小球毛细血管血压 + 囊内液胶体渗透压）−（血浆胶体渗透压 + 肾小囊内压）
> - 入球端 ≈ 10 mmHg（45 − 25 − 10）；出球端 ≈ 0 mmHg（滤过平衡）
> - 血浆胶体渗透压沿毛细血管逐渐升高，是 EFP 变化的主要因素
>
> **影响 GFR 的因素（p42-44）**
> - GFR = Kf × Pf
> - Kf：滤过系数 = 有效通透系数 × 滤过面积（系膜细胞收缩可调节；肾炎 → 蛋白尿、血尿）
> - Pf：①毛细血管血压（大失血时下降）②囊内压（结石/肿瘤）③血浆胶体渗透压（肝硬化/快速输 NS）
> - RPF 越高，毛细血管滤过段越长
>
> **肾小管重吸收/分泌（p46-49）**
> - 重吸收 = 小管液 → 血液；分泌 = 反方向
> - 肾排泄 = 滤过但未被重吸收 + 肾小管分泌
> - 跨细胞途径（管腔膜 + 基底侧膜）/ 旁细胞途径（紧密连接、细胞间隙）
> - 被动转运（单纯/易化扩散）/ 主动转运（原发 Na⁺-K⁺ 泵；继发 Na⁺ 同向/反向转运）/ 入胞
>
> **Na⁺/Cl⁻/H₂O 重吸收分布（p51）**
> - 近端小管：65-70% NaCl + 水
> - 髓袢：20% NaCl + 15% H₂O
> - 远曲 + 集合管：12% NaCl（醛固酮调节）、水（ADH 不等量调节）
>
> **近端小管重吸收机制（p52-54）**
> - 前半段：基底侧膜 Na⁺ 泵 + 顶端膜 Na⁺-H⁺ 交换体 / Na⁺-葡萄糖/AA 同向转运体；HCO3⁻ 优先重吸收（以 CO₂ 形式）
> - 后半段：Na⁺-H⁺ 交换 + Cl⁻-HCO3⁻ 交换；Cl⁻ 经旁细胞途径被动重吸收；H₂O 经 AQP1 旁细胞/跨细胞渗透
> - 近端小管：等渗性重吸收
>
> **髓袢重吸收（p55-56）**
> - 降支细段：Na⁺ 不通透、H₂O 通透
> - 升支细段：Na⁺ 通透（被动易化扩散）、H₂O 不通透
> - 升支粗段：基底侧膜 Na⁺ 泵 + 顶端膜 Na⁺-K⁺-2Cl⁻ 同向转运体 + 基底侧 Cl⁻ 通道 + 顶端 K⁺ 通道；正电荷驱使 Na⁺/K⁺/Ca²⁺/Mg²⁺ 经旁细胞途径；H₂O 不通透 → **呋塞米（速尿）作用位点**
>
> **远曲小管（p57）**
> - 顶端膜 Na⁺-Cl⁻ 同向转运体 → **噻嗪类利尿剂作用位点**
> - 对 H₂O 不通透
>
> **集合管（p59）**
> - 顶端膜 Na⁺ 通道 → **阿米洛利**作用位点
> - 负电荷驱使 K⁺ 分泌、Cl⁻ 重吸收
>
> **水通道蛋白 AQP（p60-64）**
> - AQP1：近端小管 + 髓袢降支细段（顶端膜 + 基底膜）
> - AQP2：集合管主细胞顶端膜（**ADH 诱导**）
> - AQP3/4：集合管基底侧膜
> - 2003 Nobel Chemistry：Peter Agre（发现水通道）
>
> **HCO3⁻ 重吸收与 H⁺ 分泌（p65-67）**
> - 近端小管重吸收 80% HCO3⁻（以 CO₂ 形式，优先于 Cl⁻）
> - 近端小管是 H⁺ 分泌主要部位（Na⁺-H⁺ 交换为主）
> - 髓袢升支粗段亦可重吸收 HCO3⁻
> - H⁺-ATPase 在 A 型闰细胞顶端膜（与 K⁺-ATPase 交换）
> - **乙酰唑胺**：碳酸酐酶抑制剂
>
> **NH3/NH4⁺ 分泌（p68-69）**
> - 近端小管：谷氨酰胺 → NH4⁺ + α-酮戊二酸；NH4⁺ 经 Na⁺-H⁺ antiporter 分泌
> - 集合管：NH3 高度通透（脂溶性）、NH4⁺ 通透性差
> - 肾分泌的 H⁺ ≈50% 由 NH3 缓冲
>
> **葡萄糖与 AA 重吸收（p70-73）**
> - 仅在近端小管（尤其前半段）；继发性主动转运
> - 基底侧膜：GLUT2 易化扩散
> - **肾糖阈**：180 mg/100ml（尿中刚出现葡萄糖时的血糖浓度）
> - **葡萄糖最大转运率 Tm**：300 mg/100ml 时全部肾小管达极限
> - 男 375 mg/min、女 300 mg/min
>
> **Ca²⁺ 重吸收（p74-75）**
> - 近端小管 70%（旁细胞途径为主，溶剂拖曳）
> - 髓袢升支粗段 20%
> - 远曲 + 集合管 9%（主要跨细胞途径）
> - 1% 随尿排出
>
> **球-管平衡（p76-80）**
> - 定比重吸收：不论 GFR 如何变化，近端小管 Na⁺/H₂O 重吸收率总占 GFR 的 65-70%
> - 机制：GFR ↑ → 流至管周毛细血管血量 ↓ → 管周毛细血管血压 ↓、血浆胶体渗透压 ↑ → 重吸收 ↑
> - 意义：使尿中排出的溶质和水不致因 GFR 增减而大幅变化
>
> **渗透性利尿（p77-78）**
> - 小管液中溶质浓度 ↑ → 渗透压 ↑ → 水重吸收 ↓ → 尿量 ↑
> - 临床：糖尿病多尿（葡萄糖未被完全重吸收）；甘露醇（脑水肿、青光眼）
>
> **尿液浓缩与稀释（p81-82）**
> - 与血浆渗透压比较而言
> - 正常人尿液渗透压 50-1200 mOsm/(kg·H₂O)
> - **PPT 内容严重不足，需补教科书**
>
> **神经调节（p84-85）**
> - 肾交感神经：α-R（Afferent >> Efferent 收缩 → GFR ↓、Na⁺/Cl⁻/H₂O 重吸收 ↑）；β-R（颗粒细胞 → 肾素 → Ang II ↑ → 醛固酮 ↑ → 尿量 ↓）
>
> **ADH / AVP（p87-98）**
> - 合成：下丘脑 SON + PVN → 神经垂体贮存/释放
> - 受体：V1 / V2
> - V2 → 集合管主细胞 AQP2 ↑ → 水通透性 ↑ → 尿量 ↓
> - 调节因素：
>   - 血浆晶体渗透压（最重要，1-2% 变化即起效；NaCl 最有效，尿素/葡萄糖无效）
>   - 循环血量（5-10% 变化；不如渗透压敏感）
>   - 其他：疼痛、恶心、烟碱、吗啡、Ang II ↑；酒精 ↓
> - 水利尿：大量饮水 → ECF 稀释 → ADH ↓ → 尿量 ↑；30 min 起，60 min 达峰
> - **尿崩症**：下丘脑-神经垂体病变 ADH 缺乏 / 肾脏对 ADH 不敏感（V2 受体缺陷）
>
> **RAAS（p99-105）**
> - 肾素（颗粒细胞）→ 血管紧张素原（肝）→ 血管紧张素 I → ACE（肺/血浆）→ 血管紧张素 II
> - Ang II 作用：①收缩血管（强缩血管）→ 肾血流量 ↓；②促进近端小管 NaCl 重吸收
> - GFR 影响：低浓度 Ang II → 出球 >> 入球收缩，GFR 变化不大；高浓度 → 入球也明显收缩 + Kf ↓ → GFR ↓
> - **入球小动脉局部反馈**：Ang II → PGI2/NO 释放 → 舒张
> - **醛固酮**：肾上腺皮质球状带 → 集合管/远曲保 Na⁺ 排 K⁺（醛固酮诱导蛋白：增加 Na⁺ 泵、Na⁺ 通道、ATPase）
>
> **肾素释放的调节（p100-101）**
> - 肾内机制：入球动脉血压 ↓ → 牵张感受器 ↓；致密斑 NaCl ↓ → 肾素 ↑
> - 神经机制：肾交感神经 → β 受体（+）
> - 体液机制：E/NE、PGE2/I2（+）；Ang II、ADH、ANP、NO、内皮素（−）
>
> **ANP（p107-108）**
> - 分泌：心房肌受牵拉（血量过多/头低足高/中心静脉压 ↑）；Ach/NE/降钙素基因相关肽/ADH/高血钾亦可促分泌
> - 作用：①舒张入球小动脉 → FF ↑ → GFR ↑；②舒张系膜细胞 → Kf ↑；③抑制集合管 Na⁺ 重吸收；④抑制肾素/醛固酮/ADH 分泌 → 尿量 ↑
>
> **肾清除率（p110-116）**
> - 定义：单位时间（每分）两肾能将一定毫升血浆中所含的某一物质完全清除的血浆毫升数（ml/min）
> - 公式：Cₓ = Uₓ × V / Pₓ
> - **菊粉清除率 = GFR**（自由滤过、不被重吸收/分泌）= 125 ml/min
> - 葡萄糖：C = 0（被全部重吸收）

## Class Notes

### 1. 肾脏功能总览（p2）
- 四大功能：排泄代谢废物、调节水盐平衡、维持酸碱平衡、分泌激素
- 激素：肾素（球旁细胞）、促红素、1,25-(OH)₂-D₃

### 2. 肾单位（p6-12）
- 肾脏基本功能单位；40 岁后每 10 年功能性肾单位 ↓ 10%；每肾 80-100 万
- 组成：肾小体（肾小球 + 肾小囊）+ 肾小管（近端小管 + 髓袢 + 远端小管）
- 分类（p10-12）：
  - 皮质肾单位（85-90%）：外/中皮质层；肾小球体积小；入球口径 > 出球；髓袢短；功能 = 滤过 + 重吸收
  - 近髓肾单位（10-15%）：内皮质层；肾小球体积大；入/出球口径无差异；髓袢长，可深入内髓；形成 U 形直小血管；功能 = 重吸收 + 浓缩稀释

### 3. 球旁器 Juxtaglomerular apparatus（p13-14）
- 位置：远曲小管起始部贴附于入/出球小动脉（"kiss"）
- 三部分：
  - **球旁细胞 / 颗粒细胞**：含分泌颗粒 → 释放肾素
  - **致密斑**：感受小管液 NaCl 浓度
  - **球外系膜细胞**：吞噬/收缩

### 4. 滤过膜 Glomerular filtration membrane（p15-20）
- 三层：毛细血管内皮、基膜、足细胞层；总表面积 1.5 m²
- 窗孔（Fenestrae）= 70-90 nm；基膜孔 = 2-8 nm；足细胞裂孔 = 4-11 nm
- **机械屏障**：r<2 nm 通透；2-4.2 nm 部分通透；>4.2 nm 不通透
- **电屏障**：正电荷易通透，负电荷难通透（基膜含胶原、层黏连蛋白、蛋白多糖，均带负电荷）
- 裂孔素 nephrin
- **球内系膜细胞**：可收缩，调节滤过膜面积和滤过系数

### 5. 肾脏神经支配与血供（p22-27）
- 无副交感神经
- 交感（T12-L2）：节后纤维 → 入/出球小动脉、肾小管、颗粒细胞
- NE → 调节 RBF、GFR、肾小管重吸收、肾素释放
- **血供**：肾动脉 → 叶间动脉 → 弓状动脉 → 小叶间动脉 → 入球小动脉 → 肾小球毛细血管网 → 出球小动脉 → 肾小管周围毛细血管网 + 直小血管 → 小叶间静脉 → …
- **两套串联毛细血管**（p24）
- **RBF 特点**：1200 ml/min；分布不均（皮质 94%、外髓 5%、内髓 1%）

### 6. 肾血流量的调节（p28-33）
- **自身调节**：70-180 mmHg 内 RBF 保持恒定
  - **肌源学说**：血压 ↑ → 血管壁张力 ↑ → 牵张激活阳离子通道（+）→ 平滑肌收缩 → 入球阻力 ↑ → RBF 不变
  - **管-球反馈 TGF**：血压 ↓ → RBF ↓ → GFR ↓ → 致密斑 NaCl ↓ → Adenosine ↓、NO/PG ↑ → 入球阻力 ↓；同时肾素 ↑ → Ang II ↑ → 出球阻力 ↑ → RBF 回升
- **神经体液调节**（p33）：
  - 收缩：交感神经、NE/E、ADH、Ang II、内皮素
  - 舒张：PGE2、PGI2、NO、激肽

### 7. 肾小球滤过（p35-44）
- 超滤液/原尿：血浆经滤过膜进入鲍曼囊的滤液（无细胞，除血浆蛋白外成分接近血浆）
- GFR = 125 ml/min；24h = 180 L；终尿 1.5 L → 99% 重吸收
- FF = GFR/RPF = 0.19（RPF = RBF ×（1-血细胞比容）= 1200 × 0.55 = 660 ml/min）
- **有效滤过压 EFP** = (PGC + π囊) − (π血浆 + P囊)
  - 入球端：45 − (25+10) = 10 mmHg
  - 出球端：45 − (35+10) = 0 mmHg（**滤过平衡**）
  - 关键变量：血浆胶体渗透压沿毛细血管升高
- **影响 GFR 的因素**：GFR = Kf × Pf
  - Kf（滤过系数）：通透系数 k × 滤过面积 s；系膜细胞收缩可调；肾炎 → 蛋白尿、血尿
  - Pf：
    - 毛细血管血压（大失血 → ↓ → 急性肾衰）
    - 囊内压（结石/肿瘤 → ↑）
    - 血浆胶体渗透压（肝硬化低蛋白 → ↓；快速输 NS → ↓）
  - RPF：RPF ↑ → 滤过平衡出现越晚 → GFR ↑

### 8. 肾小管/集合管溶质转运（p46-80）
- **基本概念**：
  - 重吸收 = 小管液 → 血液
  - 分泌 = 血液 → 小管液
  - 肾排泄 = 滤过但未重吸收 + 肾小管分泌
- **转运途径**：
  - 跨细胞（管腔膜 + 基底侧膜）
  - 旁细胞（紧密连接、细胞间隙）
- **转运方式**：被动（单纯/易化扩散）/ 主动（原发 Na⁺-K⁺ 泵；继发 Na⁺ 同向/反向转运）/ 入胞

### 9. Na⁺/Cl⁻/H₂O 在各段的重吸收（p51-64）
| 部位 | NaCl | H₂O | 关键机制 / 药物作用位点 |
|------|------|-----|------------------------|
| 近端小管 | 65-70% | 65-70% | 前半段：Na⁺-H⁺ 交换 + Na⁺-葡萄糖/AA 同向转运；后半段：Na⁺-H⁺ + Cl⁻-HCO3⁻ 交换；旁细胞途径 Cl⁻；等渗性重吸收 |
| 髓袢降支细 | 0 | 通透 | H₂O 出 |
| 髓袢升支细 | 通透 | 0 | Na⁺ 被动易化扩散 |
| 髓袢升支粗 | 20% | 0 | Na⁺-K⁺-2Cl⁻ 同向转运；旁细胞 Na⁺/K⁺/Ca²⁺/Mg²⁺ → **呋塞米（速尿）** |
| 远曲小管 | 12% | 0 | Na⁺-Cl⁻ 同向转运 → **噻嗪类** |
| 集合管 | (Na⁺ 通道) | ADH 调节 | Na⁺ 通道 → **阿米洛利**；负电荷驱使 K⁺ 分泌、Cl⁻ 重吸收 |

### 10. 水通道蛋白 AQP（p60-64）
- AQP1：近端小管 + 髓袢降支细段（顶端 + 基底膜）
- AQP2：集合管主细胞顶端膜（**ADH 诱导**）
- AQP3/4：集合管基底侧膜
- 历史：1988 年发现 CHIP28（28 kDa）；1991 年非洲爪蟾卵母细胞实验证实水通道功能；2003 Nobel Chemistry → Peter Agre

### 11. HCO3⁻ 重吸收与 H⁺ 分泌（p65-67）
- 近端小管重吸收 80% HCO3⁻（**以 CO₂ 形式进行，优先于 Cl⁻**）
- 近端小管是 H⁺ 分泌的主要部位（Na⁺-H⁺ 交换为主）
- 髓袢升支粗段亦重吸收 HCO3⁻
- **A 型闰细胞**：顶端膜 H⁺-ATPase（与 K⁺-ATPase 交换，泵出 H⁺，泵入 K⁺）
- **乙酰唑胺**：碳酸酐酶抑制剂 → 抑制 HCO3⁻ 重吸收与 H⁺ 分泌

### 12. NH3/NH4⁺ 分泌（p68-69）
- 近端小管：谷氨酰胺 → 谷氨酸 → α-酮戊二酸 + NH4⁺；NH4⁺ 经 Na⁺-H⁺（NH4⁺）antiporter 分泌
- 集合管：NH3 高度通透（脂溶性）、NH4⁺ 通透性差
- 肾分泌 H⁺ ≈50% 由 NH3 缓冲
- 氨的分泌也是肾脏调节酸碱平衡的重要机制

### 13. 葡萄糖与 AA 重吸收（p70-73）
- 仅在近端小管（尤其前半段）
- 管腔膜：与 Na⁺ 偶联的继发性主动转运
- 基底侧膜：GLUT2 易化扩散
- **肾糖阈**：180 mg/100ml（尿中刚出现葡萄糖的血糖浓度；**肾单位异质性**，各肾单位肾糖阈不完全相同）
- **葡萄糖 Tm**：血糖 300 mg/100ml 时全部肾小管达极限
- 男 375 mg/min；女 300 mg/min

### 14. Ca²⁺ 重吸收（p74-75）
- 近端小管 70%：旁细胞 80%（溶剂拖曳）+ 跨细胞 20%
- 髓袢升支粗段 20%
- 远曲 + 集合管 9%（跨细胞为主）
- 终尿排出 1%

### 15. 影响肾小管/集合管转运的因素（p76-80）
- **小管液溶质浓度**：渗透压差驱动水重吸收；浓度 ↑ → 渗透性利尿
  - 临床：糖尿病多尿（葡萄糖不能完全重吸收）
  - **甘露醇**：渗透性利尿剂；治疗脑水肿、青光眼，降低颅内压/眼内压
- **球-管平衡**（Glomerulotubular balance）：定比重吸收，近端 Na⁺/H₂O 重吸收率 ≈ GFR 的 65-70%
  - 机制：GFR ↑ → 入管周毛细血管血量 ↓ → 管周血压 ↓ + 血浆胶体渗透压 ↑ → 重吸收 ↑
  - 意义：尿中溶质/水排出不致因 GFR 变化大幅波动

### 16. 尿液浓缩与稀释（p81-82）
- 与血浆渗透压比较而言
- 正常人尿渗透压 50-1200 mOsm/(kg·H₂O)
- **PPT 内容严重不足，需查教科书补充**

### 17. 神经调节（p84-85）
- 肾交感神经：
  - α-R：Afferent 收缩 >> Efferent → GFR ↓；近端小管/髓袢 Na⁺/Cl⁻/H₂O 重吸收 ↑
  - β-R：颗粒细胞 → 肾素 → Ang II ↑ → 醛固酮 ↑ → 尿量 ↓

### 18. 体液调节（p86-109）
- **ADH / AVP（p87-98）**
  - 合成：下丘脑 SON（视上核）+ PVN（室旁核）→ 神经垂体释放
  - 受体：V1 / V2
  - V2 作用：集合管主细胞 AQP2 ↑ → 水通透性 ↑ → 尿量 ↓
  - 调节因素：
    - **血浆晶体渗透压**（最重要；1-2% 变化即起效；NaCl 最有效，尿素/葡萄糖无效；下丘脑前部室周器渗透压感受器）
    - **循环血量**（5-10% 变化；不如渗透压敏感；容量感受器 → 迷走 → ADH）
    - 其他：疼痛、恶心、烟碱、吗啡、Ang II（+）；酒精（−）
  - 水利尿：大量饮水 → ECF 稀释 → ADH ↓ → 尿量 ↑（30 min 起，60 min 达峰）
  - **尿崩症**：下丘脑-神经垂体病变 ADH 缺乏 / V2 受体缺陷
- **RAAS（p99-105）**
  - 路径：肾素（颗粒细胞）→ AT 原（肝）→ AT I → ACE（肺/血浆）→ AT II → AT III
  - 肾素释放调节：①肾内机制（入球 A 血压 ↓、致密斑 NaCl ↓）②神经（交感 β-R）③体液（E/NE、PGE2/I2 +；Ang II、ADH、ANP、NO、内皮素 −）
  - Ang II 作用：①强缩血管 → RBF ↓；②促进近端小管 NaCl 重吸收
  - Ang II 与 GFR：低浓度 → 出球收缩 >> 入球 → GFR 变化不大；高浓度 → 入球也收缩 + Kf ↓ → GFR ↓；入球局部 Ang II → PGI2/NO → 舒张
  - **醛固酮**：肾上腺皮质球状带 → 集合管/远曲保 Na⁺ 排 K⁺（醛固酮诱导蛋白：增加 Na⁺ 泵、Na⁺ 通道、ATPase）
- **ANP（p107-108）**
  - 分泌：心房肌受牵拉（血量过多/头低足高/中心静脉压 ↑）；Ach/NE/CGRP/ADH/高血钾亦可促分泌
  - 作用：①舒张入球 A → FF ↑ → GFR ↑；②舒张系膜细胞 → Kf ↑；③抑制集合管 Na⁺ 重吸收；④抑制肾素/醛固酮/ADH → 尿量 ↑
- **整体调节（p109）**：交感、ADH、RAAS → 尿量 ↓；ANP → 尿量 ↑

### 19. 肾清除率（p110-116）
- **定义**：单位时间（每分）两肾能将一定毫升血浆中所含的某一物质完全清除的血浆毫升数
- 反映每分钟清除的某种物质来自多少 ml 血浆
- 公式：Cₓ = Uₓ × V / Pₓ
- 排泄量 = Uₓ × V = GFR × P − R + S
- **菊粉清除率 = GFR**（自由滤过、不被重吸收/分泌）= 125 ml/min
- 内生肌酐、PAH、对氨基马尿酸、碘锐特见术语表
- 葡萄糖：C = 0（全部重吸收）
- 测定 GFR 物质要求：能自由滤过 + 不被重吸收 + 不被分泌
