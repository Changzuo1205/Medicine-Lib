# Q-CircS2-01 — Phase 0 Ion

## Stem

心室肌动作电位 0 期（快速去极化）主要由哪种离子内流引起？

## Options

- A. Ca²⁺ 经 L 型钙通道内流
- B. Na⁺ 经快钠通道内流
- C. K⁺ 外流
- D. Cl⁻ 内流

## Correct Answer

B

## Explanation

0 期快速去极化由 Na⁺ 经快钠通道内流引起（-90 → +30 mV，1-2 ms，速度 200-400 V/s）。L 型钙通道介导的是慢反应细胞 0 期与快反应细胞 2 期平台期。
