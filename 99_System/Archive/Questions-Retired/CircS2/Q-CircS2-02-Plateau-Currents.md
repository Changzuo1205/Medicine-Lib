# Q-CircS2-02 — Plateau Currents

## Stem

心室肌动作电位 2 期（平台期）膜电位维持在约 0 mV，主要由哪两组电流的动态平衡维持？

## Options

- A. Na⁺ 内流 与 K⁺ 外流
- B. Ca²⁺ 内流（I_Ca-L） 与 K⁺ 外流（I_K、I_K1）
- C. Ca²⁺ 内流 与 Na⁺ 外流
- D. Cl⁻ 内流 与 K⁺ 外流

## Correct Answer

B

## Explanation

平台期（100-150 ms）由 L 型钙通道 Ca²⁺ 内流（I_Ca-L）与钾通道 K⁺ 外流（I_K、I_K1）之间的平衡维持。

## Knowledge Point

心室肌动作电位 2 期平台期的离子平衡
