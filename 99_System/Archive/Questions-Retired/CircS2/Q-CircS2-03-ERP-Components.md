# Q-CircS2-03 — ERP Components

## Stem

心室肌的有效不应期（Effective Refractory Period, ERP）包括哪两个时期？

## Options

- A. 绝对不应期 与 局部反应期
- B. 相对不应期 与 超常期
- C. 绝对不应期 与 相对不应期
- D. 局部反应期 与 相对不应期

## Correct Answer

A

## Explanation

有效不应期（0 至 -60 mV）由绝对不应期（0 至 -55 mV，Na⁺ 通道完全失活）和局部反应期（-55 至 -60 mV，阈上刺激仅引起局部反应）组成。
