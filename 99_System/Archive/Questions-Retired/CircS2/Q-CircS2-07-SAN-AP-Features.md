# Q-CircS2-07 — SAN AP Features

## Stem

窦房结 P 细胞动作电位为什么没有 1 期和 2 期，且 0 期去极化速度和幅度较小？

## Options

（简答题，无选项）

## Correct Answer

窦房结 P 细胞是慢反应细胞：膜上无 I_Na 快钠通道、无 I_to 通道，0 期去极化由 L 型钙通道（I_Ca-L）介导。Ca²⁺ 通道慢激活、慢失活，故 0 期去极化速度慢、幅度小；同时缺乏 I_to（1 期）和明显的平台期电流平衡（2 期），因此无 1 期和 2 期。

## Explanation

慢反应细胞 0 期离子基础（Ca²⁺ 而非 Na⁺）决定了其动作电位形态。

## Knowledge Point

窦房结动作电位的离子基础（快慢反应细胞对比）
