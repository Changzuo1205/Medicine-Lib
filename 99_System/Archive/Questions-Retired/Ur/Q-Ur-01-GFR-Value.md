# Q-Ur-01 — GFR Normal Value

## Stem

正常成人安静时，两肾每分钟生成的超滤液量（肾小球滤过率，GFR）约为多少？

## Options

- A. 25 ml/min
- B. 75 ml/min
- C. 125 ml/min
- D. 250 ml/min

## Correct Answer

C

## Explanation

PPT p37：正常 GFR ≈ 125 ml/min。24h 合计 = 125 × 60 × 24 ≈ **180 L**，但终尿仅 ≈ 1.5 L，提示 99% 以上被肾小管重吸收。

## Knowledge Point

GFR 的定义与正常值。
