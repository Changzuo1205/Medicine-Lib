# Q-Ur-02 — Filtration Fraction Calculation

## Stem

若某受试者 RBF = 1200 ml/min，血细胞比容 45%，GFR = 125 ml/min，则滤过分数（FF）约为多少？

## Options

- A. 0.05
- B. 0.10
- C. 0.19
- D. 0.45

## Correct Answer

C

## Explanation

PPT p38：RPF = RBF × (1 − 血细胞比容) = 1200 × 0.55 = **660 ml/min**；FF = GFR / RPF = 125 / 660 ≈ **0.19**（约 19%）。

## Knowledge Point

滤过分数 FF 的计算与正常值。
