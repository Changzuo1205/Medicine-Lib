# Q-Ur-03 — Effective Filtration Pressure

## Stem

肾小球有效滤过压（EFP）的公式为？

## Options

- A.（肾小球毛细血管血压 + 血浆胶体渗透压）−（囊内液胶体渗透压 + 囊内压）
- B.（肾小球毛细血管血压 + 囊内液胶体渗透压）−（血浆胶体渗透压 + 囊内压）
- C.（血浆胶体渗透压 + 囊内压）−（肾小球毛细血管血压 + 囊内液胶体渗透压）
- D.（肾小球毛细血管血压 + 囊内压）−（血浆胶体渗透压 + 囊内液胶体渗透压）

## Correct Answer

B

## Explanation

PPT p39：**EFP =（肾小球毛细血管血压 + 囊内液胶体渗透压）−（血浆胶体渗透压 + 肾小囊内压）**。
入球端约 45 − (25 + 10) = **10 mmHg**；出球端因血浆胶体渗透压升高至 35 而降至 0，出现**滤过平衡**。

## Knowledge Point

有效滤过压公式；入球端/出球端数值与滤过平衡。
