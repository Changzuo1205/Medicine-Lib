# Q-Ur-05 — Afferent vs Efferent Arteriole

## Stem

关于入球小动脉和出球小动脉阻力变化的下列描述，**最准确**的是？

## Options

- A. 生理浓度的 Ang II 主要收缩入球小动脉 → GFR ↓
- B. 生理浓度的 Ang II 主要收缩出球小动脉 → GFR 变化不大
- C. 交感兴奋对入/出球小动脉作用相同
- D. 管-球反馈（TGF）只影响入球小动脉

## Correct Answer

B

## Explanation

PPT p103：**低浓度 Ang II → 出球收缩 >> 入球收缩 → GFR 变化不大**；高浓度 → 入球也强烈收缩 + Kf ↓ → GFR ↓。PPT p85：交感 α-R → **Afferent 收缩 >> Efferent** → GFR ↓。PPT p32：TGF 通过致密斑感知 NaCl 后同时调节入球（Adenosine/NO/PG）与出球（肾素/Ang II）阻力。

## Knowledge Point

入球/出球小动脉阻力调控的差异及与 TGF、Ang II、交感的关系。
