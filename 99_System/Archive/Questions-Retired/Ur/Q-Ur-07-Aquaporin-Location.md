# Q-Ur-07 — Aquaporin Distribution

## Stem

下列水通道蛋白的分布，正确的是？

## Options

- A. AQP1 在集合管主细胞顶端膜
- B. AQP2 在集合管主细胞基底侧膜
- C. AQP3/AQP4 在集合管主细胞基底侧膜
- D. AQP2 在近端小管和髓袢降支细段

## Correct Answer

C

## Explanation

PPT p60, p64：
- **AQP1**：近端小管 + 髓袢降支细段（顶端 + 基底膜）
- **AQP2**：集合管主细胞**顶端膜（ADH 诱导）**
- **AQP3 / AQP4**：集合管主细胞**基底侧膜**

## Knowledge Point

各 AQP 在肾单位的分布与 ADH 调节靶点（AQP2）。
