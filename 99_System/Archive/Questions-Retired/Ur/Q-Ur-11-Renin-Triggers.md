# Q-Ur-11 — Renin Release Triggers

## Stem

下列哪种情况**促进**肾素释放？

## Options

- A. 入球小动脉血压升高
- B. 致密斑感受到小管液 NaCl 升高
- C. 肾交感神经兴奋
- D. Ang II 浓度升高

## Correct Answer

C

## Explanation

PPT p100-101：
- 入球 A 血压 ↓（↑ 抑制）、致密斑 NaCl ↓（↑ 促进）
- **交感神经 → β-R（+）** → 肾素 ↑
- 体液：E/NE、PGE2/I2（+）；Ang II、ADH、ANP、NO、内皮素（−）

## Knowledge Point

肾素释放的三类调节（肾内机制、神经、体液）。
