# Q-Ur-12 — ANP Mechanism

## Stem

心房钠尿肽（ANP）促进尿钠排泄的主要机制是？

## Options

- A. 收缩入球小动脉 → GFR ↓
- B. 收缩出球小动脉 → FF ↑
- C. 舒张入球小动脉 → GFR ↑；并抑制集合管 Na⁺ 重吸收
- D. 促进醛固酮分泌

## Correct Answer

C

## Explanation

PPT p108：
1. **舒张入球小动脉** → FF ↑ → GFR ↑
2. **舒张球内系膜细胞** → Kf ↑ → GFR ↑
3. **抑制集合管 Na⁺ 重吸收**（抑制 Na⁺ 通道）
4. **抑制** 肾素、醛固酮、ADH 分泌
→ 尿量 ↑

## Knowledge Point

ANP 的综合排钠利尿作用机制。
