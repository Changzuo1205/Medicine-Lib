# Q-Ur-13 — Review Short Answers Set 1 (p117)

## Stem

名词解释与简答题（综合 PPT p117）：

1. 简述肾单位的构成与分类。
2. 简述球旁器的组成及作用。
3. 在正常血压波动和紧急情况下，肾血流量如何进行调节？
4. 分析影响肾小球滤过的因素。

## Reference Answer Outline

### 1. 肾单位的构成与分类
- **构成**：肾小体（肾小球 + 肾小囊）+ 肾小管（近端小管 + 髓袢 + 远端小管）
- **数量**：每肾 80-100 万；40 岁后每十年功能性肾单位 ↓10%
- **分类**：
  - 皮质肾单位（85-90%）：外/中皮质层，髓袢短 → 滤过 + 重吸收
  - 近髓肾单位（10-15%）：内皮质层，髓袢长深入内髓 → 重吸收 + 浓缩稀释

### 2. 球旁器的组成及作用
- **球旁细胞（颗粒细胞）**：释放肾素
- **致密斑**：感受小管液 NaCl（管-球反馈感受器）
- **球外系膜细胞**：吞噬、收缩

### 3. 肾血流量调节
- **自身调节**（70-180 mmHg）：
  - 肌源学说：入球 A 牵张激活阳离子通道 → 平滑肌收缩
  - 管-球反馈：致密斑感知 NaCl → 调入球/出球阻力
- **神经调节**：交感（α-R → 入球收缩 >> 出球 → GFR ↓；β-R → 肾素 ↑）
- **体液调节**：收缩（NE/E、ADH、Ang II、内皮素）；舒张（PGE2、PGI2、NO、激肽）

### 4. 影响 GFR 的因素（PPT p42-44）
GFR = Kf × Pf
- **Kf**：系膜细胞收缩；肾炎 → Kf ↓
- **Pf**：
  - P_GC（生理调节的主要方式；大失血 ↓ → GFR ↓）
  - P_B（结石/肿瘤 ↑ → GFR ↓）
  - π_GC（肝硬化低蛋白/快速输 NS ↓ → GFR ↑）
- **RPF**：RPF ↑ → 滤过平衡推迟 → GFR ↑
