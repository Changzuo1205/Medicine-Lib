# Q-Ur-14 — Review Short Answers Set 2 (p118)

## Stem

名词解释与简答题（综合 PPT p118）：

1. 在近端小管，NaCl 和水重吸收的比例 (%) 与机制。
2. 分析糖尿病病人多尿症状发生的机制。

## Reference Answer Outline

### 1. 近端小管 NaCl 与水重吸收（PPT p51-54）
- **比例**：约 **65-70%** 的 NaCl 和水在近端小管被重吸收
- **机制**：
  - 前半段（≈ 2/3）：
    - 基底侧膜 Na⁺ 泵
    - 顶端膜 Na⁺-H⁺ 交换体；Na⁺-葡萄糖/AA 同向转运体
    - HCO3⁻ 优先重吸收（以 CO₂ 形式进行）
    - Cl⁻ 不被重吸收
  - 后半段（≈ 1/3）：
    - Na⁺-H⁺ + Cl⁻-HCO3⁻ 交换
    - Cl⁻ 顺浓度梯度经旁细胞途径；正电荷驱使部分 Na⁺ 经旁细胞途径
    - H₂O 经 AQP1 + 旁细胞渗透
- **结果**：等渗性重吸收

### 2. 糖尿病多尿机制（PPT p78）
- 血糖 ↑ → 超过肾糖阈（180 mg/100ml）→ 葡萄糖滤过增多 → 近端小管不能完全重吸收 → **小管液中葡萄糖浓度 ↑ → 渗透压 ↑**
- 小管液与上皮细胞间渗透压差减小 → 水重吸收 ↓
- 同时也破坏球-管平衡 → 进一步增加尿量
- → **渗透性利尿** → 多尿

## Knowledge Point

近端小管重吸收与渗透性利尿的整合应用。
