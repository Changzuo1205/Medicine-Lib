# Q-Ur-15 — Review Short Answers Set 3 (p119)

## Stem

简答题（综合 PPT p119）：

1. 分析交感神经兴奋对尿生成的影响。
2. 分析饮用清水、饮用生理盐水后尿量的变化及机制。
3. 当机体大量失血时，机体如何通过调节心血管系统和肾脏功能来代偿？

## Reference Answer Outline

### 1. 交感神经兴奋对尿生成的影响（PPT p84-85）
- **肾血流动力学**：α-R → Afferent 收缩 >> Efferent → GFR ↓
- **肾小管**：促进近端小管 + 髓袢 Na⁺/Cl⁻/H₂O 重吸收 ↑
- **肾素**：β-R → 颗粒细胞释放肾素 ↑ → Ang II ↑ → 醛固酮 ↑ → 远曲/集合管保 Na⁺ 排 K⁺
- **整体效应**：尿量 ↓

### 2. 饮用清水 vs 饮用生理盐水
- **饮用清水**：
  - ECF 渗透压 ↓（清水为低渗）→ ADH 释放 ↓ → 集合管水重吸收 ↓ → **水利尿（尿量 ↑）**
  - 30 min 起效，60 min 达峰（PPT p96）
- **饮用生理盐水**：
  - 等渗 → 不改变血浆渗透压 → ADH 变化不明显
  - 主要扩张血容量 → GFR 短暂 ↑ → 球-管平衡保护 → 尿量仅轻度 ↑
  - 与清水对比：尿量增加程度显著小于清水

### 3. 大量失血的代偿（综合 PPT 多节）
- **即时反应**：动脉血压 ↓ → 压力感受器 → 交感兴奋 → 心率↑、心缩↑、外周阻力↑
- **肾脏反应**：
  - 自身调节失效（<70 mmHg）→ RBF ↓ → GFR ↓
  - 交感兴奋 → 入球 A 收缩 >> 出球 → GFR ↓；近端/髓袢重吸收 ↑；肾素 ↑
  - RAAS 激活 → Ang II 收缩 + 醛固酮保 Na⁺
  - ADH ↑（容量感受器 + Ang II 刺激）
  - 容量保留
- **血液重新分配**：皮肤、内脏血管收缩 → 保证心脑供血
- **血液稀释**：组织液回流（Starling 力变化）补充血容量

## Knowledge Point

整合：交感、ADH、RAAS、心血管反射在尿量调节中的协同。
